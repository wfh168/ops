# Boss直聘沟通话术

## 一、主动打招呼（首次沟通）

### 版本1：简洁直接型

```
您好，我是吴付红，软件工程专业应届生，看到贵公司招聘运维实习生的岗位，我对这个岗位很感兴趣。

我有Linux运维的项目经验，做过微服务项目的容器化部署和ELK日志分析系统，熟悉Docker、Jenkins、Nginx这些技术。

附上我的简历，期待您的回复！
```

### 版本2：突出项目型

```
您好，我叫吴付红，是软件工程专业的应届生。

我看到贵公司在招运维实习生，我觉得自己比较匹配：
- 做过微服务项目的运维部署，用Docker容器化，搭建了Jenkins CI/CD流水线
- 搭建过ELK日志分析系统，对日志收集和问题排查有实践经验
- 熟悉Linux、Shell、Nginx、MySQL、Redis等技术

简历已发送，方便的话可以详细聊聊，谢谢！
```

### 版本3：针对性型（根据JD调整）

```
您好，我是吴付红，看到贵公司招聘运维实习生。

我注意到岗位要求熟悉Docker和CI/CD，这正好是我的强项：
- 独立完成过微服务项目的容器化部署
- 搭建过Jenkins自动化流水线，实现代码自动构建部署
- 配置过Nginx负载均衡和MySQL主从架构

我的学习能力比较强，能快速上手新技术。简历已附上，期待您的回复！
```

## 二、回复HR的常见问题

### 1. HR问：方便介绍一下自己吗？

```
好的。我是软件工程专业应届生，主要学习Linux运维方向。

项目经验方面：
- 做过微服务项目的运维部署，包括Docker容器化、Jenkins自动化、Nginx负载均衡等
- 搭建过ELK日志分析系统，实现日志收集、处理和可视化

技术栈：熟悉Linux、Docker、Jenkins、Nginx、MySQL、Redis，也学习过Ansible和Zabbix

我学习能力比较强，能独立解决问题，希望能有机会加入贵公司学习成长。
```

### 2. HR问：什么时候可以入职？

**如果还在上学：**
```
我目前大四，课程已经结束了，随时可以入职。毕业时间是6月份，到时候办理正式入职手续就可以。
```

**如果已经毕业：**
```
我已经毕业了，随时可以入职，最快明天就可以到岗。
```

### 3. HR问：期望薪资是多少？

**保守型：**
```
我是应届生，主要是想找个平台学习和成长，薪资方面按照公司的标准来就可以。如果一定要说的话，希望能在4-6K左右。
```

**适中型：**
```
我了解到运维实习生的市场行情大概在4-7K，考虑到我有一些项目经验，希望能在5-6K左右。当然具体还是要看公司的薪资体系。
```

**积极型：**
```
我期望薪资在5-7K。虽然我是应届生，但我有完整的项目经验，能独立完成运维部署工作，而且学习能力强，能快速上手。
```

### 4. HR问：为什么离开上一家公司？（如果有实习经历）

```
上一家公司主要是实习，现在想找一个正式的工作机会。而且我觉得贵公司的技术栈更先进，平台更大，更适合我的职业发展。
```

### 5. HR问：能接受加班吗？

```
可以接受合理的加班。如果是项目上线、紧急故障这些情况需要加班，我完全能理解和配合。我觉得作为运维人员，保障系统稳定运行是我们的职责。
```

### 6. HR问：有什么要问我的吗？

```
我想了解一下：
1. 这个岗位主要负责哪些工作？
2. 团队目前的技术栈是什么？
3. 对新人有培训计划吗？
4. 如果合适的话，面试流程是怎样的？
```

## 三、跟进话术

### 1. 发完简历3天没回复

```
您好，我是吴付红，之前给您发过简历应聘运维实习生岗位。想跟进一下，不知道您这边看过了吗？如果有任何问题，我可以详细说明。期待您的回复！
```

### 2. 面试后跟进

```
您好，我是今天下午面试的吴付红。感谢您抽时间面试我，通过今天的交流，我对贵公司和这个岗位有了更深的了解，也更加确定这是我想要的工作。

如果有任何需要补充的信息，请随时联系我。期待您的好消息！
```

### 3. 收到offer后

```
您好，非常感谢贵公司给我这个机会！我已经收到offer了，确认接受。请问接下来需要我准备什么材料吗？入职当天需要注意什么？
```

## 四、应对不同场景

### 场景1：HR说"你经验不足"

```
我理解您的顾虑。虽然我是应届生，但我有完整的项目经验，而且学习能力比较强。

我做项目的时候遇到过很多问题，都是自己查文档、看日志解决的。我相信只要给我机会，我能快速上手，为团队做出贡献。

而且应届生的优势是学习热情高，可塑性强，能更好地融入团队文化。
```

### 场景2：HR说"薪资超出预算"

```
我理解。薪资方面我可以适当调整，主要还是看重这个平台和学习机会。

您看这样可以吗：试用期可以按照公司标准来，如果我的表现达到预期，转正后再调整到合理水平？
```

### 场景3：HR说"我们再考虑考虑"

```
好的，我理解。如果有任何疑问或者需要补充的信息，请随时联系我。

我对这个岗位很感兴趣，也相信自己能胜任。期待您的好消息！
```

### 场景4：HR问"还在面试其他公司吗"

**诚实型：**
```
是的，我也在看其他机会。但贵公司是我最想去的，因为[说出具体原因：技术栈、团队、发展空间等]。如果贵公司给我offer，我会优先考虑。
```

**策略型：**
```
我确实在看几家公司，但都还在初步沟通阶段。贵公司是我比较看重的，如果合适的话，我希望能尽快确定下来。
```

## 五、注意事项

### 1. 沟通原则
- **及时回复**：看到消息尽快回复，最好在1小时内
- **礼貌用语**：多用"您好"、"谢谢"、"麻烦您"
- **简洁明了**：不要长篇大论，突出重点
- **真诚态度**：不卑不亢，展现自信

### 2. 避免的错误
- ❌ 群发同样的话术（要针对性调整）
- ❌ 回复太慢（超过半天）
- ❌ 用语太随意（"嗯"、"哦"、"好的呀"）
- ❌ 过度谦虚（"我什么都不会"）
- ❌ 过度自信（"我肯定能做好"）

### 3. 加分项
- ✅ 提前了解公司业务
- ✅ 针对JD调整话术
- ✅ 主动询问面试时间
- ✅ 面试后及时跟进
- ✅ 展现学习热情

## 七、话术优化技巧

### 1. 根据公司规模调整

**大公司/知名企业：**
- 强调学习能力和规范性
- 提到对公司的了解和认可
- 展现长期发展意愿

**小公司/创业公司：**
- 强调动手能力和独立性
- 表示能接受多样化工作
- 展现快速适应能力

### 2. 根据岗位要求调整

**偏重开发的运维岗：**
- 突出编程能力（Shell、Python）
- 强调自动化经验
- 提到CI/CD实践

**偏重运维的岗位：**
- 突出系统管理经验
- 强调故障排查能力
- 提到监控和优化经验

### 3. 根据对话进展调整

**初次沟通：**
- 简洁介绍，突出亮点
- 表达兴趣，请求机会

**深入交流：**
- 详细说明项目经验
- 展示技术深度
- 询问具体工作内容

**临近offer：**
- 表达强烈意愿
- 确认入职细节
- 展现职业规划

---

记住：真诚、自信、专业是最好的话术！
