# Docker 容器技术学习指南

欢迎学习 Docker 容器技术！本模块将系统学习 Docker 从基础到高级的全部内容。

---

## 📚 学习目标

完成本模块后，你将能够：

✅ 理解容器技术原理  
✅ 掌握 Docker 基础操作  
✅ 编写 Dockerfile  
✅ 使用 Docker Compose  
✅ 搭建 Docker 私有仓库  
✅ 实现容器网络和存储  
✅ 掌握容器监控和日志  
✅ 部署企业级应用

**难度**：⭐⭐⭐

## 🎯 学习路线

```
第1-3天：Docker 基础
  ├─ Docker 安装
  ├─ 镜像和容器
  ├─ 基础命令
  └─ 容器管理

第4-7天：镜像和容器深入
  ├─ Dockerfile 编写
  ├─ 镜像构建
  ├─ 容器操作
  └─ 资源限制

第8-10天：网络和存储
  ├─ Docker 网络
  ├─ 数据卷
  ├─ 数据持久化
  └─ 网络互联

第11-14天：编排和仓库
  ├─ Docker Compose
  ├─ 多容器编排
  ├─ 私有仓库
  └─ Harbor 使用

第15-20天：实战应用
  ├─ Web 应用部署
  ├─ 微服务架构
  ├─ 监控和日志
  └─ 生产实践
```
