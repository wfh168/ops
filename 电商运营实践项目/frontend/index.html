系统说明

本系统基于 Spring Boot + MyBatis Plus + MySQL 后端，Vue + ECharts 前端开发。
实现了电商运营的核心数据分析功能：产品销售分析、销售趋势分析、库存预警管理。
数据来源于模拟的亚马逊蓝牙耳机销售数据，包含最近7天的销售记录。
