## 详细使用教程

### 场景1：每日运营巡检

**目标**: 快速了解昨天的销售情况和今天需要关注的问题

**步骤**:
1. 运行销售分析查询
```sql
-- 查看昨日销售数据
SELECT * FROM daily_metrics 
WHERE metric_date = CURDATE() - INTERVAL 1 DAY;
```

2. 检查库存预警
```sql
-- 查看需要补货的产品
SELECT sku, product_name, current_stock, safe_stock
FROM products
WHERE current_stock < safe_stock
ORDER BY (safe_stock - current_stock) DESC;
```

3. 查看销售排行
```sql
-- 查看昨日销售TOP5
SELECT p.product_name, SUM(s.quantity) AS sales, SUM(s.revenue) AS revenue
FROM products p
JOIN sales s ON p.product_id = s.product_id
WHERE s.sale_date = CURDATE() - INTERVAL 1 DAY
GROUP BY p.product_id
ORDER BY revenue DESC
LIMIT 5;
```

**预计时间**: 5分钟

## 常用SQL查询速查表

### 1. 查看今日销售
```sql
SELECT SUM(revenue) AS today_revenue, SUM(order_count) AS today_orders
FROM sales
WHERE sale_date = CURDATE();
```

### 2. 查看库存预警
```sql
SELECT sku, product_name, current_stock, safe_stock
FROM products
WHERE current_stock < safe_stock;
```

### 3. 查看TOP5产品
```sql
SELECT p.product_name, SUM(s.revenue) AS revenue
FROM products p
JOIN sales s ON p.product_id = s.product_id
WHERE s.sale_date >= DATE_SUB(CURDATE(), INTERVAL 7 DAY)
GROUP BY p.product_id
ORDER BY revenue DESC
LIMIT 5;
```

### 4. 查看转化率
```sql
SELECT 
    product_name,
    SUM(views) AS views,
    SUM(order_count) AS orders,
    ROUND(SUM(order_count) / SUM(views) * 100, 2) AS conversion_rate
FROM products p
JOIN sales s ON p.product_id = s.product_id
WHERE s.sale_date >= DATE_SUB(CURDATE(), INTERVAL 7 DAY)
GROUP BY p.product_id
ORDER BY conversion_rate DESC;
```

### 5. 查看利润
```sql
SELECT 
    p.product_name,
    SUM(s.revenue) AS revenue,
    SUM(s.quantity * p.cost) AS cost,
    SUM(s.revenue) - SUM(s.quantity * p.cost) AS profit
FROM products p
JOIN sales s ON p.product_id = s.product_id
WHERE s.sale_date >= DATE_SUB(CURDATE(), INTERVAL 7 DAY)
GROUP BY p.product_id
ORDER BY profit DESC;
```

## 进阶：自动化报表

### 使用 Shell 脚本自动生成报表

创建 `generate_report.sh`:
```bash
#!/bin/bash

DATE=$(date +%Y-%m-%d)
REPORT_DIR="reports/daily"
mkdir -p $REPORT_DIR

echo "生成 $DATE 运营报表..."

# 1. 产品分析
mysql -u root -p123456 ecommerce_analysis < sql-queries/01_产品分析.sql > $REPORT_DIR/产品分析_$DATE.txt

# 2. 销售分析
mysql -u root -p123456 ecommerce_analysis < sql-queries/02_销售分析.sql > $REPORT_DIR/销售分析_$DATE.txt

# 3. 库存分析
mysql -u root -p123456 ecommerce_analysis < sql-queries/03_库存分析.sql > $REPORT_DIR/库存分析_$DATE.txt

# 4. 竞品分析
mysql -u root -p123456 ecommerce_analysis < sql-queries/04_竞品分析.sql > $REPORT_DIR/竞品分析_$DATE.txt

echo "报表生成完成！保存在 $REPORT_DIR/"
```

### 设置定时任务（每天早上9点自动生成）

```bash
# 编辑 crontab
crontab -e

# 添加定时任务
0 9 * * * /path/to/generate_report.sh
```

## 常见问题

### Q1: 如何修改数据？
A: 直接修改数据库：
```sql
-- 修改产品价格
UPDATE products SET price = 399 WHERE sku = 'BT-EAR-001';

-- 添加销售记录
INSERT INTO sales (product_id, sale_date, quantity, revenue, order_count, views)
VALUES (1, CURDATE(), 20, 5980, 20, 600);
```

### Q2: 如何添加新产品？
A: 
```sql
INSERT INTO products (sku, product_name, category, price, cost, current_stock, safe_stock, status)
VALUES ('BT-EAR-006', '新款蓝牙耳机', '电子产品', 599.00, 300.00, 100, 50, '在售');
```

### Q3: 如何清空数据重新开始？
A:
```sql
-- 清空所有数据
TRUNCATE TABLE sales;
TRUNCATE TABLE inventory_logs;
TRUNCATE TABLE competitors;
TRUNCATE TABLE daily_metrics;
TRUNCATE TABLE products;

-- 重新导入示例数据
source database/sample_data.sql;
```

### Q4: 如何导出数据到Excel？
A:
```bash
# 导出为CSV格式
mysql -u root -p -e "SELECT * FROM products" ecommerce_analysis > products.csv

# 或者在MySQL中
SELECT * FROM products
INTO OUTFILE '/tmp/products.csv'
FIELDS TERMINATED BY ','
ENCLOSED BY '"'
LINES TERMINATED BY '\n';
```
