# 电商数据分析系统 - 启动指南

## 项目简介

这是一个完整的电商数据分析系统，包含：
- **后端**: Spring Boot + MyBatis Plus + MySQL
- **前端**: Vue + ECharts
- **功能**: 产品分析、销售趋势、库存预警

## 快速启动（3步）

### 第1步：创建数据库（1分钟）

```bash
# 进入项目目录
cd 电商运营实践项目

# 创建数据库和导入数据
mysql -u root -p < database/schema.sql
mysql -u root -p ecommerce_analysis < database/sample_data.sql
```

### 第2步：启动后端（1分钟）

```bash
# 进入后端目录
cd backend

# 修改数据库密码（如果需要）
# 编辑 src/main/resources/application.yml
# 修改 password: 123456 为你的MySQL密码

# 使用Maven启动
mvn spring-boot:run

# 或者使用IDE（IDEA/Eclipse）
# 直接运行 EcommerceAnalysisApplication.java
```

看到以下输出表示启动成功：
```
========================================
电商数据分析系统启动成功！
访问地址: http://localhost:8080
========================================
```

### 第3步：打开前端页面（10秒）

```bash
# 直接用浏览器打开
frontend/index.html

# 或者在浏览器地址栏输入文件路径
file:///你的路径/电商运营实践项目/frontend/index.html
```

## 技术栈详解

### 后端技术
- **Spring Boot 2.7.18**: 快速开发框架
- **MyBatis Plus 3.5.3**: ORM框架，简化数据库操作
- **MySQL 8.0**: 关系型数据库
- **Lombok**: 简化Java代码
- **Hutool**: Java工具类库

### 前端技术
- **Vue 2.6**: 渐进式JavaScript框架
- **Axios**: HTTP客户端
- **ECharts 5.4**: 数据可视化图表库

## 常见问题

### Q1: 后端启动失败，提示数据库连接错误？
A: 检查以下几点：
1. MySQL是否已启动
2. 数据库密码是否正确（修改 application.yml）
3. 数据库 ecommerce_analysis 是否已创建

### Q2: 前端页面显示"加载数据失败"？
A: 确保后端已启动，访问 http://localhost:8080/api/analysis/health 检查后端是否正常

### Q3: 如何修改端口？
A: 修改 backend/src/main/resources/application.yml 中的 server.port

### Q4: 如何添加新的数据？
A: 
```sql
-- 添加销售记录
INSERT INTO sales (product_id, sale_date, quantity, revenue, order_count, views)
VALUES (1, CURDATE(), 20, 5980, 20, 600);
```

### Q5: 如何部署到服务器？
A:
```bash
# 1. 打包后端
cd backend
mvn clean package

# 2. 运行jar包
java -jar target/ecommerce-analysis-1.0.0.jar

# 3. 前端部署到Nginx或直接访问
```
