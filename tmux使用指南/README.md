## 🔍 你的配置问题分析

### ❌ 存在的问题

1. **注释格式错误**
   ```bash
   # 错误：##### 基础设置 ######
   # 正确：##### 基础设置 #####
   ```
   tmux 配置中注释应该是 `#` 开头，但你的 `######` 可能导致解析问题

2. **状态栏转义字符问题**
   ```bash
   # 你的写法（可能显示异常）
   set -g status-right "\#[fg=#fab387]│ CPU..."
   
   # 应该改为
   set -g status-right "#[fg=#fab387]│ CPU..."
   ```

3. **缺少插件安装说明**
   - 需要先安装 TPM（Tmux Plugin Manager）
   - 插件需要手动安装才能生效

4. **CPU 插件配置位置**
   - CPU 显示配置应该在插件定义之前

## 🚀 快速开始

### 1. 安装 TPM（插件管理器）

```bash
# 克隆 TPM 到本地
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

### 2. 使用优化后的配置

```bash
# 备份原配置
cp ~/.tmux.conf ~/.tmux.conf.backup

# 使用优化配置
cp tmux使用指南/.tmux.conf ~/.tmux.conf

# 重新加载配置
tmux source ~/.tmux.conf
```

### 3. 安装插件

在 tmux 中按：`Ctrl+a` + `I`（大写 I）

等待插件安装完成。

## 📖 基础使用

### 前缀键

所有命令都需要先按 `Ctrl+a`（前缀键），然后再按功能键。

### 窗口管理

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+a` `c` | 创建新窗口 |
| `Ctrl+a` `n` | 下一个窗口 |
| `Ctrl+a` `p` | 上一个窗口 |
| `Ctrl+a` `0-9` | 切换到指定窗口 |
| `Ctrl+a` `X` | 关闭当前窗口 |

### 窗格（Pane）管理

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+a` `\|` | 垂直分割 |
| `Ctrl+a` `-` | 水平分割 |
| `Ctrl+a` `h/j/k/l` | Vim 风格切换窗格 |
| `Alt+h/j/k/l` | 调整窗格大小 |
| `Ctrl+a` `x` | 关闭当前窗格 |

### 会话管理

```bash
# 创建会话
tmux new -s 会话名

# 列出会话
tmux ls

# 附加到会话
tmux attach -t 会话名

# 分离会话
Ctrl+a d

# 杀死会话
tmux kill-session -t 会话名
```

## 🎨 状态栏说明

### 智能状态栏 ⭐ 新功能

状态栏会自动检测当前窗格类型，显示相应的系统信息：

#### 本地窗格
```
[Session名]  │  LOCAL | CPU 3.4% | MEM 17Gi/30Gi | / 27G/64G | HOME 55G/257G  │  2026-02-09 20:30
```

#### SSH 窗格
```
[Session名]  │  @ root@wfh1688:22 (10.0.0.139) | CPU 5.2% | MEM 2.1G/4G | / 15G/50G  │  2026-02-09 20:30
```

**特性**：
- ✅ 自动识别本地/远程窗格
- ✅ 实时显示系统资源（CPU、内存、磁盘）
- ✅ 支持 `ssh user@ip` 和 `~/.ssh/config` 别名
- ✅ 非标准端口黄色高亮
- ✅ Git 分支自动显示

详见：[智能状态栏说明.md](./智能状态栏说明.md)

## 🔧 常见问题

### 1. 颜色显示不正常

```bash
# 检查终端支持
echo $TERM

# 应该显示 tmux-256color 或 xterm-256color
```

### 2. 插件不生效

```bash
# 重新安装插件
Ctrl+a I

# 更新插件
Ctrl+a U
```

### 3. 鼠标滚动不工作

确保配置中有：
```bash
set -g mouse on
```

### 4. 会话没有自动恢复

首次使用需要手动保存：
```bash
Ctrl+a Ctrl+s  # 保存会话
Ctrl+a Ctrl+r  # 恢复会话
```
