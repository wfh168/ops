## 🎯 会话管理高级技巧

### 1. 嵌套会话

在远程服务器上使用 tmux 时，可以嵌套使用：

```bash
# 本地 tmux（前缀键：Ctrl+a）
tmux

# SSH 到远程服务器
ssh user@server

# 远程 tmux（前缀键：Ctrl+b，避免冲突）
tmux -f ~/.tmux-remote.conf
```

**远程配置文件** `~/.tmux-remote.conf`：
```bash
# 使用不同的前缀键
set -g prefix C-b
unbind C-a

# 不同的状态栏颜色（区分本地和远程）
set -g status-style "bg=#ff0000,fg=#ffffff"
```

**快速切换：**
```bash
# 发送命令到内层 tmux
Ctrl+a Ctrl+a    # 发送 Ctrl+a 到内层
```

### 2. 会话组（Session Groups）

多个会话共享同一组窗口：

```bash
# 创建主会话
tmux new -s main

# 创建共享会话（共享 main 的窗口）
tmux new -s shared -t main

# 现在两个会话看到相同的窗口
# 但可以独立切换到不同窗口
```

**用途：**
- 多个终端查看同一工作环境
- 不同窗口大小的客户端
- 演示和观察

### 3. 会话快照和克隆

```bash
# 保存会话布局到文件
tmux list-windows -t session_name > session_layout.txt

# 克隆会话
tmux new -s clone -t original

# 重命名会话
tmux rename-session -t old_name new_name
```

### 4. 会话模板脚本

创建 `~/tmux-templates/dev.sh`：

```bash
#!/bin/bash
SESSION="dev"

# 检查会话是否存在
tmux has-session -t $SESSION 2>/dev/null

if [ $? != 0 ]; then
    # 创建会话和第一个窗口
    tmux new-session -d -s $SESSION -n editor
    tmux send-keys -t $SESSION:editor "cd ~/project && nvim" C-m
    
    # 创建第二个窗口（服务器）
    tmux new-window -t $SESSION -n server
    tmux send-keys -t $SESSION:server "cd ~/project && npm run dev" C-m
    
    # 创建第三个窗口（日志）
    tmux new-window -t $SESSION -n logs
    tmux send-keys -t $SESSION:logs "cd ~/project && tail -f logs/app.log" C-m
    
    # 分割日志窗口
    tmux split-window -t $SESSION:logs -h
    tmux send-keys -t $SESSION:logs.1 "htop" C-m
    
    # 选择第一个窗口
    tmux select-window -t $SESSION:editor
fi

# 附加到会话
tmux attach -t $SESSION
```

使用：
```bash
chmod +x ~/tmux-templates/dev.sh
~/tmux-templates/dev.sh
```

## 🔲 窗格操作进阶

### 1. 窗格同步（批量操作）

在所有窗格执行相同命令：

```bash
# 开启同步
Ctrl+a :setw synchronize-panes on

# 现在输入的命令会在所有窗格执行
# 适合批量操作多台服务器

# 关闭同步
Ctrl+a :setw synchronize-panes off
```

**快捷键绑定：**
```bash
# 在 ~/.tmux.conf 中添加
bind S setw synchronize-panes
```

### 2. 窗格缩放和布局

```bash
# 最大化/还原当前窗格
Ctrl+a z

# 循环切换预设布局
Ctrl+a Space

# 手动设置布局
Ctrl+a :select-layout even-horizontal    # 水平平均
Ctrl+a :select-layout even-vertical      # 垂直平均
Ctrl+a :select-layout main-horizontal    # 主窗格在上
Ctrl+a :select-layout main-vertical      # 主窗格在左
Ctrl+a :select-layout tiled              # 平铺

# 保存当前布局
Ctrl+a :select-layout
# 会显示布局字符串，可以保存下来
```

### 3. 窗格标记和交换

```bash
# 标记窗格
Ctrl+a m

# 交换当前窗格和标记的窗格
Ctrl+a :swap-pane

# 取消标记
Ctrl+a M
```

### 4. 窗格管道（Pipe Pane）

将窗格输出保存到文件：

```bash
# 开始记录
Ctrl+a :pipe-pane -o 'cat >> ~/output.log'

# 停止记录
Ctrl+a :pipe-pane
```

**实用场景：**
```bash
# 记录服务器日志
Ctrl+a :pipe-pane -o 'cat >> ~/server-$(date +%Y%m%d).log'

# 记录所有命令输出
Ctrl+a :pipe-pane -o 'cat >> ~/session-history.txt'
```

### 5. 窗格命令执行

```bash
# 在指定窗格执行命令
tmux send-keys -t session:window.pane "ls -la" C-m

# 在所有窗格执行
for pane in $(tmux list-panes -F '#{pane_id}'); do
    tmux send-keys -t $pane "echo Hello" C-m
done
```

## 🤖 脚本化和自动化

### 1. Tmuxinator（项目管理工具）

安装：
```bash
gem install tmuxinator
```

创建项目配置 `~/.tmuxinator/myproject.yml`：

```yaml
name: myproject
root: ~/projects/myproject

windows:
  - editor:
      layout: main-vertical
      panes:
        - nvim
        - guard
  - server:
      panes:
        - npm run dev
  - logs:
      layout: even-horizontal
      panes:
        - tail -f log/development.log
        - htop
```

使用：
```bash
# 启动项目
tmuxinator start myproject

# 或简写
mux start myproject

# 列出所有项目
mux list

# 编辑项目
mux edit myproject
```

### 2. 自定义启动脚本

创建 `~/bin/tmux-work`：

```bash
#!/bin/bash

SESSION="work"
WORK_DIR="$HOME/projects"

# 如果会话已存在，直接附加
if tmux has-session -t $SESSION 2>/dev/null; then
    tmux attach -t $SESSION
    exit 0
fi

# 创建新会话
tmux new-session -d -s $SESSION -c $WORK_DIR

# 窗口 1: 编辑器
tmux rename-window -t $SESSION:1 'editor'
tmux send-keys -t $SESSION:1 "nvim" C-m

# 窗口 2: 服务器（3个窗格）
tmux new-window -t $SESSION:2 -n 'servers' -c $WORK_DIR
tmux split-window -t $SESSION:2 -h -c $WORK_DIR
tmux split-window -t $SESSION:2 -v -c $WORK_DIR
tmux send-keys -t $SESSION:2.0 "npm run dev" C-m
tmux send-keys -t $SESSION:2.1 "python manage.py runserver" C-m
tmux send-keys -t $SESSION:2.2 "redis-server" C-m

# 窗口 3: 数据库
tmux new-window -t $SESSION:3 -n 'database' -c $WORK_DIR
tmux send-keys -t $SESSION:3 "mysql -u root -p" C-m

# 窗口 4: 监控
tmux new-window -t $SESSION:4 -n 'monitor' -c $WORK_DIR
tmux split-window -t $SESSION:4 -h
tmux send-keys -t $SESSION:4.0 "htop" C-m
tmux send-keys -t $SESSION:4.1 "watch -n 1 'df -h'" C-m

# 窗口 5: 日志
tmux new-window -t $SESSION:5 -n 'logs' -c $WORK_DIR
tmux send-keys -t $SESSION:5 "tail -f logs/*.log" C-m

# 选择第一个窗口
tmux select-window -t $SESSION:1

# 附加到会话
tmux attach -t $SESSION
```

使用：
```bash
chmod +x ~/bin/tmux-work
~/bin/tmux-work
```

### 3. 批量服务器管理

创建 `~/bin/tmux-servers`：

```bash
#!/bin/bash

SESSION="servers"
SERVERS=(
    "web1.example.com"
    "web2.example.com"
    "db1.example.com"
    "cache1.example.com"
)

# 创建会话
tmux new-session -d -s $SESSION

# 为每台服务器创建窗口
for i in "${!SERVERS[@]}"; do
    server="${SERVERS[$i]}"
    
    if [ $i -eq 0 ]; then
        tmux rename-window -t $SESSION:1 "$server"
        tmux send-keys -t $SESSION:1 "ssh $server" C-m
    else
        tmux new-window -t $SESSION -n "$server"
        tmux send-keys -t $SESSION "ssh $server" C-m
    fi
done

# 创建监控窗口（分割为多个窗格）
tmux new-window -t $SESSION -n "monitor"
tmux send-keys -t $SESSION:monitor "watch -n 1 'uptime'" C-m

for i in {1..3}; do
    tmux split-window -t $SESSION:monitor
    tmux select-layout -t $SESSION:monitor tiled
done

# 附加到会话
tmux select-window -t $SESSION:1
tmux attach -t $SESSION
```

## 👥 多人协作

### 1. 共享会话（结对编程）

```bash
# 用户 A 创建会话
tmux new -s pair

# 用户 B 附加到同一会话（只读）
tmux attach -t pair -r

# 用户 B 附加到同一会话（可写）
tmux attach -t pair
```

### 2. 使用 Socket 共享

```bash
# 创建共享 socket
tmux -S /tmp/pair new -s shared
chmod 777 /tmp/pair

# 其他用户附加
tmux -S /tmp/pair attach -t shared
```

### 3. Tmate（远程协作）

安装：
```bash
# Ubuntu/Debian
sudo apt install tmate

# macOS
brew install tmate
```

使用：
```bash
# 启动 tmate
tmate

# 会显示 SSH 连接信息
# 分享给协作者即可远程连接
```

## ⚡ 性能优化

### 1. 减少状态栏刷新

```bash
# 降低刷新频率
set -g status-interval 5    # 从 2 秒改为 5 秒

# 简化状态栏内容
set -g status-right "#[fg=#89b4fa]%H:%M"
```

### 2. 限制历史记录

```bash
# 减少历史行数
set -g history-limit 5000    # 从 10000 改为 5000
```

### 3. 禁用不需要的功能

```bash
# 禁用活动监控
setw -g monitor-activity off
set -g visual-activity off

# 禁用铃声
set -g visual-bell off
set -g bell-action none
```

### 4. 使用更快的终端

```bash
# 使用 tmux-256color
set -g default-terminal "tmux-256color"

# 启用快速滚动
set -g @scroll-speed-num-lines-per-scroll 3
```

## 🔗 与其他工具集成

### 1. 与 Vim/Neovim 集成

安装插件 `christoomey/vim-tmux-navigator`：

```vim
" 在 ~/.vimrc 或 ~/.config/nvim/init.vim 中
Plug 'christoomey/vim-tmux-navigator'
```

在 `~/.tmux.conf` 中：

```bash
# 智能窗格切换（Vim 和 Tmux 无缝切换）
is_vim="ps -o state= -o comm= -t '#{pane_tty}' | grep -iqE '^[^TXZ ]+ +(\\S+\\/)?g?(view|n?vim?x?)(diff)?$'"

bind -n C-h if-shell "$is_vim" "send-keys C-h"  "select-pane -L"
bind -n C-j if-shell "$is_vim" "send-keys C-j"  "select-pane -D"
bind -n C-k if-shell "$is_vim" "send-keys C-k"  "select-pane -U"
bind -n C-l if-shell "$is_vim" "send-keys C-l"  "select-pane -R"
```

### 2. 与 FZF 集成

```bash
# 在 ~/.tmux.conf 中添加
bind f run-shell "tmux neww ~/.tmux/scripts/tmux-sessionizer"
```

创建 `~/.tmux/scripts/tmux-sessionizer`：

```bash
#!/bin/bash

selected=$(find ~/projects -mindepth 1 -maxdepth 1 -type d | fzf)

if [[ -z $selected ]]; then
    exit 0
fi

selected_name=$(basename "$selected" | tr . _)

if ! tmux has-session -t=$selected_name 2> /dev/null; then
    tmux new-session -ds $selected_name -c $selected
fi

tmux switch-client -t $selected_name
```

### 3. 与 Git 集成

在状态栏显示 Git 分支：

```bash
# 在 ~/.tmux.conf 中
set -g status-right "#[fg=#a6e3a1]#(cd #{pane_current_path}; git rev-parse --abbrev-ref HEAD 2>/dev/null) #[fg=#89b4fa]%H:%M"
```

### 4. 与 Docker 集成

快速进入 Docker 容器：

```bash
# 在 ~/.tmux.conf 中
bind D run-shell "tmux neww ~/.tmux/scripts/docker-attach"
```

创建 `~/.tmux/scripts/docker-attach`：

```bash
#!/bin/bash

container=$(docker ps --format "{{.Names}}" | fzf)

if [[ -z $container ]]; then
    exit 0
fi

tmux new-window -n "docker:$container" "docker exec -it $container /bin/bash"
```

## ⌨️ 自定义快捷键

### 1. 快速窗口跳转

```bash
# 在 ~/.tmux.conf 中
bind -n M-1 select-window -t 1
bind -n M-2 select-window -t 2
bind -n M-3 select-window -t 3
bind -n M-4 select-window -t 4
bind -n M-5 select-window -t 5
```

### 2. 快速会话切换

```bash
bind -n M-s choose-session
bind -n M-w choose-window
```

### 3. 快速分割窗格

```bash
# 在当前目录分割
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"

# 在 HOME 目录分割
bind '\' split-window -h -c "~"
bind '_' split-window -v -c "~"
```

### 4. 快速执行命令

```bash
# 快速打开 htop
bind H new-window -n htop "htop"

# 快速打开 Python
bind P new-window -n python "python3"

# 快速打开 MySQL
bind M new-window -n mysql "mysql -u root -p"
```

### 5. 自定义命令提示符

```bash
# 快速命令输入
bind : command-prompt
bind / command-prompt "find-window '%%'"
```

## 🎨 高级配置技巧

### 1. 条件配置

```bash
# 根据 tmux 版本加载不同配置
if-shell "test $(tmux -V | cut -d' ' -f2 | tr -d '[:alpha:]') -ge 3.2" \
    "set -g mouse on" \
    "set -g mode-mouse on"

# 根据操作系统加载不同配置
if-shell "uname | grep -q Darwin" \
    "source-file ~/.tmux-macos.conf" \
    "source-file ~/.tmux-linux.conf"
```

### 2. 动态状态栏

```bash
# 显示 CPU 温度
set -g status-right "#[fg=#f38ba8]#(sensors | grep 'Core 0' | awk '{print $3}') "

# 显示网络速度
set -g status-right "#[fg=#89b4fa]↓#(ifstat -i eth0 1 1 | tail -n 1 | awk '{print $1}')KB/s "

# 显示电池状态
set -g status-right "#[fg=#a6e3a1]🔋#(acpi | awk '{print $4}' | tr -d ',') "
```

### 3. 窗口活动监控

```bash
# 监控窗口活动
setw -g monitor-activity on
set -g visual-activity on

# 监控窗口静默
setw -g monitor-silence 30    # 30 秒无输出时提醒

# 自定义活动消息
set -g activity-action other
set -g message-style "bg=#f38ba8,fg=#1e1e2e"
```

### 4. 自动重命名窗口

```bash
# 根据当前程序自动重命名
setw -g automatic-rename on
setw -g automatic-rename-format '#{b:pane_current_path}'

# 或禁用自动重命名
setw -g automatic-rename off
setw -g allow-rename off
```

### 5. 钩子（Hooks）

```bash
# 创建窗口时自动执行
set-hook -g after-new-window 'run-shell "echo New window created"'

# 分割窗格时自动执行
set-hook -g after-split-window 'select-layout tiled'

# 附加会话时自动执行
set-hook -g client-attached 'display-message "Welcome back!"'

# 窗口重命名时自动执行
set-hook -g after-rename-window 'refresh-client -S'
```

## 🎓 实战案例

### 案例 1：开发环境自动化

```bash
#!/bin/bash
# ~/bin/dev-env

PROJECT=$1
SESSION="dev-${PROJECT}"

if [ -z "$PROJECT" ]; then
    echo "Usage: dev-env <project-name>"
    exit 1
fi

PROJECT_DIR="$HOME/projects/$PROJECT"

if [ ! -d "$PROJECT_DIR" ]; then
    echo "Project directory not found: $PROJECT_DIR"
    exit 1
fi

# 创建会话
tmux new-session -d -s $SESSION -c $PROJECT_DIR

# 编辑器窗口
tmux rename-window -t $SESSION:1 'editor'
tmux send-keys -t $SESSION:1 "nvim" C-m

# Git 窗口
tmux new-window -t $SESSION:2 -n 'git' -c $PROJECT_DIR
tmux send-keys -t $SESSION:2 "git status" C-m

# 服务器窗口
tmux new-window -t $SESSION:3 -n 'server' -c $PROJECT_DIR
tmux send-keys -t $SESSION:3 "npm run dev" C-m

# 测试窗口
tmux new-window -t $SESSION:4 -n 'test' -c $PROJECT_DIR

# 附加
tmux select-window -t $SESSION:1
tmux attach -t $SESSION
```

### 案例 2：服务器监控面板

```bash
#!/bin/bash
# ~/bin/monitor-dashboard

SESSION="monitor"

tmux new-session -d -s $SESSION

# 系统监控
tmux rename-window -t $SESSION:1 'system'
tmux send-keys -t $SESSION:1 "htop" C-m
tmux split-window -t $SESSION:1 -h
tmux send-keys -t $SESSION:1.1 "watch -n 1 'df -h'" C-m
tmux split-window -t $SESSION:1 -v
tmux send-keys -t $SESSION:1.2 "watch -n 1 'free -h'" C-m

# 网络监控
tmux new-window -t $SESSION:2 -n 'network'
tmux send-keys -t $SESSION:2 "iftop" C-m
tmux split-window -t $SESSION:2 -h
tmux send-keys -t $SESSION:2.1 "watch -n 1 'netstat -an | grep ESTABLISHED | wc -l'" C-m

# 日志监控
tmux new-window -t $SESSION:3 -n 'logs'
tmux send-keys -t $SESSION:3 "tail -f /var/log/syslog" C-m
tmux split-window -t $SESSION:3 -h
tmux send-keys -t $SESSION:3.1 "tail -f /var/log/nginx/access.log" C-m

tmux select-window -t $SESSION:1
tmux attach -t $SESSION
```
