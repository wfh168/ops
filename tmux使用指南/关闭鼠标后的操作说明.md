# 关闭鼠标后的 Tmux 操作指南

## 🎯 为什么关闭鼠标？

关闭鼠标模式的好处：
- ✅ 终端原生的鼠标选择和复制功能可用
- ✅ 可以直接用鼠标选择文本复制到系统剪贴板
- ✅ 更符合传统终端使用习惯
- ✅ 避免鼠标操作和键盘操作冲突

## 📋 关闭鼠标后的操作方式

### 1. 窗格切换（只能用键盘）

```bash
# Vim 风格切换
Ctrl+a h    # 左边窗格
Ctrl+a j    # 下边窗格
Ctrl+a k    # 上边窗格
Ctrl+a l    # 右边窗格

# 或者循环切换
Ctrl+a o    # 下一个窗格
Ctrl+a ;    # 上一个活动窗格
```

### 2. 窗格大小调整（只能用键盘）

```bash
# 使用 Alt+hjkl（不需要前缀键）
Alt+h       # 向左调整 5 列
Alt+j       # 向下调整 5 行
Alt+k       # 向上调整 5 行
Alt+l       # 向右调整 5 列

# 或者使用命令模式精细调整
Ctrl+a :resize-pane -L 10    # 向左 10 列
Ctrl+a :resize-pane -R 10    # 向右 10 列
Ctrl+a :resize-pane -U 5     # 向上 5 行
Ctrl+a :resize-pane -D 5     # 向下 5 行
```

### 3. 窗口切换（键盘）

```bash
Ctrl+a 0-9  # 切换到指定窗口
Ctrl+a n    # 下一个窗口
Ctrl+a p    # 上一个窗口
Ctrl+a w    # 窗口列表（用方向键选择）
```

### 4. 滚动查看历史（键盘）

```bash
# 进入复制模式
Ctrl+a [

# 使用 Vim 键位滚动
j/k         # 上下移动一行
Ctrl+u      # 上翻半页
Ctrl+d      # 下翻半页
Ctrl+b      # 上翻一页
Ctrl+f      # 下翻一页
g           # 跳到开头
G           # 跳到结尾

# 退出复制模式
q 或 Esc
```

## 🖱️ 使用终端原生鼠标功能

关闭 tmux 鼠标模式后，你可以使用终端自带的鼠标功能：

### Linux（大多数终端）

```bash
# 选择文本
1. 按住鼠标左键拖动选择
2. 松开后自动复制到系统剪贴板

# 粘贴
1. 鼠标中键点击
2. 或 Shift+Insert
3. 或 Ctrl+Shift+V（某些终端）
```

### 跨窗格选择文本

```bash
# 按住 Shift 键，然后用鼠标选择
Shift + 鼠标拖动

# 这样可以跨越 tmux 窗格边界选择文本
```

## 📝 复制粘贴完整方案

### 方案 1：终端原生复制（推荐）

```bash
# 1. 用鼠标选择文本（按住 Shift 可跨窗格）
Shift + 鼠标拖动

# 2. 自动复制到系统剪贴板

# 3. 粘贴
鼠标中键
# 或
Ctrl+Shift+V
```

### 方案 2：Tmux 复制模式

```bash
# 1. 进入复制模式
Ctrl+a [

# 2. 移动到起始位置（hjkl 或方向键）

# 3. 开始选择
v           # 字符选择
V           # 行选择
Ctrl+v      # 矩形选择

# 4. 移动选择范围

# 5. 复制
y           # 复制到 tmux 缓冲区和系统剪贴板

# 6. 粘贴
Ctrl+a ]    # 粘贴 tmux 缓冲区
```

### 方案 3：混合使用

```bash
# 短文本：用终端鼠标选择
Shift + 鼠标拖动

# 长文本/精确选择：用 tmux 复制模式
Ctrl+a [ → v → 移动 → y
```

## 🎨 窗格布局快捷键

```bash
# 快速切换布局
Ctrl+a Space        # 循环切换预设布局

# 预设布局包括：
# - even-horizontal   水平平均分布
# - even-vertical     垂直平均分布
# - main-horizontal   主窗格在上
# - main-vertical     主窗格在左
# - tiled             平铺布局
```

## 💡 实用技巧

### 1. 快速最大化/还原窗格

```bash
Ctrl+a z    # 最大化当前窗格
Ctrl+a z    # 再按一次还原
```

### 2. 交换窗格位置

```bash
Ctrl+a {    # 与前一个窗格交换
Ctrl+a }    # 与后一个窗格交换
```

### 3. 将窗格移到新窗口

```bash
Ctrl+a !    # 当前窗格移到新窗口
```

### 4. 显示窗格编号

```bash
Ctrl+a q    # 显示窗格编号
Ctrl+a q 0-9    # 快速跳转到指定窗格
```

## 🔄 如果想重新启用鼠标

如果你想临时启用鼠标，可以：

### 临时启用（当前会话）

```bash
# 在 tmux 中执行
Ctrl+a :set -g mouse on
```

### 临时禁用（当前会话）

```bash
Ctrl+a :set -g mouse off
```

### 永久修改

编辑 `~/.tmux.conf`：

```bash
# 启用鼠标
set -g mouse on

# 或禁用鼠标
set -g mouse off
```

然后重新加载：
```bash
tmux source ~/.tmux.conf
```

## 🎯 推荐工作流

### 纯键盘流（高效）

```bash
# 1. 创建会话
tmux new -s work

# 2. 创建窗口
Ctrl+a c    # 编辑器
Ctrl+a c    # 服务器
Ctrl+a c    # 日志

# 3. 分割窗格
Ctrl+a 0    # 切换到窗口 0
Ctrl+a |    # 垂直分割
Ctrl+a -    # 水平分割

# 4. 切换窗格
Ctrl+a h/j/k/l

# 5. 调整大小
Alt+h/j/k/l

# 6. 复制内容
Ctrl+a [ → v → 移动 → y

# 7. 粘贴
Ctrl+a ]
```

### 混合流（灵活）

```bash
# 键盘：窗格管理、窗口切换
# 鼠标：选择复制文本（按住 Shift）
```
