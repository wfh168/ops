# 测试智能状态栏

## 快速测试步骤

### 1. 重载 Tmux 配置

在 tmux 中按：
```
Ctrl+a r
```

或者在命令行执行：
```bash
tmux source-file ~/.tmux.conf
```

### 2. 测试本地窗格

在当前窗格中，状态栏右侧应该显示：
```
LOCAL | CPU 3.4% | MEM 17Gi/30Gi | / 27G/64G | HOME 55G/257G
```

### 3. 测试 SSH 窗格

#### 测试方式 1：使用 ~/.ssh/config 别名

```bash
ssh wfh1688
```

状态栏应该显示：
```
@ root@wfh1688:22 (10.0.0.139) | CPU 5.2% | MEM 2.1G/4G | / 15G/50G
```

#### 测试方式 2：直接使用 user@ip

```bash
ssh root@10.0.0.139
```

状态栏应该显示：
```
@ root@10.0.0.139:22 | CPU 5.2% | MEM 2.1G/4G | / 15G/50G
```

#### 测试方式 3：非标准端口（黄色高亮）

```bash
ssh root@10.0.0.139 -p 2222
```

状态栏应该显示（黄色）：
```
@ root@10.0.0.139:2222 | CPU 5.2% | MEM 2.1G/4G | / 15G/50G
```

### 4. 手动测试脚本

如果状态栏没有显示，可以手动运行脚本查看输出：

#### 在本地窗格中：
```bash
bash ~/.tmux/scripts/smart-status.sh
```

预期输出：
```
LOCAL | CPU 3.4% | MEM 17Gi/30Gi | / 27G/64G | HOME 55G/257G
```

#### 在 SSH 窗格中：
```bash
bash ~/.tmux/scripts/smart-status.sh
```

预期输出：
```
@ root@wfh1688:22 (10.0.0.139) | CPU 5.2% | MEM 2.1G/4G | / 15G/50G
```

### 5. 调试模式

如果脚本没有输出，可以添加调试信息：

```bash
# 查看当前窗格的进程
ps -o command= -p $(tmux display-message -p '#{pane_pid}')

# 查看子进程
pgrep -P $(tmux display-message -p '#{pane_pid}')
```

## 常见问题

### 问题 1：SSH 窗格只显示连接信息，没有系统信息

**原因**：SSH 连接需要密钥认证（无密码登录）

**解决**：
```bash
# 1. 生成 SSH 密钥（如果还没有）
ssh-keygen -t rsa

# 2. 复制公钥到服务器
ssh-copy-id root@10.0.0.139

# 3. 测试无密码登录
ssh root@10.0.0.139 "echo 'Success!'"
```

### 问题 2：状态栏不更新

**解决**：
```bash
# 方法 1：重载配置
tmux source-file ~/.tmux.conf

# 方法 2：重启 tmux
tmux kill-server
tmux
```

### 问题 3：脚本没有执行权限

**解决**：
```bash
chmod +x ~/.tmux/scripts/smart-status.sh
```

### 问题 4：远程服务器缺少命令

**测试**：
```bash
ssh root@10.0.0.139 "which top free df"
```

如果缺少命令，需要在远程服务器上安装：
```bash
# Debian/Ubuntu
apt-get install procps coreutils

# CentOS/RHEL
yum install procps-ng coreutils
```

## 完整测试流程

```bash
# 1. 确保脚本可执行
chmod +x ~/.tmux/scripts/smart-status.sh

# 2. 测试脚本（本地）
bash ~/.tmux/scripts/smart-status.sh

# 3. 配置 SSH 密钥认证
ssh-copy-id root@10.0.0.139

# 4. 测试远程命令
ssh root@10.0.0.139 "top -bn1 | grep 'Cpu(s)'; free -h; df -h /"

# 5. 重载 tmux 配置
tmux source-file ~/.tmux.conf

# 6. 在 tmux 中测试
# 窗格 1：本地
# 窗格 2：ssh wfh1688
# 窗格 3：ssh root@10.0.0.139
```
