# 智能状态栏说明

## 功能概述

智能状态栏会自动检测当前窗格的上下文，并显示相应的系统信息：

- **本地窗格**：显示本地系统的 CPU、内存、磁盘使用情况
- **SSH 窗格**：显示远程服务器的 CPU、内存、磁盘使用情况 + 连接信息

## 显示效果

### 本地窗格
```
LOCAL | CPU 3.4% | MEM 17Gi/30Gi | / 27G/64G | HOME 55G/257G
```

### SSH 窗格（标准端口 22）
```
@ root@wfh1688:22 (10.0.0.139) | CPU 5.2% | MEM 2.1G/4G | / 15G/50G
```

### SSH 窗格（非标准端口，黄色高亮）
```
@ root@server:2222 | CPU 8.1% | MEM 3.5G/8G | / 25G/100G
```

### SSH 窗格（无法获取远程信息时）
```
@ root@wfh1688:22 (10.0.0.139)
```

## 工作原理

### 1. 自动检测窗格类型

脚本通过检查窗格的进程命令来判断是本地还是 SSH 连接：

```bash
pane_command=$(ps -o command= -p $pane_pid)

if echo "$pane_command" | grep -q "^ssh "; then
    # SSH 连接
else
    # 本地窗格
fi
```

### 2. SSH 连接信息解析

支持两种 SSH 连接方式：

#### 方式 1：直接指定 `ssh user@ip`
```bash
ssh root@10.0.0.139
ssh root@10.0.0.139 -p 2222
```

脚本会直接从命令行参数中提取用户名、主机和端口。

#### 方式 2：使用 `~/.ssh/config` 别名
```bash
ssh wfh1688
ssh cicd
```

脚本会从 `~/.ssh/config` 中读取对应的配置：
```
Host wfh1688
    HostName 10.0.0.139
    User root
    Port 22
```

### 3. 远程系统信息获取

脚本通过 SSH 在远程服务器上执行命令获取系统信息：

```bash
remote_info=$(ssh -o ConnectTimeout=2 -o BatchMode=yes $ssh_host "
    # CPU 使用率
    cpu=\$(top -bn1 | grep 'Cpu(s)' | awk '{print \$2}' | cut -d'%' -f1)
    
    # 内存使用
    mem=\$(free -h | awk 'NR==2{printf \"%s/%s\", \$3, \$2}')
    
    # 根分区使用
    disk=\$(df -h / | awk 'NR==2{print \$3\"/\"\$2}')
    
    echo \"CPU \${cpu}% | MEM \${mem} | / \${disk}\"
")
```

**注意事项**：
- 使用 `ConnectTimeout=2` 避免长时间等待
- 使用 `BatchMode=yes` 避免交互式提示
- 需要配置 SSH 密钥认证（无密码登录）

### 4. 本地系统信息获取

对于本地窗格，直接在本地执行命令：

```bash
# CPU 使用率
cpu=$(top -bn1 | grep 'Cpu(s)' | awk '{print $2}' | cut -d'%' -f1)

# 内存使用
mem=$(free -h | awk 'NR==2{printf "%s/%s", $3, $2}')

# 磁盘使用
disk=$(df -h / | awk 'NR==2{print $3"/"$2}')
home=$(df -h /home | awk 'NR==2{print $3"/"$2}')
```

## 配置说明

### Tmux 配置

在 `.tmux.conf` 中，智能状态栏被放置在右侧：

```bash
set -g status-right-length 200
set -g status-right "#[fg=#a6e3a1]#(cd #{pane_current_path}; git rev-parse --abbrev-ref HEAD 2>/dev/null | sed 's/^/ /') #[fg=#fab387]│ #[fg=#7f849c]#(~/.tmux/scripts/smart-status.sh) #[fg=#fab387]│ #[fg=#89b4fa]%Y-%m-%d %H:%M "
```

状态栏布局：
```
[Git 分支] │ [智能状态信息] │ [日期时间]
```

### 刷新频率

状态栏每 2 秒刷新一次：

```bash
set -g status-interval 2
```

如果觉得刷新太频繁，可以调整为 5 秒：

```bash
set -g status-interval 5
```

## 使用场景

### 场景 1：本地开发

在本地窗格中工作时，可以实时监控本地系统资源：

```
[tmux] session-name  │  LOCAL | CPU 3.4% | MEM 17Gi/30Gi | / 27G/64G | HOME 55G/257G  │  2026-02-09 20:30
```

### 场景 2：SSH 到服务器

SSH 连接到服务器后，自动显示远程服务器的资源使用情况：

```bash
# 在 tmux 中执行
ssh wfh1688
```

状态栏自动切换为：
```
[tmux] session-name  │  @ root@wfh1688:22 (10.0.0.139) | CPU 5.2% | MEM 2.1G/4G | / 15G/50G  │  2026-02-09 20:30
```

### 场景 3：多窗格混合

在同一个 tmux 会话中，可以同时打开多个窗格：

- 窗格 1：本地开发 → 显示本地系统信息
- 窗格 2：SSH 到服务器 A → 显示服务器 A 的信息
- 窗格 3：SSH 到服务器 B → 显示服务器 B 的信息

每个窗格的状态栏都会自动显示对应的信息。

## 故障排查

### 问题 1：SSH 窗格不显示远程信息

**可能原因**：
1. SSH 连接未配置密钥认证（需要输入密码）
2. 远程服务器响应超时
3. 远程服务器缺少必要的命令（`top`, `free`, `df`）

**解决方法**：

1. 配置 SSH 密钥认证：
```bash
# 生成密钥（如果还没有）
ssh-keygen -t rsa

# 复制公钥到服务器
ssh-copy-id user@server
```

2. 手动测试远程命令：
```bash
ssh user@server "top -bn1 | grep 'Cpu(s)'"
```

3. 检查脚本输出：
```bash
# 在 SSH 窗格中手动运行脚本
~/.tmux/scripts/smart-status.sh
```

### 问题 2：本地窗格不显示信息

**可能原因**：
1. 脚本没有执行权限
2. 系统命令不兼容（非 Linux 系统）

**解决方法**：

1. 添加执行权限：
```bash
chmod +x ~/.tmux/scripts/smart-status.sh
```

2. 手动测试脚本：
```bash
bash ~/.tmux/scripts/smart-status.sh
```

### 问题 3：状态栏不更新

**解决方法**：

1. 重载 tmux 配置：
```bash
# 在 tmux 中按
Ctrl+a r
```

2. 或者重启 tmux：
```bash
tmux kill-server
tmux
```

### 问题 4：显示格式错乱

**可能原因**：
- 状态栏长度不够

**解决方法**：

增加状态栏长度：
```bash
set -g status-right-length 250
```

## 自定义配置

### 修改显示格式

编辑 `~/.tmux/scripts/smart-status.sh`，找到输出部分：

```bash
# 本地显示格式
echo "LOCAL | CPU ${cpu}% | MEM ${mem} | / ${disk} | HOME ${home}"

# SSH 显示格式
echo "@ ${user}@${host}:${port} | ${remote_info}"
```

可以根据需要修改显示内容和格式。

### 添加更多监控项

例如，添加网络流量监控：

```bash
# 获取网络流量
rx=$(cat /sys/class/net/eth0/statistics/rx_bytes)
tx=$(cat /sys/class/net/eth0/statistics/tx_bytes)
```

### 修改颜色

在 `.tmux.conf` 中修改颜色：

```bash
# 当前配置（灰色）
set -g status-right "... #[fg=#7f849c]#(~/.tmux/scripts/smart-status.sh) ..."

# 改为绿色
set -g status-right "... #[fg=#a6e3a1]#(~/.tmux/scripts/smart-status.sh) ..."

# 改为黄色
set -g status-right "... #[fg=#f9e2af]#(~/.tmux/scripts/smart-status.sh) ..."
```

## 性能优化

### 减少刷新频率

如果觉得 CPU 占用过高，可以降低刷新频率：

```bash
# 从 2 秒改为 5 秒
set -g status-interval 5
```

### 缓存远程信息

对于 SSH 连接，可以添加缓存机制避免频繁查询：

```bash
# 在脚本中添加缓存
cache_file="/tmp/tmux-ssh-status-${pane_pid}"
cache_ttl=10  # 缓存 10 秒

if [ -f "$cache_file" ]; then
    cache_age=$(($(date +%s) - $(stat -c %Y "$cache_file")))
    if [ $cache_age -lt $cache_ttl ]; then
        cat "$cache_file"
        exit 0
    fi
fi

# 获取新数据并缓存
remote_info=$(ssh ...)
echo "$remote_info" > "$cache_file"
echo "$remote_info"
```

## 总结

智能状态栏通过自动检测窗格类型，为你提供最相关的系统信息：

- ✅ 自动识别本地/远程窗格
- ✅ 实时显示系统资源使用情况
- ✅ 支持多种 SSH 连接方式
- ✅ 颜色高亮非标准端口
- ✅ 无需手动切换，完全自动化

现在你可以在一个 tmux 会话中同时监控多台服务器的状态，大大提高运维效率！
