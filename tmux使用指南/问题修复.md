# Tmux 配置问题修复说明

## 🔍 你的原始配置问题分析

### ❌ 问题 1：注释格式不规范

**原配置：**
```bash
##### 基础设置 ######
```

**问题：**
- 注释应该是 `#` 开头，但 `######` 可能被误解析
- 虽然通常不会报错，但不规范

**修复：**
```bash
# -------------------- 基础设置 --------------------
```

**说明：**
- 使用统一的分隔线格式
- 更清晰易读

---

### ❌ 问题 2：状态栏转义字符问题

**原配置：**
```bash
set -g status-right "\#[fg=#fab387]│ CPU..."
```

**问题：**
- `\#` 转义可能导致显示异常
- 在某些 tmux 版本中会显示为 `\#` 而不是 `#`

**修复：**
```bash
set -g status-right "#[fg=#fab387]│ CPU..."
```

**说明：**
- 直接使用 `#`，不需要转义
- tmux 会正确解析颜色代码

---

### ❌ 问题 3：AWK 脚本中的变量转义

**原配置：**
```bash
set -g status-right "... #(awk '/MemTotal/ {t=$2} ...' /proc/meminfo) ..."
```

**问题：**
- AWK 中的 `$2` 可能被 tmux 解析为变量
- 导致命令执行失败

**修复：**
```bash
set -g status-right "... #(awk '/MemTotal/ {t=\$2} ...' /proc/meminfo) ..."
```

**说明：**
- 在 tmux 配置中，AWK 的 `$` 需要转义为 `\$`
- 这样 tmux 才会正确传递给 shell

---

### ⚠️ 问题 4：插件配置顺序

**原配置：**
```bash
set -g @plugin 'tmux-plugins/tmux-cpu'
# ... 其他插件 ...
set -g @cpu_percentage_format "%3.0f%%"
```

**问题：**
- 插件配置应该在插件定义之前
- 否则可能不生效

**修复：**
```bash
# 先配置
set -g @cpu_percentage_format "%3.0f%%"
# 后定义插件
set -g @plugin 'tmux-plugins/tmux-cpu'
```

## 🐛 常见错误和解决方案

### 错误 1：状态栏显示异常

**症状：**
```
\#[fg=#fab387]│ CPU 10%
```

**原因：**
- 转义字符使用不当

**解决：**
```bash
# 错误
set -g status-right "\#[fg=#fab387]..."

# 正确
set -g status-right "#[fg=#fab387]..."
```

---

### 错误 2：CPU 百分比不显示

**症状：**
```
CPU #{cpu_percentage}
```

**原因：**
- 插件未安装或未加载

**解决：**
```bash
# 1. 确保 TPM 已安装
ls ~/.tmux/plugins/tpm

# 2. 安装插件
Ctrl+a I

# 3. 重启 tmux
tmux kill-server
tmux
```

---

### 错误 3：内存显示为空

**症状：**
```
MEM G/G
```

**原因：**
- AWK 变量未正确转义

**解决：**
```bash
# 错误
#(awk '/MemTotal/ {t=$2} ...' /proc/meminfo)

# 正确
#(awk '/MemTotal/ {t=\$2} ...' /proc/meminfo)
```

---

### 错误 4：分割窗格不在当前路径

**症状：**
- 分割窗格后，路径回到 HOME

**解决：**
```bash
# 添加 -c "#{pane_current_path}"
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"
bind c new-window -c "#{pane_current_path}"
```

---

### 错误 5：颜色显示不正常

**症状：**
- 颜色显示为黑白或错误

**解决：**
```bash
# 1. 检查终端支持
echo $TERM

# 2. 在 ~/.bashrc 或 ~/.zshrc 中添加
export TERM=xterm-256color

# 3. 在 tmux 配置中确保有
set -g default-terminal "tmux-256color"
set -as terminal-features ',xterm-256color:RGB'

# 4. 重新加载
source ~/.bashrc
tmux source ~/.tmux.conf
```
