# Tmux 会话切换指南

## 你遇到的问题

```bash
wfh@wfh-B550i-GAMING:~$ tmux ls
default: 1 windows (created Mon Feb  9 20:47:34 2026) (attached)
servers: 1 windows (created Mon Feb  9 20:43:24 2026)

wfh@wfh-B550i-GAMING:~$ tmux attach -t servers
sessions should be nested with care, unset $TMUX to force
```

**原因**：你已经在 `default` 会话中，tmux 不允许在一个会话内直接连接到另一个会话（嵌套）。

## 解决方案

### 方法 1：在 tmux 内切换会话（推荐）⭐

在 tmux 中按：
```
Ctrl+a s
```

会显示会话列表：
```
(0) + default: 1 windows
(1) - servers: 1 windows
```

使用方向键选择 `servers`，按 `Enter` 切换。

### 方法 2：使用快捷键切换

```bash
# 切换到下一个会话
Ctrl+a )

# 切换到上一个会话
Ctrl+a (
```

### 方法 3：分离后重新连接

```bash
# 1. 分离当前会话
Ctrl+a d

# 2. 连接到其他会话
tmux attach -t servers

# 3. 再次切换回 default
Ctrl+a d
tmux attach -t default
```

### 方法 4：在窗口中查看其他会话

在 tmux 中创建新窗口，然后在新窗口中查看其他会话的内容：

```bash
# 1. 创建新窗口
Ctrl+a c

# 2. 在新窗口中强制连接（不推荐，仅查看用）
TMUX= tmux attach -t servers
```

## 会话管理最佳实践

### 1. 使用有意义的会话名

```bash
# 创建会话时指定名称
tmux new -s work      # 工作相关
tmux new -s dev       # 开发环境
tmux new -s monitor   # 监控
tmux new -s ssh       # SSH 连接
```

### 2. 查看所有会话

```bash
# 在命令行
tmux ls

# 在 tmux 中
Ctrl+a s
```

### 3. 重命名会话

```bash
# 在命令行
tmux rename-session -t servers work-servers

# 在 tmux 中（重命名当前会话）
Ctrl+a $
```

### 4. 杀死不需要的会话

```bash
# 在命令行
tmux kill-session -t servers

# 在 tmux 中（杀死当前会话）
Ctrl+a x  # 关闭所有窗格后会话自动结束
```

## 你的当前情况

你有两个会话：
1. **default** - 当前连接的会话（attached）
2. **servers** - 后台运行的会话

### 推荐操作

#### 选项 A：合并会话（如果不需要两个会话）

```bash
# 1. 在 default 会话中，切换到 servers 查看内容
Ctrl+a s  # 选择 servers

# 2. 如果 servers 中没有重要内容，可以删除
# 先切换回 default
Ctrl+a s  # 选择 default

# 3. 在命令行窗口中删除 servers
tmux kill-session -t servers
```

#### 选项 B：保留两个会话，按需切换

```bash
# 在 tmux 中随时切换
Ctrl+a s  # 显示会话列表，选择要切换的会话
```

## 常用会话操作快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+a s` | 显示会话列表并切换 |
| `Ctrl+a (` | 切换到上一个会话 |
| `Ctrl+a )` | 切换到下一个会话 |
| `Ctrl+a d` | 分离当前会话 |
| `Ctrl+a $` | 重命名当前会话 |
| `Ctrl+a L` | 切换到上次使用的会话 |

## 会话工作流示例

### 场景 1：开发 + 监控

```bash
# 创建开发会话
tmux new -s dev
# 在这里编辑代码、运行程序

# 创建监控会话（分离后创建）
Ctrl+a d
tmux new -s monitor
# 在这里运行 top, htop, 查看日志

# 在两个会话之间切换
Ctrl+a s  # 选择要切换的会话
```

### 场景 2：多个项目

```bash
# 项目 A
tmux new -s project-a
# 窗口 1: 编辑器
# 窗口 2: 服务器
# 窗口 3: 数据库

# 项目 B
Ctrl+a d
tmux new -s project-b
# 窗口 1: 编辑器
# 窗口 2: 服务器

# 快速切换项目
Ctrl+a s  # 选择 project-a 或 project-b
```

### 场景 3：本地 + 远程

```bash
# 本地会话
tmux new -s local
# 本地开发工作

# SSH 会话
Ctrl+a d
tmux new -s remote
ssh server1
ssh server2

# 在本地和远程之间切换
Ctrl+a s
```

## 高级技巧

### 1. 在会话之间移动窗口

```bash
# 将当前窗口移动到另一个会话
Ctrl+a :
move-window -t target-session:
```

### 2. 链接窗口到多个会话

```bash
# 在命令行
tmux link-window -s source-session:1 -t target-session:1
```

### 3. 同时查看多个会话

在一个会话中创建窗格，每个窗格连接到不同的会话：

```bash
# 窗格 1: 当前会话
# 窗格 2: 创建新窗格
Ctrl+a |

# 在新窗格中强制连接到其他会话
TMUX= tmux attach -t servers
```

### 4. 批量操作所有会话

```bash
# 保存所有会话
Ctrl+a Ctrl+s

# 列出所有会话的窗口
tmux list-windows -a

# 杀死所有会话
tmux kill-server
```

## 总结

### 你现在的状态

- ✅ 在 `default` 会话中（attached）
- ✅ 有一个 `servers` 会话在后台运行

### 如何切换到 servers

**最简单的方法**：
```
Ctrl+a s
```
然后选择 `servers`，按 `Enter`。

### 如何管理会话

1. **查看会话**：`Ctrl+a s`
2. **切换会话**：`Ctrl+a s` 或 `Ctrl+a (` / `Ctrl+a )`
3. **重命名会话**：`Ctrl+a $`
4. **删除会话**：`tmux kill-session -t session-name`

### 建议

如果 `servers` 会话是之前测试留下的，可以考虑删除：
```bash
# 1. 确保在 default 会话中
# 2. 创建新窗口
Ctrl+a c

# 3. 删除 servers 会话
tmux kill-session -t servers

# 4. 关闭当前窗口
exit
```

这样就只保留一个 `default` 会话，更清爽。
