# Tmux 常用命令速查表

## 📋 命令行操作

### 会话管理

```bash
# 创建会话
tmux new                          # 创建匿名会话
tmux new -s 会话名                # 创建命名会话
tmux new -s 会话名 -n 窗口名      # 创建会话并指定窗口名

# 列出会话
tmux ls                           # 列出所有会话
tmux list-sessions                # 同上

# 附加会话
tmux attach                       # 附加到最后一个会话
tmux a                            # 简写
tmux attach -t 会话名             # 附加到指定会话
tmux a -t 会话名                  # 简写

# 杀死会话
tmux kill-session -t 会话名       # 杀死指定会话
tmux kill-session -a              # 杀死所有会话（除当前）
tmux kill-server                  # 杀死所有会话和服务器

# 重命名会话
tmux rename-session -t 旧名 新名
```

## ⌨️ 快捷键操作

> 前缀键：`Ctrl+a`（配置中已修改，默认是 `Ctrl+b`）

| 快捷键 | 功能 |
|--------|------|

| `Ctrl+a D` | 选择要分离的会话 |

| `Ctrl+a (` | 切换到上一个会话 |

## 🔧 命令模式

按 `Ctrl+a :` 进入命令模式，可以执行更多命令。

### 常用命令

```bash
# 会话管理
:new-session -s 会话名              # 创建新会话
:kill-session -t 会话名             # 杀死会话
:rename-session 新名                # 重命名会话

# 窗口管理
:new-window -n 窗口名               # 创建新窗口
:kill-window                        # 关闭当前窗口
:rename-window 新名                 # 重命名窗口
:move-window -t 目标会话:编号       # 移动窗口到其他会话

# 窗格管理
:split-window -h                    # 水平分割
:split-window -v                    # 垂直分割
:kill-pane                          # 关闭当前窗格
:resize-pane -L 10                  # 向左调整10列
:resize-pane -R 10                  # 向右调整10列
:resize-pane -U 10                  # 向上调整10行
:resize-pane -D 10                  # 向下调整10行
:swap-pane -U                       # 与上一个窗格交换
:swap-pane -D                       # 与下一个窗格交换

# 布局
:select-layout even-horizontal      # 水平平均分布
:select-layout even-vertical        # 垂直平均分布
:select-layout main-horizontal      # 主窗格在上
:select-layout main-vertical        # 主窗格在左
:select-layout tiled                # 平铺布局

# 配置
:source-file ~/.tmux.conf           # 重载配置
:show-options -g                    # 显示全局选项
:show-window-options -g             # 显示窗口选项

# 同步输入
:setw synchronize-panes on          # 开启同步
:setw synchronize-panes off         # 关闭同步

# 保存和恢复
:capture-pane -S -                  # 捕获整个窗格内容
:save-buffer ~/output.txt           # 保存缓冲区到文件
:show-buffer                        # 显示缓冲区内容
```

## 📊 状态栏变量

在配置文件中可以使用的变量：

```bash
#S    # 会话名
#I    # 窗口编号
#W    # 窗口名
#P    # 窗格编号
#T    # 窗格标题
#H    # 主机名
#h    # 主机名（短）
#F    # 窗口标志
#D    # 窗格ID
```

## 🎨 常用配置选项

```bash
# 鼠标支持
set -g mouse on

# 窗口编号从1开始
set -g base-index 1
setw -g pane-base-index 1

# 自动重新编号
set -g renumber-windows on

# 历史记录
set -g history-limit 10000

# 响应时间
set -sg escape-time 0

# 状态栏刷新间隔
set -g status-interval 2

# 允许重命名
setw -g allow-rename off
setw -g automatic-rename off

# 活动监控
setw -g monitor-activity on
set -g visual-activity on
```

## 💡 实用技巧

### 1. 批量操作

```bash
# 在所有窗格执行相同命令
Ctrl+a :setw synchronize-panes on
# 执行命令...
Ctrl+a :setw synchronize-panes off
```

### 2. 快速布局切换

```bash
Ctrl+a Space    # 循环切换布局
```

### 3. 交换窗格位置

```bash
Ctrl+a {        # 与前一个窗格交换
Ctrl+a }        # 与后一个窗格交换
```

### 4. 查看所有快捷键

```bash
Ctrl+a ?        # 显示帮助
# 按 q 退出
```

### 5. 临时最大化窗格

```bash
Ctrl+a z        # 最大化当前窗格
Ctrl+a z        # 再按一次恢复
```

```bash
tmux show-options -g

tmux list-keys

tmux list-commands
```

## 📚 插件相关

### TPM（Tmux Plugin Manager）

```bash
# 安装插件
Ctrl+a I        # 大写 I

# 更新插件
Ctrl+a U        # 大写 U

# 卸载插件
Ctrl+a Alt+u    # 小写 u
```

### Resurrect（会话保存）

```bash
# 保存会话
Ctrl+a Ctrl+s

# 恢复会话
Ctrl+a Ctrl+r
```

## 🎯 记忆技巧

- **c** = create（创建）
- **n** = next（下一个）
- **p** = previous（上一个）
- **d** = detach（分离）
- **s** = session（会话列表）
- **w** = window（窗口列表）
- **z** = zoom（最大化）
- **?** = help（帮助）
- **|** = 竖着分割
- **-** = 横着分割
