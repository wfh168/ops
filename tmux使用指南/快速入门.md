# Tmux 快速入门教程

## 🎯 什么是 Tmux？

Tmux 是一个终端复用器，让你可以：
- 在一个终端窗口中运行多个会话
- 分割窗口为多个窗格
- 断开连接后程序继续运行
- 随时重新连接到会话

## 📦 安装

```bash
# Ubuntu/Debian
sudo apt install tmux

# CentOS/RHEL
sudo yum install tmux

# macOS
brew install tmux

# 验证安装
tmux -V
```

## 🚀 第一次使用

### 1. 启动 Tmux

```bash
# 创建新会话
tmux

# 创建命名会话（推荐）
tmux new -s 工作

# 创建会话并指定窗口名
tmux new -s 开发 -n 编辑器
```

### 2. 理解三个概念

```
会话（Session）
  └── 窗口（Window）
        └── 窗格（Pane）
```

- **会话**：一个独立的工作环境（类似浏览器的配置文件）
- **窗口**：会话中的标签页（类似浏览器标签）
- **窗格**：窗口的分割区域（类似 IDE 的分屏）

### 3. 前缀键

所有 tmux 命令都需要先按 **前缀键**，默认是 `Ctrl+b`，我们的配置改为了 `Ctrl+a`。

**使用方式：**
1. 按下 `Ctrl+a`
2. 松开
3. 按功能键

例如：创建新窗口 = `Ctrl+a` 然后按 `c`

## 📝 基础操作（10分钟掌握）

### 会话管理

```bash
# 创建会话
tmux new -s 会话名

# 列出所有会话
tmux ls

# 附加到会话
tmux attach -t 会话名
# 简写
tmux a -t 会话名

# 分离会话（程序继续运行）
Ctrl+a d

# 切换会话
Ctrl+a s    # 显示会话列表，用方向键选择

# 重命名会话
Ctrl+a $

# 杀死会话
tmux kill-session -t 会话名
```

### 窗口操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+a c` | 创建新窗口 | create |
| `Ctrl+a n` | 下一个窗口 | next |
| `Ctrl+a p` | 上一个窗口 | previous |
| `Ctrl+a 0-9` | 切换到指定窗口 | 数字键 |
| `Ctrl+a w` | 窗口列表 | window list |
| `Ctrl+a ,` | 重命名窗口 | |
| `Ctrl+a X` | 关闭窗口 | 需要确认 |

### 窗格操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+a \|` | 垂直分割 | 竖线 |
| `Ctrl+a -` | 水平分割 | 横线 |
| `Ctrl+a h/j/k/l` | 切换窗格 | Vim 风格 |
| `Alt+h/j/k/l` | 调整大小 | 不需要前缀键 |
| `Ctrl+a x` | 关闭窗格 | 需要确认 |
| `Ctrl+a z` | 最大化/还原窗格 | zoom |
| `Ctrl+a {` | 窗格左移 | |
| `Ctrl+a }` | 窗格右移 | |

### 其他常用

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+a ?` | 显示所有快捷键 |
| `Ctrl+a r` | 重载配置文件 |
| `Ctrl+a [` | 进入复制模式（可滚动查看历史） |
| `Ctrl+a ]` | 粘贴 |

## 🎬 实战演练

### 场景1：开发环境

```bash
# 1. 创建开发会话
tmux new -s dev

# 2. 创建三个窗口
Ctrl+a c    # 窗口1：编辑器
Ctrl+a c    # 窗口2：服务器
Ctrl+a c    # 窗口3：日志

# 3. 重命名窗口
Ctrl+a ,    # 输入 "编辑器"
Ctrl+a n    # 切换到下一个
Ctrl+a ,    # 输入 "服务器"

# 4. 在窗口1中分割窗格
Ctrl+a 0    # 切换到窗口1
Ctrl+a |    # 垂直分割
Ctrl+a -    # 水平分割

# 5. 分离会话
Ctrl+a d

# 6. 重新连接
tmux a -t dev
```

### 场景2：运维监控

```bash
# 创建监控会话
tmux new -s monitor

# 分割为4个窗格
Ctrl+a |    # 垂直分割
Ctrl+a h    # 切换到左边
Ctrl+a -    # 水平分割
Ctrl+a l    # 切换到右边
Ctrl+a -    # 水平分割

# 现在有4个窗格，分别运行：
# 左上：htop
# 左下：tail -f /var/log/syslog
# 右上：watch -n 1 df -h
# 右下：命令行
```

### 场景3：远程工作

```bash
# 在服务器上创建会话
ssh user@server
tmux new -s work

# 运行长时间任务
./long_running_script.sh

# 分离会话（关闭 SSH 连接，任务继续运行）
Ctrl+a d
exit

# 第二天重新连接
ssh user@server
tmux a -t work    # 任务还在运行！
```

## 🎨 复制模式（滚动查看历史）

```bash
# 1. 进入复制模式
Ctrl+a [

# 2. 使用 Vim 键位移动
h/j/k/l    # 左/下/上/右
Ctrl+u     # 上翻半页
Ctrl+d     # 下翻半页
g          # 跳到开头
G          # 跳到结尾

# 3. 搜索
/          # 向下搜索
?          # 向上搜索
n          # 下一个
N          # 上一个

# 4. 复制文本
Space      # 开始选择
Enter      # 复制并退出

# 5. 粘贴
Ctrl+a ]

# 6. 退出复制模式
q 或 Esc
```

## 🐛 常见问题

### 1. 颜色显示不正常

```bash
# 在 ~/.bashrc 或 ~/.zshrc 中添加
export TERM=xterm-256color

# 重新加载
source ~/.bashrc
```

### 2. 鼠标滚动不工作

确保配置中有：
```bash
set -g mouse on
```

然后重载配置：
```bash
Ctrl+a r
```

### 3. 复制的内容无法粘贴到其他程序

需要安装 `xclip` 或 `xsel`：
```bash
# Ubuntu/Debian
sudo apt install xclip

# 然后在配置中添加
set -g set-clipboard on
```

### 4. 会话没有自动保存

首次使用需要手动保存一次：
```bash
Ctrl+a Ctrl+s    # 保存会话
```

之后会每5分钟自动保存。

## 💡 使用技巧

### 1. 快速切换会话

```bash
# 创建多个会话
tmux new -s work
tmux new -s personal
tmux new -s test

# 在会话间快速切换
Ctrl+a s    # 显示会话列表
# 用方向键选择，Enter 确认
```

### 2. 同步输入到所有窗格

```bash
# 开启同步（在所有窗格执行相同命令）
Ctrl+a :setw synchronize-panes on

# 关闭同步
Ctrl+a :setw synchronize-panes off
```

### 3. 保存终端输出

```bash
# 进入复制模式
Ctrl+a [

# 保存当前窗格内容
Ctrl+a :capture-pane -S -
Ctrl+a :save-buffer ~/output.txt
```

### 4. 创建会话模板

```bash
# 创建脚本 ~/tmux-dev.sh
#!/bin/bash
tmux new-session -d -s dev -n editor
tmux send-keys -t dev:editor 'cd ~/project && nvim' C-m
tmux new-window -t dev -n server
tmux send-keys -t dev:server 'cd ~/project && npm run dev' C-m
tmux new-window -t dev -n logs
tmux send-keys -t dev:logs 'tail -f ~/project/logs/app.log' C-m
tmux select-window -t dev:editor
tmux attach -t dev

# 使用
chmod +x ~/tmux-dev.sh
~/tmux-dev.sh
```
