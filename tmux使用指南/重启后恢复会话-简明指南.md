# 重启后恢复会话 - 简明指南

## 问题

重启电脑后 tmux 会话全部丢失。

## 原因

虽然配置了自动保存插件，但：
1. ❌ **之前从未保存过会话**（第一次使用）
2. ❌ **tmux 不会自动启动**（需要手动启动）
3. ✅ **插件已正确安装**

## 解决方案（3 步）

### 第 1 步：首次保存会话

在当前 tmux 会话中按：
```
Ctrl+a Ctrl+s
```

等待状态栏显示 "Tmux environment saved!"

**验证保存**：
```bash
ls -lh ~/.tmux/resurrect/
```

应该看到保存文件。

### 第 2 步：配置自动启动（可选但推荐）

运行自动配置脚本：
```bash
bash tmux使用指南/添加自动启动.sh
```

或者手动添加到 `~/.bashrc`：
```bash
# Tmux 自动启动
if command -v tmux &> /dev/null && [ -z "$TMUX" ]; then
    tmux attach -t default || tmux new -s default
fi
```

重新加载配置：
```bash
source ~/.bashrc
```

### 第 3 步：测试

1. **保存当前会话**：
   ```
   Ctrl+a Ctrl+s
   ```

2. **退出 tmux**：
   ```bash
   exit  # 或 Ctrl+d
   ```

3. **重新打开终端**：
   - 如果配置了自动启动，会自动进入 tmux 并恢复会话
   - 如果没有配置，手动运行 `tmux`，会自动恢复

## 日常使用

### 自动保存

配置已启用每 5 分钟自动保存：
```bash
set -g @continuum-save-interval '5'
```

无需手动操作，插件会自动保存。

### 手动保存（推荐在关机前）

```
Ctrl+a Ctrl+s
```

### 手动恢复（如果没有自动恢复）

```
Ctrl+a Ctrl+r
```

## 常见问题

### Q1: 重启后会话还是丢失？

**检查**：
```bash
# 1. 确认有保存文件
ls -lh ~/.tmux/resurrect/last

# 2. 查看保存内容
cat ~/.tmux/resurrect/last | head -20
```

**解决**：
- 如果没有文件：需要先保存 `Ctrl+a Ctrl+s`
- 如果有文件：启动 tmux 后手动恢复 `Ctrl+a Ctrl+r`

### Q2: 自动恢复不工作？

**检查配置**：
```bash
# 在 tmux 中执行
tmux show-option -g @continuum-restore
```

应该显示 `on`。

**手动恢复**：
```
Ctrl+a Ctrl+r
```

### Q3: 恢复后窗格是空的？

**正常现象**。tmux-resurrect 只恢复：
- ✅ 会话名称
- ✅ 窗口布局
- ✅ 窗格布局
- ❌ 不恢复正在运行的程序（vim、ssh 等）

需要手动重新启动这些程序。

### Q4: 不想每次都自动启动 tmux？

**方法 1**：不配置自动启动，手动运行 `tmux`

**方法 2**：设置环境变量跳过自动启动
```bash
export TMUX_AUTO_START=0
```
