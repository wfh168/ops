# 窗口列表快捷键说明

## 使用窗口列表

### 打开窗口列表

```bash
Ctrl+a w
```

这会显示所有窗口的列表，你可以用方向键或 `hjkl` 来选择窗口。

## 窗口列表中的操作

### 基本操作

| 快捷键 | 功能 |
|--------|------|
| `↑` / `k` | 向上移动 |
| `↓` / `j` | 向下移动 |
| `Enter` | 切换到选中的窗口 |
| `x` | 删除选中的窗口（需要确认） |
| `q` / `Esc` | 退出窗口列表 |

### 删除窗口

1. 按 `Ctrl+a w` 打开窗口列表
2. 用 `j/k` 或方向键选择要删除的窗口
3. 按 `x` 键
4. 会提示确认：`kill window #I? (y/n)`
5. 按 `y` 确认删除，按 `n` 取消

## 示例场景

### 场景 1：删除多个窗口

```bash
# 1. 打开窗口列表
Ctrl+a w

# 2. 选择第一个要删除的窗口
j j  # 向下移动两次

# 3. 删除
x
y    # 确认

# 4. 继续选择下一个
j

# 5. 再次删除
x
y
```

### 场景 2：快速浏览和删除

```bash
# 打开窗口列表
Ctrl+a w

# 浏览窗口
j j j k k  # 上下移动查看

# 找到不需要的窗口
x          # 删除
y          # 确认

# 退出列表
q
```

## 其他窗口管理快捷键

### 不通过列表删除窗口

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+a X` | 删除当前窗口（需要确认） |
| `Ctrl+a x` | 删除当前窗格（需要确认） |
| `Ctrl+a &` | 强制删除当前窗口（tmux 默认） |

### 窗口切换

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+a 0-9` | 切换到指定编号的窗口 |
| `Ctrl+a n` | 下一个窗口 |
| `Ctrl+a p` | 上一个窗口 |
| `Ctrl+a l` | 最后使用的窗口 |

### 窗口创建和重命名

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+a c` | 创建新窗口 |
| `Ctrl+a ,` | 重命名当前窗口 |

## 窗口列表显示格式

窗口列表会显示：

```
(0) 0: bash*                    "wfh-B550i-GAMING" {1 panes}
(1) 1: vim                      "wfh-B550i-GAMING" {1 panes}
(2) 2: htop                     "wfh-B550i-GAMING" {1 panes}
```

- `(0)` - 列表中的序号
- `0:` - 窗口编号
- `bash*` - 窗口名称（`*` 表示当前窗口）
- `"wfh-B550i-GAMING"` - 会话名称
- `{1 panes}` - 窗格数量

## 高级技巧

### 批量管理窗口

如果你有很多窗口需要管理，可以：

1. 使用窗口列表快速浏览（`Ctrl+a w`）
2. 逐个删除不需要的窗口（`x` + `y`）
3. 或者使用命令行批量操作：

```bash
# 列出所有窗口
tmux list-windows

# 删除指定窗口
tmux kill-window -t 2

# 删除多个窗口
tmux kill-window -t 2
tmux kill-window -t 3
tmux kill-window -t 4
```

### 保留重要窗口

如果担心误删重要窗口，可以：

1. 给重要窗口起有意义的名字（`Ctrl+a ,`）
2. 删除前仔细确认窗口名称
3. 使用会话保存功能（`Ctrl+a Ctrl+s`）定期备份

## 注意事项

1. 删除窗口会关闭窗口中的所有窗格
2. 删除窗口会终止窗口中运行的所有程序
3. 删除操作需要确认，避免误删
4. 如果删除最后一个窗口，会话也会被关闭

## 故障排除

### 按 x 没有反应

1. 确认你在窗口列表模式中（`Ctrl+a w`）
2. 确认已选中某个窗口（高亮显示）
3. 重载配置：`Ctrl+a r`

### 无法删除窗口

1. 检查窗口中是否有正在运行的程序
2. 尝试先切换到该窗口，手动退出程序
3. 使用强制删除：`Ctrl+a &`

### 配置不生效

```bash
# 重载配置
tmux source-file ~/.tmux.conf

# 或在 tmux 中
Ctrl+a r
```
