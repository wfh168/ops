# Tmux 命令别名使用说明

## 快速安装

在 `~/.bashrc` 中添加：

```bash
# Tmux 别名
alias ta='tmux attach -t'
alias tn='tmux new -s'
```

然后重载：

```bash
source ~/.bashrc
```

## 使用方法

### 连接会话

```bash
# 原命令（太长）
tmux attach -t work

# 新命令（简短）
ta work
```

### 创建会话

```bash
# 原命令（太长）
tmux new -s dev

# 新命令（简短）
tn dev
```

## 示例

```bash
# 创建会话
tn work
tn dev
tn servers

# 连接会话
ta work
ta dev
ta servers
```

就这么简单！
