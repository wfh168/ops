# Tmux 复制模式问题解决

## 🐛 问题：按空格无法开始选择

### 原因分析

Tmux 有两种复制模式：
1. **Emacs 模式**（默认）
2. **Vi/Vim 模式**

你的配置可能使用的是 **Emacs 模式**，在这个模式下：
- 空格键不是开始选择
- 需要使用不同的按键

## ✅ 解决方案

### 方案 1：启用 Vi 模式（推荐）

在 `~/.tmux.conf` 中添加：

```bash
# 启用 Vi 复制模式
setw -g mode-keys vi

# Vi 风格的复制粘贴
bind -T copy-mode-vi v send-keys -X begin-selection
bind -T copy-mode-vi y send-keys -X copy-selection-and-cancel
bind -T copy-mode-vi C-v send-keys -X rectangle-toggle
```

然后重新加载配置：
```bash
tmux source ~/.tmux.conf
```

### 方案 2：使用 Emacs 模式的按键

如果不想改配置，使用 Emacs 模式的按键：

| 操作 | Emacs 模式 | Vi 模式 |
|------|-----------|---------|
| 进入复制模式 | `Ctrl+a [` | `Ctrl+a [` |
| 开始选择 | `Ctrl+Space` | `Space` 或 `v` |
| 复制 | `Alt+w` | `Enter` 或 `y` |
| 粘贴 | `Ctrl+a ]` | `Ctrl+a ]` |
| 取消 | `Ctrl+g` | `Esc` 或 `q` |

## 🎯 完整的 Vi 模式配置（推荐）

将以下内容添加到你的 `~/.tmux.conf`：

```bash
# ==================== 复制模式配置 ====================

# 启用 Vi 模式
setw -g mode-keys vi

# 进入复制模式
bind [ copy-mode

# Vi 风格的选择和复制
bind -T copy-mode-vi v send-keys -X begin-selection
bind -T copy-mode-vi V send-keys -X select-line
bind -T copy-mode-vi C-v send-keys -X rectangle-toggle
bind -T copy-mode-vi y send-keys -X copy-selection-and-cancel
bind -T copy-mode-vi Y send-keys -X copy-line

# 鼠标拖动选择后自动复制
bind -T copy-mode-vi MouseDragEnd1Pane send-keys -X copy-selection-and-cancel

# 粘贴
bind ] paste-buffer

# 与系统剪贴板集成（需要 xclip 或 xsel）
# Linux
bind -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "xclip -in -selection clipboard"
# macOS
# bind -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "pbcopy"

# 快速粘贴系统剪贴板内容
bind P run "xclip -o -selection clipboard | tmux load-buffer - ; tmux paste-buffer"
```

## 🔧 系统剪贴板集成

### Linux 系统

1. **安装 xclip**
```bash
# Ubuntu/Debian
sudo apt install xclip

# CentOS/RHEL
sudo yum install xclip
```

2. **配置 tmux**
```bash
# 复制到系统剪贴板
bind -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "xclip -in -selection clipboard"

# 从系统剪贴板粘贴
bind P run "xclip -o -selection clipboard | tmux load-buffer - ; tmux paste-buffer"
```

### macOS 系统

macOS 自带 `pbcopy` 和 `pbpaste`：

```bash
# 复制到系统剪贴板
bind -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "pbcopy"

# 从系统剪贴板粘贴
bind P run "pbpaste | tmux load-buffer - ; tmux paste-buffer"
```

## 🎯 推荐配置

将以下完整配置添加到 `~/.tmux.conf`：

```bash
# ==================== 复制模式（Vi 风格）====================

# 启用 Vi 模式
setw -g mode-keys vi

# 进入复制模式
bind [ copy-mode
bind Escape copy-mode

# 选择和复制
bind -T copy-mode-vi v send-keys -X begin-selection
bind -T copy-mode-vi V send-keys -X select-line
bind -T copy-mode-vi C-v send-keys -X rectangle-toggle
bind -T copy-mode-vi y send-keys -X copy-selection-and-cancel
bind -T copy-mode-vi Y send-keys -X copy-line
bind -T copy-mode-vi Escape send-keys -X cancel

# 鼠标支持
bind -T copy-mode-vi MouseDragEnd1Pane send-keys -X copy-selection-and-cancel

# 粘贴
bind ] paste-buffer
bind P paste-buffer

# 系统剪贴板集成（Linux）
bind -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "xclip -in -selection clipboard"
bind -T copy-mode-vi Enter send-keys -X copy-pipe-and-cancel "xclip -in -selection clipboard"

# 从系统剪贴板粘贴
bind C-p run "xclip -o -selection clipboard | tmux load-buffer - ; tmux paste-buffer"
```

重新加载配置：
```bash
tmux source ~/.tmux.conf
```

现在按 `Space` 或 `v` 都可以开始选择了！
