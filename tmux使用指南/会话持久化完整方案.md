# Tmux 会话持久化完整方案

## 问题说明

你遇到的问题：**重启电脑后 tmux 会话全部丢失**

### 原因分析

虽然配置了 `tmux-continuum` 和 `tmux-resurrect` 插件：

```bash
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @plugin 'tmux-plugins/tmux-continuum'
set -g @continuum-restore 'on'
```

但是：
1. ❌ **tmux-continuum 不会自动启动 tmux**
2. ❌ **系统重启后，tmux 进程被终止，会话数据虽然保存了，但需要手动恢复**
3. ✅ **插件只能在 tmux 运行时自动保存和恢复**

### 工作流程

```
正常情况（tmux 运行中）：
1. tmux-continuum 每 5 分钟自动保存会话
2. 保存到 ~/.tmux/resurrect/last
3. 下次启动 tmux 时自动恢复

系统重启后：
1. tmux 进程被终止
2. 会话数据已保存（如果之前保存过）
3. 需要手动启动 tmux
4. 启动后会自动恢复（如果有保存的数据）
```

## 解决方案

### 方案 1：手动恢复（推荐）⭐

最简单可靠的方法：

#### 1. 启动 tmux
```bash
tmux
```

#### 2. 检查是否自动恢复

如果配置正确，tmux 启动时会自动恢复上次保存的会话。

#### 3. 如果没有自动恢复，手动恢复

在 tmux 中按：
```
Ctrl+a Ctrl+r
```

等待几秒，会话就会恢复。

#### 4. 验证恢复

```bash
# 查看会话列表
tmux ls

# 查看窗口
Ctrl+a w
```

### 方案 2：系统启动时自动启动 tmux

让系统启动后自动启动 tmux 并恢复会话。

#### 方法 A：使用 systemd（推荐）

创建 systemd 用户服务：

```bash
# 创建服务文件
mkdir -p ~/.config/systemd/user/
cat > ~/.config/systemd/user/tmux.service << 'EOF'
[Unit]
Description=Tmux server
Documentation=man:tmux(1)

[Service]
Type=forking
ExecStart=/usr/bin/tmux new-session -d -s auto
ExecStop=/usr/bin/tmux kill-server
Restart=on-failure
RestartSec=5

[Install]
WantedBy=default.target
EOF

# 重载 systemd
systemctl --user daemon-reload

# 启用服务（开机自启）
systemctl --user enable tmux.service

# 立即启动服务
systemctl --user start tmux.service

# 查看状态
systemctl --user status tmux.service
```

**优点**：
- ✅ 系统启动后自动运行
- ✅ 崩溃后自动重启
- ✅ 易于管理

**缺点**：
- ❌ 需要手动连接到会话：`tmux attach -t auto`

#### 方法 B：添加到 shell 启动脚本

在 `~/.bashrc` 或 `~/.zshrc` 中添加：

```bash
# 自动启动 tmux
if command -v tmux &> /dev/null && [ -z "$TMUX" ]; then
    # 尝试连接到现有会话，如果没有则创建新会话
    tmux attach -t default || tmux new -s default
fi
```

**优点**：
- ✅ 打开终端自动进入 tmux
- ✅ 简单易用

**缺点**：
- ❌ 只在打开终端时启动
- ❌ 可能影响某些脚本执行

#### 方法 C：使用 cron @reboot

```bash
# 编辑 crontab
crontab -e

# 添加以下行
@reboot /usr/bin/tmux new-session -d -s auto
```

**优点**：
- ✅ 系统启动后自动运行

**缺点**：
- ❌ 需要手动连接到会话

### 方案 3：定期手动保存重要会话

如果不想自动启动，可以在关机前手动保存：

```bash
# 在 tmux 中按
Ctrl+a Ctrl+s

# 等待保存完成（状态栏会显示 "Tmux environment saved!"）
```

重启后：
```bash
# 启动 tmux
tmux

# 恢复会话
Ctrl+a Ctrl+r
```

## 验证配置

### 1. 检查插件是否正确安装

```bash
ls -la ~/.tmux/plugins/
```

应该看到：
- `tmux-resurrect/`
- `tmux-continuum/`
- `tpm/`

### 2. 检查配置是否生效

在 tmux 中执行：
```bash
tmux show-option -g @continuum-restore
```

应该输出：
```
@continuum-restore on
```

### 3. 检查保存目录

```bash
ls -la ~/.tmux/resurrect/
```

如果有保存过，应该看到：
- `last` - 最新的保存（符号链接）
- `tmux_resurrect_*.txt` - 历史保存文件

### 4. 测试保存和恢复

#### 测试保存：
```bash
# 1. 创建测试会话
tmux new -s test

# 2. 创建几个窗口和窗格
Ctrl+a c  # 新窗口
Ctrl+a |  # 垂直分割

# 3. 手动保存
Ctrl+a Ctrl+s

# 4. 检查保存文件
ls -lh ~/.tmux/resurrect/
```

#### 测试恢复：
```bash
# 1. 杀死所有 tmux 会话
tmux kill-server

# 2. 重新启动 tmux
tmux

# 3. 应该自动恢复（等待几秒）
# 或手动恢复
Ctrl+a Ctrl+r

# 4. 检查会话是否恢复
tmux ls
```

## 推荐工作流程

### 日常使用

1. **启动 tmux**：
   ```bash
   tmux
   ```

2. **创建会话**：
   ```bash
   tmux new -s work
   tmux new -s dev
   ```

3. **工作中**：
   - tmux-continuum 每 5 分钟自动保存
   - 无需手动操作

4. **关机前**（可选）：
   ```bash
   # 手动保存一次确保最新状态
   Ctrl+a Ctrl+s
   ```

5. **重启后**：
   ```bash
   # 启动 tmux（会自动恢复）
   tmux
   
   # 如果没有自动恢复，手动恢复
   Ctrl+a Ctrl+r
   ```

### 最佳实践

1. **定期检查保存**：
   ```bash
   # 查看最后保存时间
   ls -lh ~/.tmux/resurrect/last
   ```

2. **重要工作前手动保存**：
   ```bash
   Ctrl+a Ctrl+s
   ```

3. **使用有意义的会话名**：
   ```bash
   tmux new -s project-name
   ```

4. **不要依赖自动恢复处理临时数据**：
   - 重要数据要保存到文件
   - 长时间运行的任务使用 `nohup` 或 `screen`

## 故障排查

### 问题 1：重启后没有自动恢复

**检查**：
```bash
# 1. 检查是否有保存文件
ls -la ~/.tmux/resurrect/

# 2. 查看保存文件内容
cat ~/.tmux/resurrect/last
```

**解决**：
```bash
# 手动恢复
Ctrl+a Ctrl+r
```

### 问题 2：保存文件不存在

**原因**：从未保存过会话

**解决**：
```bash
# 手动保存一次
Ctrl+a Ctrl+s

# 检查是否生成文件
ls -la ~/.tmux/resurrect/
```

### 问题 3：恢复后窗格内容为空

**原因**：tmux-resurrect 只恢复窗口和窗格布局，不恢复进程

**解决**：
- 配置 `@resurrect-capture-pane-contents 'on'` 可以恢复部分内容
- 但无法恢复正在运行的程序（如 vim、ssh）
- 需要手动重新启动这些程序

### 问题 4：自动保存不工作

**检查**：
```bash
# 查看 continuum 状态
tmux show-option -g @continuum-save-interval
```

**解决**：
```bash
# 重新安装插件
Ctrl+a I

# 重载配置
Ctrl+a r
```

## 高级配置

### 1. 调整自动保存间隔

```bash
# 改为每 10 分钟保存一次
set -g @continuum-save-interval '10'

# 改为每 1 分钟保存一次（不推荐，太频繁）
set -g @continuum-save-interval '1'
```

### 2. 保存更多内容

```bash
# 保存窗格内容
set -g @resurrect-capture-pane-contents 'on'

# 保存 vim 会话
set -g @resurrect-strategy-vim 'session'

# 保存 neovim 会话
set -g @resurrect-strategy-nvim 'session'

# 恢复窗格内容
set -g @resurrect-processes 'ssh mysql psql'
```

### 3. 自定义保存目录

```bash
# 改变保存目录
set -g @resurrect-dir '~/.tmux/resurrect-backup'
```

### 4. 禁用自动恢复

```bash
# 只自动保存，不自动恢复
set -g @continuum-restore 'off'
```

## 总结

### 当前配置状态

你的配置已经启用了自动保存和恢复：
```bash
set -g @continuum-restore 'on'
set -g @continuum-save-interval '5'
```

### 为什么重启后会话丢失

- ✅ **会话数据已保存**（如果之前运行过 tmux）
- ❌ **tmux 进程未自动启动**（需要手动启动）
- ✅ **启动后会自动恢复**（如果有保存数据）

### 推荐方案

**方案 1（最简单）**：
- 重启后手动启动 tmux：`tmux`
- 会自动恢复上次的会话
- 如果没有自动恢复，按 `Ctrl+a Ctrl+r`

**方案 2（最自动）**：
- 使用 systemd 服务自动启动 tmux
- 重启后自动恢复会话
- 需要手动连接：`tmux attach`

**方案 3（最灵活）**：
- 在 `~/.bashrc` 中添加自动启动脚本
- 打开终端自动进入 tmux
- 自动恢复会话

选择适合你的方案即可！
