# Tmux 配置更新日志

## 2026-02-09 - 智能状态栏功能

### 新增功能 ⭐

#### 智能状态栏（Smart Status Bar）

自动检测窗格类型并显示相应的系统信息：

**本地窗格**：
```
LOCAL | CPU 3.4% | MEM 17Gi/30Gi | / 27G/64G | HOME 55G/257G
```

**SSH 窗格**：
```
@ root@wfh1688:22 (10.0.0.139) | CPU 5.2% | MEM 2.1G/4G | / 15G/50G
```

### 功能特性

- ✅ **自动识别**：无需手动切换，自动检测本地/远程窗格
- ✅ **实时监控**：显示 CPU、内存、磁盘使用情况
- ✅ **SSH 支持**：
  - 支持 `ssh user@ip` 直接连接
  - 支持 `~/.ssh/config` 别名连接
  - 自动解析主机名、端口、IP 地址
- ✅ **远程监控**：通过 SSH 获取远程服务器的系统信息
- ✅ **颜色高亮**：非标准端口（非 22）使用黄色高亮
- ✅ **Git 集成**：自动显示当前目录的 Git 分支

### 使用方法

#### 1. 重载配置

```bash
# 在 tmux 中按
Ctrl+a r

# 或者执行
tmux source-file ~/.tmux.conf
```

#### 2. 测试本地窗格

在当前窗格中，状态栏应该显示本地系统信息。

#### 3. 测试 SSH 窗格

```bash
# 使用 ~/.ssh/config 别名
ssh wfh1688

# 或直接连接
ssh root@10.0.0.139
```

状态栏应该自动切换为显示远程服务器信息。

### 前置要求

#### SSH 密钥认证（重要！）

为了获取远程服务器信息，需要配置 SSH 密钥认证（无密码登录）：

```bash
# 1. 生成密钥（如果还没有）
ssh-keygen -t rsa

# 2. 复制公钥到服务器
ssh-copy-id root@10.0.0.139

# 3. 测试无密码登录
ssh root@10.0.0.139 "echo 'Success!'"
```

如果没有配置密钥认证，SSH 窗格只会显示连接信息，不会显示系统信息。

#### 远程服务器命令

远程服务器需要有以下命令：
- `top` - CPU 使用率
- `free` - 内存使用
- `df` - 磁盘使用

大多数 Linux 发行版默认都有这些命令。

### 技术细节

#### 窗格类型检测

```bash
# 获取窗格进程
pane_pid=$(tmux display-message -p '#{pane_pid}')
pane_command=$(ps -o command= -p $pane_pid)

# 检查是否是 SSH
if echo "$pane_command" | grep -q "^ssh "; then
    # SSH 窗格
else
    # 本地窗格
fi
```

#### SSH 信息解析

支持两种格式：

1. **直接连接**：`ssh user@host -p port`
   - 直接从命令行参数提取

2. **配置别名**：`ssh alias`
   - 从 `~/.ssh/config` 读取配置
   - 解析 `HostName`、`User`、`Port`

#### 远程信息获取

```bash
ssh -o ConnectTimeout=2 -o BatchMode=yes $ssh_host "
    cpu=\$(top -bn1 | grep 'Cpu(s)' | awk '{print \$2}')
    mem=\$(free -h | awk 'NR==2{printf \"%s/%s\", \$3, \$2}')
    disk=\$(df -h / | awk 'NR==2{print \$3\"/\"\$2}')
    echo \"CPU \${cpu}% | MEM \${mem} | / \${disk}\"
"
```

### 性能优化

#### 刷新频率

默认每 2 秒刷新一次：
```bash
set -g status-interval 2
```

如果觉得太频繁，可以改为 5 秒：
```bash
set -g status-interval 5
```

#### SSH 超时

远程命令设置了 2 秒超时，避免长时间等待：
```bash
ssh -o ConnectTimeout=2 ...
```

### 故障排查

#### 问题 1：SSH 窗格不显示系统信息

**原因**：未配置 SSH 密钥认证

**解决**：
```bash
ssh-copy-id root@10.0.0.139
```

#### 问题 2：脚本没有输出

**检查**：
```bash
# 手动运行脚本
bash ~/.tmux/scripts/smart-status.sh

# 检查权限
ls -l ~/.tmux/scripts/smart-status.sh

# 添加执行权限
chmod +x ~/.tmux/scripts/smart-status.sh
```

#### 问题 3：状态栏不更新

**解决**：
```bash
# 重载配置
tmux source-file ~/.tmux.conf

# 或重启 tmux
tmux kill-server
tmux
```

### 自定义配置

#### 修改显示格式

编辑 `~/.tmux/scripts/smart-status.sh`：

```bash
# 本地显示
echo "LOCAL | CPU ${cpu}% | MEM ${mem} | / ${disk} | HOME ${home}"

# SSH 显示
echo "@ ${user}@${host}:${port} | ${remote_info}"
```

#### 修改颜色

编辑 `.tmux.conf`：

```bash
# 当前（灰色）
#[fg=#7f849c]#(~/.tmux/scripts/smart-status.sh)

# 改为绿色
#[fg=#a6e3a1]#(~/.tmux/scripts/smart-status.sh)

# 改为黄色
#[fg=#f9e2af]#(~/.tmux/scripts/smart-status.sh)
```
