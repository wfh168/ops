# Tmux 会话保存和恢复完整指南

## 🎯 你的配置已经包含自动保存功能！

你的 `.tmux.conf` 中已经配置了：

```bash
# 会话保存和恢复插件
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @plugin 'tmux-plugins/tmux-continuum'

# 自动保存（每 5 分钟）
set -g @continuum-restore 'on'
set -g @continuum-save-interval '5'

# 保存窗格内容
set -g @resurrect-capture-pane-contents 'on'
set -g @resurrect-strategy-nvim 'session'
```

## 🚀 快速设置（3步完成）

### 第 1 步：安装 TPM（插件管理器）

```bash
# 克隆 TPM 到本地
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

### 第 2 步：应用配置

```bash
# 使用优化后的配置
cp tmux使用指南/.tmux.conf ~/.tmux.conf

# 启动 tmux
tmux

# 或者如果已经在 tmux 中，重新加载配置
tmux source ~/.tmux.conf
```

### 第 3 步：安装插件

在 tmux 中按：

```bash
Ctrl+a I    # 大写的 I（Install）
```

等待几秒，插件会自动安装。你会看到类似这样的提示：
```
Installing plugins...
  tmux-resurrect
  tmux-continuum
  tmux-cpu
Done!
```

## ✅ 验证安装

### 检查插件是否安装成功

```bash
# 查看插件目录
ls ~/.tmux/plugins/

# 应该看到：
# tmux-continuum/
# tmux-cpu/
# tmux-resurrect/
# tpm/
```

### 检查自动保存是否启用

```bash
# 在 tmux 中执行
Ctrl+a :display-message "Continuum status: #{continuum_status}"

# 应该显示类似：
# Continuum status: on
```

## 📖 使用方法

### 自动保存（已启用）

配置完成后，tmux 会：
- ✅ **每 5 分钟自动保存**一次会话
- ✅ **启动 tmux 时自动恢复**上次的会话
- ✅ **保存窗格内容**（包括滚动历史）
- ✅ **保存窗口布局**

### 手动保存和恢复

虽然有自动保存，但你也可以手动操作：

```bash
# 手动保存当前会话
Ctrl+a Ctrl+s

# 手动恢复上次保存的会话
Ctrl+a Ctrl+r
```

## 🔍 保存的内容

### 会保存什么？

✅ **会保存：**
- 会话名称
- 窗口数量和名称
- 窗格布局
- 窗格的工作目录
- 窗格中运行的程序
- 窗格的滚动历史（如果启用）

❌ **不会保存：**
- 程序的运行状态（程序会重新启动）
- 程序的内部状态（如 vim 未保存的编辑）
- SSH 连接（需要重新连接）

### 保存文件位置

```bash
# 保存文件存储在
~/.tmux/resurrect/

# 查看保存的文件
ls -lh ~/.tmux/resurrect/

# 最新的保存会链接到 last
ls -l ~/.tmux/resurrect/last
```

## 🎬 完整演示

### 场景：关机前后的会话恢复

```bash
# 1. 创建一些工作环境
tmux new -s work

# 窗口 1：编辑器
Ctrl+a c
cd ~/project
vim main.py

# 窗口 2：服务器（分割窗格）
Ctrl+a c
Ctrl+a |
cd ~/project
npm run dev

# 窗口 3：日志监控
Ctrl+a c
tail -f /var/log/syslog

# 2. 手动保存（可选，因为有自动保存）
Ctrl+a Ctrl+s

# 3. 关机
sudo shutdown -h now

# ========== 重启后 ==========

# 4. 启动 tmux
tmux

# 🎉 自动恢复！所有窗口、窗格、布局都回来了！
# 程序会重新启动（但需要你手动重新运行命令）
```

## ⚙️ 高级配置

### 调整自动保存间隔

```bash
# 在 ~/.tmux.conf 中修改
set -g @continuum-save-interval '5'    # 5 分钟（默认）
set -g @continuum-save-interval '15'   # 15 分钟
set -g @continuum-save-interval '0'    # 禁用自动保存
```

### 禁用自动恢复

```bash
# 如果不想启动时自动恢复
set -g @continuum-restore 'off'

# 然后手动恢复
Ctrl+a Ctrl+r
```

### 保存特定程序的状态

```bash
# 保存 vim 会话
set -g @resurrect-strategy-vim 'session'

# 保存 nvim 会话
set -g @resurrect-strategy-nvim 'session'

# 保存其他程序
set -g @resurrect-processes 'ssh mysql psql'
```

### 完整的高级配置示例

```bash
# ==================== Resurrect & Continuum 配置 ====================

# 基础插件
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @plugin 'tmux-plugins/tmux-continuum'

# 自动保存间隔（分钟）
set -g @continuum-save-interval '5'

# 启动时自动恢复
set -g @continuum-restore 'on'

# 保存窗格内容
set -g @resurrect-capture-pane-contents 'on'

# 保存编辑器会话
set -g @resurrect-strategy-vim 'session'
set -g @resurrect-strategy-nvim 'session'

# 保存特定程序
set -g @resurrect-processes 'ssh mysql psql redis-cli'

# 保存目录
set -g @resurrect-dir '~/.tmux/resurrect'
```

## 🐛 常见问题

### 问题 1：插件安装失败

**症状：** 按 `Ctrl+a I` 没反应

**解决：**
```bash
# 1. 检查 TPM 是否安装
ls ~/.tmux/plugins/tpm

# 2. 如果没有，重新安装
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm

# 3. 重启 tmux
tmux kill-server
tmux

# 4. 再次安装插件
Ctrl+a I
```

### 问题 2：自动恢复不工作

**症状：** 重启后没有自动恢复会话

**解决：**
```bash
# 1. 检查配置
grep continuum-restore ~/.tmux.conf

# 应该显示：
# set -g @continuum-restore 'on'

# 2. 检查是否有保存文件
ls ~/.tmux/resurrect/

# 3. 手动恢复测试
Ctrl+a Ctrl+r

# 4. 查看 continuum 状态
Ctrl+a :display-message "#{continuum_status}"
```

### 问题 3：程序没有恢复

**症状：** 窗格恢复了，但程序没有运行

**原因：** Resurrect 只保存程序名称，不保存运行状态

**解决：**
```bash
# 需要在配置中指定要恢复的程序
set -g @resurrect-processes 'vim nvim ssh mysql'

# 然后重新加载配置
tmux source ~/.tmux.conf
```

### 问题 4：保存文件太大

**症状：** `~/.tmux/resurrect/` 目录占用空间大

**解决：**
```bash
# 清理旧的保存文件（保留最近 5 个）
cd ~/.tmux/resurrect/
ls -t | tail -n +6 | xargs rm -f

# 或者禁用窗格内容保存
set -g @resurrect-capture-pane-contents 'off'
```
