# 数据库学习指南

欢迎学习数据库技术！本模块涵盖 MySQL 从初级到高级的完整学习路径。

---

## 📚 学习内容

### MySQL 初级（6 个文档）

**学习目标**：掌握 MySQL 基础操作和 SQL 语法

1. **MySQL 安装与配置** - 安装、配置、用户管理
2. **SQL 基础语法** - DDL、数据类型、约束
3. **数据操作（DML）** - INSERT、UPDATE、DELETE
4. **数据查询（DQL）** - SELECT、WHERE、排序、分页
5. **多表查询** - JOIN、子查询、UNION
6. **函数与运算符** - 字符串、数值、日期函数

**学习时间**：10 天  
**难度**：⭐⭐

---

### MySQL 中级（6 个文档）

**学习目标**：掌握索引优化、视图、存储过程等高级特性

1. **索引原理与优化** - 索引类型、创建、优化
2. **视图与临时表** - 视图创建、临时表使用
3. **存储过程与函数** - 创建存储过程、函数
4. **触发器** - 触发器创建和应用
5. **事务与锁** - 事务隔离级别、锁机制
6. **SQL 优化** - 慢查询分析、执行计划

**学习时间**：12 天  
**难度**：⭐⭐⭐

---

### MySQL 高级（6 个文档）

**学习目标**：掌握 MySQL 架构设计、性能调优、高可用方案

1. **MySQL 架构原理** - 存储引擎、日志系统
2. **主从复制** - 主从配置、读写分离
3. **性能调优** - 参数优化、硬件优化
4. **备份与恢复** - 备份策略、恢复方案
5. **高可用架构** - MHA、MGR、ProxySQL
6. **分库分表** - 分片策略、中间件

**学习时间**：15 天  
**难度**：⭐⭐⭐⭐

## 💻 实验环境

### 最小配置
- CPU：2核
- 内存：2GB
- 硬盘：20GB
- 操作系统：CentOS 7/8 或 Ubuntu 18.04+

### 推荐配置
- CPU：4核
- 内存：8GB
- 硬盘：100GB
- SSD 硬盘

### 软件要求
- MySQL 5.7 或 8.0
- MySQL Workbench（可选）
- Navicat（可选）
