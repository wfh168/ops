# MySQL 中级学习指南

欢迎学习 MySQL 中级课程！本模块将深入学习索引优化、存储过程、事务等高级特性。

---

## 📚 学习目标

完成本模块后，你将能够：

✅ 理解索引原理和类型  
✅ 创建和优化索引  
✅ 使用视图和临时表  
✅ 编写存储过程和函数  
✅ 创建和使用触发器  
✅ 理解事务隔离级别和锁机制  
✅ 分析和优化慢查询  
✅ 使用 EXPLAIN 分析执行计划  

---

## 📖 学习内容

### 1️⃣ 索引原理与优化
- 索引的作用和原理
- B+Tree 索引结构
- 索引类型（主键、唯一、普通、全文）
- 创建和删除索引
- 索引优化策略
- 索引失效场景

**学习时间**：2天  
**难度**：⭐⭐⭐

---

### 2️⃣ 视图与临时表
- 视图的创建和使用
- 视图的优缺点
- 临时表的使用
- 内存表
- 视图和临时表的应用场景

**学习时间**：1.5天  
**难度**：⭐⭐

---

### 3️⃣ 存储过程与函数
- 存储过程基础
- 变量和参数
- 流程控制
- 游标使用
- 自定义函数
- 存储过程优化

**学习时间**：2.5天  
**难度**：⭐⭐⭐

---

### 4️⃣ 触发器
- 触发器概念
- 创建触发器
- BEFORE 和 AFTER 触发器
- INSERT、UPDATE、DELETE 触发器
- 触发器应用场景
- 触发器注意事项

**学习时间**：1.5天  
**难度**：⭐⭐⭐

---

### 5️⃣ 事务与锁
- 事务的 ACID 特性
- 事务隔离级别
- 锁的类型和机制
- 死锁问题
- MVCC 多版本并发控制
- 事务优化

**学习时间**：2.5天  
**难度**：⭐⭐⭐⭐

---

### 6️⃣ SQL 优化
- 慢查询日志
- EXPLAIN 执行计划
- 索引优化
- 查询优化
- 表结构优化
- 配置优化

**学习时间**：2天  
**难度**：⭐⭐⭐⭐

---


## 💻 实验环境

### 软件要求
- MySQL 5.7 或 8.0
- MySQL Workbench
- Sysbench（性能测试工具）

### 系统要求
- CPU：4核
- 内存：4GB
- 硬盘：50GB
