# 视图与临时表

## 一、视图（VIEW）

### 1.1 什么是视图

视图是一个虚拟表，其内容由查询定义。视图不存储数据，只存储查询语句。

**优点**：
- 简化复杂查询
- 提高安全性（隐藏敏感列）
- 逻辑数据独立性
- 提高代码复用性

**缺点**：
- 性能可能较差
- 修改限制较多
- 依赖基表结构

### 1.2 创建视图

```sql
-- 基本语法
CREATE VIEW view_name AS
SELECT column1, column2, ...
FROM table_name
WHERE condition;

-- 示例：学生班级视图
CREATE VIEW v_student_class AS
SELECT 
    s.id,
    s.name AS student_name,
    s.age,
    c.name AS class_name,
    c.teacher
FROM students s
LEFT JOIN classes c ON s.class_id = c.id;

-- 使用视图
SELECT * FROM v_student_class;
SELECT * FROM v_student_class WHERE age > 20;

-- 创建或替换视图
CREATE OR REPLACE VIEW v_student_class AS
SELECT 
    s.id,
    s.name AS student_name,
    s.age,
    s.gender,
    c.name AS class_name
FROM students s
LEFT JOIN classes c ON s.class_id = c.id;
```

### 1.3 查看视图

```sql
-- 查看所有视图
SHOW TABLES;

-- 查看视图定义
SHOW CREATE VIEW v_student_class;

-- 查看视图结构
DESC v_student_class;

-- 从 information_schema 查询
SELECT * FROM information_schema.VIEWS
WHERE table_schema = 'mydb';
```

### 1.4 修改视图

```sql
-- 方式1：CREATE OR REPLACE
CREATE OR REPLACE VIEW v_student_class AS
SELECT s.id, s.name, s.age
FROM students s;

-- 方式2：ALTER VIEW
ALTER VIEW v_student_class AS
SELECT s.id, s.name, s.age, s.gender
FROM students s;
```

### 1.5 删除视图

```sql
-- 删除视图
DROP VIEW v_student_class;

-- 判断存在再删除
DROP VIEW IF EXISTS v_student_class;

-- 删除多个视图
DROP VIEW v_student_class, v_course_info;
```

### 1.6 可更新视图

```sql
-- 简单视图可以更新
CREATE VIEW v_students AS
SELECT id, name, age FROM students;

-- 插入数据
INSERT INTO v_students (name, age) VALUES ('新学生', 20);

-- 更新数据
UPDATE v_students SET age = 21 WHERE id = 1;

-- 删除数据
DELETE FROM v_students WHERE id = 1;

-- 不可更新的视图
-- 1. 包含聚合函数
CREATE VIEW v_class_count AS
SELECT class_id, COUNT(*) AS count FROM students GROUP BY class_id;

-- 2. 包含 DISTINCT
CREATE VIEW v_distinct_age AS
SELECT DISTINCT age FROM students;

-- 3. 包含 JOIN
CREATE VIEW v_student_class AS
SELECT s.*, c.name FROM students s JOIN classes c ON s.class_id = c.id;

-- 4. 包含子查询
-- 5. 包含 UNION
```

### 1.7 WITH CHECK OPTION

```sql
-- 创建带检查选项的视图
CREATE VIEW v_adult_students AS
SELECT * FROM students WHERE age >= 18
WITH CHECK OPTION;

-- ✅ 允许（满足条件）
INSERT INTO v_adult_students (name, age) VALUES ('张三', 20);

-- ❌ 不允许（不满足条件）
INSERT INTO v_adult_students (name, age) VALUES ('李四', 16);
-- ERROR: CHECK OPTION failed

-- 更新也会检查
UPDATE v_adult_students SET age = 16 WHERE id = 1;
-- ERROR: CHECK OPTION failed
```

## 二、临时表

### 2.1 什么是临时表

临时表是会话级别的表，会话结束后自动删除。

**特点**：
- 只对当前会话可见
- 会话结束自动删除
- 可以与普通表同名
- 存储在临时表空间

**使用场景**：
- 存储中间结果
- 复杂查询优化
- 数据处理和转换

### 2.2 创建临时表

```sql
-- 创建临时表
CREATE TEMPORARY TABLE temp_students (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50),
    age INT
);

-- 插入数据
INSERT INTO temp_students (name, age) VALUES
    ('张三', 20),
    ('李四', 21),
    ('王五', 22);

-- 查询临时表
SELECT * FROM temp_students;

-- 从查询结果创建临时表
CREATE TEMPORARY TABLE temp_adult_students AS
SELECT * FROM students WHERE age >= 18;
```

### 2.3 临时表操作

```sql
-- 查询临时表
SELECT * FROM temp_students;

-- 更新临时表
UPDATE temp_students SET age = 21 WHERE id = 1;

-- 删除临时表数据
DELETE FROM temp_students WHERE age < 20;

-- 清空临时表
TRUNCATE TABLE temp_students;

-- 删除临时表
DROP TEMPORARY TABLE temp_students;

-- 判断存在再删除
DROP TEMPORARY TABLE IF EXISTS temp_students;
```

### 2.4 临时表 vs 普通表

| 特性 | 临时表 | 普通表 |
|------|--------|--------|
| 可见性 | 仅当前会话 | 所有会话 |
| 生命周期 | 会话结束删除 | 永久存储 |
| 存储位置 | 临时表空间 | 数据文件 |
| 性能 | 较快 | 一般 |
| 索引 | 支持 | 支持 |

### 2.5 临时表实战案例

```sql
-- 案例：复杂数据统计

-- 1. 创建临时表存储中间结果
CREATE TEMPORARY TABLE temp_class_stats AS
SELECT 
    class_id,
    COUNT(*) AS student_count,
    AVG(age) AS avg_age
FROM students
GROUP BY class_id;

-- 2. 创建另一个临时表
CREATE TEMPORARY TABLE temp_course_stats AS
SELECT 
    course_id,
    COUNT(*) AS enrollment_count,
    AVG(score) AS avg_score
FROM scores
GROUP BY course_id;

-- 3. 关联查询
SELECT 
    c.name AS class_name,
    tcs.student_count,
    tcs.avg_age,
    tcos.enrollment_count,
    tcos.avg_score
FROM classes c
LEFT JOIN temp_class_stats tcs ON c.id = tcs.class_id
LEFT JOIN temp_course_stats tcos ON c.id = tcos.course_id;

-- 4. 会话结束，临时表自动删除
```

## 三、内存表（MEMORY 引擎）

### 3.1 什么是内存表

内存表将数据存储在内存中，访问速度极快。

**特点**：
- 数据存储在内存
- 访问速度快
- 服务器重启数据丢失
- 不支持 TEXT/BLOB 类型
- 只支持固定长度的行

### 3.2 创建内存表

```sql
-- 创建内存表
CREATE TABLE mem_cache (
    id INT PRIMARY KEY,
    key_name VARCHAR(100),
    value VARCHAR(500),
    expire_time DATETIME,
    INDEX idx_key (key_name)
) ENGINE=MEMORY;

-- 插入数据
INSERT INTO mem_cache VALUES
    (1, 'user:1001', '{"name":"张三","age":20}', '2024-01-30 00:00:00'),
    (2, 'user:1002', '{"name":"李四","age":21}', '2024-01-30 00:00:00');

-- 查询数据
SELECT * FROM mem_cache WHERE key_name = 'user:1001';
```

### 3.3 内存表 vs 临时表

| 特性 | 内存表 | 临时表 |
|------|--------|--------|
| 存储位置 | 内存 | 内存或磁盘 |
| 可见性 | 所有会话 | 当前会话 |
| 持久性 | 重启丢失 | 会话结束删除 |
| 性能 | 最快 | 快 |

## 四、实战练习

### 练习1：创建视图

```sql
-- 1. 创建学生成绩视图
CREATE VIEW v_student_scores AS
SELECT 
    s.name AS student_name,
    c.name AS course_name,
    sc.score,
    CASE 
        WHEN sc.score >= 90 THEN '优秀'
        WHEN sc.score >= 80 THEN '良好'
        WHEN sc.score >= 70 THEN '中等'
        WHEN sc.score >= 60 THEN '及格'
        ELSE '不及格'
    END AS grade
FROM students s
JOIN scores sc ON s.id = sc.student_id
JOIN courses c ON sc.course_id = c.id;

-- 2. 使用视图查询
SELECT * FROM v_student_scores WHERE grade = '优秀';
```

### 练习2：使用临时表

```sql
-- 1. 创建临时表存储统计结果
CREATE TEMPORARY TABLE temp_stats AS
SELECT 
    class_id,
    COUNT(*) AS count,
    AVG(age) AS avg_age,
    MAX(age) AS max_age,
    MIN(age) AS min_age
FROM students
GROUP BY class_id;

-- 2. 查询临时表
SELECT * FROM temp_stats WHERE count > 5;

-- 3. 关联查询
SELECT 
    c.name AS class_name,
    t.count,
    t.avg_age
FROM classes c
JOIN temp_stats t ON c.id = t.class_id;
```
