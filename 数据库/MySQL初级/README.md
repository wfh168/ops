# MySQL 初级学习指南

欢迎学习 MySQL 数据库！本模块将带你从零开始掌握 MySQL 基础知识。

---

## 📚 学习目标

完成本模块后，你将能够：

✅ 理解数据库基本概念  
✅ 安装和配置 MySQL  
✅ 掌握 SQL 基础语法  
✅ 进行数据库和表的基本操作  
✅ 掌握数据的增删改查  
✅ 理解数据类型和约束  
✅ 使用基本函数和运算符  
✅ 进行简单的数据查询和统计  

---

## 📖 学习内容

### 1️⃣ MySQL 安装与配置
- MySQL 简介和版本选择
- Linux 环境安装
- Windows 环境安装
- 初始化配置
- 客户端工具使用
- 基本管理命令

**学习时间**：1天  
**难度**：⭐

---

### 2️⃣ SQL 基础语法
- SQL 语言分类（DDL、DML、DQL、DCL）
- 数据库操作
- 数据表操作
- 数据类型详解
- 约束条件
- 字符集和校对规则

**学习时间**：2天  
**难度**：⭐⭐

---

### 3️⃣ 数据操作（DML）
- INSERT 插入数据
- UPDATE 更新数据
- DELETE 删除数据
- TRUNCATE 清空表
- 批量操作
- 事务基础

**学习时间**：1.5天  
**难度**：⭐⭐

---

### 4️⃣ 数据查询（DQL）
- SELECT 基础查询
- WHERE 条件过滤
- ORDER BY 排序
- LIMIT 分页
- 聚合函数
- GROUP BY 分组
- HAVING 分组过滤

**学习时间**：2天  
**难度**：⭐⭐

---

### 5️⃣ 多表查询
- 内连接（INNER JOIN）
- 左连接（LEFT JOIN）
- 右连接（RIGHT JOIN）
- 全连接（FULL JOIN）
- 交叉连接（CROSS JOIN）
- 子查询
- 联合查询（UNION）

**学习时间**：2天  
**难度**：⭐⭐⭐

---

### 6️⃣ 函数与运算符
- 字符串函数
- 数值函数
- 日期时间函数
- 条件函数
- 系统函数
- 运算符详解

**学习时间**：1.5天  
**难度**：⭐⭐

---

## 🎯 学习路线

```
第1天：安装配置
  ├─ MySQL 安装
  ├─ 基本配置
  ├─ 客户端使用
  └─ 管理命令

第2-3天：SQL 基础
  ├─ 数据库操作
  ├─ 数据表操作
  ├─ 数据类型
  └─ 约束条件

第4-5天：数据操作
  ├─ 插入数据
  ├─ 更新数据
  ├─ 删除数据
  └─ 基础查询

第6-7天：高级查询
  ├─ 条件过滤
  ├─ 排序分页
  ├─ 聚合统计
  └─ 分组查询

第8-9天：多表查询
  ├─ 表连接
  ├─ 子查询
  └─ 联合查询

第10天：函数运算
  ├─ 常用函数
  ├─ 运算符
  └─ 综合练习
```

## 💻 实验环境

### 软件要求
- MySQL 5.7 或 8.0
- MySQL Workbench（可选）
- Navicat（可选）

### 系统要求
- CPU：2核
- 内存：2GB
- 硬盘：20GB
- 操作系统：CentOS 7/8 或 Ubuntu 18.04+
