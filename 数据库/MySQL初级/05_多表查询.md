# 多表查询

## 一、多表查询概述

### 1.1 为什么需要多表查询

在实际应用中，数据通常分散在多个表中，需要通过多表查询来获取完整的信息。

**示例场景**：
- 学生表 + 班级表 → 查询学生所在班级信息
- 订单表 + 用户表 → 查询订单的用户信息
- 文章表 + 作者表 → 查询文章的作者信息

### 1.2 准备测试数据

```sql
-- 创建班级表
CREATE TABLE classes (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    teacher VARCHAR(50)
);

-- 创建学生表
CREATE TABLE students (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    age INT,
    class_id INT,
    FOREIGN KEY (class_id) REFERENCES classes(id)
);

-- 创建课程表
CREATE TABLE courses (
    id INT PRIMARY KEY AUTO_INCREMENT,

    credit DECIMAL(3,1)

-- 创建成绩表
CREATE TABLE scores (
    id INT PRIMARY KEY AUTO_INCREMENT,
    student_id INT,
```

## 二、笛卡尔积

### 2.1 什么是笛卡尔积

笛卡尔积是两个表的所有行的组合，结果行数 = 表1行数 × 表2行数。

```sql
-- 笛卡尔积（不推荐）
SELECT * FROM students, classes;

-- 结果：6个学生 × 3个班级 = 18行记录
```

### 2.2 避免笛卡尔积

```sql
-- 使用 WHERE 条件关联
SELECT * FROM students, classes
WHERE students.class_id = classes.id;

-- 使用 JOIN（推荐）
SELECT * FROM students
JOIN classes ON students.class_id = classes.id;
```

## 三、内连接（INNER JOIN）

### 3.1 基本语法

```sql
SELECT columns
FROM table1
INNER JOIN table2 ON table1.column = table2.column;

-- INNER 可以省略
SELECT columns
FROM table1
JOIN table2 ON table1.column = table2.column;
```

### 3.2 两表内连接

```sql
-- 查询学生和班级信息
SELECT 
    students.id,
    students.name AS student_name,
    students.age,
    classes.name AS class_name,
    classes.teacher
FROM students
INNER JOIN classes ON students.class_id = classes.id;

-- 使用表别名（推荐）
SELECT 
    s.id,
    s.name AS student_name,
    s.age,
    c.name AS class_name,
    c.teacher
FROM students s
INNER JOIN classes c ON s.class_id = c.id;
```

### 3.3 多表内连接

```sql
-- 查询学生、课程和成绩信息
SELECT 
    s.name AS student_name,
    c.name AS course_name,
    sc.score
FROM students s
INNER JOIN scores sc ON s.id = sc.student_id
INNER JOIN courses c ON sc.course_id = c.id;

-- 查询学生、班级、课程和成绩信息
SELECT 
    s.name AS student_name,
    cl.name AS class_name,
    c.name AS course_name,
    sc.score
FROM students s
INNER JOIN classes cl ON s.class_id = cl.id
INNER JOIN scores sc ON s.id = sc.student_id
INNER JOIN courses c ON sc.course_id = c.id;
```

### 3.4 内连接 + WHERE 条件

```sql
-- 查询成绩大于85分的学生和课程
SELECT 
    s.name AS student_name,
    c.name AS course_name,
    sc.score
FROM students s
INNER JOIN scores sc ON s.id = sc.student_id
INNER JOIN courses c ON sc.course_id = c.id
WHERE sc.score > 85;

-- 查询一班学生的成绩
SELECT 
    s.name AS student_name,
    cl.name AS class_name,
    c.name AS course_name,
    sc.score
FROM students s
INNER JOIN classes cl ON s.class_id = cl.id
INNER JOIN scores sc ON s.id = sc.student_id
INNER JOIN courses c ON sc.course_id = c.id
WHERE cl.name = '一班';
```

## 四、左连接（LEFT JOIN）

### 4.1 基本语法

```sql
SELECT columns
FROM table1
LEFT JOIN table2 ON table1.column = table2.column;

-- LEFT OUTER JOIN（OUTER 可省略）
SELECT columns
FROM table1
LEFT OUTER JOIN table2 ON table1.column = table2.column;
```

### 4.2 左连接示例

```sql
-- 查询所有学生和班级信息（包括没有班级的学生）
SELECT 
    s.id,
    s.name AS student_name,
    s.age,
    c.name AS class_name,
    c.teacher
FROM students s
LEFT JOIN classes c ON s.class_id = c.id;

-- 结果：包含"周八"（class_id 为 NULL）
```

### 4.3 查询没有匹配的记录

```sql
-- 查询没有班级的学生
SELECT 
    s.id,
    s.name AS student_name,
    s.age
FROM students s
LEFT JOIN classes c ON s.class_id = c.id
WHERE c.id IS NULL;

-- 查询没有成绩的学生
SELECT 
    s.id,
    s.name AS student_name
FROM students s
LEFT JOIN scores sc ON s.id = sc.student_id
WHERE sc.id IS NULL;
```

### 4.4 左连接 + 聚合

```sql
-- 查询每个学生的选课数量（包括没选课的学生）
SELECT 
    s.name AS student_name,
    COUNT(sc.id) AS course_count
FROM students s
LEFT JOIN scores sc ON s.id = sc.student_id
GROUP BY s.id, s.name;

-- 查询每个学生的平均成绩（包括没成绩的学生）
SELECT 
    s.name AS student_name,
    ROUND(AVG(sc.score), 2) AS avg_score
FROM students s
LEFT JOIN scores sc ON s.id = sc.student_id
GROUP BY s.id, s.name;
```

## 五、右连接（RIGHT JOIN）

### 5.1 基本语法

```sql
SELECT columns
FROM table1
RIGHT JOIN table2 ON table1.column = table2.column;

-- RIGHT OUTER JOIN（OUTER 可省略）
SELECT columns
FROM table1
RIGHT OUTER JOIN table2 ON table1.column = table2.column;
```

### 5.2 右连接示例

```sql
-- 查询所有班级和学生信息（包括没有学生的班级）
SELECT 
    c.id,
    c.name AS class_name,
    c.teacher,
    s.name AS student_name
FROM students s
RIGHT JOIN classes c ON s.class_id = c.id;

-- 等价于左连接（调换表顺序）
SELECT 
    c.id,
    c.name AS class_name,
    c.teacher,
    s.name AS student_name
FROM classes c
LEFT JOIN students s ON c.id = s.class_id;
```

### 5.3 查询没有匹配的记录

```sql
-- 查询没有学生的班级
SELECT 
    c.id,
    c.name AS class_name,
    c.teacher
FROM students s
RIGHT JOIN classes c ON s.class_id = c.id
WHERE s.id IS NULL;

-- 查询没有人选的课程
SELECT 
    c.id,
    c.name AS course_name
FROM scores sc
RIGHT JOIN courses c ON sc.course_id = c.id
WHERE sc.id IS NULL;
```

## 六、全连接（FULL JOIN）

### 6.1 MySQL 不支持 FULL JOIN

MySQL 不直接支持 FULL OUTER JOIN，但可以通过 UNION 实现。

```sql
-- 使用 UNION 模拟全连接
SELECT 
    s.name AS student_name,
    c.name AS class_name
FROM students s
LEFT JOIN classes c ON s.class_id = c.id

UNION

SELECT 
    s.name AS student_name,
    c.name AS class_name
FROM students s
RIGHT JOIN classes c ON s.class_id = c.id;
```

## 七、交叉连接（CROSS JOIN）

### 7.1 基本语法

```sql
SELECT columns
FROM table1
CROSS JOIN table2;

-- 等价于笛卡尔积
SELECT columns
FROM table1, table2;
```

### 7.2 交叉连接示例

```sql
-- 生成学生和课程的所有组合
SELECT 
    s.name AS student_name,
    c.name AS course_name
FROM students s
CROSS JOIN courses c;

-- 结果：6个学生 × 3门课程 = 18行记录
```

## 八、自连接

### 8.1 什么是自连接

自连接是表与自身进行连接，通常用于处理层级关系或比较同表中的数据。

### 8.2 自连接示例

```sql
-- 创建员工表（包含上级关系）
CREATE TABLE employees (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50),
    manager_id INT
);

INSERT INTO employees (name, manager_id) VALUES
    ('张总', NULL),
    ('李经理', 1),
    ('王经理', 1),
    ('赵员工', 2),
    ('孙员工', 2),
    ('周员工', 3);

-- 查询员工和其上级
SELECT 
    e.name AS employee_name,
    m.name AS manager_name
FROM employees e
LEFT JOIN employees m ON e.manager_id = m.id;

-- 查询同一个班级的学生对
SELECT 
    s1.name AS student1,
    s2.name AS student2,
    s1.class_id
FROM students s1
JOIN students s2 ON s1.class_id = s2.class_id
WHERE s1.id < s2.id;
```

## 九、子查询

### 9.1 标量子查询

返回单个值的子查询。

```sql
-- 查询年龄大于平均年龄的学生
SELECT * FROM students
WHERE age > (SELECT AVG(age) FROM students);

-- 查询成绩最高的学生
SELECT * FROM students
WHERE id = (
    SELECT student_id FROM scores
    ORDER BY score DESC LIMIT 1
);
```

### 9.2 列子查询

返回一列值的子查询。

```sql
-- 查询有成绩的学生
SELECT * FROM students
WHERE id IN (SELECT DISTINCT student_id FROM scores);

-- 查询没有成绩的学生
SELECT * FROM students
WHERE id NOT IN (SELECT DISTINCT student_id FROM scores);

-- 查询选了数学课的学生
SELECT * FROM students
WHERE id IN (
    SELECT student_id FROM scores
    WHERE course_id = (SELECT id FROM courses WHERE name = '数学')
);
```

### 9.3 行子查询

返回一行多列的子查询。

```sql
-- 查询年龄和班级都匹配的学生
SELECT * FROM students
WHERE (age, class_id) = (
    SELECT age, class_id FROM students WHERE name = '张三'
);
```

### 9.4 表子查询

返回多行多列的子查询。

```sql
-- 查询每个班级年龄最大的学生
SELECT * FROM students
WHERE (class_id, age) IN (
    SELECT class_id, MAX(age)
    FROM students
    GROUP BY class_id
);

-- 使用子查询作为临时表
SELECT 
    t.class_id,
    t.avg_age,
    c.name AS class_name
FROM (
    SELECT class_id, AVG(age) AS avg_age
    FROM students
    GROUP BY class_id
) t
JOIN classes c ON t.class_id = c.id;
```

### 9.5 EXISTS 子查询

```sql
-- 查询有学生的班级
SELECT * FROM classes c
WHERE EXISTS (
    SELECT 1 FROM students s WHERE s.class_id = c.id
);

-- 查询没有学生的班级
SELECT * FROM classes c
WHERE NOT EXISTS (
    SELECT 1 FROM students s WHERE s.class_id = c.id
);

-- 查询选了数学课的学生
SELECT * FROM students s
WHERE EXISTS (
    SELECT 1 FROM scores sc
    JOIN courses c ON sc.course_id = c.id
    WHERE sc.student_id = s.id AND c.name = '数学'
);
```

## 十、UNION 联合查询

### 10.1 UNION 基础

```sql
-- UNION：合并结果集并去重
SELECT name FROM students
UNION
SELECT name FROM classes;

-- UNION ALL：合并结果集不去重（性能更好）
SELECT name FROM students
UNION ALL
SELECT name FROM classes;
```

### 10.2 UNION 要求

- 每个 SELECT 语句必须有相同数量的列
- 列的数据类型必须兼容
- 列的顺序必须相同

```sql
-- ✅ 正确
SELECT id, name FROM students
UNION
SELECT id, name FROM classes;

-- ❌ 错误：列数不同
SELECT id, name FROM students
UNION
SELECT id FROM classes;

-- ❌ 错误：数据类型不兼容
SELECT id, name FROM students
UNION
SELECT name, id FROM classes;
```

### 10.3 UNION 排序

```sql
-- 对整个结果集排序
SELECT name, age FROM students
UNION
SELECT name, NULL FROM classes
ORDER BY name;

-- 对每个查询分别排序（需要使用括号）
(SELECT name FROM students ORDER BY name LIMIT 3)
UNION
(SELECT name FROM classes ORDER BY name LIMIT 3);
```

## 十一、实战练习

### 练习1：内连接

```sql
-- 1. 查询所有学生的姓名、年龄和班级名称
SELECT s.name, s.age, c.name AS class_name
FROM students s
JOIN classes c ON s.class_id = c.id;

-- 2. 查询所有学生的成绩信息
SELECT s.name, c.name AS course_name, sc.score
FROM students s
JOIN scores sc ON s.id = sc.student_id
JOIN courses c ON sc.course_id = c.id;

-- 3. 查询一班学生的平均成绩
SELECT AVG(sc.score) AS avg_score
FROM students s
JOIN classes cl ON s.class_id = cl.id
JOIN scores sc ON s.id = sc.student_id
WHERE cl.name = '一班';
```

### 练习2：左连接

```sql
-- 1. 查询所有学生的选课数量（包括没选课的）
SELECT s.name, COUNT(sc.id) AS course_count
FROM students s
LEFT JOIN scores sc ON s.id = sc.student_id
GROUP BY s.id, s.name;

-- 2. 查询没有班级的学生
SELECT s.* FROM students s
LEFT JOIN classes c ON s.class_id = c.id
WHERE c.id IS NULL;

-- 3. 查询每个班级的学生数量（包括没学生的班级）
SELECT c.name, COUNT(s.id) AS student_count
FROM classes c
LEFT JOIN students s ON c.id = s.class_id
GROUP BY c.id, c.name;
```

### 练习3：子查询

```sql
-- 1. 查询成绩高于平均分的记录
SELECT * FROM scores
WHERE score > (SELECT AVG(score) FROM scores);

-- 2. 查询选了3门课的学生
SELECT * FROM students
WHERE id IN (
    SELECT student_id FROM scores
    GROUP BY student_id
    HAVING COUNT(*) = 3
);

-- 3. 查询每门课程的最高分学生
SELECT s.name, c.name AS course_name, sc.score
FROM students s
JOIN scores sc ON s.id = sc.student_id
JOIN courses c ON sc.course_id = c.id
WHERE (sc.course_id, sc.score) IN (
    SELECT course_id, MAX(score)
    FROM scores
    GROUP BY course_id
);
```

### 练习4：综合查询

```sql
-- 1. 查询每个班级的平均成绩
SELECT 
    cl.name AS class_name,
    ROUND(AVG(sc.score), 2) AS avg_score
FROM classes cl
JOIN students s ON cl.id = s.class_id
JOIN scores sc ON s.id = sc.student_id
GROUP BY cl.id, cl.name;

-- 2. 查询选课数量最多的学生
SELECT s.name, COUNT(sc.id) AS course_count
FROM students s
JOIN scores sc ON s.id = sc.student_id
GROUP BY s.id, s.name
ORDER BY course_count DESC
LIMIT 1;

-- 3. 查询每门课程的选课人数和平均分
SELECT 
    c.name AS course_name,
    COUNT(sc.student_id) AS student_count,
    ROUND(AVG(sc.score), 2) AS avg_score
FROM courses c
LEFT JOIN scores sc ON c.id = sc.course_id
GROUP BY c.id, c.name;
```
