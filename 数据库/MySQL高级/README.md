# MySQL 高级学习指南

欢迎学习 MySQL 高级课程！本模块将学习 MySQL 架构设计、主从复制、性能调优、高可用方案。

---

## 📚 学习目标

完成本模块后，你将能够：

✅ 理解 MySQL 架构和存储引擎  
✅ 配置主从复制和读写分离  
✅ 进行 MySQL 性能调优  
✅ 设计备份和恢复方案  
✅ 搭建高可用架构  
✅ 理解分库分表方案  
✅ 监控 MySQL 性能  
✅ 处理生产环境故障

### 1️⃣ MySQL 架构原理
- MySQL 架构组成
- InnoDB 存储引擎
- MyISAM 存储引擎
- 日志系统（redo log、undo log、binlog）
- 缓冲池机制
- 查询执行流程

**学习时间**：2.5天  
**难度**：⭐⭐⭐⭐

- GTID 复制

- 主从延迟问题

**学习时间**：2.5天  
**难度**：⭐⭐⭐⭐

---

### 3️⃣ 性能调优
- 硬件优化

## 💻 实验环境

### 硬件要求
- CPU：8核
- 内存：16GB
- 硬盘：200GB SSD
- 网络：千兆网卡

### 软件要求
- MySQL 5.7 或 8.0
- MHA
- ProxySQL
- XtraBackup
- Sysbench
- Prometheus + Grafana

### 服务器数量
- 至少 3 台服务器（主从复制）
- 推荐 5 台服务器（高可用架构）
