# Rsync 文件同步学习指南

## 📚 模块简介

Rsync 是 Linux 系统中最强大的文件同步工具，广泛应用于数据备份、网站同步、代码部署等场景。掌握 Rsync 是 Linux 运维工程师的必备技能。

## 📝 常用命令速查

### 基本同步

```bash
# 本地同步
rsync -av /source/ /dest/

# 远程推送
rsync -avz /source/ root@192.168.1.10:/dest/

# 远程拉取
rsync -avz root@192.168.1.10:/source/ /dest/

# 删除目标多余文件
rsync -av --delete /source/ /dest/

# 模拟运行
rsync -avn /source/ /dest/
```

### 守护进程模式

```bash
# 启动守护进程
rsync --daemon

# 查看模块列表
rsync rsync://192.168.1.10/

# 同步（需要认证）
rsync -avz --password-file=/etc/rsync.password \
  /source/ rsync://user@192.168.1.10/module/
```

### 实时同步

```bash
# 监控目录
inotifywait -m /data/web/

# 递归监控
inotifywait -mr /data/web/

# 监控特定事件
inotifywait -m -e modify,create,delete /data/web/
```

## ⚠️ 注意事项

### 安全注意事项

1. **使用 SSH 密钥认证**：避免密码泄露
2. **限制访问 IP**：使用 hosts allow/deny
3. **设置密码文件权限**：chmod 600
4. **使用 chroot**：提高守护进程安全性
5. **定期审计日志**：检查异常访问

### 性能注意事项

1. **调整块大小**：根据网络环境优化 rsize/wsize
2. **使用压缩**：远程传输使用 -z 选项
3. **限制带宽**：避免占用过多带宽
4. **批量同步**：避免频繁小文件同步
5. **排除不需要的文件**：减少传输量

### 可靠性注意事项

1. **测试后再部署**：使用 -n 选项模拟运行
2. **备份重要数据**：同步前先备份
3. **监控同步状态**：配置日志和告警
4. **处理异常情况**：脚本中添加错误处理
5. **定期检查**：验证同步结果
