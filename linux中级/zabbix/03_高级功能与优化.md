# 高级功能与优化

## Zabbix Proxy 分布式监控

### 什么是 Zabbix Proxy？

**Zabbix Proxy** 是一个代理服务器，用于分担 Zabbix Server 的负载，适用于以下场景：

- **跨网段监控**：监控不同网段的主机
- **大规模监控**：减轻 Server 压力
- **远程监控**：监控远程分支机构

### Proxy 架构

```
┌──────────────┐
│ Zabbix Server│
└──────┬───────┘
       │
   ┌───┴────┬────────┬────────┐
   │        │        │        │
┌──▼──┐  ┌──▼──┐  ┌──▼──┐  ┌──▼──┐
│Proxy│  │Proxy│  │Proxy│  │Agent│
│  1  │  │  2  │  │  3  │  │     │
└──┬──┘  └──┬──┘  └──┬──┘  └─────┘
   │        │        │
 Agents   Agents   Agents
```

### 安装 Zabbix Proxy

```bash
# 1. 安装 Proxy
yum install -y zabbix-proxy-mysql zabbix-sql-scripts

# 2. 创建数据库
mysql -u root -p

CREATE DATABASE zabbix_proxy CHARACTER SET utf8 COLLATE utf8_bin;
CREATE USER 'zabbix_proxy'@'localhost' IDENTIFIED BY 'proxy_password';
GRANT ALL PRIVILEGES ON zabbix_proxy.* TO 'zabbix_proxy'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# 3. 导入数据库结构
zcat /usr/share/doc/zabbix-sql-scripts/mysql/schema.sql.gz | mysql -uzabbix_proxy -p zabbix_proxy

# 4. 配置 Proxy
vim /etc/zabbix/zabbix_proxy.conf

Server=192.168.1.10              # Zabbix Server IP
Hostname=Proxy-Beijing           # Proxy 名称
DBHost=localhost
DBName=zabbix_proxy
DBUser=zabbix_proxy
DBPassword=proxy_password
ProxyMode=0                      # 0=主动模式，1=被动模式

# 5. 启动 Proxy
systemctl start zabbix-proxy
systemctl enable zabbix-proxy
```

### 在 Server 上添加 Proxy

1. 管理 → Proxy
2. 点击 "创建代理"
3. 配置参数：
   - 代理名称：Proxy-Beijing（与配置文件一致）
   - 代理模式：主动式
4. 保存

### 配置主机使用 Proxy

1. 配置 → 主机
2. 选择主机 → 编辑
3. 由代理监控：选择 Proxy-Beijing
4. 保存

## 自动发现和自动注册

### 网络发现

**配置发现规则**：

1. 配置 → 自动发现
2. 点击 "创建发现规则"
3. 配置参数：
   - 名称：Local network discovery
   - IP 范围：192.168.1.1-254
   - 更新间隔：1h
   - 检查：
     - Zabbix agent "system.uname"
     - ICMP ping
4. 保存

**配置发现动作**：

1. 配置 → 动作 → 自动发现动作
2. 点击 "创建动作"
3. 配置条件：
   - 发现规则 = Local network discovery
   - 发现状态 = Up
4. 配置操作：
   - 添加主机
   - 关联模板：Template OS Linux
   - 添加到主机群组：Discovered hosts
5. 保存

### 主动注册

**配置 Agent 主动注册**：

```bash
# Agent 配置
vim /etc/zabbix/zabbix_agentd.conf

ServerActive=192.168.1.10
Hostname=auto-register-host
HostMetadata=Linux

# 重启 Agent
systemctl restart zabbix-agent
```

**配置自动注册动作**：

1. 配置 → 动作 → 自动注册动作
2. 点击 "创建动作"
3. 配置条件：
   - 主机元数据 包含 Linux
4. 配置操作：
   - 添加主机
   - 关联模板
5. 保存

## 低级别自动发现（LLD）

### 什么是 LLD？

**Low-Level Discovery（LLD）** 可以自动发现和创建监控项，适用于：

- 自动发现网络接口
- 自动发现磁盘分区
- 自动发现数据库
- 自动发现进程

### 内置 LLD 规则

Zabbix 模板中包含了常用的 LLD 规则：

- **Network interface discovery**：网络接口发现
- **Mounted filesystem discovery**：文件系统发现
- **CPU discovery**：CPU 发现

### 自定义 LLD 规则

**示例：自动发现 Nginx 虚拟主机**

**步骤 1：创建发现脚本**

```bash
# 创建脚本
vim /etc/zabbix/scripts/nginx_vhost_discovery.sh
```

```bash
#!/bin/bash

# 输出 JSON 格式
echo '{"data":['

# 获取虚拟主机列表
first=1
for vhost in $(ls /etc/nginx/sites-enabled/); do
    if [ $first -eq 0 ]; then
        echo ','
    fi
    first=0
    echo -n "{\"{#VHOST}\":\"$vhost\"}"
done

echo ']}'
```

```bash
# 设置权限
chmod +x /etc/zabbix/scripts/nginx_vhost_discovery.sh

# 测试脚本
/etc/zabbix/scripts/nginx_vhost_discovery.sh
```

**步骤 2：配置 Agent**

```bash
vim /etc/zabbix/zabbix_agentd.conf

# 添加自定义键值
UserParameter=nginx.vhost.discovery,/etc/zabbix/scripts/nginx_vhost_discovery.sh

# 重启 Agent
systemctl restart zabbix-agent
```

**步骤 3：创建发现规则**

1. 配置 → 主机 → 选择主机 → 自动发现规则
2. 点击 "创建发现规则"
3. 配置参数：
   - 名称：Nginx Virtual Host Discovery
   - 类型：Zabbix 客户端
   - 键值：nginx.vhost.discovery
   - 更新间隔：1h
4. 保存

**步骤 4：创建监控项原型**

1. 点击发现规则 → 监控项原型
2. 点击 "创建监控项原型"
3. 配置参数：
   - 名称：Nginx VHost {#VHOST} Status
   - 键值：nginx.vhost.status[{#VHOST}]
4. 保存

## 宏变量

### 什么是宏？

**宏（Macro）** 是 Zabbix 中的变量，用于简化配置和提高灵活性。

### 宏的类型

| 类型 | 作用域 | 示例 |
|------|--------|------|
| **内置宏** | 全局 | {HOST.NAME}、{ITEM.VALUE} |
| **用户宏** | 全局/模板/主机 | {$MYSQL.USER} |

### 常用内置宏

```bash
# 主机相关
{HOST.NAME}          # 主机名称
{HOST.IP}            # 主机 IP
{HOST.CONN}          # 主机连接地址

# 监控项相关
{ITEM.NAME}          # 监控项名称
{ITEM.VALUE}         # 监控项当前值
{ITEM.LASTVALUE}     # 监控项上一个值

# 触发器相关
{TRIGGER.NAME}       # 触发器名称
{TRIGGER.STATUS}     # 触发器状态
{TRIGGER.SEVERITY}   # 触发器严重性

# 时间相关
{DATE}               # 当前日期
{TIME}               # 当前时间
```

### 创建用户宏

**全局宏**：

1. 管理 → 一般 → 宏
2. 点击 "添加"
3. 配置参数：
   - 宏：{$MYSQL.PORT}
   - 值：3306
4. 保存

**主机宏**：

1. 配置 → 主机 → 选择主机 → 宏
2. 点击 "添加"
3. 配置宏和值
4. 保存

### 使用宏

在监控项、触发器中使用宏：

```bash
# 监控项键值
mysql.status[{$MYSQL.PORT}]

# 触发器表达式
{host:mysql.status[{$MYSQL.PORT}].last()}=0

# 告警消息
主机 {HOST.NAME} 的 MySQL 服务（端口 {$MYSQL.PORT}）不可用
```

## 性能优化

### 数据库优化

**MySQL 配置优化**：

```bash
vim /etc/my.cnf

[mysqld]
# InnoDB 优化
innodb_buffer_pool_size = 2G        # 设置为物理内存的 50-70%
innodb_log_file_size = 256M
innodb_flush_log_at_trx_commit = 2
innodb_flush_method = O_DIRECT

# 查询缓存
query_cache_size = 0                # Zabbix 不需要查询缓存
query_cache_type = 0

# 连接数
max_connections = 500

# 临时表
tmp_table_size = 64M
max_heap_table_size = 64M
```

**数据库分区**：

```sql
-- 对 history 表进行分区（按月）
ALTER TABLE history PARTITION BY RANGE (clock) (
    PARTITION p202401 VALUES LESS THAN (UNIX_TIMESTAMP('2024-02-01')),
    PARTITION p202402 VALUES LESS THAN (UNIX_TIMESTAMP('2024-03-01')),
    PARTITION p202403 VALUES LESS THAN (UNIX_TIMESTAMP('2024-04-01'))
);
```

### Zabbix Server 优化

```bash
vim /etc/zabbix/zabbix_server.conf

# 进程数优化
StartPollers=50              # 轮询进程数（默认 5）
StartPollersUnreachable=10   # 不可达主机轮询进程数
StartTrappers=10             # 陷阱进程数
StartPingers=10              # ICMP ping 进程数
StartDiscoverers=5           # 自动发现进程数

# 缓存优化
CacheSize=128M               # 配置缓存（默认 8M）
HistoryCacheSize=64M         # 历史数据缓存（默认 16M）
TrendCacheSize=32M           # 趋势数据缓存（默认 4M）
ValueCacheSize=256M          # 值缓存（默认 8M）

# 超时设置
Timeout=30                   # 超时时间（秒）
```

### 数据保留策略

**配置数据保留时间**：

1. 管理 → 一般 → 管家
2. 配置参数：
   - 覆盖项目历史周期：启用
   - 历史数据保留时间：7d
   - 覆盖项目趋势周期：启用
   - 趋势数据保留时间：365d
3. 保存

**手动清理历史数据**：

```sql
-- 删除 30 天前的历史数据
DELETE FROM history WHERE clock < UNIX_TIMESTAMP(DATE_SUB(NOW(), INTERVAL 30 DAY));
DELETE FROM history_uint WHERE clock < UNIX_TIMESTAMP(DATE_SUB(NOW(), INTERVAL 30 DAY));
DELETE FROM history_str WHERE clock < UNIX_TIMESTAMP(DATE_SUB(NOW(), INTERVAL 30 DAY));
DELETE FROM history_text WHERE clock < UNIX_TIMESTAMP(DATE_SUB(NOW(), INTERVAL 30 DAY));
DELETE FROM history_log WHERE clock < UNIX_TIMESTAMP(DATE_SUB(NOW(), INTERVAL 30 DAY));

-- 优化表
OPTIMIZE TABLE history;
OPTIMIZE TABLE history_uint;
```

### 监控项优化

**减少监控项数量**：
- 禁用不需要的监控项
- 增加更新间隔
- 使用 LLD 代替手动创建

**调整更新间隔**：
- 重要指标：30s-60s
- 一般指标：5m-10m
- 不重要指标：1h

## 高可用配置

### Zabbix Server 高可用

**使用 Keepalived 实现高可用**：

```bash
# 主服务器 Keepalived 配置
vim /etc/keepalived/keepalived.conf

vrrp_script check_zabbix {
    script "/etc/keepalived/check_zabbix.sh"
    interval 2
    weight -20
}

vrrp_instance VI_1 {
    state MASTER
    interface eth0
    virtual_router_id 51
    priority 100
    
    virtual_ipaddress {
        192.168.1.100
    }
    
    track_script {
        check_zabbix
    }
}
```

**健康检查脚本**：

```bash
vim /etc/keepalived/check_zabbix.sh

#!/bin/bash
if [ $(ps -C zabbix_server --no-header | wc -l) -eq 0 ]; then
    exit 1
fi
exit 0
```

使用 MySQL 主从复制或 Galera 集群实现数据库高可用。

### 日志管理

```bash
# 查看 Server 日志
tail -f /var/log/zabbix/zabbix_server.log

# 查看 Agent 日志
tail -f /var/log/zabbix/zabbix_agentd.log

# 日志轮转配置
vim /etc/logrotate.d/zabbix-server

/var/log/zabbix/zabbix_server.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    create 0640 zabbix zabbix
```

### 备份和恢复

**备份配置**：

```bash
#!/bin/bash
# Zabbix 备份脚本

BACKUP_DIR="/backup/zabbix"
DATE=$(date +%Y%m%d)

# 备份数据库
mysqldump -uzabbix -p zabbix | gzip > $BACKUP_DIR/zabbix_db_$DATE.sql.gz

# 备份配置文件
tar -czf $BACKUP_DIR/zabbix_conf_$DATE.tar.gz /etc/zabbix/

# 删除 7 天前的备份
find $BACKUP_DIR -name "*.gz" -mtime +7 -delete
```

**恢复数据**：

```bash
# 恢复数据库
zcat zabbix_db_20240129.sql.gz | mysql -uzabbix -p zabbix

# 恢复配置文件
tar -xzf zabbix_conf_20240129.tar.gz -C /
```
