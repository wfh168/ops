# Zabbix 监控系统学习指南

## 📚 模块简介

Zabbix 是企业级的开源监控解决方案，用于监控服务器、网络设备、应用程序的性能和可用性。掌握 Zabbix 是运维工程师的核心技能之一。

**最少需要 2 台服务器**：

## 📝 常用命令速查

### 服务管理

```bash
# 启动服务
systemctl start zabbix-server zabbix-agent

# 查看状态
systemctl status zabbix-server

# 查看日志
tail -f /var/log/zabbix/zabbix_server.log

# 重启服务
systemctl restart zabbix-server
```

### 数据库操作

```bash
# 登录数据库
mysql -uzabbix -p zabbix

# 查看表
SHOW TABLES;

# 查看主机
SELECT hostid, host, name FROM hosts;

# 清理历史数据
DELETE FROM history WHERE clock < UNIX_TIMESTAMP(DATE_SUB(NOW(), INTERVAL 30 DAY));
```

### Agent 测试

```bash
# 测试监控项
zabbix_agentd -t system.cpu.util[,idle]

# 查看 Agent 配置
zabbix_agentd -p

# 测试连接
zabbix_get -s 192.168.1.20 -k system.cpu.util[,idle]
```

## ⚠️ 注意事项

### 安全注意事项

1. **修改默认密码**：首次登录后立即修改
2. **限制访问**：配置防火墙规则
3. **使用 HTTPS**：配置 SSL 证书
4. **定期更新**：及时更新 Zabbix 版本
5. **备份数据**：定期备份数据库

### 性能注意事项

1. **合理配置进程数**：根据监控规模调整
2. **优化数据库**：配置索引和分区
3. **控制监控项数量**：禁用不需要的监控项
4. **调整更新间隔**：根据重要性设置
5. **使用 Proxy**：大规模监控使用 Proxy

### 可靠性注意事项

1. **配置高可用**：使用 Keepalived 或集群
2. **数据库备份**：定期备份数据库
3. **监控 Zabbix 自身**：监控 Server 状态
4. **告警测试**：定期测试告警功能
5. **文档化**：记录配置和操作流程
