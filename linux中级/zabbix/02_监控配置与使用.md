# 监控配置与使用

## Zabbix 核心概念

### 1. 主机（Host）

被监控的设备或服务器。

### 2. 监控项（Item）

具体的监控指标，如 CPU 使用率、内存使用率等。

### 3. 触发器（Trigger）

定义告警条件，当监控项达到阈值时触发告警。

### 4. 模板（Template）

监控项、触发器、图形的集合，可以批量应用到主机。

### 5. 动作（Action）

告警触发后执行的操作，如发送邮件、执行脚本等。

## 安装 Zabbix Agent

### 在被监控主机上安装

#### CentOS 7

```bash
# 1. 安装 Zabbix 仓库
rpm -Uvh https://repo.zabbix.com/zabbix/5.0/rhel/7/x86_64/zabbix-release-5.0-1.el7.noarch.rpm

# 2. 安装 Zabbix Agent
yum install -y zabbix-agent

# 3. 配置 Agent
vim /etc/zabbix/zabbix_agentd.conf

# 修改以下参数
Server=192.168.1.10              # Zabbix Server IP
ServerActive=192.168.1.10        # 主动模式 Server IP
Hostname=web-server-01           # 主机名（与 Web 界面配置一致）

# 4. 启动 Agent
systemctl start zabbix-agent
systemctl enable zabbix-agent

# 5. 配置防火墙
firewall-cmd --permanent --add-port=10050/tcp
firewall-cmd --reload

# 6. 查看状态
systemctl status zabbix-agent
```

#### Ubuntu/Debian

```bash
# 1. 安装 Zabbix 仓库
wget https://repo.zabbix.com/zabbix/5.0/ubuntu/pool/main/z/zabbix-release/zabbix-release_5.0-1+focal_all.deb
dpkg -i zabbix-release_5.0-1+focal_all.deb

# 2. 更新并安装
apt update
apt install -y zabbix-agent

# 3. 配置 Agent
vim /etc/zabbix/zabbix_agentd.conf

# 4. 启动服务
systemctl start zabbix-agent
systemctl enable zabbix-agent
```

## 添加监控主机

### 方法 1：手动添加

**步骤 1：进入主机配置**
1. 登录 Zabbix Web 界面
2. 配置 → 主机
3. 点击 "创建主机"

**步骤 2：配置主机信息**
- **主机名称**：web-server-01（与 Agent 配置一致）
- **可见名称**：Web 服务器 01
- **群组**：Linux servers（或创建新群组）
- **Agent 接口**：
  - IP 地址：192.168.1.20
  - 端口：10050

**步骤 3：关联模板**
- 点击 "模板" 标签
- 选择 "Template OS Linux by Zabbix agent"
- 点击 "添加"

**步骤 4：保存**
- 点击 "添加" 按钮

**步骤 5：验证**
- 等待 1-2 分钟
- 查看主机状态，ZBX 图标应该变绿

### 方法 2：自动发现

**配置自动发现规则**：

1. 配置 → 自动发现
2. 点击 "创建发现规则"
3. 配置参数：
   - 名称：Local network
   - IP 范围：192.168.1.1-254
   - 更新间隔：1h
   - 检查：Zabbix agent "system.uname"
4. 保存

**配置自动发现动作**：

1. 配置 → 动作 → 自动发现动作
2. 点击 "创建动作"
3. 配置条件和操作
4. 保存

## 监控项配置

### 查看监控项

1. 配置 → 主机
2. 点击主机名称
3. 点击 "监控项" 标签

### 创建自定义监控项

**示例：监控 Nginx 连接数**

**步骤 1：在 Agent 端配置**

```bash
# 1. 创建监控脚本
vim /etc/zabbix/scripts/nginx_status.sh
```

```bash
#!/bin/bash
# 获取 Nginx 连接数

# 配置 Nginx status 模块
# location /nginx_status {
#     stub_status on;
#     access_log off;
#     allow 127.0.0.1;
#     deny all;
# }

case $1 in
    active)
        curl -s http://localhost/nginx_status | grep 'Active' | awk '{print $3}'
        ;;
    reading)
        curl -s http://localhost/nginx_status | grep 'Reading' | awk '{print $2}'
        ;;
    writing)
        curl -s http://localhost/nginx_status | grep 'Writing' | awk '{print $4}'
        ;;
    waiting)
        curl -s http://localhost/nginx_status | grep 'Waiting' | awk '{print $6}'
        ;;
    *)
        echo "Usage: $0 {active|reading|writing|waiting}"
        exit 1
        ;;
esac
```

```bash
# 2. 设置权限
chmod +x /etc/zabbix/scripts/nginx_status.sh

# 3. 配置 Agent
vim /etc/zabbix/zabbix_agentd.conf

# 添加自定义键值
UserParameter=nginx.status[*],/etc/zabbix/scripts/nginx_status.sh $1

# 4. 重启 Agent
systemctl restart zabbix-agent

# 5. 测试
zabbix_agentd -t nginx.status[active]
```

**步骤 2：在 Web 界面创建监控项**

1. 配置 → 主机 → 选择主机 → 监控项
2. 点击 "创建监控项"
3. 配置参数：
   - 名称：Nginx Active Connections
   - 类型：Zabbix 客户端
   - 键值：nginx.status[active]
   - 信息类型：数字（无符号）
   - 更新间隔：60s
4. 保存

## 触发器配置

### 创建触发器

**示例：CPU 使用率告警**

1. 配置 → 主机 → 选择主机 → 触发器
2. 点击 "创建触发器"
3. 配置参数：
   - 名称：CPU 使用率过高
   - 严重性：警告
   - 表达式：`{web-server-01:system.cpu.util[,idle].avg(5m)}<20`
   - 说明：CPU 空闲率低于 20%（即使用率超过 80%）
4. 保存

### 常用触发器表达式

```bash
# CPU 使用率超过 80%
{host:system.cpu.util[,idle].avg(5m)}<20

# 内存使用率超过 80%
{host:vm.memory.size[available].last()}<{host:vm.memory.size[total].last()}*0.2

# 磁盘使用率超过 80%
{host:vfs.fs.size[/,pused].last()}>80

# 磁盘 IO 等待超过 20%
{host:system.cpu.util[,iowait].avg(5m)}>20

# 网络流量超过 100MB/s
{host:net.if.in[eth0].avg(5m)}>100000000

# 进程不存在
{host:proc.num[nginx].last()}=0

# 端口不可达
{host:net.tcp.service[http].last()}=0

# 服务响应时间超过 3 秒
{host:net.tcp.service.perf[http].avg(5m)}>3
```

## 告警配置

### 配置邮件告警

**步骤 1：配置邮件服务器**

1. 管理 → 报警媒介类型
2. 点击 "Email"
3. 配置 SMTP 服务器：
   - SMTP 服务器：smtp.example.com
   - SMTP 服务器端口：25
   - SMTP HELO：zabbix.example.com
   - SMTP 电邮：zabbix@example.com
4. 保存

**步骤 2：配置用户邮箱**

1. 管理 → 用户
2. 点击 "Admin"
3. 报警媒介 → 添加
4. 配置参数：
   - 类型：Email
   - 收件人：admin@example.com
   - 启用时段：1-7,00:00-24:00
5. 保存

**步骤 3：配置告警动作**

1. 配置 → 动作 → 触发器动作
2. 点击 "创建动作"
3. 配置参数：
   - 名称：Send email on problem
   - 条件：触发器示警度 >= 警告
4. 操作：
   - 发送消息给用户：Admin
   - 仅送到：Email
5. 保存

### 配置钉钉告警

**步骤 1：创建钉钉机器人**

1. 打开钉钉群
2. 群设置 → 智能群助手 → 添加机器人
3. 选择 "自定义" → 添加
4. 复制 Webhook 地址

**步骤 2：创建告警脚本**

```bash
# 创建脚本目录
mkdir -p /usr/lib/zabbix/alertscripts

# 创建钉钉告警脚本
vim /usr/lib/zabbix/alertscripts/dingding.sh
```

```bash
#!/bin/bash

# 钉钉机器人 Webhook
WEBHOOK="https://oapi.dingtalk.com/robot/send?access_token=YOUR_TOKEN"

# 接收参数
TO=$1
SUBJECT=$2
MESSAGE=$3

# 发送消息
curl -X POST "$WEBHOOK" \
  -H 'Content-Type: application/json' \
  -d "{
    \"msgtype\": \"text\",
    \"text\": {
      \"content\": \"$SUBJECT\n\n$MESSAGE\"
    }
  }"
```

```bash
# 设置权限
chmod +x /usr/lib/zabbix/alertscripts/dingding.sh
chown zabbix:zabbix /usr/lib/zabbix/alertscripts/dingding.sh

# 测试脚本
/usr/lib/zabbix/alertscripts/dingding.sh "" "测试" "这是一条测试消息"
```

**步骤 3：配置报警媒介**

1. 管理 → 报警媒介类型
2. 点击 "创建报警媒介类型"
3. 配置参数：
   - 名称：DingDing
   - 类型：脚本
   - 脚本名称：dingding.sh
   - 脚本参数：
     - {ALERT.SENDTO}
     - {ALERT.SUBJECT}
     - {ALERT.MESSAGE}
4. 保存

**步骤 4：配置用户报警媒介**

1. 管理 → 用户 → Admin
2. 报警媒介 → 添加
3. 配置参数：
   - 类型：DingDing
   - 收件人：dingding（任意值）
4. 保存

## 实战案例

### 案例 1：监控 Web 服务器

**监控指标**：
- 系统资源：CPU、内存、磁盘、网络
- Nginx 状态：连接数、请求数、响应时间
- 进程监控：Nginx 进程是否存在
- 端口监控：80、443 端口是否开放

**配置步骤**：

```bash
# 1. 安装 Agent
yum install -y zabbix-agent

# 2. 配置 Nginx status
vim /etc/nginx/conf.d/status.conf
```

```nginx
server {
    listen 127.0.0.1:80;
    server_name localhost;
    
    location /nginx_status {
        stub_status on;
        access_log off;
        allow 127.0.0.1;
        deny all;
    }
}
```

```bash
# 3. 重启 Nginx
systemctl restart nginx

# 4. 配置 Agent
vim /etc/zabbix/zabbix_agentd.conf

Server=192.168.1.10
ServerActive=192.168.1.10
Hostname=web-server-01

# 5. 添加自定义监控项
UserParameter=nginx.status[*],/etc/zabbix/scripts/nginx_status.sh $1
UserParameter=nginx.process,ps aux | grep -c '[n]ginx'
UserParameter=nginx.port[*],netstat -tunlp | grep -c ":$1 "

# 6. 重启 Agent
systemctl restart zabbix-agent
```

**Web 界面配置**：

1. 添加主机
2. 关联模板：Template OS Linux by Zabbix agent
3. 创建自定义监控项和触发器
4. 配置告警

### 案例 2：监控 MySQL 数据库

**监控指标**：
- 连接数
- 查询数（QPS）
- 慢查询
- 主从延迟
- 表锁

**配置步骤**：

```bash
# 1. 创建 MySQL 监控用户
mysql -u root -p

CREATE USER 'zabbix'@'localhost' IDENTIFIED BY 'zabbix_password';
GRANT PROCESS, REPLICATION CLIENT ON *.* TO 'zabbix'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# 2. 配置 Agent
vim /etc/zabbix/zabbix_agentd.conf

# 添加 MySQL 监控
UserParameter=mysql.ping,mysqladmin -uzabbix -pzabbix_password ping | grep -c alive
UserParameter=mysql.version,mysql -V
UserParameter=mysql.status[*],mysql -uzabbix -pzabbix_password -e "SHOW GLOBAL STATUS LIKE '$1'" | tail -1 | awk '{print $$2}'

# 3. 重启 Agent
systemctl restart zabbix-agent
```

**Web 界面配置**：

1. 关联模板：Template DB MySQL by Zabbix agent
2. 配置宏变量：
   - {$MYSQL.USER}：zabbix
   - {$MYSQL.PASSWORD}：zabbix_password
3. 启用监控项
