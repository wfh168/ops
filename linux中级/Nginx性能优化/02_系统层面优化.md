# 系统层面优化

## 操作系统优化

### 文件描述符限制

```bash
# 查看当前限制
ulimit -n

# 临时修改（当前会话）
ulimit -n 65535

# 永久修改
# 编辑 /etc/security/limits.conf
cat >> /etc/security/limits.conf << EOF
* soft nofile 65535
* hard nofile 65535
* soft nproc 65535
* hard nproc 65535
EOF

# 编辑 /etc/systemd/system.conf（systemd 系统）
cat >> /etc/systemd/system.conf << EOF
DefaultLimitNOFILE=65535
DefaultLimitNPROC=65535
EOF

# 重启生效
reboot

# 或重新加载 systemd
systemctl daemon-reexec
```

### 系统资源限制

```bash
# 查看所有限制
ulimit -a

# 核心转储文件大小
ulimit -c unlimited

# 最大进程数
ulimit -u 65535

# 最大内存锁定
ulimit -l unlimited
```

## 内核参数优化

### TCP 参数优化

```bash
# 编辑 /etc/sysctl.conf
cat >> /etc/sysctl.conf << EOF

# ===== 网络优化 =====

# TCP 连接队列
net.core.somaxconn = 65535
net.core.netdev_max_backlog = 65535
net.ipv4.tcp_max_syn_backlog = 65535

# TCP 连接复用
net.ipv4.tcp_tw_reuse = 1
net.ipv4.tcp_tw_recycle = 0

# TIME_WAIT 超时时间
net.ipv4.tcp_fin_timeout = 30

# TCP KeepAlive
net.ipv4.tcp_keepalive_time = 600
net.ipv4.tcp_keepalive_probes = 3
net.ipv4.tcp_keepalive_intvl = 15

# TCP 缓冲区
net.core.rmem_default = 262144
net.core.rmem_max = 16777216
net.core.wmem_default = 262144
net.core.wmem_max = 16777216
net.ipv4.tcp_rmem = 4096 87380 16777216
net.ipv4.tcp_wmem = 4096 65536 16777216

# TCP 拥塞控制
net.ipv4.tcp_congestion_control = bbr

# TCP Fast Open
net.ipv4.tcp_fastopen = 3

# TCP SYN Cookies（防 SYN 洪水攻击）
net.ipv4.tcp_syncookies = 1

# TCP 最大孤儿连接数
net.ipv4.tcp_max_orphans = 262144

# IP 本地端口范围
net.ipv4.ip_local_port_range = 1024 65535

# 禁用 ICMP 重定向
net.ipv4.conf.all.send_redirects = 0
net.ipv4.conf.default.send_redirects = 0

# 禁用源路由
net.ipv4.conf.all.accept_source_route = 0
net.ipv4.conf.default.accept_source_route = 0

EOF

# 应用配置
sysctl -p

# 查看配置
sysctl -a | grep tcp
```

### 安全参数

```bash
cat >> /etc/sysctl.conf << EOF

# ===== 安全优化 =====

# 防止 SYN 洪水攻击
net.ipv4.tcp_syncookies = 1
net.ipv4.tcp_syn_retries = 2
net.ipv4.tcp_synack_retries = 2

# 防止 IP 欺骗
net.ipv4.conf.all.rp_filter = 1
net.ipv4.conf.default.rp_filter = 1

# 忽略 ICMP 请求
net.ipv4.icmp_echo_ignore_all = 0
net.ipv4.icmp_echo_ignore_broadcasts = 1

# 忽略错误的 ICMP 消息
net.ipv4.icmp_ignore_bogus_error_responses = 1

EOF

sysctl -p
```

## BBR 拥塞控制算法

### 什么是 BBR？

BBR（Bottleneck Bandwidth and RTT）是 Google 开发的 TCP 拥塞控制算法，可以显著提升网络吞吐量。

### 启用 BBR

```bash
# 检查内核版本（需要 4.9+）
uname -r

# 加载 BBR 模块
modprobe tcp_bbr

# 查看可用的拥塞控制算法
sysctl net.ipv4.tcp_available_congestion_control

# 启用 BBR
cat >> /etc/sysctl.conf << EOF
net.core.default_qdisc = fq
net.ipv4.tcp_congestion_control = bbr
EOF

# 应用配置
sysctl -p

# 验证 BBR 是否启用
sysctl net.ipv4.tcp_congestion_control
lsmod | grep bbr
```

### BBR 效果

```
传统算法（Cubic）：
- 基于丢包判断拥塞
- 高延迟网络性能差

BBR 算法：
- 基于带宽和延迟判断
- 高延迟网络性能好
- 吞吐量提升 2-10 倍
```

## 磁盘 I/O 优化

### 文件系统选择

```bash
# 推荐使用 XFS 或 ext4

# XFS 特点
- 高性能
- 支持大文件
- 适合大量小文件

# ext4 特点
- 稳定可靠
- 兼容性好
- 适合一般场景

# 挂载选项优化
# /etc/fstab
/dev/sda1 /data xfs defaults,noatime,nodiratime 0 0

# noatime：不更新访问时间
# nodiratime：不更新目录访问时间
```

### I/O 调度器

```bash
# 查看当前调度器
cat /sys/block/sda/queue/scheduler

# 可用调度器
[noop] deadline cfq

# 修改调度器（临时）
echo deadline > /sys/block/sda/queue/scheduler

# 修改调度器（永久）
# 编辑 /etc/default/grub
GRUB_CMDLINE_LINUX="elevator=deadline"

# 更新 grub
grub2-mkconfig -o /boot/grub2/grub.cfg

# 调度器选择
noop      # SSD 推荐
deadline  # 机械硬盘推荐
cfq       # 默认，适合桌面
```

### 缓存优化

```bash
# 查看缓存
free -h

# 清理缓存（谨慎使用）
sync
echo 3 > /proc/sys/vm/drop_caches

# 缓存参数
cat >> /etc/sysctl.conf << EOF
vm.vfs_cache_pressure = 50
EOF

sysctl -p
```

## 内存优化

### 透明大页（THP）

```bash
# 查看 THP 状态
cat /sys/kernel/mm/transparent_hugepage/enabled

# 禁用 THP（推荐）
echo never > /sys/kernel/mm/transparent_hugepage/enabled
echo never > /sys/kernel/mm/transparent_hugepage/defrag

# 永久禁用
# 编辑 /etc/rc.local
echo never > /sys/kernel/mm/transparent_hugepage/enabled
echo never > /sys/kernel/mm/transparent_hugepage/defrag

chmod +x /etc/rc.d/rc.local
```

### Swap 优化

```bash
# 查看 swap 使用情况
free -h
swapon -s

# 调整 swappiness（0-100，越小越少使用 swap）
cat >> /etc/sysctl.conf << EOF
vm.swappiness = 10
EOF

sysctl -p

# 禁用 swap（如果内存充足）
swapoff -a

# 永久禁用（注释 /etc/fstab 中的 swap 行）
sed -i '/swap/s/^/#/' /etc/fstab
```

## 防火墙优化

### iptables 优化

```bash
# 使用 ipset 管理大量 IP
yum install ipset -y

# 创建 IP 集合
ipset create whitelist hash:ip

# 添加 IP
ipset add whitelist 192.168.1.100

# iptables 规则
iptables -A INPUT -m set --match-set whitelist src -j ACCEPT

# 使用连接跟踪
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 限制连接数
iptables -A INPUT -p tcp --dport 80 -m connlimit --connlimit-above 100 -j REJECT
```

### firewalld 优化

```bash
# 禁用不必要的服务
firewall-cmd --list-services
firewall-cmd --remove-service=dhcpv6-client --permanent

# 使用 direct 规则（性能更好）
firewall-cmd --direct --add-rule ipv4 filter INPUT 0 -p tcp --dport 80 -j ACCEPT

# 重载配置
firewall-cmd --reload
```

```bash
#!/bin/bash
# nginx_system_optimize.sh

net.ipv4.tcp_fastopen = 3
net.ipv4.tcp_syncookies = 1
net.ipv4.ip_local_port_range = 1024 65535
```
