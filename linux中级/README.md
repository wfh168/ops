## 推荐学习顺序

### 第一阶段：网络基础（2-3周）

1. **HTTP 协议** (2天)
   - HTTP 工作原理
   - 请求和响应
   - 状态码
   - Headers

2. **SSH 远程管理** (2天)
   - SSH 原理
   - 密钥认证
   - SSH 隧道
   - 安全配置

3. **Nginx Web 服务器** (5天)
   - Nginx 安装配置
   - 虚拟主机
   - 反向代理
   - 负载均衡
   - 静态资源优化

4. **HTTPS 加密** (2天)
   - SSL/TLS 原理
   - 证书申请
   - Nginx HTTPS 配置
   - 证书更新

5. **Rewrite 重写** (2天)
   - URL 重写规则
   - 正则表达式
   - 常见应用场景

6. **Nginx 性能优化** (3天)
   - 性能调优参数
   - 缓存配置
   - 压缩优化
   - 连接优化

### 第二阶段：存储与同步（1-2周）

7. **NFS 网络文件系统** (2天)
   - NFS 原理
   - 服务端配置
   - 客户端挂载
   - 权限管理

8. **Rsync 文件同步** (3天)
   - Rsync 基本用法
   - Rsync + SSH
   - Rsync 服务模式
   - 实时同步（inotify）

### 第三阶段：安全与高可用（1-2周）

9. **iptables 防火墙** (3天)
   - iptables 原理
   - 四表五链
   - 规则编写
   - 常见场景

10. **Keepalived 高可用** (3天)
    - VRRP 协议
    - 主备配置
    - 健康检查
    - Nginx 高可用

### 第四阶段：自动化运维（2-3周）

11. **Ansible 自动化** (5天)
    - Ansible 基础
    - Inventory 管理
    - Playbook 编写
    - Roles 角色
    - 实战案例

12. **Zabbix 监控** (5天)
    - Zabbix 架构
    - 安装部署
    - 监控配置
    - 告警设置
    - 自定义监控

### 第五阶段：应用部署（2-3周）

13. **PHP + WordPress 部署** (3天)
    - LNMP 环境搭建
    - WordPress 安装
    - 性能优化
    - 备份策略

14. **Tomcat 集群部署** (4天)
    - Tomcat 安装配置
    - 集群架构
    - Session 共享
    - 负载均衡

15. **阿里云实战** (3天)
    - ECS 云服务器
    - SLB 负载均衡
    - RDS 数据库
    - OSS 对象存储

## 学习建议

### 1. 实践为主
- 每个模块都要实际搭建环境
- 建议使用虚拟机或云服务器
- 记录每一步操作和遇到的问题

### 2. 循序渐进
- 按照推荐顺序学习
- 不要跳过基础模块
- 每个模块学完后做总结

### 3. 项目驱动
- 尝试搭建完整的项目
- 例如：个人博客、企业官网
- 模拟真实的生产环境

### 4. 文档习惯
- 记录配置文件
- 整理常用命令
- 编写部署文档

### 5. 故障排查
- 主动制造故障
- 练习排查问题
- 总结解决方案
