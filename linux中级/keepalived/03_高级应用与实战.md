# 高级应用与实战

## 双主模式

### 什么是双主模式？

**双主模式（Dual Master）** 是指两台服务器互为主备，各自管理一个 VIP，实现负载分担和高可用。

```
服务器 A：
  - VIP1 的 MASTER（优先级 100）
  - VIP2 的 BACKUP（优先级 90）

服务器 B：
  - VIP1 的 BACKUP（优先级 90）
  - VIP2 的 MASTER（优先级 100）
```

### 双主模式配置

#### 服务器 A 配置

```bash
# /etc/keepalived/keepalived.conf (服务器 A)

global_defs {
    router_id SERVER_A
}

# VIP1 实例（MASTER）
vrrp_instance VI_1 {
    state MASTER
    interface eth0
    virtual_router_id 51
    priority 100
    advert_int 1
    
    authentication {
        auth_type PASS
        auth_pass 1111
    }
    
    virtual_ipaddress {
        192.168.1.100
    }
}

# VIP2 实例（BACKUP）
vrrp_instance VI_2 {
    state BACKUP
    interface eth0
    virtual_router_id 52
    priority 90
    advert_int 1
    
    authentication {
        auth_type PASS
        auth_pass 2222
    }
    
    virtual_ipaddress {
        192.168.1.101
    }
}
```

#### 服务器 B 配置

```bash
# /etc/keepalived/keepalived.conf (服务器 B)

global_defs {
    router_id SERVER_B
}

# VIP1 实例（BACKUP）
vrrp_instance VI_1 {
    state BACKUP
    interface eth0
    virtual_router_id 51
    priority 90
    advert_int 1
    
    authentication {
        auth_type PASS
        auth_pass 1111
    }
    
    virtual_ipaddress {
        192.168.1.100
    }
}

# VIP2 实例（MASTER）
vrrp_instance VI_2 {
    state MASTER
    interface eth0
    virtual_router_id 52
    priority 100
    advert_int 1
    
    authentication {
        auth_type PASS
        auth_pass 2222
    }
    
    virtual_ipaddress {
        192.168.1.101
    }
}
```

### 双主模式优势

✅ **负载分担**：两个 VIP 分别处理不同的流量  
✅ **资源利用**：两台服务器都在工作，不浪费资源  
✅ **高可用**：任一服务器故障，另一台接管所有 VIP

## MySQL 主从高可用

### 架构设计

```
┌─────────────────────────────────────┐
│         VIP: 192.168.1.100          │
└────────────┬────────────────────────┘
             │
    ┌────────┴────────┐
    │                 │
┌───▼────┐      ┌─────▼───┐
│ MASTER │      │ BACKUP  │
│ MySQL  │ ───→ │ MySQL   │
│ 主库   │ 主从  │ 从库    │
│192.168.1.10│  │192.168.1.11│
└────────┘      └─────────┘
```

### 配置步骤

#### 1. 配置 MySQL 主从复制

**主库配置**（192.168.1.10）：

```bash
# 编辑 MySQL 配置
vim /etc/my.cnf

[mysqld]
server-id=1
log-bin=mysql-bin
binlog-do-db=mydb

# 重启 MySQL
systemctl restart mysqld

# 创建复制用户
mysql -u root -p
GRANT REPLICATION SLAVE ON *.* TO 'repl'@'192.168.1.11' IDENTIFIED BY 'password';
FLUSH PRIVILEGES;
SHOW MASTER STATUS;
```

**从库配置**（192.168.1.11）：

```bash
# 编辑 MySQL 配置
vim /etc/my.cnf

[mysqld]
server-id=2
relay-log=mysql-relay-bin
read-only=1

# 重启 MySQL
systemctl restart mysqld

# 配置主从复制
mysql -u root -p
CHANGE MASTER TO
  MASTER_HOST='192.168.1.10',
  MASTER_USER='repl',
  MASTER_PASSWORD='password',
  MASTER_LOG_FILE='mysql-bin.000001',
  MASTER_LOG_POS=154;

START SLAVE;
SHOW SLAVE STATUS\G
```

#### 2. 配置 Keepalived

**主库 Keepalived 配置**：

```bash
# /etc/keepalived/keepalived.conf (主库)

global_defs {
    router_id MYSQL_MASTER
}

vrrp_script check_mysql {
    script "/etc/keepalived/check_mysql.sh"
    interval 2
    weight -20
    fall 3
    rise 2
}

vrrp_instance VI_1 {
    state MASTER
    interface eth0
    virtual_router_id 51
    priority 100
    advert_int 1
    
    authentication {
        auth_type PASS
        auth_pass 1111
    }
    
    virtual_ipaddress {
        192.168.1.100
    }
    
    track_script {
        check_mysql
    }
    
    notify_master "/etc/keepalived/mysql_master.sh"
    notify_backup "/etc/keepalived/mysql_backup.sh"
}
```

**从库 Keepalived 配置**：

```bash
# /etc/keepalived/keepalived.conf (从库)

global_defs {
    router_id MYSQL_BACKUP
}

vrrp_script check_mysql {
    script "/etc/keepalived/check_mysql.sh"
    interval 2
    weight -20
    fall 3
    rise 2
}

vrrp_instance VI_1 {
    state BACKUP
    interface eth0
    virtual_router_id 51
    priority 90
    advert_int 1
    
    authentication {
        auth_type PASS
        auth_pass 1111
    }
    
    virtual_ipaddress {
        192.168.1.100
    }
    
    track_script {
        check_mysql
    }
    
    notify_master "/etc/keepalived/mysql_master.sh"
    notify_backup "/etc/keepalived/mysql_backup.sh"
}
```

#### 3. MySQL 健康检查脚本

```bash
# /etc/keepalived/check_mysql.sh

#!/bin/bash

MYSQL_HOST="localhost"
MYSQL_USER="root"
MYSQL_PASS="password"

# 检查 MySQL 进程
if [ $(ps -C mysqld --no-header | wc -l) -eq 0 ]; then
    exit 1
fi

# 检查 MySQL 连接
mysql -h$MYSQL_HOST -u$MYSQL_USER -p$MYSQL_PASS -e "SELECT 1" &>/dev/null
if [ $? -ne 0 ]; then
    exit 1
fi

exit 0
```

#### 4. 主从切换脚本

**切换为主库脚本**：

```bash
# /etc/keepalived/mysql_master.sh

#!/bin/bash

LOG_FILE="/var/log/keepalived_mysql.log"
echo "$(date) - 切换为主库" >> $LOG_FILE

# 停止从库复制
mysql -u root -ppassword -e "STOP SLAVE;"

# 设置为可写
mysql -u root -ppassword -e "SET GLOBAL read_only=0;"

# 发送通知
echo "MySQL 切换为主库" | mail -s "MySQL HA Alert" admin@example.com
```

**切换为从库脚本**：

```bash
# /etc/keepalived/mysql_backup.sh

#!/bin/bash

LOG_FILE="/var/log/keepalived_mysql.log"
echo "$(date) - 切换为从库" >> $LOG_FILE

# 设置为只读
mysql -u root -ppassword -e "SET GLOBAL read_only=1;"

# 启动从库复制
mysql -u root -ppassword -e "START SLAVE;"

# 发送通知
echo "MySQL 切换为从库" | mail -s "MySQL HA Alert" admin@example.com
```

```bash
# 设置脚本权限
chmod +x /etc/keepalived/*.sh
```

## Keepalived + LVS 负载均衡

### LVS 简介

**LVS（Linux Virtual Server）** 是 Linux 内核级别的负载均衡器，性能极高。

### 架构设计

```
                  ┌─────────────┐
                  │  VIP (LVS)  │
                  │192.168.1.100│
                  └──────┬──────┘
                         │
            ┌────────────┼────────────┐
            │                         │
      ┌─────▼─────┐            ┌──────▼────┐
      │  Director │            │  Director │
      │  (MASTER) │            │  (BACKUP) │
      │192.168.1.10│           │192.168.1.11│
      └─────┬─────┘            └──────┬────┘
            │                         │
            └────────────┬────────────┘
                         │
         ┌───────────────┼───────────────┐
         │               │               │
    ┌────▼───┐      ┌────▼───┐     ┌────▼───┐
    │ RS1    │      │ RS2    │     │ RS3    │
    │ Web1   │      │ Web2   │     │ Web3   │
    │.1.20   │      │.1.21   │     │.1.22   │
    └────────┘      └────────┘     └────────┘
```

### 配置 LVS + Keepalived

#### Director MASTER 配置

```bash
# /etc/keepalived/keepalived.conf (Director MASTER)

global_defs {
    router_id LVS_MASTER
}

vrrp_instance VI_1 {
    state MASTER
    interface eth0
    virtual_router_id 51
    priority 100
    advert_int 1
    
    authentication {
        auth_type PASS
        auth_pass 1111
    }
    
    virtual_ipaddress {
        192.168.1.100
    }
}

# 虚拟服务器配置
virtual_server 192.168.1.100 80 {
    delay_loop 6                    # 健康检查间隔
    lb_algo rr                      # 负载均衡算法（rr/wrr/lc/wlc）
    lb_kind DR                      # LVS 模式（NAT/DR/TUN）
    persistence_timeout 50          # 会话保持时间
    protocol TCP                    # 协议
    
    # 真实服务器 1
    real_server 192.168.1.20 80 {
        weight 1                    # 权重
        TCP_CHECK {
            connect_timeout 3       # 连接超时
            nb_get_retry 3          # 重试次数
            delay_before_retry 3    # 重试间隔
            connect_port 80         # 检查端口
        }
    }
    
    # 真实服务器 2
    real_server 192.168.1.21 80 {
        weight 1
        TCP_CHECK {
            connect_timeout 3
            nb_get_retry 3
            delay_before_retry 3
            connect_port 80
        }
    }
    
    # 真实服务器 3
    real_server 192.168.1.22 80 {
        weight 1
        TCP_CHECK {
            connect_timeout 3
            nb_get_retry 3
            delay_before_retry 3
            connect_port 80
        }
    }
}
```

#### Director BACKUP 配置


#### Real Server 配置（DR 模式）

```bash
# 在每台 Real Server 上执行

#!/bin/bash
# /etc/init.d/realserver

VIP=192.168.1.100

case "$1" in
start)
    # 配置 lo 接口
    ifconfig lo:0 $VIP netmask 255.255.255.255 broadcast $VIP
    
    # 抑制 ARP 响应
    echo "1" > /proc/sys/net/ipv4/conf/lo/arp_ignore
    echo "2" > /proc/sys/net/ipv4/conf/lo/arp_announce
    echo "1" > /proc/sys/net/ipv4/conf/all/arp_ignore
    echo "2" > /proc/sys/net/ipv4/conf/all/arp_announce
    
    echo "RealServer Start OK"
    ;;
stop)
    ifconfig lo:0 down
    echo "0" > /proc/sys/net/ipv4/conf/lo/arp_ignore
    echo "0" > /proc/sys/net/ipv4/conf/lo/arp_announce
    echo "0" > /proc/sys/net/ipv4/conf/all/arp_ignore
    echo "0" > /proc/sys/net/ipv4/conf/all/arp_announce
    
    echo "RealServer Stop OK"
    ;;
*)
    echo "Usage: $0 {start|stop}"
    exit 1
esac
```

```bash
# 设置权限并启动
chmod +x /etc/init.d/realserver
/etc/init.d/realserver start
```

## 多网段高可用

### 场景说明

服务器有多个网卡，需要在不同网段配置高可用。

```
eth0: 192.168.1.10/24 (内网)
eth1: 10.0.0.10/24 (外网)
```

### 配置示例

```bash
# /etc/keepalived/keepalived.conf

global_defs {
    router_id MULTI_NET
}

# 内网 VIP
vrrp_instance VI_1 {
    state MASTER
    interface eth0
    virtual_router_id 51
    priority 100
    advert_int 1
    
    authentication {
        auth_type PASS
        auth_pass 1111
    }
    
    virtual_ipaddress {
        192.168.1.100
    }
}

# 外网 VIP
vrrp_instance VI_2 {
    state MASTER
    interface eth1
    virtual_router_id 52
    priority 100
    advert_int 1
    
    authentication {
        auth_type PASS
        auth_pass 2222
    }
    
    virtual_ipaddress {
        10.0.0.100
    }
}
```

## 性能优化

### 1. 调整 VRRP 参数

```bash
vrrp_instance VI_1 {
    state MASTER
    interface eth0
    virtual_router_id 51
    priority 100
    advert_int 1            # 通告间隔（秒），可调整为 0.5
    
    # 快速故障检测
    garp_master_delay 1     # MASTER 发送免费 ARP 的延迟
    garp_master_repeat 3    # MASTER 发送免费 ARP 的次数
    
    virtual_ipaddress {
        192.168.1.100
    }
}
```

### 2. 优化健康检查

```bash
vrrp_script check_service {
    script "/etc/keepalived/check.sh"
    interval 1              # 检查间隔（秒）
    timeout 3               # 超时时间（秒）
    weight -20
    fall 2                  # 失败次数（减少以加快故障检测）
    rise 1                  # 成功次数（减少以加快恢复）
}
```

### 3. 系统参数优化

```bash
# /etc/sysctl.conf

# 允许绑定非本地 IP
net.ipv4.ip_nonlocal_bind = 1

# ARP 优化
net.ipv4.conf.all.arp_announce = 2
net.ipv4.conf.all.arp_ignore = 1

# 应用配置
sysctl -p
```

## 监控和告警

### 监控脚本

```bash
#!/bin/bash
# /usr/local/bin/keepalived_monitor.sh

VIP="192.168.1.100"
LOG_FILE="/var/log/keepalived_monitor.log"

# 检查 VIP 是否存在
if ip addr show | grep -q "$VIP"; then
    ROLE="MASTER"
else
    ROLE="BACKUP"
fi

# 检查 Keepalived 进程
if ! ps aux | grep -v grep | grep -q keepalived; then
    echo "$(date) - Keepalived 进程不存在！" >> $LOG_FILE
    systemctl start keepalived
fi

# 记录状态
echo "$(date) - 当前角色: $ROLE" >> $LOG_FILE
```

### 配置定时监控

```bash
# 添加到 crontab
crontab -e
*/1 * * * * /usr/local/bin/keepalived_monitor.sh
```

## 故障排查

### 常见问题

#### 1. 脑裂（两台都是 MASTER）

**原因**：
- 主备之间网络不通
- 防火墙阻止 VRRP
- virtual_router_id 不一致

**排查**：
```bash
# 测试网络
ping 192.168.1.11

# 抓包查看 VRRP
tcpdump -i eth0 vrrp

# 检查配置
grep virtual_router_id /etc/keepalived/keepalived.conf
```

#### 2. VIP 无法绑定

**原因**：
- 网络接口名称错误
- IP 地址冲突
- 权限不足

**排查**：
```bash
# 检查网络接口
ip addr show

# 检查 IP 冲突
arping -I eth0 192.168.1.100

# 查看日志
tail -f /var/log/messages
```

#### 3. 健康检查不生效

**原因**：
- 脚本权限不足
- 脚本路径错误
- 脚本逻辑错误

**排查**：
```bash
# 检查脚本权限
ls -l /etc/keepalived/check.sh

# 手动执行脚本
bash -x /etc/keepalived/check.sh

# 查看日志
tail -f /var/log/messages | grep vrrp_script
```
