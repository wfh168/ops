# Keepalived 高可用学习指南

## 📚 模块简介

Keepalived 是 Linux 系统中实现高可用（HA）的重要工具，基于 VRRP 协议实现服务器的故障转移和负载均衡。掌握 Keepalived 是构建高可用架构的核心技能。

## 💡 学习建议

### 1. 准备实验环境

**最少需要 2 台服务器**：
- 服务器 A：主服务器（192.168.1.10）
- 服务器 B：备服务器（192.168.1.11）
- VIP：192.168.1.100

**推荐配置**：
- 虚拟机或云服务器
- CentOS 7/8 或 Ubuntu 18.04/20.04
- 至少 1GB 内存
- 网络互通

### 2. 理解核心概念

- **VIP（虚拟 IP）**：统一的访问入口
- **MASTER**：主服务器，拥有 VIP
- **BACKUP**：备服务器，待命状态
- **优先级**：决定谁是 MASTER
- **故障转移**：MASTER 故障时自动切换

### 3. 循序渐进

- 先搭建基本环境，再添加健康检查
- 从简单服务开始（Nginx），再到复杂服务（MySQL）
- 每个配置都要测试验证
- 记录每一步操作

### 4. 多做实验

- 模拟各种故障场景
- 测试故障转移时间
- 优化配置参数
- 监控系统状态

## 📝 常用命令速查

### 基本操作

```bash
# 启动服务
systemctl start keepalived

# 查看状态
systemctl status keepalived

# 查看日志
tail -f /var/log/messages | grep Keepalived

# 查看 VIP
ip addr show eth0 | grep 192.168.1.100

# 查看 VRRP 通告
tcpdump -i eth0 vrrp
```

### 配置检查

```bash
# 检查配置文件语法
keepalived -t -f /etc/keepalived/keepalived.conf

# 查看配置
cat /etc/keepalived/keepalived.conf

# 测试健康检查脚本
/etc/keepalived/check.sh
echo $?
```

## ⚠️ 注意事项

### 安全注意事项

1. **配置认证**：使用 auth_pass 防止未授权访问
2. **限制网段**：只允许必要的网段通信
3. **脚本权限**：健康检查脚本权限设置为 755
4. **日志审计**：定期检查日志
5. **备份配置**：定期备份配置文件

### 可靠性注意事项

1. **测试充分**：上线前充分测试故障转移
2. **监控告警**：配置监控和告警
3. **文档化**：记录配置和操作流程
4. **定期演练**：定期进行故障演练
5. **备份方案**：准备应急预案

### 性能注意事项

1. **调整参数**：根据实际情况调整检查间隔
2. **优化脚本**：健康检查脚本要高效
3. **减少切换**：使用非抢占模式减少切换
4. **监控资源**：监控 CPU 和内存使用
5. **网络优化**：确保网络稳定
