# NFS 网络文件系统学习指南

## 📚 模块简介

NFS（Network File System，网络文件系统）是企业环境中最常用的文件共享解决方案之一。通过 NFS，你可以让多台服务器共享同一份数据，实现集中管理和资源共享。

## 📝 常用命令速查

### 服务端命令

```bash
# 启动服务
systemctl start nfs-server

# 重新加载配置
exportfs -arv

# 查看共享列表
exportfs -v
showmount -e localhost

# 查看 RPC 服务
rpcinfo -p
```

### 客户端命令

```bash
# 查看服务端共享
showmount -e 192.168.1.10

# 挂载 NFS
mount -t nfs 192.168.1.10:/data/share /mnt/nfs

# 查看挂载
df -h | grep nfs
mount | grep nfs

# 卸载 NFS
umount /mnt/nfs

# 查看统计信息
nfsstat -m
```

## ⚠️ 注意事项

### 安全注意事项

1. **不要使用 * 通配符**：限制客户端访问范围
2. **启用 root_squash**：防止客户端 root 破坏服务端
3. **配置防火墙**：只允许必要的 IP 访问
4. **使用 NFSv4**：更安全的协议版本
5. **定期审计**：检查访问日志和权限配置

### 性能注意事项

1. **调整块大小**：根据网络环境优化 rsize/wsize
2. **选择合适的同步模式**：平衡性能和安全
3. **使用 NFSv4**：性能优于 NFSv3
4. **避免频繁小文件操作**：NFS 不适合大量小文件
5. **监控性能**：使用 nfsstat 监控

### 可靠性注意事项

1. **使用 soft 挂载**：避免客户端挂起
2. **配置超时和重试**：合理设置 timeo 和 retrans
3. **使用 bg 选项**：后台挂载，不阻塞启动
4. **定期备份**：NFS 不是备份方案
5. **高可用方案**：考虑使用 Keepalived 或集群
