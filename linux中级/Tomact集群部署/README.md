## 💻 实验环境

### 最小配置
- 3 台服务器（或虚拟机）
- 每台：2核 CPU、4GB 内存、20GB 硬盘
- CentOS 7/8 或 Ubuntu 18.04+

### 推荐配置
- 5 台服务器
- 每台：4核 CPU、8GB 内存、50GB 硬盘

### 服务器规划
```
192.168.1.10  nginx-lb      # Nginx 负载均衡器
192.168.1.11  tomcat-01     # Tomcat 节点1
192.168.1.12  tomcat-02     # Tomcat 节点2
192.168.1.13  tomcat-03     # Tomcat 节点3
192.168.1.14  redis-server  # Redis 服务器
```

## 🎓 实战项目

### 项目：电商网站集群部署

**需求**：
- 3 个 Tomcat 节点
- Nginx 负载均衡
- Redis Session 共享
- 支持 1000+ 并发用户

**架构**：
```
                  Internet
                     |
                 [Nginx LB]
                     |
        +------------+------------+
        |            |            |
    [Tomcat-1]  [Tomcat-2]  [Tomcat-3]
        |            |            |
        +------------+------------+
                     |
                 [Redis]
                     |
                 [MySQL]
```

**实施步骤**：
1. 安装 JDK 和 Tomcat
2. 部署多个 Tomcat 实例
3. 配置 Nginx 负载均衡
4. 安装 Redis
5. 配置 Session 共享
6. 部署应用并测试
7. 性能优化和监控

## ⚠️ 常见问题

### 1. Tomcat 启动失败
- 检查 JDK 是否正确安装
- 检查端口是否被占用
- 查看 catalina.out 日志

### 2. Session 丢失
- 检查 Session 共享配置
- 验证 Redis 连接
- 检查负载均衡策略

### 3. 性能问题
- 调整 JVM 参数
- 优化连接池配置
- 检查系统资源

### 4. 集群节点不均衡
- 检查 Nginx 负载均衡算法
- 验证健康检查配置
- 查看各节点负载
