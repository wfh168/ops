# iptables 防火墙学习指南

## 📚 模块简介

iptables 是 Linux 系统中最强大的防火墙工具，用于保护服务器安全、控制网络流量、实现 NAT 等功能。掌握 iptables 是 Linux 运维工程师的核心技能之一。

**最少需要 2 台服务器**：

- 至少 1GB 内存

### 2. 安全第一

⚠️ **重要提示**：
- 配置防火墙前先允许 SSH，避免被锁在外面
- 使用 `-I` 插入规则到最前面，确保 SSH 可用
- 测试规则前先备份当前规则
- 使用 `iptables -L -n -v` 查看规则是否生效

- 先理解概念，再动手实践

## 📝 常用命令速查

### 基本操作

```bash
# 查看规则
iptables -L -n -v
iptables -L -n --line-numbers

# 清空规则
iptables -F

# 设置默认策略
iptables -P INPUT DROP

# 保存规则
service iptables save
```

### 常用规则

```bash
# 允许本地回环
iptables -A INPUT -i lo -j ACCEPT

# 允许已建立的连接
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许 SSH
iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# 允许 HTTP/HTTPS
iptables -A INPUT -p tcp -m multiport --dports 80,443 -j ACCEPT

# 允许 ping
iptables -A INPUT -p icmp --icmp-type echo-request -j ACCEPT
```

### NAT 规则

```bash
# 开启 IP 转发
echo 1 > /proc/sys/net/ipv4/ip_forward

# SNAT（内网上网）
iptables -t nat -A POSTROUTING -s 192.168.1.0/24 -o eth0 -j MASQUERADE

# DNAT（端口转发）
iptables -t nat -A PREROUTING -d 公网IP -p tcp --dport 80 -j DNAT --to-destination 内网IP:80
```

## ⚠️ 注意事项

### 安全注意事项

1. **先允许 SSH**：避免被锁在外面
2. **测试后再保存**：确保规则正确
3. **备份规则**：修改前先备份
4. **最小权限原则**：只开放必要的端口
5. **定期审计**：检查规则是否合理

### 性能注意事项

1. **规则顺序**：常用规则放在前面
2. **使用状态匹配**：减少规则数量
3. **合并规则**：使用 multiport
4. **避免过多规则**：影响性能
5. **使用自定义链**：提高效率

### 可靠性注意事项

1. **设置开机自启**：systemctl enable iptables
2. **定期备份规则**：防止丢失
3. **监控日志**：及时发现问题
4. **测试故障转移**：确保高可用
5. **文档化配置**：便于维护
