# LNMP + WordPress 部署学习指南

## 📚 模块简介

本模块学习如何搭建 LNMP（Linux + Nginx + MySQL + PHP）环境，并部署 WordPress 网站。这是 Web 运维的核心技能之一。

---

## 🎯 学习目标

✅ 掌握 LNMP 环境的搭建  
✅ 理解 Nginx 与 PHP 的集成  
✅ 部署和配置 WordPress  
✅ 优化网站性能  
✅ 配置 HTTPS 安全访问  
✅ 掌握日常维护和故障排查  

---

## 💡 学习建议

### 1. 准备环境

- 1 台服务器（2 核 4GB 内存）
- CentOS 7/8 或 Ubuntu 18.04/20.04
- 域名（可选，用于 HTTPS）

### 2. 循序渐进

- 先搭建基础环境
- 再部署 WordPress
- 最后优化和加固

### 3. 实践为主

- 每个步骤都要实际操作
- 测试每个配置的效果
- 记录遇到的问题
