# 存储与网络

## 一、OSS 对象存储

### 1.1 OSS 简介

OSS（Object Storage Service）是阿里云提供的海量、安全、低成本、高可靠的云存储服务。

**核心特性**：
- 海量存储：无限容量
- 高可靠：99.9999999999%（12个9）数据可靠性
- 低成本：按使用量付费
- 高性能：支持高并发访问
- 多种存储类型：标准、低频、归档、冷归档

**适用场景**：
- 图片和视频存储
- 静态网站托管
- 数据备份和归档
- 大数据分析
- 内容分发

### 1.2 核心概念

```
Bucket（存储空间）
  ├── Object（对象/文件）
  │   ├── Key（文件名）
  │   ├── Data（文件内容）
  │   └── Metadata（元数据）
  └── ACL（访问控制）
```

**Bucket**：
- 存储空间，用于存储对象
- 全局唯一命名
- 有地域属性

**Object**：
- 存储的文件
- 由 Key、Data、Metadata 组成
- 最大 48.8TB

## 二、创建和管理 OSS

### 2.1 创建 Bucket

#### 通过控制台创建

```
1. 产品与服务 → 对象存储 OSS
2. Bucket 列表 → 创建 Bucket

基本信息：
- Bucket 名称：my-website-assets（全局唯一）
- 地域：华东1（杭州）
- 存储类型：标准存储
- 版本控制：关闭
- 读写权限：私有

高级设置：
- 服务端加密：关闭
- 实时日志查询：关闭
- 定时备份：关闭

3. 点击"确定"
```

#### 通过 ossutil 创建

```bash
# 安装 ossutil
wget http://gosspublic.alicdn.com/ossutil/1.7.14/ossutil64
chmod +x ossutil64
sudo mv ossutil64 /usr/local/bin/ossutil

# 配置 ossutil
ossutil config
# 输入 Endpoint：oss-cn-hangzhou.aliyuncs.com
# 输入 AccessKey ID
# 输入 AccessKey Secret

# 创建 Bucket
ossutil mb oss://my-website-assets
```

### 2.2 上传文件

#### 通过控制台上传

```
1. 选择 Bucket
2. 文件管理 → 上传文件
3. 选择文件
4. 设置 ACL（可选）
5. 点击"上传"
```

#### 通过 ossutil 上传

```bash
# 上传单个文件
ossutil cp /path/to/file.jpg oss://my-website-assets/images/

# 上传目录
ossutil cp -r /path/to/directory/ oss://my-website-assets/files/

# 上传并设置 ACL
ossutil cp file.jpg oss://my-website-assets/ --acl public-read

# 查看上传进度
ossutil cp large-file.zip oss://my-website-assets/ --progress
```

#### 通过 SDK 上传（Python）

```python
import oss2

# 初始化
auth = oss2.Auth('your-access-key-id', 'your-access-key-secret')
bucket = oss2.Bucket(auth, 'oss-cn-hangzhou.aliyuncs.com', 'my-website-assets')

# 上传文件
bucket.put_object('images/test.jpg', open('/path/to/test.jpg', 'rb'))

# 上传字符串
bucket.put_object('data/test.txt', 'Hello OSS!')

# 分片上传（大文件）
oss2.resumable_upload(bucket, 'videos/large.mp4', '/path/to/large.mp4')
```

### 2.3 下载文件

```bash
# 下载单个文件
ossutil cp oss://my-website-assets/images/file.jpg /path/to/local/

# 下载目录
ossutil cp -r oss://my-website-assets/images/ /path/to/local/

# 列出文件
ossutil ls oss://my-website-assets/

# 递归列出
ossutil ls oss://my-website-assets/ -r
```

### 2.4 删除文件

```bash
# 删除单个文件
ossutil rm oss://my-website-assets/images/file.jpg

# 删除目录
ossutil rm oss://my-website-assets/images/ -r

# 批量删除
ossutil rm oss://my-website-assets/ -r --include "*.tmp"
```

## 三、访问控制

### 3.1 Bucket ACL

```
权限类型：
- 私有（private）：只有 Bucket 拥有者可以访问
- 公共读（public-read）：任何人可以读取
- 公共读写（public-read-write）：任何人可以读写（不推荐）
```

#### 设置 Bucket ACL

```bash
# 通过控制台
1. 选择 Bucket → 权限管理
2. 读写权限 → 修改
3. 选择权限类型

# 通过 ossutil
ossutil set-acl oss://my-website-assets public-read
```

### 3.2 Object ACL

```bash
# 上传时设置
ossutil cp file.jpg oss://my-website-assets/ --acl public-read

# 修改已有文件的 ACL
ossutil set-acl oss://my-website-assets/file.jpg private
```

### 3.3 Bucket Policy

更细粒度的访问控制。

```json
{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": ["*"],
      "Action": ["oss:GetObject"],
      "Resource": ["acs:oss:*:*:my-website-assets/public/*"]
    }
  ]
}
```

### 3.4 签名 URL

生成临时访问 URL。

```python
import oss2

auth = oss2.Auth('your-access-key-id', 'your-access-key-secret')
bucket = oss2.Bucket(auth, 'oss-cn-hangzhou.aliyuncs.com', 'my-website-assets')

# 生成签名 URL（有效期 3600 秒）
url = bucket.sign_url('GET', 'images/private.jpg', 3600)
print(url)
```

## 四、静态网站托管

### 4.1 配置静态网站

```
1. 选择 Bucket → 基础设置
2. 静态页面 → 设置

配置：
- 默认首页：index.html
- 默认 404 页：404.html

3. 点击"保存"
```

### 4.2 上传网站文件

```bash
# 创建网站目录结构
mkdir -p website/{css,js,images}

# 创建 index.html
cat > website/index.html << 'EOF'
<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <h1>Welcome to My Website</h1>
    <p>Hosted on Alibaba Cloud OSS</p>
    <img src="images/logo.png" alt="Logo">
    <script src="js/main.js"></script>
</body>
</html>
EOF

# 创建 404.html
cat > website/404.html << 'EOF'
<!DOCTYPE html>
<html>
<head>
    <title>404 Not Found</title>
</head>
<body>
    <h1>404 - Page Not Found</h1>
    <p>The page you are looking for does not exist.</p>
</body>
</html>
EOF

# 上传网站文件
ossutil cp -r website/ oss://my-website-assets/ --acl public-read
```

### 4.3 访问网站

```
访问地址：
http://my-website-assets.oss-cn-hangzhou.aliyuncs.com/index.html

或使用自定义域名（需要绑定域名）：
http://www.example.com/
```

## 五、CDN 内容分发

### 5.1 CDN 简介

CDN（Content Delivery Network）是内容分发网络，将内容缓存到全球各地的边缘节点，加速用户访问。

**核心优势**：
- 加速访问：就近访问边缘节点
- 降低成本：减少源站带宽消耗
- 提高可用性：分散流量
- 防护攻击：隐藏源站 IP

### 5.2 配置 CDN

#### 添加加速域名

```
1. 产品与服务 → CDN
2. 域名管理 → 添加域名

域名配置：
- 加速域名：cdn.example.com
- 业务类型：图片小文件
- 源站信息：OSS 域名
- 端口：80
- 加速区域：仅中国内地

3. 点击"下一步"
```

#### 配置 CNAME

```
1. 获取 CNAME 地址：cdn.example.com.w.kunlunsl.com
2. 到域名服务商添加 CNAME 记录

记录类型：CNAME
主机记录：cdn
记录值：cdn.example.com.w.kunlunsl.com
TTL：10 分钟

3. 等待 DNS 生效（10-30 分钟）
```

#### 验证 CDN

```bash
# 查询 CNAME
nslookup cdn.example.com

# 测试访问
curl -I http://cdn.example.com/images/test.jpg

# 查看响应头
# X-Cache: HIT 表示命中缓存
# X-Swift-CacheTime: 缓存时间
```

### 5.3 缓存配置

```
1. 域名管理 → 选择域名 → 缓存配置
2. 缓存过期时间 → 添加

配置示例：
- 目录：/images/
- 过期时间：30 天
- 权重：90

- 文件类型：jpg,png,gif
- 过期时间：7 天
- 权重：80

- 目录：/api/
- 过期时间：不缓存
- 权重：100
```

### 5.4 刷新和预热

#### 刷新缓存

```
1. 刷新预热 → 刷新缓存
2. 操作类型：刷新
3. 对象类型：URL 或目录
4. 输入 URL：
   http://cdn.example.com/images/test.jpg
5. 点击"提交"
```

#### 预热内容

```
1. 刷新预热 → 预热
2. 输入 URL：
   http://cdn.example.com/images/popular.jpg
3. 点击"提交"
```

## 六、VPC 专有网络

### 6.1 VPC 简介

VPC（Virtual Private Cloud）是用户在阿里云上构建的隔离网络环境。

**核心概念**：
```
VPC（专有网络）
  ├── 交换机（VSwitch）
  │   ├── 可用区 A
  │   └── 可用区 B
  ├── 路由表
  └── 安全组
```

**优势**：
- 网络隔离：逻辑隔离
- 自定义网段：自由规划 IP
- 灵活路由：自定义路由规则
- 安全可控：安全组控制

### 6.2 创建 VPC

```
1. 产品与服务 → 专有网络 VPC
2. 专有网络 → 创建专有网络

基本信息：
- 名称：my-vpc
- IPv4 网段：192.168.0.0/16
- 描述：生产环境 VPC

交换机配置：
- 名称：my-vswitch-a
- 可用区：可用区 A
- IPv4 网段：192.168.1.0/24

- 名称：my-vswitch-b
- 可用区：可用区 B
- IPv4 网段：192.168.2.0/24

3. 点击"确定"
```

### 6.3 网络规划

```
VPC 网段：192.168.0.0/16

子网划分：
- 192.168.1.0/24  Web 服务器（可用区 A）
- 192.168.2.0/24  Web 服务器（可用区 B）
- 192.168.10.0/24 应用服务器
- 192.168.20.0/24 数据库服务器
- 192.168.100.0/24 管理网络
```

## 七、弹性公网 IP

### 7.1 EIP 简介

EIP（Elastic IP Address）是可以独立购买和持有的公网 IP 地址资源。

**特点**：
- 独立购买：不依赖 ECS
- 灵活绑定：可绑定到不同资源
- 按需付费：按流量或带宽计费

### 7.2 申请 EIP

```
1. 专有网络 → 弹性公网 IP
2. 申请弹性公网 IP

配置：
- 地域：华东1（杭州）
- 带宽峰值：5 Mbps
- 计费方式：按使用流量
- 购买数量：1

3. 点击"立即购买"
```

### 7.3 绑定 EIP

```
1. 选择 EIP → 绑定资源
2. 实例类型：ECS 实例
3. 选择 ECS 实例
4. 点击"确定"
```

### 7.4 解绑和释放

```bash
# 解绑 EIP
1. 选择 EIP → 解绑
2. 确认解绑

# 释放 EIP
1. 选择 EIP → 释放
2. 确认释放（立即释放或定时释放）
```

## 八、NAT 网关

### 8.1 NAT 网关简介

NAT 网关是企业级的公网网关，提供 NAT 代理功能。

**功能**：
- SNAT：使 VPC 内的 ECS 访问互联网
- DNAT：将公网访问映射到 VPC 内的 ECS

### 8.2 创建 NAT 网关

```
1. 专有网络 → NAT 网关
2. 创建 NAT 网关

配置：
- 地域：华东1（杭州）
- VPC：选择 VPC
- 交换机：选择交换机
- 规格：小型
- 计费方式：按使用量计费

3. 点击"立即购买"
```

### 8.3 配置 SNAT

```
1. 选择 NAT 网关 → SNAT 管理
2. 创建 SNAT 条目

配置：
- 交换机：选择需要访问公网的交换机
- 公网 IP：选择 EIP
- 条目名称：web-snat

3. 点击"确定"
```

测试 SNAT：
```bash
# 在没有公网 IP 的 ECS 上测试
curl http://myip.ipip.net
# 应该显示 NAT 网关的公网 IP
```

### 8.4 配置 DNAT

```
1. 选择 NAT 网关 → DNAT 管理
2. 创建 DNAT 条目

配置：
- 公网 IP：选择 EIP
- 公网端口：80
- 私网 IP：192.168.1.10（ECS 内网 IP）
- 私网端口：80
- 协议类型：TCP

3. 点击"确定"
```

测试 DNAT：
```bash
# 从外网访问
curl http://EIP地址/
# 应该访问到内网 ECS 的服务
```

## 九、云监控

### 9.1 云监控简介

云监控是阿里云提供的一站式监控解决方案。

**监控对象**：
- ECS、RDS、SLB、OSS 等云产品
- 自定义监控指标
- 站点监控
- 日志监控

### 9.2 配置监控

#### 查看监控数据

```
1. 产品与服务 → 云监控
2. 主机监控 → 选择 ECS
3. 查看监控图表：
   - CPU 使用率
   - 内存使用率
   - 磁盘使用率
   - 网络流量
```

#### 配置告警规则

```
1. 报警服务 → 报警规则
2. 创建报警规则

规则配置：
- 产品：云服务器 ECS
- 资源范围：实例
- 选择实例：选择 ECS
- 规则名称：CPU 使用率告警

告警规则：
- 监控项：CPU 使用率
- 统计方法：平均值
- 比较符：>
- 阈值：80%
- 连续次数：3 次
- 统计周期：1 分钟

通知方式：
- 联系人组：选择联系人组
- 通知方式：短信 + 邮件
- 生效时间：全天

3. 点击"确认"
```

### 9.3 自定义监控

```bash
# 安装云监控插件
wget http://cms-agent-cn-hangzhou.oss-cn-hangzhou-internal.aliyuncs.com/release/cms_go_agent/cms_go_agent_linux-amd64.tar.gz
tar -zxvf cms_go_agent_linux-amd64.tar.gz
cd cms_go_agent
./install.sh

# 上报自定义指标
aliyun cms PutCustomMetric \
  --MetricList.1.MetricName=MyMetric \
  --MetricList.1.Value=100 \
  --MetricList.1.Time=$(date +%s)000
```
