### 推荐配置
```

  - 规格：ecs.t5-lc1m2.small（1核2GB）
  - 数量：3台
  - 系统：CentOS 7.9 64位
  - 带宽：1-5 Mbps

  - 类型：应用型负载均衡（ALB）
  - 规格：slb.s1.small

RDS 数据库：
  - 类型：MySQL 8.0
  - 规格：rds.mysql.t1.small（1核1GB）

OSS 存储：
  - 存储类型：标准存储
  - 容量：按需使用
```

## 🏗️ 实战架构

### 项目：电商网站云上部署

```
                    Internet
                        |
                    [CDN 加速]
                        |
                  [公网 SLB]
                        |
        +---------------+---------------+
        |               |               |
    [ECS-1]         [ECS-2]         [ECS-3]
    (Nginx+PHP)     (Nginx+PHP)     (Nginx+PHP)
        |               |               |
        +---------------+---------------+
                        |
                    [RDS MySQL]
                        |
                    [OSS 存储]
                        |
                  [云监控 + 日志]
```

**架构特点**：
- 高可用：多台 ECS + SLB 负载均衡

## ⚠️ 常见问题

### 1. 无法连接 ECS
- 检查安全组规则
- 检查公网 IP 是否绑定
- 检查 SSH 服务是否启动
- 尝试使用 VNC 连接

### 2. SLB 无法访问后端
- 检查后端 ECS 状态
- 检查健康检查配置
- 检查安全组规则
- 查看 SLB 日志

### 3. RDS 连接失败
- 检查白名单配置
- 检查账号密码
- 检查网络连通性
- 查看 RDS 日志

### 4. OSS 上传失败
- 检查 Bucket 权限
- 检查 AccessKey
- 检查跨域配置
- 查看错误日志
