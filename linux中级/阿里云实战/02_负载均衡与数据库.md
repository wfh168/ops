# 负载均衡与数据库

## 一、SLB 负载均衡

### 1.1 SLB 简介

SLB（Server Load Balancer）是阿里云提供的负载均衡服务，可以将流量分发到多台 ECS 实例。

**核心功能**：
- 流量分发：将请求分发到后端服务器
- 健康检查：自动检测后端服务器状态
- 会话保持：保持用户会话的连续性
- 高可用：多可用区部署
- 弹性扩展：支持动态添加/删除后端服务器

**SLB 类型**：
- **应用型负载均衡（ALB）**：七层负载均衡，支持 HTTP/HTTPS ⭐推荐
- **网络型负载均衡（NLB）**：四层负载均衡，支持 TCP/UDP
- **传统型负载均衡（CLB）**：经典负载均衡

### 1.2 SLB 架构

```
                    Internet
                        |
                    [SLB 实例]
                        |
            +-----------+-----------+
            |                       |
        [监听器]                [监听器]
        HTTP:80                HTTPS:443
            |                       |
        [后端服务器组]          [后端服务器组]
            |                       |
    +-------+-------+       +-------+-------+
    |       |       |       |       |       |
[ECS-1] [ECS-2] [ECS-3] [ECS-1] [ECS-2] [ECS-3]
```

## 二、创建 SLB 实例

### 2.1 准备后端 ECS

首先创建 3 台 ECS 实例作为后端服务器。

```bash
# 在每台 ECS 上安装 Nginx
yum install -y nginx

# 创建测试页面（区分不同服务器）
# ECS-1
echo "This is ECS-1" > /usr/share/nginx/html/index.html
systemctl start nginx
systemctl enable nginx

# ECS-2
echo "This is ECS-2" > /usr/share/nginx/html/index.html
systemctl start nginx
systemctl enable nginx

# ECS-3
echo "This is ECS-3" > /usr/share/nginx/html/index.html
systemctl start nginx
systemctl enable nginx

# 配置安全组，开放 80 端口
```

### 2.2 创建 SLB 实例

#### 通过控制台创建

```
1. 产品与服务 → 负载均衡 SLB
2. 创建负载均衡

基本配置：
- 实例类型：应用型负载均衡（ALB）
- 地域：华东1（杭州）
- 可用区：选择多个可用区（高可用）
- 实例规格：slb.s1.small
- 实例名称：web-slb

网络配置：
- 网络类型：公网
- IP 版本：IPv4
- 计费方式：按使用流量

3. 点击"立即购买"
```

#### 通过 CLI 创建

```bash
# 创建 SLB 实例
aliyun slb CreateLoadBalancer \
  --RegionId cn-hangzhou \
  --LoadBalancerName web-slb \
  --AddressType internet \
  --InternetChargeType paybytraffic \
  --LoadBalancerSpec slb.s1.small
```

### 2.3 配置监听器

#### HTTP 监听器

```
1. 选择 SLB 实例 → 监听
2. 添加监听

监听配置：
- 监听协议：HTTP
- 监听端口：80
- 调度算法：加权轮询（WRR）
- 会话保持：关闭（或开启）

健康检查：
- 健康检查：开启
- 健康检查方式：HTTP
- 健康检查路径：/
- 正常状态码：http_2xx,http_3xx
- 检查间隔：2 秒
- 响应超时：5 秒
- 健康阈值：3 次
- 不健康阈值：3 次

3. 点击"下一步"
```

#### HTTPS 监听器

```
监听配置：
- 监听协议：HTTPS
- 监听端口：443
- 调度算法：加权轮询（WRR）

SSL 证书：
- 选择已有证书（或上传新证书）
- TLS 版本：TLSv1.2 及以上

其他配置同 HTTP 监听器
```

### 2.4 添加后端服务器

```
1. 选择监听器 → 后端服务器
2. 添加后端服务器

选择服务器：
- 选择 3 台 ECS 实例
- 设置权重（默认 100）
- 设置端口（80）

3. 点击"确定"
```

## 三、负载均衡算法

### 3.1 加权轮询（WRR）

按照权重依次分配请求。

```
配置示例：
ECS-1：权重 3
ECS-2：权重 2
ECS-3：权重 1

分配比例：3:2:1
```

**适用场景**：
- 服务器性能不同
- 需要精确控制流量分配

### 3.2 加权最小连接数（WLC）

将请求分配到连接数最少的服务器。

```
配置：
- 调度算法：加权最小连接数（WLC）
```

**适用场景**：
- 请求处理时间差异大
- 长连接应用

### 3.3 一致性哈希（CH）

根据源 IP 或请求 URI 进行哈希分配。

```
配置：
- 调度算法：一致性哈希（CH）
- 哈希键：源 IP 或 URI
```

**适用场景**：
- 需要会话保持
- 缓存命中率要求高

## 四、会话保持

### 4.1 Cookie 会话保持

#### 植入 Cookie

```
配置：
- 会话保持：开启
- 会话保持类型：植入 Cookie
- Cookie 超时时间：1800 秒
```

SLB 会在响应中插入 Cookie：
```
Set-Cookie: SERVERID=ecs-1; path=/
```

#### 重写 Cookie

```
配置：
- 会话保持：开启
- 会话保持类型：重写 Cookie
- Cookie 名称：JSESSIONID
```

使用应用程序的 Cookie 进行会话保持。

### 4.2 测试会话保持

```bash
# 多次请求，观察是否返回同一台服务器
for i in {1..10}; do

# 查看 Cookie
cat cookies.txt
```

## 五、健康检查

### 5.1 HTTP 健康检查

```
配置：
- 健康检查方式：HTTP
- 健康检查域名：www.example.com（可选）
- 健康检查路径：/health
- 正常状态码：http_2xx
- 检查间隔：2 秒
- 响应超时：5 秒
- 健康阈值：3 次
- 不健康阈值：3 次
```

**工作原理**：
```
1. SLB 每 2 秒向后端服务器发送 HTTP GET 请求
2. 如果返回 2xx 状态码，计数器 +1
3. 连续 3 次成功，标记为健康
4. 如果超时或返回错误，计数器 +1
5. 连续 3 次失败，标记为不健康
```

### 5.2 TCP 健康检查

```
配置：
- 健康检查方式：TCP
- 检查端口：80
- 检查间隔：2 秒
- 响应超时：5 秒
```

**工作原理**：
```
1. SLB 尝试建立 TCP 连接
2. 如果连接成功，标记为健康
3. 如果连接失败或超时，标记为不健康
```

### 5.3 创建健康检查页面

```bash
# 在每台 ECS 上创建健康检查页面
vim /usr/share/nginx/html/health

# 添加以下内容
#!/bin/bash
echo "Content-Type: text/plain"
echo ""
echo "OK"

# 设置权限
chmod +x /usr/share/nginx/html/health

# 配置 Nginx
vim /etc/nginx/conf.d/health.conf

# 添加以下内容
server {
    listen 80;
    location /health {
        default_type text/plain;
        return 200 "OK";
    }
}

# 重新加载 Nginx
nginx -s reload

# 测试
curl http://localhost/health
```

## 六、RDS 云数据库

### 6.1 RDS 简介

RDS（Relational Database Service）是阿里云提供的关系型数据库服务。

**支持的数据库**：
- MySQL
- PostgreSQL
- SQL Server
- MariaDB
- PPAS（兼容 Oracle）

**核心优势**：
- 自动备份和恢复
- 高可用架构
- 读写分离
- 性能监控
- 自动故障切换

### 6.2 创建 RDS 实例

#### 通过控制台创建

```
1. 产品与服务 → 云数据库 RDS
2. 创建实例

基本配置：
- 数据库类型：MySQL
- 版本：8.0
- 系列：基础版（学习用）或高可用版
- 存储类型：SSD 云盘
- 地域：华东1（杭州）
- 可用区：与 ECS 相同

规格配置：
- 规格：rds.mysql.t1.small（1核1GB）
- 存储空间：20GB

网络配置：
- 网络类型：专有网络 VPC
- 专有网络：与 ECS 相同
- 交换机：与 ECS 相同

3. 设置密码
4. 点击"立即购买"
```

#### 通过 CLI 创建

```bash
# 创建 RDS 实例
aliyun rds CreateDBInstance \
  --RegionId cn-hangzhou \
  --Engine MySQL \
  --EngineVersion 8.0 \
  --DBInstanceClass rds.mysql.t1.small \
  --DBInstanceStorage 20 \
  --DBInstanceNetType Intranet \
  --SecurityIPList "192.168.1.0/24" \
  --PayType Postpaid
```

### 6.3 配置白名单

```
1. 选择 RDS 实例 → 数据安全性
2. 白名单设置 → 修改

添加 ECS 内网 IP：
- 192.168.1.11
- 192.168.1.12
- 192.168.1.13

或添加 IP 段：
- 192.168.1.0/24

3. 点击"确定"
```

### 6.4 创建数据库和账号

#### 创建数据库

```
1. 数据库管理 → 创建数据库

数据库信息：
- 数据库名称：wordpress
- 字符集：utf8mb4
- 排序规则：utf8mb4_general_ci
- 授权账号：选择账号

2. 点击"创建"
```

#### 创建账号

```
1. 账号管理 → 创建账号

账号信息：

授权数据库：

### 6.5 连接 RDS

#### 获取连接地址

```

## 九、综合实战

### 9.1 部署 WordPress 集群

#### 架构设计

```
                Internet
                    |
                [SLB 实例]
                    |
        +-----------+-----------+
        |           |           |
    [ECS-1]     [ECS-2]     [ECS-3]
    Nginx+PHP   Nginx+PHP   Nginx+PHP
        |           |           |
        +-----------+-----------+
                    |
            [RDS MySQL 主实例]
                    |
            [RDS MySQL 只读实例]
```

#### 步骤1：准备 ECS

```bash
# 在每台 ECS 上安装 LNMP
yum install -y nginx php php-fpm php-mysql

# 配置 PHP-FPM
vim /etc/php-fpm.d/www.conf
# 修改：listen = 127.0.0.1:9000

# 启动服务
systemctl start nginx php-fpm
systemctl enable nginx php-fpm
```

#### 步骤2：配置 Nginx

```bash
vim /etc/nginx/conf.d/wordpress.conf
```

添加以下内容：
```nginx
server {
    listen 80;
    server_name _;
    root /usr/share/nginx/html/wordpress;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$args;
    }

    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
```

```bash
nginx -t
nginx -s reload
```

#### 步骤3：部署 WordPress

```bash
# 下载 WordPress
cd /usr/share/nginx/html
wget https://wordpress.org/latest.tar.gz
tar -zxvf latest.tar.gz
chown -R nginx:nginx wordpress

# 配置数据库连接
cd wordpress
cp wp-config-sample.php wp-config.php
vim wp-config.php
```

修改数据库配置：
```php
define('DB_NAME', 'wordpress');
define('DB_USER', 'admin');
define('DB_PASSWORD', 'your_password');
define('DB_HOST', 'rm-xxxxx.mysql.rds.aliyuncs.com');
```

#### 步骤4：配置 SLB

```
1. 创建 SLB 实例
2. 添加 HTTP 监听器（端口 80）
3. 添加 3 台 ECS 作为后端服务器
4. 配置健康检查
5. 测试访问
```

#### 步骤5：初始化 WordPress

```
1. 访问 http://SLB公网IP/
2. 选择语言：简体中文
3. 填写站点信息
4. 安装 WordPress
5. 登录后台管理
```

## 十、监控和优化

### 10.1 SLB 监控

```
1. SLB 控制台 → 监控
2. 查看指标：
   - QPS（每秒请求数）
   - 活跃连接数
   - 新建连接数
   - 流量
   - 健康检查状态
```

### 10.2 RDS 监控

```
1. RDS 控制台 → 监控与报警
2. 查看指标：
   - CPU 使用率
   - 内存使用率
   - IOPS
   - 连接数
   - 慢查询
```

### 10.3 性能优化

#### SLB 优化

```
1. 启用会话保持（减少后端压力）
2. 启用 HTTP/2（提高性能）
3. 配置合适的超时时间
4. 使用 HTTPS 卸载（减轻后端负担）
```

#### RDS 优化

```
1. 开启慢查询日志
2. 优化慢查询
3. 添加索引
4. 使用读写分离
5. 升级实例规格
```
