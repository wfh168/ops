# 快照和克隆

## 快照管理

快照可以保存虚拟机在某个时间点的完整状态，方便回滚和测试。

### 快照类型

1. **内部快照 (Internal Snapshot)**
   - 保存在 qcow2 文件内部
   - 只支持 qcow2 格式
   - 性能较好
   - 便于管理

2. **外部快照 (External Snapshot)**
   - 创建新的 qcow2 文件
   - 支持所有格式
   - 更灵活
   - 需要手动管理

## 内部快照操作

### 1. 创建快照

```bash
# 创建快照
virsh snapshot-create-as vm-name \
  --name snapshot-name \
  --description "快照描述"

# 示例
virsh snapshot-create-as centos7-web \
  --name before-update \
  --description "系统更新前的快照"

# 创建快照（包含内存状态）
virsh snapshot-create-as vm-name \
  --name snapshot-name \
  --description "快照描述" \
  --memspec file=/var/lib/libvirt/images/vm-memory.snap
```

### 2. 列出快照

```bash
# 列出所有快照
virsh snapshot-list vm-name

# 显示快照树
virsh snapshot-list vm-name --tree

# 显示详细信息
virsh snapshot-list vm-name --details
```

**输出示例**:
```
 Name              Creation Time               State
--------------------------------------------------------
 before-update     2026-02-09 10:00:00 +0800   shutoff
 after-install     2026-02-09 11:00:00 +0800   running
```

### 3. 查看快照信息

```bash
# 查看快照详情
virsh snapshot-info vm-name snapshot-name

# 查看快照 XML 配置
virsh snapshot-dumpxml vm-name snapshot-name

# 查看当前快照
virsh snapshot-current vm-name
```

### 4. 恢复快照

```bash
# 恢复到指定快照
virsh snapshot-revert vm-name snapshot-name

# 恢复并启动虚拟机
virsh snapshot-revert vm-name snapshot-name --running

# 恢复并暂停虚拟机
virsh snapshot-revert vm-name snapshot-name --paused
```

### 5. 删除快照

```bash
# 删除单个快照
virsh snapshot-delete vm-name snapshot-name

# 删除快照及其子快照
virsh snapshot-delete vm-name snapshot-name --children

# 删除快照但保留元数据
virsh snapshot-delete vm-name snapshot-name --metadata
```

### 6. 快照链管理

```bash
# 查看快照父子关系
virsh snapshot-list vm-name --tree

# 查看快照的父快照
virsh snapshot-parent vm-name snapshot-name

# 查看快照的子快照
virsh snapshot-list vm-name --parent snapshot-name
```

## 外部快照操作

### 1. 创建外部快照

```bash
# 创建外部快照
virsh snapshot-create-as vm-name \
  --name external-snapshot \
  --description "外部快照" \
  --disk-only \
  --diskspec vda,snapshot=external

# 查看磁盘链
qemu-img info --backing-chain /var/lib/libvirt/images/vm-disk.qcow2
```

### 2. 合并外部快照

```bash
# 合并快照到基础镜像
virsh blockcommit vm-name vda \
  --active \
  --pivot

# 或使用 qemu-img
qemu-img commit /var/lib/libvirt/images/vm-disk.qcow2
```

## 虚拟机克隆

克隆可以快速创建虚拟机的副本。

### 1. 完整克隆

```bash
# 基本克隆（自动克隆所有磁盘）
virt-clone \
  --original source-vm \
  --name clone-vm \
  --auto-clone

# 指定新磁盘路径
virt-clone \
  --original source-vm \
  --name clone-vm \
  --file /var/lib/libvirt/images/clone-vm.qcow2

# 克隆多个磁盘
virt-clone \
  --original source-vm \
  --name clone-vm \
  --file /var/lib/libvirt/images/clone-vm-disk1.qcow2 \
  --file /var/lib/libvirt/images/clone-vm-disk2.qcow2
```

### 2. 链接克隆

链接克隆基于原始磁盘创建，节省空间。

```bash
# 创建后端镜像
qemu-img create -f qcow2 \
  -b /var/lib/libvirt/images/source-vm.qcow2 \
  /var/lib/libvirt/images/clone-vm.qcow2

# 导入虚拟机
virt-install \
  --name clone-vm \
  --memory 2048 \
  --vcpus 2 \
  --disk path=/var/lib/libvirt/images/clone-vm.qcow2 \
  --import \
  --os-variant centos7.0 \
  --network network=default \
  --graphics vnc \
  --noautoconsole
```

### 3. 克隆后配置

克隆后需要修改一些配置以避免冲突：

```bash
# 1. 修改主机名
hostnamectl set-hostname new-hostname

# 2. 修改网卡 MAC 地址（已自动修改）
# 查看新 MAC 地址
virsh domiflist clone-vm

# 3. 重新生成 SSH 密钥
rm -f /etc/ssh/ssh_host_*
ssh-keygen -A

# 4. 修改静态 IP（如果有）
vi /etc/sysconfig/network-scripts/ifcfg-eth0  # CentOS
vi /etc/netplan/00-installer-config.yaml      # Ubuntu

# 5. 重新生成 machine-id
rm -f /etc/machine-id
systemd-machine-id-setup
```

## 模板虚拟机

创建模板虚拟机可以快速部署标准化环境。

### 1. 创建模板

```bash
# 1. 创建基础虚拟机
virt-install \
  --name template-centos7 \
  --memory 2048 \
  --vcpus 2 \
  --disk size=20 \
  --cdrom /path/to/centos7.iso \
  --os-variant centos7.0 \
  --network network=default \
  --graphics vnc

# 2. 安装和配置系统
# - 安装操作系统
# - 安装常用软件
# - 配置系统设置
# - 清理日志和缓存

# 3. 清理模板
# 在虚拟机内执行
yum clean all
rm -rf /var/log/*
rm -rf /tmp/*
history -c

# 4. 关闭虚拟机
virsh shutdown template-centos7

# 5. 创建快照作为模板
virsh snapshot-create-as template-centos7 \
  --name clean-template \
  --description "干净的模板快照"
```

### 2. 从模板部署

```bash
# 克隆模板
virt-clone \
  --original template-centos7 \
  --name web-server-01 \
  --auto-clone

# 启动并配置
virsh start web-server-01
```

## 实用脚本

### 1. 快照管理脚本

```bash
#!/bin/bash
# 快照管理脚本

VM_NAME=$1
ACTION=$2
SNAPSHOT_NAME=$3

if [ -z "$VM_NAME" ] || [ -z "$ACTION" ]; then
    echo "用法: $0 <虚拟机名> <操作> [快照名]"
    echo "操作: create, list, revert, delete"
    exit 1
fi

case $ACTION in
    create)
        if [ -z "$SNAPSHOT_NAME" ]; then
            SNAPSHOT_NAME="snapshot-$(date +%Y%m%d-%H%M%S)"
        fi
        echo "创建快照: $SNAPSHOT_NAME"
        virsh snapshot-create-as $VM_NAME \
          --name $SNAPSHOT_NAME \
          --description "Created at $(date)"
        ;;
    
    list)
        echo "快照列表:"
        virsh snapshot-list $VM_NAME --tree
        ;;
    
    revert)
        if [ -z "$SNAPSHOT_NAME" ]; then
            echo "错误: 必须指定快照名"
            exit 1
        fi
        echo "恢复快照: $SNAPSHOT_NAME"
        virsh snapshot-revert $VM_NAME $SNAPSHOT_NAME
        ;;
    
    delete)
        if [ -z "$SNAPSHOT_NAME" ]; then
            echo "错误: 必须指定快照名"
            exit 1
        fi
        echo "删除快照: $SNAPSHOT_NAME"
        virsh snapshot-delete $VM_NAME $SNAPSHOT_NAME
        ;;
    
    *)
        echo "错误: 未知操作 $ACTION"
        exit 1
        ;;
esac
```

### 2. 批量克隆脚本

```bash
#!/bin/bash
# 批量克隆虚拟机

TEMPLATE=$1
PREFIX=$2
COUNT=$3

if [ -z "$TEMPLATE" ] || [ -z "$PREFIX" ] || [ -z "$COUNT" ]; then
    echo "用法: $0 <模板名> <前缀> <数量>"
    echo "示例: $0 template-centos7 web-server 5"
    exit 1
fi

echo "从模板 $TEMPLATE 克隆 $COUNT 个虚拟机"
echo "前缀: $PREFIX"
echo ""

for i in $(seq 1 $COUNT); do
    VM_NAME="${PREFIX}-$(printf "%02d" $i)"
    echo "克隆虚拟机: $VM_NAME"
    
    virt-clone \
      --original $TEMPLATE \
      --name $VM_NAME \
      --auto-clone
    
    if [ $? -eq 0 ]; then
        echo "✓ $VM_NAME 克隆成功"
    else
        echo "✗ $VM_NAME 克隆失败"
    fi
    echo ""
done

echo "克隆完成！"
echo ""
echo "虚拟机列表:"
virsh list --all | grep $PREFIX
```

### 3. 自动快照脚本

```bash
#!/bin/bash
# 自动创建快照（可用于 cron）

VM_NAME=$1
MAX_SNAPSHOTS=5

if [ -z "$VM_NAME" ]; then
    echo "用法: $0 <虚拟机名>"
    exit 1
fi

# 创建快照
SNAPSHOT_NAME="auto-$(date +%Y%m%d-%H%M%S)"
echo "创建自动快照: $SNAPSHOT_NAME"

virsh snapshot-create-as $VM_NAME \
  --name $SNAPSHOT_NAME \
  --description "Auto snapshot at $(date)"

# 清理旧快照
SNAPSHOT_COUNT=$(virsh snapshot-list $VM_NAME --name | grep "^auto-" | wc -l)

if [ $SNAPSHOT_COUNT -gt $MAX_SNAPSHOTS ]; then
    echo "清理旧快照..."
    OLD_SNAPSHOTS=$(virsh snapshot-list $VM_NAME --name | grep "^auto-" | head -n $((SNAPSHOT_COUNT - MAX_SNAPSHOTS)))
    
    for snapshot in $OLD_SNAPSHOTS; do
        echo "删除快照: $snapshot"
        virsh snapshot-delete $VM_NAME $snapshot
    done
fi

echo "完成！"
```

**添加到 cron**:
```bash
# 每天凌晨 2 点自动创建快照
0 2 * * * /path/to/auto-snapshot.sh vm-name
```

## 最佳实践

### 1. 快照命名规范

```bash
# 格式: 类型-日期-描述
before-update-20260209-system
after-install-20260209-nginx
test-20260209-config-change
```

### 2. 快照管理策略

- **定期清理**: 删除不需要的旧快照
- **限制数量**: 每个虚拟机保持 3-5 个快照
- **重要节点**: 在重大变更前创建快照
- **测试环境**: 频繁使用快照进行测试

### 3. 克隆使用场景

- **快速部署**: 从模板快速创建虚拟机
- **测试环境**: 克隆生产环境进行测试
- **备份**: 克隆作为备份
- **开发环境**: 为每个开发者克隆独立环境

### 4. 性能考虑

- **快照链**: 避免过长的快照链（影响性能）
- **定期合并**: 合并不需要的快照
- **磁盘格式**: 使用 qcow2 支持快照
- **存储空间**: 预留足够的存储空间

## 常见问题

### Q1: 快照占用多少空间？

快照只保存变化的数据，初始占用很小，随着虚拟机的变化而增长。

```bash
# 查看快照大小
qemu-img info /var/lib/libvirt/images/vm-disk.qcow2
```

### Q2: 如何删除所有快照？

```bash
# 列出所有快照
virsh snapshot-list vm-name --name

# 批量删除
for snap in $(virsh snapshot-list vm-name --name); do
    virsh snapshot-delete vm-name $snap
done
```

### Q3: 快照恢复后数据会丢失吗？

是的，恢复快照会回到快照创建时的状态，之后的所有变化都会丢失。

### Q4: raw 格式支持快照吗？

raw 格式不支持内部快照，但可以使用外部快照或 LVM 快照。

### Q5: 如何备份快照？

```bash
# 导出虚拟机配置
virsh dumpxml vm-name > vm-config.xml

# 导出快照配置
virsh snapshot-dumpxml vm-name snapshot-name > snapshot-config.xml

# 复制磁盘文件
cp /var/lib/libvirt/images/vm-disk.qcow2 /backup/
```

## 高级技巧

### 1. 快照与备份结合

```bash
# 1. 创建快照
virsh snapshot-create-as vm-name backup-snapshot

# 2. 备份磁盘
cp /var/lib/libvirt/images/vm-disk.qcow2 /backup/

# 3. 删除快照
virsh snapshot-delete vm-name backup-snapshot
```

### 2. 使用 LVM 快照

```bash
# 创建 LVM 快照
lvcreate -L 10G -s -n vm-snapshot /dev/vg_kvm/vm-lv

# 挂载快照
mount /dev/vg_kvm/vm-snapshot /mnt/snapshot

# 备份数据
tar czf /backup/vm-backup.tar.gz /mnt/snapshot

# 删除快照
lvremove /dev/vg_kvm/vm-snapshot
```

### 3. 快照前自动清理

```bash
#!/bin/bash
# 快照前清理虚拟机

VM_NAME=$1

# 在虚拟机内执行清理
virsh domifaddr $VM_NAME | grep -oP '\d+\.\d+\.\d+\.\d+' | while read ip; do
    ssh root@$ip "
        yum clean all
        rm -rf /var/log/*.log
        rm -rf /tmp/*
        history -c
    "
done

# 创建快照
virsh snapshot-create-as $VM_NAME clean-snapshot
```
