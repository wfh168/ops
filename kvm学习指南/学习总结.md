## 🎯 核心命令速查

### 虚拟机管理
```bash
# 列出虚拟机
virsh list --all

# 启动/关闭
virsh start vm-name
virsh shutdown vm-name
virsh destroy vm-name

# 查看信息
virsh dominfo vm-name
virsh domstats vm-name

# 连接控制台
virt-viewer vm-name
virsh console vm-name
```

### 网络管理
```bash
# 列出网络
virsh net-list --all

# 查看网络信息
virsh net-info default
virsh net-dumpxml default

# 查看虚拟机 IP
virsh domifaddr vm-name
```

### 存储管理
```bash
# 列出存储池
virsh pool-list --all

# 列出存储卷
virsh vol-list default

# 查看磁盘
virsh domblklist vm-name
qemu-img info disk.qcow2
```

## 💡 最佳实践

### 1. 虚拟机命名规范
```
格式: 系统-用途-编号-环境
示例: centos7-web-01-prod
```

### 2. 资源分配建议
- **开发测试**: 2 CPU, 2-4GB RAM, 20GB 磁盘
- **生产环境**: 4+ CPU, 8+ GB RAM, 100+ GB 磁盘

### 3. 网络模式选择
- **NAT**: 开发测试，简单易用
- **桥接**: 生产环境，独立 IP
- **隔离**: 安全隔离，内部通信

### 4. 磁盘格式选择
- **qcow2**: 支持快照，动态分配，适合开发测试
- **raw**: 性能最好，适合生产环境

### 5. 定期维护
- 定期备份虚拟机
- 监控资源使用
- 清理不用的虚拟机
- 更新系统和软件
