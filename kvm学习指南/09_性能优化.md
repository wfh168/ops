# 性能优化

## 性能优化概述

KVM 虚拟机的性能优化涉及多个方面：CPU、内存、磁盘 I/O、网络 I/O 等。

### 优化目标

- 提高虚拟机性能
- 降低资源开销
- 提升用户体验
- 优化资源利用率

## CPU 优化

### 1. CPU 模式选择

```xml
<!-- host-passthrough: 直接透传宿主机 CPU（性能最好） -->
<cpu mode='host-passthrough'/>

<!-- host-model: 使用宿主机 CPU 模型 -->
<cpu mode='host-model'/>

<!-- custom: 自定义 CPU 模型 -->
<cpu mode='custom' match='exact'>
  <model>Haswell</model>
</cpu>
```

**配置方法**:
```bash
# 编辑虚拟机配置
virsh edit vm-name

# 或使用 virt-xml
virt-xml vm-name --edit --cpu host-passthrough
```

### 2. CPU 绑定 (CPU Pinning)

将虚拟 CPU 绑定到物理 CPU，避免 CPU 迁移开销。

```xml
<vcpu placement='static'>4</vcpu>
<cputune>
  <vcpupin vcpu='0' cpuset='0'/>
  <vcpupin vcpu='1' cpuset='1'/>
  <vcpupin vcpu='2' cpuset='2'/>
  <vcpupin vcpu='3' cpuset='3'/>
</cputune>
```

**命令行配置**:
```bash
# 绑定 vCPU 0 到物理 CPU 0
virsh vcpupin vm-name 0 0

# 绑定 vCPU 1 到物理 CPU 1
virsh vcpupin vm-name 1 1

# 查看 CPU 绑定
virsh vcpupin vm-name
```

### 3. NUMA 优化

对于 NUMA 架构的服务器，配置 NUMA 亲和性。

```xml
<numatune>
  <memory mode='strict' nodeset='0'/>
</numatune>
```

**查看 NUMA 信息**:
```bash
# 查看 NUMA 节点
numactl --hardware

# 查看虚拟机 NUMA 配置
virsh numatune vm-name
```

### 4. CPU 拓扑

配置 CPU 拓扑以匹配物理 CPU。

```xml
<cpu>
  <topology sockets='1' cores='4' threads='2'/>
</cpu>
```

## 内存优化

### 1. 大页内存 (Huge Pages)

使用大页内存可以减少 TLB 缺失，提高性能。

**配置大页内存**:
```bash
# 查看大页配置
cat /proc/meminfo | grep Huge

# 配置大页数量（每个大页 2MB）
echo 1024 > /proc/sys/vm/nr_hugepages

# 永久配置
echo "vm.nr_hugepages = 1024" >> /etc/sysctl.conf
sysctl -p

# 挂载 hugetlbfs
mkdir -p /dev/hugepages
mount -t hugetlbfs hugetlbfs /dev/hugepages
```

**虚拟机配置**:
```xml
<memoryBacking>
  <hugepages/>
</memoryBacking>
```

### 2. 内存气球 (Memory Ballooning)

动态调整虚拟机内存。

```xml
<memballoon model='virtio'/>
```

**使用方法**:
```bash
# 设置虚拟机内存
virsh setmem vm-name 2G --live

# 查看内存统计
virsh dommemstat vm-name
```

### 3. KSM (Kernel Samepage Merging)

合并相同的内存页，节省内存。

```bash
# 启用 KSM
echo 1 > /sys/kernel/mm/ksm/run

# 查看 KSM 状态
cat /sys/kernel/mm/ksm/pages_sharing
cat /sys/kernel/mm/ksm/pages_shared
```

### 4. 内存超分配

允许虚拟机总内存超过物理内存。

```bash
# 配置内存超分配比例
# 在 /etc/libvirt/qemu.conf 中
# max_memory_slots = 16
```

## 磁盘 I/O 优化

### 1. 使用 virtio 驱动

```xml
<disk type='file' device='disk'>
  <driver name='qemu' type='qcow2' cache='none' io='native'/>
  <source file='/var/lib/libvirt/images/vm-disk.qcow2'/>
  <target dev='vda' bus='virtio'/>
</disk>
```

### 2. 缓存模式

```xml
<!-- none: 无缓存（推荐生产环境） -->
<driver cache='none'/>

<!-- writethrough: 写穿透 -->
<driver cache='writethrough'/>

<!-- writeback: 写回（性能最好，但可能丢数据） -->
<driver cache='writeback'/>

<!-- directsync: 直接同步 -->
<driver cache='directsync'/>
```

### 3. I/O 模式

```xml
<!-- native: 原生 I/O（推荐） -->
<driver io='native'/>

<!-- threads: 线程 I/O -->
<driver io='threads'/>
```

### 4. I/O 调度器

**在宿主机上**:
```bash
# 查看当前调度器
cat /sys/block/sda/queue/scheduler

# 设置为 deadline（推荐虚拟化环境）
echo deadline > /sys/block/sda/queue/scheduler
```

**在虚拟机内**:
```bash
# 设置为 noop（推荐虚拟机）
echo noop > /sys/block/vda/queue/scheduler
```

### 5. 磁盘格式选择

- **qcow2**: 支持快照，动态分配
- **raw**: 性能最好，适合生产环境

```bash
# 转换为 raw 格式
qemu-img convert -f qcow2 -O raw source.qcow2 target.raw
```

### 6. 磁盘预分配

```bash
# 创建预分配的 qcow2
qemu-img create -f qcow2 -o preallocation=metadata disk.qcow2 20G

# 或使用 falloc
qemu-img create -f qcow2 -o preallocation=falloc disk.qcow2 20G
```

### 7. I/O 限流

限制虚拟机的磁盘 I/O。

```xml
<disk type='file' device='disk'>
  <driver name='qemu' type='qcow2'/>
  <source file='/var/lib/libvirt/images/vm-disk.qcow2'/>
  <target dev='vda' bus='virtio'/>
  <iotune>
    <read_bytes_sec>104857600</read_bytes_sec>   <!-- 100 MB/s -->
    <write_bytes_sec>104857600</write_bytes_sec>  <!-- 100 MB/s -->
  </iotune>
</disk>
```

## 网络 I/O 优化

### 1. 使用 virtio 网卡

```xml
<interface type='network'>
  <source network='default'/>
  <model type='virtio'/>
</interface>
```

### 2. 多队列网卡

```xml
<interface type='network'>
  <source network='default'/>
  <model type='virtio'/>
  <driver name='vhost' queues='4'/>
</interface>
```

**在虚拟机内启用**:
```bash
# 查看网卡队列
ethtool -l eth0

# 设置队列数量
ethtool -L eth0 combined 4
```

### 3. vhost-net

使用内核态的 vhost-net 提高性能。

```bash
# 加载 vhost-net 模块
modprobe vhost-net

# 检查是否加载
lsmod | grep vhost
```

### 4. 网络调优

**在虚拟机内**:
```bash
# 增加接收缓冲区
ethtool -G eth0 rx 4096

# 增加发送缓冲区
ethtool -G eth0 tx 4096

# 启用 TSO/GSO
ethtool -K eth0 tso on gso on

# 禁用 GRO（某些情况下）
ethtool -K eth0 gro off
```

### 5. 桥接优化

```bash
# 禁用 STP（如果不需要）
brctl stp br0 off

# 设置转发延迟为 0
brctl setfd br0 0
```

## 系统级优化

### 1. 关闭不必要的服务

```bash
# 在虚拟机内关闭不需要的服务
systemctl disable bluetooth
systemctl disable cups
systemctl disable avahi-daemon
```

### 2. 调整内核参数

**在宿主机上**:
```bash
# /etc/sysctl.conf
vm.swappiness = 10
vm.dirty_ratio = 10
vm.dirty_background_ratio = 5
net.core.netdev_max_backlog = 5000
net.ipv4.tcp_max_syn_backlog = 8192
```

**在虚拟机内**:
```bash
# /etc/sysctl.conf
vm.swappiness = 10
net.ipv4.tcp_timestamps = 0
net.ipv4.tcp_sack = 1
net.core.netdev_max_backlog = 2500
```

### 3. 使用 tuned

```bash
# 安装 tuned
yum install tuned

# 启动 tuned
systemctl start tuned
systemctl enable tuned

# 选择性能配置
tuned-adm profile virtual-guest  # 虚拟机内
tuned-adm profile virtual-host   # 宿主机上
```

## 性能测试

### 1. CPU 性能测试

```bash
# 使用 sysbench
sysbench cpu --cpu-max-prime=20000 run

# 使用 stress
stress --cpu 4 --timeout 60s
```

### 2. 内存性能测试

```bash
# 使用 sysbench
sysbench memory --memory-total-size=10G run

# 使用 mbw
mbw 1024
```

### 3. 磁盘性能测试

```bash
# 使用 fio
fio --name=randwrite --ioengine=libaio --iodepth=16 \
    --rw=randwrite --bs=4k --direct=1 --size=1G \
    --numjobs=4 --runtime=60 --group_reporting

# 使用 dd
dd if=/dev/zero of=/tmp/test bs=1M count=1024 oflag=direct
```

### 4. 网络性能测试

```bash
# 使用 iperf3
# 服务端
iperf3 -s

# 客户端
iperf3 -c server-ip -t 60

# 使用 netperf
netperf -H server-ip -l 60
```

## 常见性能问题

### Q1: 虚拟机 CPU 使用率高

**排查**:
```bash
# 查看 CPU 使用
virsh domstats vm-name --cpu-total

# 在虚拟机内查看
top
```

**优化**:
- 增加 vCPU 数量
- 配置 CPU 绑定
- 使用 host-passthrough 模式

### Q2: 磁盘 I/O 慢

**排查**:
```bash
# 查看磁盘 I/O
virsh domblkstat vm-name vda

# 在虚拟机内测试
fio --name=test --ioengine=libaio --rw=randread --bs=4k --size=1G
```

**优化**:
- 使用 virtio 驱动
- 使用 cache='none' 和 io='native'
- 使用 raw 格式
- 使用 SSD 存储

### Q3: 网络延迟高

**排查**:
```bash
# 查看网络统计
virsh domifstat vm-name vnet0

# 测试延迟
ping -c 100 vm-ip
```

**优化**:
- 使用 virtio 网卡
- 启用多队列
- 使用桥接网络而不是 NAT

## 最佳实践

1. **合理分配资源**: 不要过度分配 CPU 和内存
2. **使用 virtio 驱动**: CPU、内存、磁盘、网络都使用 virtio
3. **定期监控**: 使用 virt-top 或其他工具监控性能
4. **性能测试**: 部署前进行充分的性能测试
5. **逐步优化**: 一次优化一个方面，测试效果
