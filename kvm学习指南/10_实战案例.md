# 实战案例

## 案例 1：搭建 Web 服务集群

### 场景描述

搭建一个包含负载均衡器、Web 服务器和数据库服务器的集群。

### 架构设计

```
                    ┌─────────────┐
                    │   客户端     │
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │  Nginx LB   │ (192.168.122.10)
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
       ┌──────▼──────┐ ┌──▼────────┐ ┌▼──────────┐
       │  Web Server │ │ Web Server│ │Web Server │
       │     #1      │ │    #2     │ │    #3     │
       │ .122.11     │ │  .122.12  │ │  .122.13  │
       └──────┬──────┘ └──┬────────┘ └┬──────────┘
              │            │            │
              └────────────┼────────────┘
                           │
                    ┌──────▼──────┐
                    │   MySQL DB  │ (192.168.122.20)
                    └─────────────┘
```

### 实施步骤

#### 1. 创建虚拟机模板

```bash
# 创建 CentOS 7 模板
virt-install \
  --name template-centos7 \
  --memory 2048 \
  --vcpus 2 \
  --disk size=20 \
  --cdrom /var/lib/libvirt/images/iso/CentOS-7-x86_64-Minimal-2009.iso \
  --os-variant centos7.0 \
  --network network=default \
  --graphics vnc

# 安装系统并配置基础环境
# - 更新系统
# - 安装常用工具
# - 配置 SSH
# - 清理日志

# 关闭虚拟机
virsh shutdown template-centos7
```

#### 2. 克隆虚拟机

```bash
# 克隆负载均衡器
virt-clone --original template-centos7 --name nginx-lb --auto-clone

# 克隆 Web 服务器
virt-clone --original template-centos7 --name web-server-01 --auto-clone
virt-clone --original template-centos7 --name web-server-02 --auto-clone
virt-clone --original template-centos7 --name web-server-03 --auto-clone

# 克隆数据库服务器
virt-clone --original template-centos7 --name mysql-db --auto-clone
```

#### 3. 配置网络

```bash
# 为每个虚拟机配置静态 IP
# 在每个虚拟机内执行

# Nginx LB (192.168.122.10)
cat > /etc/sysconfig/network-scripts/ifcfg-eth0 << EOF
TYPE=Ethernet
BOOTPROTO=static
NAME=eth0
DEVICE=eth0
ONBOOT=yes
IPADDR=192.168.122.10
NETMASK=255.255.255.0
GATEWAY=192.168.122.1
DNS1=8.8.8.8
EOF

# Web Server 01 (192.168.122.11)
# Web Server 02 (192.168.122.12)
# Web Server 03 (192.168.122.13)
# MySQL DB (192.168.122.20)
# 类似配置，修改 IPADDR

# 重启网络
systemctl restart network
```

#### 4. 安装和配置 Nginx 负载均衡器

```bash
# 在 nginx-lb 虚拟机上

# 安装 Nginx
yum install -y epel-release
yum install -y nginx

# 配置负载均衡
cat > /etc/nginx/nginx.conf << 'EOF'
user nginx;
worker_processes auto;

events {
    worker_connections 1024;
}

http {
    upstream web_backend {
        server 192.168.122.11:80;
        server 192.168.122.12:80;
        server 192.168.122.13:80;
    }

    server {
        listen 80;
        server_name _;

        location / {
            proxy_pass http://web_backend;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
        }
    }
}
EOF

# 启动 Nginx
systemctl start nginx
systemctl enable nginx
```

#### 5. 安装和配置 Web 服务器

```bash
# 在每个 Web 服务器上

# 安装 Nginx 和 PHP
yum install -y epel-release
yum install -y nginx php php-fpm php-mysql

# 配置 Nginx
cat > /etc/nginx/nginx.conf << 'EOF'
user nginx;
worker_processes auto;

events {
    worker_connections 1024;
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    server {
        listen 80;
        server_name _;
        root /var/www/html;
        index index.php index.html;

        location ~ \.php$ {
            fastcgi_pass 127.0.0.1:9000;
            fastcgi_index index.php;
            fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
            include fastcgi_params;
        }
    }
}
EOF

# 创建测试页面
mkdir -p /var/www/html
cat > /var/www/html/index.php << 'EOF'
<?php
echo "Web Server: " . gethostname() . "<br>";
echo "IP Address: " . $_SERVER['SERVER_ADDR'] . "<br>";
echo "Time: " . date('Y-m-d H:i:s') . "<br>";

// 测试数据库连接
$conn = new mysqli("192.168.122.20", "webuser", "password", "webdb");
if ($conn->connect_error) {
    echo "Database: Disconnected<br>";
} else {
    echo "Database: Connected<br>";
    $conn->close();
}
?>
EOF

# 启动服务
systemctl start nginx php-fpm
systemctl enable nginx php-fpm
```

#### 6. 安装和配置 MySQL 数据库

```bash
# 在 mysql-db 虚拟机上

# 安装 MySQL
yum install -y mariadb-server

# 启动 MySQL
systemctl start mariadb
systemctl enable mariadb

# 安全配置
mysql_secure_installation

# 创建数据库和用户
mysql -u root -p << EOF
CREATE DATABASE webdb;
CREATE USER 'webuser'@'192.168.122.%' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON webdb.* TO 'webuser'@'192.168.122.%';
FLUSH PRIVILEGES;
EOF
```

#### 7. 测试集群

```bash
# 从宿主机测试
for i in {1..10}; do
    curl http://192.168.122.10
    echo ""
done

# 应该看到请求被分发到不同的 Web 服务器
```

### 优化建议

1. **会话保持**: 配置 Nginx 的 ip_hash 或 sticky 模块
2. **健康检查**: 配置后端服务器健康检查
3. **缓存**: 配置 Nginx 缓存静态文件
4. **数据库主从**: 配置 MySQL 主从复制
5. **监控**: 部署监控系统（Zabbix、Prometheus）

## 案例 2：Docker 容器平台

### 场景描述

在 KVM 虚拟机中搭建 Docker 容器平台。

### 实施步骤

#### 1. 创建虚拟机

```bash
virt-install \
  --name docker-host \
  --memory 4096 \
  --vcpus 4 \
  --disk size=50 \
  --cdrom /var/lib/libvirt/images/iso/CentOS-7-x86_64-Minimal-2009.iso \
  --os-variant centos7.0 \
  --network network=default \
  --graphics vnc
```

#### 2. 安装 Docker

```bash
# 在虚拟机内

# 安装 Docker
yum install -y yum-utils
yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
yum install -y docker-ce docker-ce-cli containerd.io

# 启动 Docker
systemctl start docker
systemctl enable docker

# 测试
docker run hello-world
```

#### 3. 部署应用

```bash
# 部署 Nginx
docker run -d --name nginx -p 80:80 nginx

# 部署 MySQL
docker run -d --name mysql \
  -e MYSQL_ROOT_PASSWORD=password \
  -v /data/mysql:/var/lib/mysql \
  mysql:5.7

# 部署 WordPress
docker run -d --name wordpress \
  -p 8080:80 \
  -e WORDPRESS_DB_HOST=mysql \
  -e WORDPRESS_DB_PASSWORD=password \
  --link mysql:mysql \
  wordpress
```

## 案例 3：Kubernetes 集群

### 场景描述

使用 KVM 虚拟机搭建 Kubernetes 集群。

### 架构设计

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│   Master    │  │   Worker 1  │  │   Worker 2  │
│ .122.30     │  │  .122.31    │  │  .122.32    │
└─────────────┘  └─────────────┘  └─────────────┘
```

### 实施步骤

#### 1. 创建虚拟机

```bash
# 创建 Master 节点
virt-install \
  --name k8s-master \
  --memory 4096 \
  --vcpus 2 \
  --disk size=50 \
  --cdrom /var/lib/libvirt/images/iso/CentOS-7-x86_64-Minimal-2009.iso \
  --os-variant centos7.0 \
  --network network=default \
  --graphics vnc

# 创建 Worker 节点
virt-clone --original k8s-master --name k8s-worker-01 --auto-clone
virt-clone --original k8s-master --name k8s-worker-02 --auto-clone
```

#### 2. 安装 Kubernetes

```bash
# 在所有节点上

# 关闭 SELinux 和防火墙
setenforce 0
sed -i 's/^SELINUX=enforcing$/SELINUX=permissive/' /etc/selinux/config
systemctl stop firewalld
systemctl disable firewalld

# 关闭 swap
swapoff -a
sed -i '/ swap / s/^\(.*\)$/#\1/g' /etc/fstab

# 安装 Docker
yum install -y yum-utils
yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
yum install -y docker-ce
systemctl start docker
systemctl enable docker

# 安装 kubeadm、kubelet、kubectl
cat <<EOF > /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://packages.cloud.google.com/yum/repos/kubernetes-el7-x86_64
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://packages.cloud.google.com/yum/doc/yum-key.gpg https://packages.cloud.google.com/yum/doc/rpm-package-key.gpg
EOF

yum install -y kubelet kubeadm kubectl
systemctl enable kubelet
```

#### 3. 初始化集群

```bash
# 在 Master 节点上

# 初始化
kubeadm init --pod-network-cidr=10.244.0.0/16

# 配置 kubectl
mkdir -p $HOME/.kube
cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
chown $(id -u):$(id -g) $HOME/.kube/config

# 安装网络插件（Flannel）
kubectl apply -f https://raw.githubusercontent.com/coreos/flannel/master/Documentation/kube-flannel.yml
```

#### 4. 加入 Worker 节点

```bash
# 在 Worker 节点上
# 使用 Master 节点初始化时输出的 join 命令
kubeadm join 192.168.122.30:6443 --token <token> --discovery-token-ca-cert-hash sha256:<hash>
```

## 案例 4：CI/CD 环境

### 场景描述

搭建 Jenkins + GitLab + Harbor 的 CI/CD 环境。

### 实施步骤

#### 1. 创建虚拟机

```bash
# Jenkins 服务器
virt-install --name jenkins --memory 4096 --vcpus 2 --disk size=50 ...

# GitLab 服务器
virt-install --name gitlab --memory 8192 --vcpus 4 --disk size=100 ...

# Harbor 镜像仓库
virt-install --name harbor --memory 4096 --vcpus 2 --disk size=100 ...
```

#### 2. 安装 Jenkins

```bash
# 在 jenkins 虚拟机上
yum install -y java-11-openjdk
wget -O /etc/yum.repos.d/jenkins.repo https://pkg.jenkins.io/redhat-stable/jenkins.repo
rpm --import https://pkg.jenkins.io/redhat-stable/jenkins.io.key
yum install -y jenkins
systemctl start jenkins
systemctl enable jenkins
```

#### 3. 安装 GitLab

```bash
# 在 gitlab 虚拟机上
curl -sS https://packages.gitlab.com/install/repositories/gitlab/gitlab-ce/script.rpm.sh | bash
yum install -y gitlab-ce
gitlab-ctl reconfigure
```

#### 4. 安装 Harbor

```bash
# 在 harbor 虚拟机上
# 下载并安装 Docker Compose
curl -L "https://github.com/docker/compose/releases/download/1.29.2/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

# 下载 Harbor
wget https://github.com/goharbor/harbor/releases/download/v2.5.0/harbor-offline-installer-v2.5.0.tgz
tar xzvf harbor-offline-installer-v2.5.0.tgz
cd harbor
./install.sh
```
