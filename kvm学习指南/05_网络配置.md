# 网络配置

## KVM 网络模式

KVM 支持多种网络模式，每种模式适用于不同的场景。

### 网络模式对比

| 模式 | 虚拟机访问外网 | 外网访问虚拟机 | 虚拟机互访 | 配置难度 | 适用场景 |
|------|--------------|--------------|----------|---------|---------|
| NAT | ✅ | ❌ (需端口转发) | ✅ | 简单 | 开发测试 |
| 桥接 | ✅ | ✅ | ✅ | 中等 | 生产环境 |
| 隔离 | ❌ | ❌ | ✅ | 简单 | 安全隔离 |
| 路由 | ✅ | ✅ (需路由) | ✅ | 复杂 | 复杂网络 |

## NAT 网络模式（默认）

### 1. 查看默认 NAT 网络

```bash
# 列出所有网络
virsh net-list --all

# 查看默认网络信息
virsh net-info default

# 查看网络配置
virsh net-dumpxml default
```

**默认配置**:
```xml
<network>
  <name>default</name>
  <forward mode='nat'/>
  <bridge name='virbr0' stp='on' delay='0'/>
  <ip address='192.168.122.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.122.2' end='192.168.122.254'/>
    </dhcp>
  </ip>
</network>
```

### 2. 创建自定义 NAT 网络

```bash
# 创建网络配置文件
cat > /tmp/nat-network.xml << EOF
<network>
  <name>nat-network</name>
  <forward mode='nat'/>
  <bridge name='virbr1' stp='on' delay='0'/>
  <ip address='192.168.100.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.100.100' end='192.168.100.200'/>
    </dhcp>
  </ip>
</network>
EOF

# 定义网络
virsh net-define /tmp/nat-network.xml

# 启动网络
virsh net-start nat-network

# 设置自动启动
virsh net-autostart nat-network

# 查看网络
virsh net-list --all
```

### 3. NAT 端口转发

将宿主机端口转发到虚拟机：

```bash
# 方法 1: 使用 iptables
# 转发宿主机 8080 端口到虚拟机 192.168.122.10:80
sudo iptables -t nat -A PREROUTING -p tcp --dport 8080 \
  -j DNAT --to-destination 192.168.122.10:80

sudo iptables -A FORWARD -p tcp -d 192.168.122.10 --dport 80 \
  -j ACCEPT

# 保存规则
sudo iptables-save > /etc/iptables/rules.v4

# 方法 2: 在网络配置中添加
virsh net-edit default
```

添加端口转发配置：
```xml
<network>
  <name>default</name>
  <forward mode='nat'>
    <nat>
      <port start='1024' end='65535'/>
    </nat>
  </forward>
  <bridge name='virbr0' stp='on' delay='0'/>
  <ip address='192.168.122.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.122.2' end='192.168.122.254'/>
    </dhcp>
  </ip>
  <forward mode='nat'>
    <port start='8080' end='8080'/>
  </forward>
</network>
```

### 4. DHCP 静态分配

为虚拟机分配固定 IP：

```bash
# 编辑网络配置
virsh net-edit default
```

添加静态 DHCP 配置：
```xml
<network>
  <name>default</name>
  <forward mode='nat'/>
  <bridge name='virbr0' stp='on' delay='0'/>
  <ip address='192.168.122.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.122.100' end='192.168.122.200'/>
      <!-- 静态分配 -->
      <host mac='52:54:00:xx:xx:xx' name='web-server' ip='192.168.122.10'/>
      <host mac='52:54:00:yy:yy:yy' name='db-server' ip='192.168.122.11'/>
    </dhcp>
  </ip>
</network>
```

重启网络使配置生效：
```bash
virsh net-destroy default
virsh net-start default
```

## 桥接网络模式

桥接模式让虚拟机直接连接到物理网络，获得独立 IP。

### 1. 创建网桥

#### Ubuntu/Debian (使用 netplan)

```bash
# 备份网络配置
sudo cp /etc/netplan/00-installer-config.yaml /etc/netplan/00-installer-config.yaml.bak

# 编辑配置
sudo vi /etc/netplan/00-installer-config.yaml
```

配置示例：
```yaml
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: no
  bridges:
    br0:
      interfaces: [enp0s3]
      dhcp4: yes
      # 或使用静态 IP
      # addresses: [192.168.1.100/24]
      # gateway4: 192.168.1.1
      # nameservers:
      #   addresses: [8.8.8.8, 8.8.4.4]
```

应用配置：
```bash
sudo netplan apply
```

#### CentOS/RHEL (使用 nmcli)

```bash
# 创建网桥
sudo nmcli connection add type bridge ifname br0 con-name br0

# 添加物理网卡到网桥
sudo nmcli connection add type bridge-slave ifname eth0 master br0

# 配置 IP（DHCP）
sudo nmcli connection modify br0 ipv4.method auto

# 或配置静态 IP
sudo nmcli connection modify br0 \
  ipv4.addresses 192.168.1.100/24 \
  ipv4.gateway 192.168.1.1 \
  ipv4.dns "8.8.8.8 8.8.4.4" \
  ipv4.method manual

# 启动网桥
sudo nmcli connection up br0
```

### 2. 创建桥接网络

```bash
# 创建桥接网络配置
cat > /tmp/bridge-network.xml << EOF
<network>
  <name>bridge-network</name>
  <forward mode='bridge'/>
  <bridge name='br0'/>
</network>
EOF

# 定义网络
virsh net-define /tmp/bridge-network.xml

# 启动网络
virsh net-start bridge-network

# 设置自动启动
virsh net-autostart bridge-network
```

### 3. 虚拟机使用桥接网络

#### 创建虚拟机时指定

```bash
virt-install \
  --name bridge-vm \
  --memory 2048 \
  --vcpus 2 \
  --disk size=20 \
  --network bridge=br0,model=virtio \
  --cdrom /path/to/iso \
  --os-variant centos7.0
```

#### 修改现有虚拟机

```bash
# 编辑虚拟机配置
virsh edit vm-name
```

修改网络部分：
```xml
<interface type='bridge'>
  <source bridge='br0'/>
  <model type='virtio'/>
</interface>
```

## 隔离网络模式

隔离网络让虚拟机之间可以通信，但无法访问外网。

### 创建隔离网络

```bash
# 创建隔离网络配置
cat > /tmp/isolated-network.xml << EOF
<network>
  <name>isolated-network</name>
  <bridge name='virbr2' stp='on' delay='0'/>
  <ip address='10.0.0.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='10.0.0.2' end='10.0.0.254'/>
    </dhcp>
  </ip>
</network>
EOF

# 定义并启动网络
virsh net-define /tmp/isolated-network.xml
virsh net-start isolated-network
virsh net-autostart isolated-network
```

## 多网卡配置

虚拟机可以配置多个网卡，连接到不同的网络。

### 1. 添加网卡

```bash
# 添加网卡（临时）
virsh attach-interface vm-name \
  --type network \
  --source default \
  --model virtio \
  --live

# 添加网卡（永久）
virsh attach-interface vm-name \
  --type network \
  --source default \
  --model virtio \
  --config

# 添加网卡（临时+永久）
virsh attach-interface vm-name \
  --type network \
  --source default \
  --model virtio \
  --live --config
```

### 2. 删除网卡

```bash
# 查看网卡 MAC 地址
virsh domiflist vm-name

# 删除网卡
virsh detach-interface vm-name \
  --type network \
  --mac 52:54:00:xx:xx:xx \
  --config
```

### 3. 多网卡配置示例

```xml
<devices>
  <!-- 管理网络 (NAT) -->
  <interface type='network'>
    <source network='default'/>
    <model type='virtio'/>
  </interface>
  
  <!-- 业务网络 (桥接) -->
  <interface type='bridge'>
    <source bridge='br0'/>
    <model type='virtio'/>
  </interface>
  
  <!-- 存储网络 (隔离) -->
  <interface type='network'>
    <source network='storage-network'/>
    <model type='virtio'/>
  </interface>
</devices>
```

## 网络性能优化

### 1. 使用 virtio 驱动

```xml
<interface type='network'>
  <source network='default'/>
  <model type='virtio'/>  <!-- 使用 virtio -->
</interface>
```

### 2. 启用多队列

```xml
<interface type='network'>
  <source network='default'/>
  <model type='virtio'/>
  <driver name='vhost' queues='4'/>  <!-- 多队列 -->
</interface>
```

### 3. 调整网络参数

```bash
# 在虚拟机内调整
ethtool -K eth0 tso off gso off
ethtool -G eth0 rx 4096 tx 4096
```

## 网络故障排查

### 1. 检查网络配置

```bash
# 查看所有网络
virsh net-list --all

# 查看网络详情
virsh net-info default

# 查看网桥
ip addr show virbr0
brctl show

# 查看虚拟机网卡
virsh domiflist vm-name
```

### 2. 检查网络连通性

```bash
# 在宿主机 ping 虚拟机
ping 192.168.122.10

# 在虚拟机 ping 网关
ping 192.168.122.1

# 在虚拟机 ping 外网
ping 8.8.8.8
```

### 3. 检查防火墙

```bash
# 查看 iptables 规则
sudo iptables -L -n -v
sudo iptables -t nat -L -n -v

# 查看 firewalld 规则
sudo firewall-cmd --list-all

# 临时关闭防火墙测试
sudo systemctl stop firewalld
```

### 4. 检查 DHCP

```bash
# 查看 DHCP 租约
virsh net-dhcp-leases default

# 在虚拟机内重新获取 IP
sudo dhclient -r
sudo dhclient
```

## 实用脚本

### 1. 网络信息查看脚本

```bash
#!/bin/bash
# 查看所有虚拟机网络信息

echo "虚拟网络列表:"
echo "================================"
virsh net-list --all
echo ""

echo "虚拟机网络配置:"
echo "================================"
for vm in $(virsh list --all --name); do
    echo "虚拟机: $vm"
    virsh domiflist $vm
    virsh domifaddr $vm
    echo ""
done
```

### 2. 端口转发配置脚本

```bash
#!/bin/bash
# 配置端口转发

HOST_PORT=$1
VM_IP=$2
VM_PORT=$3

if [ -z "$HOST_PORT" ] || [ -z "$VM_IP" ] || [ -z "$VM_PORT" ]; then
    echo "用法: $0 <宿主机端口> <虚拟机IP> <虚拟机端口>"
    echo "示例: $0 8080 192.168.122.10 80"
    exit 1
fi

echo "配置端口转发:"
echo "  宿主机端口: $HOST_PORT"
echo "  虚拟机: $VM_IP:$VM_PORT"

# 添加 iptables 规则
sudo iptables -t nat -A PREROUTING -p tcp --dport $HOST_PORT \
  -j DNAT --to-destination $VM_IP:$VM_PORT

sudo iptables -A FORWARD -p tcp -d $VM_IP --dport $VM_PORT \
  -j ACCEPT

echo "端口转发配置完成"
echo ""
echo "测试: curl http://localhost:$HOST_PORT"
```
