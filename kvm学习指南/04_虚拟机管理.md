# 虚拟机管理

## virsh 命令详解

virsh 是 KVM 虚拟机管理的核心命令行工具。

### 基本语法

```bash
virsh [选项] <命令> [参数]

# 常用选项
-c, --connect URI    # 连接到指定的 hypervisor
-q, --quiet          # 静默模式
-t, --timing         # 显示命令执行时间
```

## 虚拟机生命周期管理

### 1. 列出虚拟机

```bash
# 列出运行中的虚拟机
virsh list

# 列出所有虚拟机（包括关闭的）
virsh list --all

# 只显示名称
virsh list --name

# 只显示 UUID
virsh list --uuid

# 显示标题
virsh list --title
```

**输出示例**:
```
 Id   Name                State
------------------------------------
 1    centos7-web         running
 -    ubuntu-db           shut off
 -    test-vm             shut off
```

### 2. 启动虚拟机

```bash
# 启动虚拟机
virsh start <vm-name>

# 示例
virsh start centos7-web

# 启动并连接到控制台
virsh start centos7-web --console

# 启动时传递参数
virsh start centos7-web --paused  # 启动后暂停
```

### 3. 关闭虚拟机

```bash
# 正常关机（发送 ACPI 关机信号）
virsh shutdown <vm-name>

# 强制关机（类似拔电源）
virsh destroy <vm-name>

# 重启虚拟机
virsh reboot <vm-name>

# 强制重启
virsh reset <vm-name>
```

**区别说明**:
- `shutdown`: 正常关机，给系统时间保存数据
- `destroy`: 立即关闭，可能导致数据丢失
- `reboot`: 正常重启
- `reset`: 强制重启（类似按重启按钮）

### 4. 暂停和恢复

```bash
# 暂停虚拟机（挂起到内存）
virsh suspend <vm-name>

# 恢复虚拟机
virsh resume <vm-name>

# 保存虚拟机状态到文件
virsh save <vm-name> /path/to/save/file

# 从文件恢复虚拟机
virsh restore /path/to/save/file
```

**使用场景**:
- `suspend/resume`: 临时暂停，快速恢复
- `save/restore`: 保存状态到磁盘，可以关闭宿主机

### 5. 自动启动

```bash
# 设置开机自启
virsh autostart <vm-name>

# 取消开机自启
virsh autostart --disable <vm-name>

# 查看自启状态
virsh dominfo <vm-name> | grep Autostart
```

### 6. 删除虚拟机

```bash
# 删除虚拟机定义（保留磁盘）
virsh undefine <vm-name>

# 删除虚拟机并删除存储
virsh undefine <vm-name> --remove-all-storage

# 删除虚拟机并删除快照
virsh undefine <vm-name> --snapshots-metadata

# 完全删除（定义+存储+快照）
virsh undefine <vm-name> --remove-all-storage --snapshots-metadata
```

**注意**: 删除前确保虚拟机已关闭！

## 虚拟机信息查看

### 1. 基本信息

```bash
# 查看虚拟机详细信息
virsh dominfo <vm-name>

# 查看虚拟机 ID
virsh domid <vm-name>

# 查看虚拟机 UUID
virsh domuuid <vm-name>

# 查看虚拟机状态
virsh domstate <vm-name>
```

**输出示例**:
```
Id:             1
Name:           centos7-web
UUID:           xxx-xxx-xxx
OS Type:        hvm
State:          running
CPU(s):         2
CPU time:       10.5s
Max memory:     2097152 KiB
Used memory:    2097152 KiB
Persistent:     yes
Autostart:      enable
```

### 2. 资源使用情况

```bash
# 查看 CPU 使用
virsh domstats <vm-name> --cpu-total

# 查看内存使用
virsh domstats <vm-name> --balloon

# 查看磁盘 I/O
virsh domstats <vm-name> --block

# 查看网络 I/O
virsh domstats <vm-name> --net

# 查看所有统计信息
virsh domstats <vm-name>
```

### 3. 硬件配置

```bash
# 查看 CPU 配置
virsh vcpucount <vm-name>

# 查看内存配置
virsh dommemstat <vm-name>

# 查看磁盘列表
virsh domblklist <vm-name>

# 查看网卡列表
virsh domiflist <vm-name>

# 查看所有设备
virsh domblkinfo <vm-name> <disk-target>
```

### 4. XML 配置

```bash
# 查看完整 XML 配置
virsh dumpxml <vm-name>

# 保存 XML 到文件
virsh dumpxml <vm-name> > vm-config.xml

# 只查看设备部分
virsh dumpxml <vm-name> | grep -A 10 "<devices>"
```

## 虚拟机配置修改

### 1. 修改内存

```bash
# 修改最大内存（需要关机）
virsh setmaxmem <vm-name> 4G --config

# 修改当前内存（运行时）
virsh setmem <vm-name> 2G --live

# 同时修改配置和运行时
virsh setmem <vm-name> 2G --live --config
```

**单位说明**:
- `K` 或 `KiB`: KB
- `M` 或 `MiB`: MB
- `G` 或 `GiB`: GB

### 2. 修改 CPU

```bash
# 修改 CPU 数量（需要关机）
virsh setvcpus <vm-name> 4 --config

# 热添加 CPU（运行时）
virsh setvcpus <vm-name> 4 --live

# 查看 CPU 信息
virsh vcpuinfo <vm-name>

# 设置 CPU 亲和性
virsh vcpupin <vm-name> 0 0-3
```

### 3. 修改磁盘

```bash
# 添加磁盘
virsh attach-disk <vm-name> \
  /var/lib/libvirt/images/new-disk.qcow2 \
  vdb \
  --driver qemu \
  --subdriver qcow2 \
  --persistent

# 移除磁盘
virsh detach-disk <vm-name> vdb --persistent

# 调整磁盘大小（需要关机）
qemu-img resize /var/lib/libvirt/images/vm-disk.qcow2 +10G
```

### 4. 修改网卡

```bash
# 添加网卡
virsh attach-interface <vm-name> \
  --type network \
  --source default \
  --model virtio \
  --persistent

# 移除网卡
virsh detach-interface <vm-name> \
  --type network \
  --mac 52:54:00:xx:xx:xx \
  --persistent

# 查看网卡 MAC 地址
virsh domiflist <vm-name>
```

### 5. 编辑配置

```bash
# 直接编辑 XML 配置
virsh edit <vm-name>

# 这会打开默认编辑器（通常是 vi）
# 修改后保存即可生效
```

**常见修改**:
- 修改启动顺序
- 添加/删除设备
- 修改网络配置
- 修改显示配置

## 虚拟机控制台

### 1. 文本控制台

```bash
# 连接到串口控制台
virsh console <vm-name>

# 退出控制台: Ctrl + ]
```

**注意**: 需要虚拟机配置了串口控制台。

### 2. 图形控制台

```bash
# 使用 virt-viewer
virt-viewer <vm-name>

# 查看 VNC 端口
virsh vncdisplay <vm-name>

# 查看 SPICE 端口
virsh domdisplay <vm-name>
```

### 3. 发送按键

```bash
# 发送 Ctrl+Alt+Del
virsh send-key <vm-name> KEY_LEFTCTRL KEY_LEFTALT KEY_DELETE

# 发送 Ctrl+Alt+F1
virsh send-key <vm-name> KEY_LEFTCTRL KEY_LEFTALT KEY_F1
```

## 虚拟机克隆

### 1. 完整克隆

```bash
# 克隆虚拟机（自动克隆磁盘）
virt-clone \
  --original <source-vm> \
  --name <new-vm> \
  --auto-clone

# 指定新磁盘路径
virt-clone \
  --original <source-vm> \
  --name <new-vm> \
  --file /var/lib/libvirt/images/new-vm.qcow2
```

### 2. 链接克隆

```bash
# 创建链接克隆（基于原磁盘）
qemu-img create -f qcow2 \
  -b /var/lib/libvirt/images/source-vm.qcow2 \
  /var/lib/libvirt/images/clone-vm.qcow2

# 然后使用 virt-install --import 导入
```

## 虚拟机迁移

### 1. 离线迁移

```bash
# 导出虚拟机配置
virsh dumpxml <vm-name> > vm-config.xml

# 复制磁盘文件到目标主机
scp /var/lib/libvirt/images/vm-disk.qcow2 user@target-host:/var/lib/libvirt/images/

# 在目标主机导入
virsh define vm-config.xml
```

### 2. 在线迁移（需要共享存储）

```bash
# 迁移到另一台主机
virsh migrate <vm-name> \
  qemu+ssh://target-host/system \
  --live \
  --persistent \
  --undefinesource
```

## 批量管理脚本

### 1. 批量启动虚拟机

```bash
#!/bin/bash
# 启动所有虚拟机

for vm in $(virsh list --all --name); do
    state=$(virsh domstate $vm)
    if [ "$state" = "shut off" ]; then
        echo "启动虚拟机: $vm"
        virsh start $vm
    fi
done
```

### 2. 批量关闭虚拟机

```bash
#!/bin/bash
# 关闭所有运行中的虚拟机

for vm in $(virsh list --name); do
    echo "关闭虚拟机: $vm"
    virsh shutdown $vm
done

# 等待所有虚拟机关闭
echo "等待虚拟机关闭..."
sleep 30

# 强制关闭未关闭的虚拟机
for vm in $(virsh list --name); do
    echo "强制关闭虚拟机: $vm"
    virsh destroy $vm
done
```

### 3. 虚拟机状态监控

```bash
#!/bin/bash
# 监控虚拟机状态

echo "虚拟机状态监控"
echo "================================"

for vm in $(virsh list --all --name); do
    state=$(virsh domstate $vm)
    cpu=$(virsh domstats $vm --cpu-total 2>/dev/null | grep cpu.time | awk '{print $2}')
    mem=$(virsh dommemstat $vm 2>/dev/null | grep actual | awk '{print $2}')
    
    printf "%-20s %-15s CPU: %-10s MEM: %-10s\n" \
        "$vm" "$state" "${cpu:-N/A}" "${mem:-N/A}"
done
```

### 4. 虚拟机备份脚本

```bash
#!/bin/bash
# 备份虚拟机

VM_NAME=$1
BACKUP_DIR="/backup/vms"
DATE=$(date +%Y%m%d_%H%M%S)

if [ -z "$VM_NAME" ]; then
    echo "用法: $0 <vm-name>"
    exit 1
fi

echo "备份虚拟机: $VM_NAME"

# 创建备份目录
mkdir -p "$BACKUP_DIR/$VM_NAME"

# 导出配置
virsh dumpxml $VM_NAME > "$BACKUP_DIR/$VM_NAME/${VM_NAME}_${DATE}.xml"

# 获取磁盘路径
DISK_PATH=$(virsh domblklist $VM_NAME | grep vda | awk '{print $2}')

# 备份磁盘
if [ -n "$DISK_PATH" ]; then
    echo "备份磁盘: $DISK_PATH"
    cp "$DISK_PATH" "$BACKUP_DIR/$VM_NAME/${VM_NAME}_${DATE}.qcow2"
fi

echo "备份完成: $BACKUP_DIR/$VM_NAME/"
```

## 常见问题

### Q1: 虚拟机无法启动

```bash
# 查看错误信息
virsh start <vm-name>

# 查看日志
sudo journalctl -u libvirtd -f

# 检查配置
virsh dumpxml <vm-name>

# 验证配置
virt-xml-validate vm-config.xml
```

### Q2: 虚拟机性能差

```bash
# 检查 CPU 使用
virsh domstats <vm-name> --cpu-total

# 检查内存使用
virsh dommemstat <vm-name>

# 检查磁盘 I/O
virsh domblkstat <vm-name> vda

# 使用 virt-top 监控
virt-top
```

### Q3: 无法连接控制台

```bash
# 检查虚拟机状态
virsh domstate <vm-name>

# 检查 VNC 配置
virsh vncdisplay <vm-name>

# 使用 virt-viewer
virt-viewer <vm-name>

# 检查防火墙
sudo firewall-cmd --list-all
```

### Q4: 虚拟机磁盘满了

```bash
# 查看磁盘使用
virsh domblkinfo <vm-name> vda

# 扩容磁盘（需要关机）
virsh shutdown <vm-name>
qemu-img resize /path/to/disk.qcow2 +10G
virsh start <vm-name>

# 在虚拟机内扩展分区
# CentOS/RHEL
growpart /dev/vda 1
xfs_growfs /

# Ubuntu
growpart /dev/vda 1
resize2fs /dev/vda1
```
