# 存储管理

## 存储架构

KVM 存储管理分为两个层次：
1. **存储池 (Storage Pool)**: 存储资源的集合
2. **存储卷 (Storage Volume)**: 存储池中的具体存储单元

```
存储池 (Pool)
├── 存储卷 1 (Volume) - vm1.qcow2
├── 存储卷 2 (Volume) - vm2.qcow2
└── 存储卷 3 (Volume) - vm3.qcow2
```

## 存储池管理

### 1. 查看存储池

```bash
# 列出所有存储池
virsh pool-list --all

# 查看存储池详情
virsh pool-info default

# 查看存储池配置
virsh pool-dumpxml default
```

**输出示例**:
```
Name:           default
UUID:           xxx-xxx-xxx
State:          running
Persistent:     yes
Autostart:      yes
Capacity:       100.00 GiB
Allocation:     20.00 GiB
Available:      80.00 GiB
```

### 2. 创建目录类型存储池

```bash
# 创建存储目录
sudo mkdir -p /data/kvm/images

# 定义存储池
virsh pool-define-as \
  --name data-pool \
  --type dir \
  --target /data/kvm/images

# 构建存储池
virsh pool-build data-pool

# 启动存储池
virsh pool-start data-pool

# 设置自动启动
virsh pool-autostart data-pool

# 查看存储池
virsh pool-list --all
```

### 3. 创建 LVM 存储池

```bash
# 创建 VG（如果还没有）
sudo vgcreate vg_kvm /dev/sdb

# 定义 LVM 存储池
virsh pool-define-as \
  --name lvm-pool \
  --type logical \
  --source-name vg_kvm \
  --target /dev/vg_kvm

# 启动存储池
virsh pool-start lvm-pool
virsh pool-autostart lvm-pool
```

### 4. 创建 NFS 存储池

```bash
# 定义 NFS 存储池
virsh pool-define-as \
  --name nfs-pool \
  --type netfs \
  --source-host 192.168.1.100 \
  --source-path /export/kvm \
  --target /mnt/nfs-kvm

# 启动存储池
virsh pool-start nfs-pool
virsh pool-autostart nfs-pool
```

### 5. 删除存储池

```bash
# 停止存储池
virsh pool-destroy pool-name

# 删除存储池定义
virsh pool-undefine pool-name

# 删除存储池目录（可选）
sudo rm -rf /path/to/pool
```

## 存储卷管理

### 1. 查看存储卷

```bash
# 列出存储池中的所有卷
virsh vol-list default

# 查看存储卷详情
virsh vol-info vm-disk.qcow2 --pool default

# 查看存储卷路径
virsh vol-path vm-disk.qcow2 --pool default
```

### 2. 创建存储卷

```bash
# 创建 qcow2 格式存储卷
virsh vol-create-as \
  --pool default \
  --name new-vm.qcow2 \
  --capacity 20G \
  --format qcow2

# 创建 raw 格式存储卷
virsh vol-create-as \
  --pool default \
  --name new-vm.raw \
  --capacity 20G \
  --format raw
```

### 3. 克隆存储卷

```bash
# 克隆存储卷
virsh vol-clone \
  --pool default \
  --vol source-vm.qcow2 \
  --newname clone-vm.qcow2
```

### 4. 删除存储卷

```bash
# 删除存储卷
virsh vol-delete vm-disk.qcow2 --pool default

# 或使用完整路径
virsh vol-delete /var/lib/libvirt/images/vm-disk.qcow2
```

### 5. 上传/下载存储卷

```bash
# 上传文件到存储池
virsh vol-upload \
  --pool default \
  --vol vm-disk.qcow2 \
  --file /path/to/local/disk.qcow2

# 从存储池下载文件
virsh vol-download \
  --pool default \
  --vol vm-disk.qcow2 \
  --file /path/to/save/disk.qcow2
```

## 磁盘格式

### qcow2 vs raw

| 特性 | qcow2 | raw |
|------|-------|-----|
| 性能 | 较好 | 最好 |
| 空间使用 | 动态分配 | 固定大小 |
| 快照支持 | ✅ | ❌ |
| 压缩支持 | ✅ | ❌ |
| 加密支持 | ✅ | ❌ |
| 适用场景 | 开发测试 | 生产环境 |

### 1. 创建磁盘

```bash
# 创建 qcow2 磁盘
qemu-img create -f qcow2 vm-disk.qcow2 20G

# 创建 raw 磁盘
qemu-img create -f raw vm-disk.raw 20G

# 创建预分配的 qcow2（性能更好）
qemu-img create -f qcow2 -o preallocation=metadata vm-disk.qcow2 20G
```

### 2. 查看磁盘信息

```bash
# 查看磁盘信息
qemu-img info vm-disk.qcow2

# 输出示例:
# image: vm-disk.qcow2
# file format: qcow2
# virtual size: 20 GiB (21474836480 bytes)
# disk size: 196 KiB
# cluster_size: 65536
```

### 3. 转换磁盘格式

```bash
# qcow2 转 raw
qemu-img convert -f qcow2 -O raw source.qcow2 target.raw

# raw 转 qcow2
qemu-img convert -f raw -O qcow2 source.raw target.qcow2

# 转换时压缩
qemu-img convert -f qcow2 -O qcow2 -c source.qcow2 target.qcow2
```

### 4. 调整磁盘大小

```bash
# 扩容磁盘
qemu-img resize vm-disk.qcow2 +10G

# 缩小磁盘（需要先在虚拟机内缩小文件系统）
qemu-img resize vm-disk.qcow2 --shrink 30G

# 查看新大小
qemu-img info vm-disk.qcow2
```

### 5. 压缩磁盘

```bash
# 压缩 qcow2 磁盘（回收未使用空间）
qemu-img convert -O qcow2 -c source.qcow2 compressed.qcow2

# 或使用 virt-sparsify
virt-sparsify --compress source.qcow2 compressed.qcow2
```

## 虚拟机磁盘操作

### 1. 添加磁盘

```bash
# 创建新磁盘
qemu-img create -f qcow2 /var/lib/libvirt/images/vm-data.qcow2 50G

# 添加到虚拟机（临时）
virsh attach-disk vm-name \
  /var/lib/libvirt/images/vm-data.qcow2 \
  vdb \
  --driver qemu \
  --subdriver qcow2 \
  --live

# 添加到虚拟机（永久）
virsh attach-disk vm-name \
  /var/lib/libvirt/images/vm-data.qcow2 \
  vdb \
  --driver qemu \
  --subdriver qcow2 \
  --config

# 添加到虚拟机（临时+永久）
virsh attach-disk vm-name \
  /var/lib/libvirt/images/vm-data.qcow2 \
  vdb \
  --driver qemu \
  --subdriver qcow2 \
  --live --config
```

### 2. 移除磁盘

```bash
# 移除磁盘（临时）
virsh detach-disk vm-name vdb --live

# 移除磁盘（永久）
virsh detach-disk vm-name vdb --config

# 移除磁盘（临时+永久）
virsh detach-disk vm-name vdb --live --config
```

### 3. 查看磁盘

```bash
# 查看虚拟机所有磁盘
virsh domblklist vm-name

# 查看磁盘详情
virsh domblkinfo vm-name vda

# 查看磁盘 I/O 统计
virsh domblkstat vm-name vda
```

### 4. 扩容虚拟机磁盘

完整流程：

```bash
# 1. 关闭虚拟机
virsh shutdown vm-name

# 2. 扩容磁盘文件
qemu-img resize /var/lib/libvirt/images/vm-disk.qcow2 +10G

# 3. 启动虚拟机
virsh start vm-name

# 4. 在虚拟机内扩展分区和文件系统
# CentOS/RHEL (XFS)
growpart /dev/vda 1
xfs_growfs /

# Ubuntu (ext4)
growpart /dev/vda 1
resize2fs /dev/vda1
```

## 磁盘性能优化

### 1. 使用 virtio 驱动

```xml
<disk type='file' device='disk'>
  <driver name='qemu' type='qcow2' cache='none' io='native'/>
  <source file='/var/lib/libvirt/images/vm-disk.qcow2'/>
  <target dev='vda' bus='virtio'/>  <!-- 使用 virtio -->
</disk>
```

### 2. 缓存模式

```xml
<!-- 无缓存（推荐生产环境） -->
<driver name='qemu' type='qcow2' cache='none'/>

<!-- 写穿透（推荐开发环境） -->
<driver name='qemu' type='qcow2' cache='writethrough'/>

<!-- 写回（性能最好，但可能丢数据） -->
<driver name='qemu' type='qcow2' cache='writeback'/>
```

### 3. I/O 模式

```xml
<!-- 原生 I/O（推荐） -->
<driver name='qemu' type='qcow2' io='native'/>

<!-- 线程 I/O -->
<driver name='qemu' type='qcow2' io='threads'/>
```

### 4. 磁盘调度器

```bash
# 在虚拟机内设置
echo noop > /sys/block/vda/queue/scheduler

# 或在启动参数中设置
# 编辑 /etc/default/grub
GRUB_CMDLINE_LINUX="elevator=noop"
```

## 存储池类型

### 1. 目录存储池 (dir)

最常用，简单易用。

```bash
virsh pool-define-as \
  --name dir-pool \
  --type dir \
  --target /var/lib/libvirt/images
```

### 2. LVM 存储池 (logical)

性能好，适合生产环境。

```bash
virsh pool-define-as \
  --name lvm-pool \
  --type logical \
  --source-name vg_kvm \
  --target /dev/vg_kvm
```

### 3. NFS 存储池 (netfs)

支持共享存储，适合集群环境。

```bash
virsh pool-define-as \
  --name nfs-pool \
  --type netfs \
  --source-host 192.168.1.100 \
  --source-path /export/kvm \
  --target /mnt/nfs-kvm
```

### 4. iSCSI 存储池 (iscsi)

企业级存储。

```bash
virsh pool-define-as \
  --name iscsi-pool \
  --type iscsi \
  --source-host 192.168.1.100 \
  --source-dev iqn.2024-01.com.example:storage \
  --target /dev/disk/by-path
```

## 实用脚本

### 1. 存储信息查看脚本

```bash
#!/bin/bash
# 查看存储池和存储卷信息

echo "存储池列表:"
echo "================================"
virsh pool-list --all
echo ""

for pool in $(virsh pool-list --name); do
    echo "存储池: $pool"
    echo "--------------------------------"
    virsh pool-info $pool
    echo ""
    echo "存储卷:"
    virsh vol-list $pool
    echo ""
done
```

### 2. 磁盘扩容脚本

```bash
#!/bin/bash
# 虚拟机磁盘扩容脚本

VM_NAME=$1
DISK_PATH=$2
SIZE=$3

if [ -z "$VM_NAME" ] || [ -z "$DISK_PATH" ] || [ -z "$SIZE" ]; then
    echo "用法: $0 <虚拟机名> <磁盘路径> <增加大小>"
    echo "示例: $0 centos7-web /var/lib/libvirt/images/vm.qcow2 +10G"
    exit 1
fi

echo "扩容虚拟机磁盘:"
echo "  虚拟机: $VM_NAME"
echo "  磁盘: $DISK_PATH"
echo "  大小: $SIZE"
echo ""

# 检查虚拟机状态
STATE=$(virsh domstate $VM_NAME)
if [ "$STATE" = "running" ]; then
    echo "警告: 虚拟机正在运行"
    read -p "是否关闭虚拟机? (y/n) " -n 1 -r
    echo
    if [[ $REPLY =~ ^[Yy]$ ]]; then
        virsh shutdown $VM_NAME
        echo "等待虚拟机关闭..."
        sleep 10
    else
        echo "取消操作"
        exit 1
    fi
fi

# 扩容磁盘
echo "扩容磁盘..."
qemu-img resize $DISK_PATH $SIZE

# 显示新大小
echo ""
echo "新磁盘大小:"
qemu-img info $DISK_PATH | grep "virtual size"

echo ""
echo "扩容完成！"
echo "请启动虚拟机并在系统内扩展分区和文件系统"
```

### 3. 磁盘清理脚本

```bash
#!/bin/bash
# 清理未使用的磁盘文件

POOL_PATH="/var/lib/libvirt/images"

echo "查找未使用的磁盘文件..."
echo ""

# 获取所有虚拟机使用的磁盘
USED_DISKS=$(virsh list --all --name | while read vm; do
    virsh domblklist $vm 2>/dev/null | grep -v "^Target" | grep -v "^---" | awk '{print $2}'
done | sort -u)

# 查找所有磁盘文件
ALL_DISKS=$(find $POOL_PATH -name "*.qcow2" -o -name "*.raw")

# 找出未使用的磁盘
echo "未使用的磁盘文件:"
echo "================================"
for disk in $ALL_DISKS; do
    if ! echo "$USED_DISKS" | grep -q "$disk"; then
        size=$(du -h "$disk" | awk '{print $1}')
        echo "$disk ($size)"
    fi
done
```

## 常见问题

### Q1: 磁盘空间不足

```bash
# 查看存储池空间
virsh pool-info default

# 清理不用的虚拟机
virsh undefine old-vm --remove-all-storage

# 压缩磁盘
virt-sparsify --compress source.qcow2 compressed.qcow2
```

### Q2: 磁盘性能差

```bash
# 使用 virtio 驱动
# 使用 cache='none' 和 io='native'
# 使用 raw 格式而不是 qcow2
# 使用 SSD 存储
```

### Q3: 无法扩容磁盘

```bash
# 确保虚拟机已关闭
virsh shutdown vm-name

# 使用 qemu-img resize
qemu-img resize disk.qcow2 +10G

# 在虚拟机内扩展分区
growpart /dev/vda 1
xfs_growfs /  # 或 resize2fs /dev/vda1
```
