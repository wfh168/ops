# 环境检查和安装

## 硬件要求检查

### 1. 检查 CPU 虚拟化支持

#### 方法 1：检查 CPU 标志

```bash
# 检查 CPU 是否支持虚拟化
egrep -c '(vmx|svm)' /proc/cpuinfo
```

**输出说明**：
- `0` - 不支持虚拟化
- `> 0` - 支持虚拟化（数字表示支持虚拟化的 CPU 核心数）

**你的系统**：
```bash
# 输出: 16
# ✅ 你的 CPU 支持虚拟化，有 16 个虚拟核心
```

#### 方法 2：查看虚拟化类型

```bash
# 查看虚拟化技术类型
lscpu | grep -i virtualization
```

**输出说明**：
- `Virtualization: VT-x` - Intel CPU
- `Virtualization: AMD-V` - AMD CPU

**你的系统**：
```bash
# 输出: 虚拟化: AMD-V
# ✅ AMD CPU，支持 AMD-V 虚拟化技术
```

#### 方法 3：检查详细 CPU 信息

```bash
# 查看 CPU 详细信息
lscpu
```

### 2. 检查 BIOS 设置

如果上面的命令显示不支持虚拟化，需要在 BIOS 中启用：

**Intel CPU**：
1. 重启进入 BIOS（通常按 F2, F10, Del）
2. 找到 "Intel Virtualization Technology" 或 "VT-x"
3. 设置为 "Enabled"
4. 保存并重启

**AMD CPU**：
1. 重启进入 BIOS
2. 找到 "SVM Mode" 或 "AMD-V"
3. 设置为 "Enabled"
4. 保存并重启

### 3. 检查内存

```bash
# 查看总内存
free -h

# 推荐配置
# 最低: 4GB
# 推荐: 8GB+
# 理想: 16GB+
```

### 4. 检查磁盘空间

```bash
# 查看磁盘空间
df -h

# 推荐配置
# 最低: 50GB 可用空间
# 推荐: 100GB+
# 理想: 500GB+
```

## 软件安装

### Ubuntu/Debian 系统

#### 1. 更新软件包列表

```bash
sudo apt update
```

#### 2. 安装 KVM 和相关工具

```bash
# 安装 KVM 核心组件
sudo apt install -y qemu-kvm

# 安装 libvirt 管理工具
sudo apt install -y libvirt-daemon-system libvirt-clients

# 安装虚拟机管理工具
sudo apt install -y virt-manager

# 安装其他实用工具
sudo apt install -y bridge-utils virtinst virt-viewer

# 一键安装（推荐）
sudo apt install -y qemu-kvm libvirt-daemon-system libvirt-clients bridge-utils virt-manager virtinst virt-viewer
```

### CentOS/RHEL 系统

#### 1. 安装 KVM 和相关工具

```bash
# CentOS 7
sudo yum install -y qemu-kvm libvirt libvirt-python libguestfs-tools virt-install virt-manager

# CentOS 8 / RHEL 8
sudo dnf install -y qemu-kvm libvirt virt-install virt-manager virt-viewer
```

### Arch Linux 系统

```bash
# 安装 KVM 和相关工具
sudo pacman -S qemu libvirt virt-manager virt-viewer dnsmasq bridge-utils
```

## 验证安装

### 1. 检查 KVM 模块

```bash
# 检查 KVM 模块是否加载
lsmod | grep kvm
```

**预期输出**：
```
kvm_amd               147456  0    # AMD CPU
kvm                  1048576  1 kvm_amd

# 或者 Intel CPU
kvm_intel             311296  0
kvm                  1048576  1 kvm_intel
```

如果没有输出，手动加载模块：

```bash
# AMD CPU
sudo modprobe kvm_amd

# Intel CPU
sudo modprobe kvm_intel
```

### 2. 检查 libvirt 服务

```bash
# 检查 libvirt 服务状态
sudo systemctl status libvirtd
```

**预期输出**：
```
● libvirtd.service - Virtualization daemon
   Loaded: loaded (/lib/systemd/system/libvirtd.service; enabled)
   Active: active (running)
```

如果服务未运行，启动服务：

```bash
# 启动 libvirt 服务
sudo systemctl start libvirtd

# 设置开机自启
sudo systemctl enable libvirtd
```

### 3. 检查命令行工具

```bash
# 检查 virsh 命令
virsh --version

# 检查 qemu 命令
qemu-system-x86_64 --version

# 检查 virt-install 命令
virt-install --version
```

### 4. 检查用户权限

```bash
# 查看当前用户组
groups

# 将当前用户添加到 libvirt 组
sudo usermod -aG libvirt $USER
sudo usermod -aG kvm $USER

# 重新登录或刷新组
newgrp libvirt
```

### 5. 测试 virsh 连接

```bash
# 测试连接到 libvirt
virsh list --all
```

**预期输出**：
```
 Id   Name   State
--------------------
```

如果出现权限错误：

```bash
# 检查 libvirt socket 权限
ls -l /var/run/libvirt/libvirt-sock

# 确保用户在 libvirt 组中
sudo usermod -aG libvirt $USER

# 重新登录
```

## 配置网络

### 1. 检查默认网络

```bash
# 列出所有网络
virsh net-list --all
```

**预期输出**：
```
 Name      State    Autostart   Persistent
--------------------------------------------
 default   active   yes         yes
```

### 2. 启动默认网络

如果默认网络未启动：

```bash
# 启动默认网络
virsh net-start default

# 设置自动启动
virsh net-autostart default
```

### 3. 查看网络配置

```bash
# 查看默认网络配置
virsh net-dumpxml default
```

**输出示例**：
```xml
<network>
  <name>default</name>
  <uuid>...</uuid>
  <forward mode='nat'/>
  <bridge name='virbr0' stp='on' delay='0'/>
  <ip address='192.168.122.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.122.2' end='192.168.122.254'/>
    </dhcp>
  </ip>
</network>
```

### 4. 检查网桥

```bash
# 查看网桥
ip addr show virbr0

# 或使用 brctl
brctl show
```

## 配置存储

### 1. 检查默认存储池

```bash
# 列出所有存储池
virsh pool-list --all
```

**预期输出**：
```
 Name      State    Autostart
-------------------------------
 default   active   yes
```

### 2. 查看存储池信息

```bash
# 查看默认存储池信息
virsh pool-info default
```

**输出示例**：
```
Name:           default
UUID:           ...
State:          running
Persistent:     yes
Autostart:      yes
Capacity:       100.00 GiB
Allocation:     10.00 GiB
Available:      90.00 GiB
```

### 3. 查看存储池路径

```bash
# 查看存储池配置
virsh pool-dumpxml default
```

**默认路径**：`/var/lib/libvirt/images/`

### 4. 创建自定义存储池（可选）

```bash
# 创建存储目录
sudo mkdir -p /data/kvm/images

# 定义存储池
virsh pool-define-as --name data --type dir --target /data/kvm/images

# 构建存储池
virsh pool-build data

# 启动存储池
virsh pool-start data

# 设置自动启动
virsh pool-autostart data
```

## 环境检查脚本

创建一个自动检查脚本：

```bash
#!/bin/bash

echo "=== KVM 环境检查 ==="
echo ""

# 1. 检查 CPU 虚拟化支持
echo "1. 检查 CPU 虚拟化支持"
virt_count=$(egrep -c '(vmx|svm)' /proc/cpuinfo)
if [ $virt_count -gt 0 ]; then
    echo "   ✅ CPU 支持虚拟化 ($virt_count 核心)"
    virt_type=$(lscpu | grep -i virtualization | awk '{print $2}')
    echo "   虚拟化类型: $virt_type"
else
    echo "   ❌ CPU 不支持虚拟化"
    echo "   请在 BIOS 中启用 VT-x/AMD-V"
fi
echo ""

# 2. 检查 KVM 模块
echo "2. 检查 KVM 模块"
if lsmod | grep -q kvm; then
    echo "   ✅ KVM 模块已加载"
    lsmod | grep kvm
else
    echo "   ❌ KVM 模块未加载"
fi
echo ""

# 3. 检查 libvirt 服务
echo "3. 检查 libvirt 服务"
if systemctl is-active --quiet libvirtd; then
    echo "   ✅ libvirt 服务运行中"
else
    echo "   ❌ libvirt 服务未运行"
fi
echo ""

# 4. 检查命令行工具
echo "4. 检查命令行工具"
for cmd in virsh qemu-system-x86_64 virt-install virt-manager; do
    if command -v $cmd &> /dev/null; then
        echo "   ✅ $cmd"
    else
        echo "   ❌ $cmd 未安装"
    fi
done
echo ""

# 5. 检查网络
echo "5. 检查默认网络"
if virsh net-list --all | grep -q default; then
    state=$(virsh net-list --all | grep default | awk '{print $2}')
    if [ "$state" = "active" ]; then
        echo "   ✅ 默认网络已启动"
    else
        echo "   ⚠️  默认网络未启动"
        echo "   运行: virsh net-start default"
    fi
else
    echo "   ❌ 默认网络不存在"
fi
echo ""

# 6. 检查存储池
echo "6. 检查默认存储池"
if virsh pool-list --all | grep -q default; then
    state=$(virsh pool-list --all | grep default | awk '{print $2}')
    if [ "$state" = "active" ]; then
        echo "   ✅ 默认存储池已启动"
    else
        echo "   ⚠️  默认存储池未启动"
        echo "   运行: virsh pool-start default"
    fi
else
    echo "   ❌ 默认存储池不存在"
fi
echo ""

# 7. 检查用户权限
echo "7. 检查用户权限"
if groups | grep -q libvirt; then
    echo "   ✅ 用户在 libvirt 组中"
else
    echo "   ⚠️  用户不在 libvirt 组中"
    echo "   运行: sudo usermod -aG libvirt $USER"
fi
echo ""

# 8. 系统资源
echo "8. 系统资源"
echo "   CPU: $(nproc) 核心"
echo "   内存: $(free -h | awk 'NR==2{print $2}')"
echo "   磁盘: $(df -h / | awk 'NR==2{print $4}') 可用"
echo ""

echo "=== 检查完成 ==="
```

保存为 `check-kvm.sh` 并运行：

```bash
bash kvm学习指南/scripts/check-kvm.sh
```

## 常见问题

### Q1: KVM 模块加载失败

**问题**：`modprobe: ERROR: could not insert 'kvm_intel': Operation not supported`

**解决**：
1. 检查 BIOS 是否启用虚拟化
2. 检查是否在虚拟机中运行（不支持嵌套虚拟化）

### Q2: libvirt 连接失败

**问题**：`error: Failed to connect socket to '/var/run/libvirt/libvirt-sock': Permission denied`

**解决**：
```bash
# 添加用户到 libvirt 组
sudo usermod -aG libvirt $USER

# 重新登录
```

### Q3: 默认网络启动失败

**问题**：`error: Failed to start network default`

**解决**：
```bash
# 检查网络配置
virsh net-dumpxml default

# 删除并重新创建
virsh net-destroy default
virsh net-undefine default
virsh net-define /usr/share/libvirt/networks/default.xml
virsh net-start default
virsh net-autostart default
```

### Q4: virt-manager 无法连接

**问题**：图形界面无法连接到 libvirt

**解决**：
```bash
# 检查服务
sudo systemctl status libvirtd

# 检查 socket
ls -l /var/run/libvirt/libvirt-sock

# 重启服务
sudo systemctl restart libvirtd
```
