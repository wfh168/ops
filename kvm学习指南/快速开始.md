# KVM 快速开始指南

## 你的环境状态

✅ **环境已就绪！**

你的系统已经完全配置好 KVM，可以直接开始使用：
- CPU: AMD-V 虚拟化，16 核心
- 内存: 30GB
- 存储: 36.62 GB 可用
- 已有 3 个虚拟机

## 5 分钟快速体验

### 1. 查看现有虚拟机

```bash
virsh list --all
```

输出：
```
 Id   Name                   State
---------------------------------------
 -    android-x86-9.0        shut off
 -    centos7.0              shut off
 -    centos7.0-10.0.0.166   shut off
```

### 2. 启动一个虚拟机

```bash
# 启动 centos7.0 虚拟机
virsh start centos7.0

# 查看状态
virsh list
```

### 3. 查看虚拟机信息

```bash
# 查看详细信息
virsh dominfo centos7.0

# 查看 CPU 和内存
virsh domstats centos7.0
```

### 4. 连接到虚拟机

#### 方法 1：使用 virsh console（文本控制台）

```bash
virsh console centos7.0

# 退出控制台：Ctrl + ]
```

#### 方法 2：使用 virt-viewer（图形界面）

```bash
virt-viewer centos7.0
```

#### 方法 3：使用 SSH（如果虚拟机配置了网络）

```bash
# 查看虚拟机 IP
virsh domifaddr centos7.0

# SSH 连接
ssh root@<虚拟机IP>
```

### 5. 关闭虚拟机

```bash
# 正常关机
virsh shutdown centos7.0

# 强制关机（类似拔电源）
virsh destroy centos7.0
```

## 常用命令速查

### 虚拟机生命周期

```bash
# 列出所有虚拟机
virsh list --all

# 启动虚拟机
virsh start <vm-name>

# 重启虚拟机
virsh reboot <vm-name>

# 关闭虚拟机（正常关机）
virsh shutdown <vm-name>

# 强制关闭（立即关闭）
virsh destroy <vm-name>

# 暂停虚拟机
virsh suspend <vm-name>

# 恢复虚拟机
virsh resume <vm-name>

# 设置开机自启
virsh autostart <vm-name>

# 取消开机自启
virsh autostart --disable <vm-name>
```

### 虚拟机信息查看

```bash
# 查看虚拟机详细信息
virsh dominfo <vm-name>

# 查看虚拟机 XML 配置
virsh dumpxml <vm-name>

# 查看虚拟机 IP 地址
virsh domifaddr <vm-name>

# 查看虚拟机磁盘
virsh domblklist <vm-name>

# 查看虚拟机网卡
virsh domiflist <vm-name>

# 查看虚拟机资源使用
virsh domstats <vm-name>
```

### 虚拟机配置修改

```bash
# 修改内存（需要关机）
virsh setmem <vm-name> 2G --config

# 修改 CPU（需要关机）
virsh setvcpus <vm-name> 2 --config

# 编辑虚拟机配置
virsh edit <vm-name>
```

### 网络管理

```bash
# 列出所有网络
virsh net-list --all

# 查看网络信息
virsh net-info default

# 查看网络配置
virsh net-dumpxml default

# 启动网络
virsh net-start default

# 停止网络
virsh net-destroy default
```

### 存储管理

```bash
# 列出存储池
virsh pool-list --all

# 查看存储池信息
virsh pool-info default

# 列出存储卷
virsh vol-list default

# 查看存储卷信息
virsh vol-info <vol-name> --pool default
```

## 常见问题

### Q1: 虚拟机启动失败？

```bash
# 查看错误日志
virsh dominfo <vm-name>

# 查看 libvirt 日志
sudo journalctl -u libvirtd -f

# 检查虚拟机配置
virsh dumpxml <vm-name>
```

### Q2: 无法连接到虚拟机控制台？

```bash
# 检查虚拟机是否运行
virsh list

# 使用 virt-viewer
virt-viewer <vm-name>

# 或使用 VNC
virsh vncdisplay <vm-name>
```

### Q3: 虚拟机没有网络？

```bash
# 检查虚拟网络
virsh net-list --all

# 启动默认网络
virsh net-start default

# 检查虚拟机网卡
virsh domiflist <vm-name>
```

### Q4: 如何删除虚拟机？

```bash
# 1. 关闭虚拟机
virsh destroy <vm-name>

# 2. 删除虚拟机定义
virsh undefine <vm-name>

# 3. 删除磁盘文件（可选）
virsh vol-delete <vm-name>.qcow2 --pool default
```

## 有用的技巧

### 1. 批量操作虚拟机

```bash
# 启动所有虚拟机
for vm in $(virsh list --all --name); do
    virsh start $vm
done

# 关闭所有运行中的虚拟机
for vm in $(virsh list --name); do
    virsh shutdown $vm
done
```

### 2. 监控虚拟机资源

```bash
# 实时监控（类似 top）
virt-top

# 查看所有虚拟机状态
watch -n 1 'virsh list --all'
```

### 3. 快速创建测试虚拟机

```bash
# 克隆现有虚拟机
virt-clone --original centos7.0 --name centos7-test --auto-clone
```
