# virt-manager 图形界面

## 简介

virt-manager (Virtual Machine Manager) 是 KVM 的图形化管理工具，提供直观的界面来管理虚拟机。

### 优势

- ✅ 图形化界面，易于使用
- ✅ 支持远程管理
- ✅ 实时监控资源使用
- ✅ 可视化配置虚拟机
- ✅ 集成控制台访问

## 启动 virt-manager

```bash
# 启动 virt-manager
virt-manager

# 或从应用菜单启动
# 应用程序 -> 系统工具 -> Virtual Machine Manager
```

## 主界面介绍

### 连接管理

1. **本地连接**: QEMU/KVM
2. **远程连接**: 通过 SSH 连接到远程主机

### 虚拟机列表

显示所有虚拟机及其状态：
- 名称
- CPU 使用率
- 内存使用
- 磁盘 I/O
- 网络 I/O

## 创建虚拟机

### 方法 1：使用向导

1. **点击 "新建虚拟机"**
   - 或按 `Ctrl+N`

2. **选择安装方式**
   - 本地安装介质（ISO 镜像或 CDROM）
   - 网络安装（HTTP、FTP、NFS）
   - 网络启动（PXE）
   - 导入现有磁盘镜像

3. **选择操作系统**
   - 选择 ISO 文件
   - 选择操作系统类型和版本

4. **配置内存和 CPU**
   - 设置内存大小（MB）
   - 设置 CPU 核心数

5. **配置存储**
   - 创建新磁盘
   - 使用现有磁盘
   - 设置磁盘大小和格式

6. **配置网络**
   - 选择网络类型
   - NAT、桥接或隔离

7. **完成创建**
   - 检查配置
   - 点击 "完成" 开始安装

### 方法 2：快速创建

1. 右键点击连接
2. 选择 "新建"
3. 快速配置并创建

## 虚拟机管理

### 启动和停止

**启动虚拟机**:
- 右键 -> 运行
- 或双击虚拟机
- 或点击工具栏的 "运行" 按钮

**关闭虚拟机**:
- 右键 -> 关闭
- 正常关机（发送 ACPI 信号）
- 强制关闭（立即关闭）

**重启虚拟机**:
- 右键 -> 重启
- 或在控制台中重启

**暂停虚拟机**:
- 右键 -> 暂停
- 暂停后可以恢复

### 查看虚拟机详情

双击虚拟机打开详情窗口：

1. **概览**
   - 基本信息
   - 性能图表
   - CPU、内存、磁盘、网络使用情况

2. **性能**
   - 实时 CPU 使用图表
   - 实时内存使用图表
   - 实时磁盘 I/O 图表
   - 实时网络 I/O 图表

3. **处理器**
   - CPU 数量
   - CPU 拓扑
   - CPU 模型

4. **内存**
   - 当前分配
   - 最大内存
   - 内存调整

5. **引导选项**
   - 启动顺序
   - 引导菜单
   - 内核参数

6. **磁盘**
   - 磁盘列表
   - 添加/删除磁盘
   - 磁盘性能选项

7. **网卡**
   - 网卡列表
   - 添加/删除网卡
   - 网络配置

8. **显示**
   - 显示类型（VNC、SPICE）
   - 显示端口
   - 密码设置

## 虚拟机配置

### 修改 CPU

1. 打开虚拟机详情
2. 点击 "处理器"
3. 调整 CPU 数量
4. 配置 CPU 拓扑（可选）
5. 点击 "应用"

**注意**: 某些修改需要关闭虚拟机。

### 修改内存

1. 打开虚拟机详情
2. 点击 "内存"
3. 调整当前分配和最大内存
4. 点击 "应用"

**热添加内存**:
- 只能增加，不能减少
- 需要虚拟机支持

### 添加磁盘

1. 打开虚拟机详情
2. 点击 "添加硬件"
3. 选择 "存储"
4. 配置磁盘：
   - 创建新磁盘
   - 使用现有磁盘
   - 设置磁盘大小
   - 选择磁盘格式（qcow2/raw）
   - 选择总线类型（virtio/IDE/SCSI）
5. 点击 "完成"

### 添加网卡

1. 打开虚拟机详情
2. 点击 "添加硬件"
3. 选择 "网络"
4. 配置网卡：
   - 选择网络源
   - 选择设备模型（virtio/e1000）
   - 设置 MAC 地址（可选）
5. 点击 "完成"

### 修改显示设置

1. 打开虚拟机详情
2. 点击 "显示 Spice" 或 "显示 VNC"
3. 配置：
   - 监听地址
   - 端口
   - 密码
   - TLS 设置
4. 点击 "应用"

## 控制台访问

### 打开控制台

1. 双击虚拟机
2. 或右键 -> 打开
3. 或点击工具栏的 "打开" 按钮

### 控制台功能

**工具栏**:
- 发送按键（Ctrl+Alt+Del 等）
- 全屏模式
- 截图
- USB 重定向

**菜单**:
- 虚拟机 -> 运行/暂停/关闭/重启
- 查看 -> 全屏/缩放/自动调整大小
- 发送按键 -> 特殊按键组合

**快捷键**:
- `Ctrl+Alt+F`: 全屏
- `Ctrl+Alt+G`: 释放鼠标
- `Ctrl+Alt+Del`: 发送到虚拟机

## 快照管理

### 创建快照

1. 打开虚拟机详情
2. 点击 "快照" 标签
3. 点击 "+" 按钮
4. 输入快照名称和描述
5. 点击 "完成"

### 恢复快照

1. 在快照列表中选择快照
2. 点击 "运行快照" 按钮
3. 确认恢复

### 删除快照

1. 在快照列表中选择快照
2. 点击 "-" 按钮
3. 确认删除

## 克隆虚拟机

### 克隆操作

1. 右键点击虚拟机
2. 选择 "克隆"
3. 配置克隆选项：
   - 新虚拟机名称
   - 网络配置
   - 存储配置
4. 点击 "克隆"

**注意**: 虚拟机必须处于关闭状态。

## 虚拟网络管理

### 查看网络

1. 编辑 -> 连接详情
2. 点击 "虚拟网络" 标签
3. 查看所有虚拟网络

### 创建网络

1. 点击 "+" 按钮
2. 配置网络：
   - 网络名称
   - 网络模式（NAT/隔离/桥接）
   - IP 地址范围
   - DHCP 配置
3. 点击 "完成"

### 编辑网络

1. 选择网络
2. 点击 "编辑" 按钮
3. 修改配置
4. 点击 "应用"

### 删除网络

1. 选择网络
2. 点击 "-" 按钮
3. 确认删除

## 存储池管理

### 查看存储池

1. 编辑 -> 连接详情
2. 点击 "存储" 标签
3. 查看所有存储池

### 创建存储池

1. 点击 "+" 按钮
2. 选择存储池类型：
   - 目录
   - LVM
   - NFS
   - iSCSI
3. 配置存储池
4. 点击 "完成"

### 管理存储卷

1. 选择存储池
2. 查看存储卷列表
3. 可以：
   - 创建新卷
   - 删除卷
   - 刷新列表

## 远程管理

### 添加远程连接

1. 文件 -> 添加连接
2. 选择 Hypervisor: QEMU/KVM
3. 选择连接方式: SSH
4. 输入远程主机信息：
   - 主机名或 IP
   - 用户名
5. 点击 "连接"

### SSH 密钥配置

```bash
# 生成 SSH 密钥
ssh-keygen -t rsa

# 复制公钥到远程主机
ssh-copy-id user@remote-host

# 测试连接
ssh user@remote-host
```

### 管理远程虚拟机

连接后，可以像管理本地虚拟机一样管理远程虚拟机。

## 性能监控

### 实时监控

在虚拟机详情的 "性能" 标签中：

1. **CPU 使用率图表**
   - 实时显示 CPU 使用情况
   - 可以看到每个 vCPU 的使用率

2. **内存使用图表**
   - 显示内存分配和使用
   - 可以看到内存压力

3. **磁盘 I/O 图表**
   - 显示读写速率
   - 可以看到磁盘瓶颈

4. **网络 I/O 图表**
   - 显示网络流量
   - 可以看到网络使用情况

### 导出统计数据

可以通过命令行导出详细统计：

```bash
virsh domstats vm-name
```

## 常见问题

### Q1: virt-manager 无法启动

```bash
# 检查 libvirt 服务
sudo systemctl status libvirtd

# 检查用户权限
groups | grep libvirt

# 添加用户到 libvirt 组
sudo usermod -aG libvirt $USER
```

### Q2: 无法连接到虚拟机控制台

```bash
# 检查虚拟机状态
virsh list --all

# 检查 VNC/SPICE 配置
virsh dumpxml vm-name | grep graphics

# 重启虚拟机
virsh destroy vm-name
virsh start vm-name
```

### Q3: 远程连接失败

```bash
# 检查 SSH 连接
ssh user@remote-host

# 检查远程 libvirt 服务
ssh user@remote-host "systemctl status libvirtd"

# 检查防火墙
ssh user@remote-host "sudo firewall-cmd --list-all"
```

### Q4: 性能图表不显示

```bash
# 确保虚拟机正在运行
virsh list

# 检查统计信息
virsh domstats vm-name
```
