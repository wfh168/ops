# 创建第一个虚拟机

## 准备工作

### 1. 准备 ISO 镜像

首先需要下载操作系统的 ISO 镜像文件。

#### 常用 Linux 发行版下载地址

**CentOS 7**:
```bash
# 下载 CentOS 7 Minimal ISO
wget https://mirrors.aliyun.com/centos/7/isos/x86_64/CentOS-7-x86_64-Minimal-2009.iso

# 或使用清华镜像
wget https://mirrors.tuna.tsinghua.edu.cn/centos/7/isos/x86_64/CentOS-7-x86_64-Minimal-2009.iso
```

**Ubuntu 22.04**:
```bash
# 下载 Ubuntu 22.04 Server ISO
wget https://mirrors.aliyun.com/ubuntu-releases/22.04/ubuntu-22.04.3-live-server-amd64.iso
```

**Rocky Linux 9**:
```bash
# 下载 Rocky Linux 9 Minimal ISO
wget https://mirrors.aliyun.com/rockylinux/9/isos/x86_64/Rocky-9-latest-x86_64-minimal.iso
```

#### 存放 ISO 文件

```bash
# 创建 ISO 存储目录
sudo mkdir -p /var/lib/libvirt/images/iso

# 移动 ISO 文件
sudo mv *.iso /var/lib/libvirt/images/iso/

# 设置权限
sudo chmod 644 /var/lib/libvirt/images/iso/*.iso
```

### 2. 检查存储空间

```bash
# 查看默认存储池空间
virsh pool-info default

# 查看可用空间
df -h /var/lib/libvirt/images/
```

## 使用 virt-install 创建虚拟机

### 方法 1：基本创建（推荐新手）

```bash
virt-install \
  --name centos7-test \
  --memory 2048 \
  --vcpus 2 \
  --disk size=20 \
  --cdrom /var/lib/libvirt/images/iso/CentOS-7-x86_64-Minimal-2009.iso \
  --os-variant centos7.0 \
  --network network=default \
  --graphics vnc,listen=0.0.0.0 \
  --noautoconsole
```

**参数说明**：
- `--name`: 虚拟机名称
- `--memory`: 内存大小（MB）
- `--vcpus`: CPU 核心数
- `--disk size=20`: 创建 20GB 磁盘
- `--cdrom`: ISO 镜像路径
- `--os-variant`: 操作系统类型
- `--network`: 网络配置
- `--graphics`: 图形显示配置
- `--noautoconsole`: 不自动连接控制台

### 方法 2：完整配置

```bash
virt-install \
  --name ubuntu-server \
  --memory 4096 \
  --vcpus 4 \
  --disk path=/var/lib/libvirt/images/ubuntu-server.qcow2,size=50,format=qcow2 \
  --cdrom /var/lib/libvirt/images/iso/ubuntu-22.04.3-live-server-amd64.iso \
  --os-variant ubuntu22.04 \
  --network network=default,model=virtio \
  --graphics vnc,listen=0.0.0.0,port=5901 \
  --console pty,target_type=serial \
  --noautoconsole
```

**高级参数**：
- `--disk path=...`: 指定磁盘路径和格式
- `--network model=virtio`: 使用 virtio 网卡（性能更好）
- `--graphics port=5901`: 指定 VNC 端口
- `--console pty`: 添加串口控制台

### 方法 3：使用现有磁盘

如果已经有虚拟机磁盘文件：

```bash
virt-install \
  --name existing-vm \
  --memory 2048 \
  --vcpus 2 \
  --disk path=/var/lib/libvirt/images/existing.qcow2 \
  --import \
  --os-variant centos7.0 \
  --network network=default \
  --graphics vnc \
  --noautoconsole
```

**注意**：使用 `--import` 参数表示导入现有磁盘。

## 安装操作系统

### CentOS 7 安装步骤

1. **启动安装程序**
   - 选择 "Install CentOS 7"
   - 等待加载

2. **选择语言**
   - 选择 "English" 或 "简体中文"
   - 点击 "Continue"

3. **配置安装选项**
   - **日期和时间**: 选择时区（Asia/Shanghai）
   - **键盘**: 默认即可
   - **语言支持**: 默认即可
   - **安装源**: 默认（本地媒体）
   - **软件选择**: 选择 "Minimal Install"（最小化安装）
   - **安装位置**: 
     - 选择磁盘
     - 点击 "Done"
   - **网络和主机名**:
     - 打开网络开关（ON）
     - 设置主机名
     - 点击 "Done"

4. **开始安装**
   - 点击 "Begin Installation"
   - 设置 root 密码
   - 创建用户（可选）

5. **完成安装**
   - 等待安装完成
   - 点击 "Reboot"

### Ubuntu 22.04 安装步骤

1. **启动安装程序**
   - 选择语言
   - 选择 "Install Ubuntu Server"

2. **网络配置**
   - 自动获取 IP（DHCP）
   - 或手动配置

3. **存储配置**
   - 选择 "Use an entire disk"
   - 确认分区

4. **用户配置**
   - 设置用户名和密码
   - 设置服务器名称

5. **SSH 配置**
   - 选择安装 OpenSSH server

6. **完成安装**
   - 等待安装完成
   - 重启系统

## 安装后配置

### 1. 移除 ISO 镜像

安装完成后，移除 ISO 镜像以便从硬盘启动：

```bash
# 方法 1: 使用 virsh 命令
virsh change-media centos7-test hda --eject

# 方法 2: 编辑虚拟机配置
virsh edit centos7-test
# 删除 <disk type='file' device='cdrom'> 部分

# 方法 3: 使用 virt-manager
# 在图形界面中移除 CDROM 设备
```

### 2. 启动虚拟机

```bash
# 启动虚拟机
virsh start centos7-test

# 查看状态
virsh list

# 连接到控制台
virsh console centos7-test
```

### 3. 配置网络

#### 查看虚拟机 IP

```bash
# 方法 1: 使用 virsh
virsh domifaddr centos7-test

# 方法 2: 在虚拟机内查看
# 登录虚拟机后执行
ip addr show
```

#### 配置静态 IP（可选）

**CentOS 7**:
```bash
# 编辑网络配置
vi /etc/sysconfig/network-scripts/ifcfg-eth0

# 修改为静态 IP
BOOTPROTO=static
IPADDR=192.168.122.100
NETMASK=255.255.255.0
GATEWAY=192.168.122.1
DNS1=8.8.8.8

# 重启网络
systemctl restart network
```

**Ubuntu**:
```bash
# 编辑 netplan 配置
vi /etc/netplan/00-installer-config.yaml

# 配置静态 IP
network:
  ethernets:
    enp1s0:
      addresses:
        - 192.168.122.100/24
      gateway4: 192.168.122.1
      nameservers:
        addresses: [8.8.8.8, 8.8.4.4]
  version: 2

# 应用配置
netplan apply
```

### 4. 配置 SSH 访问

```bash
# 在虚拟机内启动 SSH 服务
systemctl start sshd
systemctl enable sshd

# 从宿主机 SSH 连接
ssh root@192.168.122.100
```

### 5. 更新系统

**CentOS 7**:
```bash
yum update -y
```

**Ubuntu**:
```bash
apt update && apt upgrade -y
```

## 创建虚拟机脚本

创建一个快速创建虚拟机的脚本：

```bash
#!/bin/bash

# 快速创建虚拟机脚本

# 参数
VM_NAME=${1:-"test-vm"}
VM_MEMORY=${2:-2048}
VM_VCPUS=${3:-2}
VM_DISK_SIZE=${4:-20}
ISO_PATH=${5:-"/var/lib/libvirt/images/iso/CentOS-7-x86_64-Minimal-2009.iso"}

echo "创建虚拟机: $VM_NAME"
echo "内存: ${VM_MEMORY}MB"
echo "CPU: ${VM_VCPUS} 核"
echo "磁盘: ${VM_DISK_SIZE}GB"
echo "ISO: $ISO_PATH"
echo ""

# 检查 ISO 文件是否存在
if [ ! -f "$ISO_PATH" ]; then
    echo "错误: ISO 文件不存在: $ISO_PATH"
    exit 1
fi

# 创建虚拟机
virt-install \
  --name "$VM_NAME" \
  --memory "$VM_MEMORY" \
  --vcpus "$VM_VCPUS" \
  --disk size="$VM_DISK_SIZE",format=qcow2 \
  --cdrom "$ISO_PATH" \
  --os-variant centos7.0 \
  --network network=default,model=virtio \
  --graphics vnc,listen=0.0.0.0 \
  --console pty,target_type=serial \
  --noautoconsole

echo ""
echo "虚拟机创建成功！"
echo ""
echo "连接到虚拟机:"
echo "  virt-viewer $VM_NAME"
echo ""
echo "查看状态:"
echo "  virsh list --all"
```

**使用方法**:
```bash
# 保存为 create-vm.sh
chmod +x create-vm.sh

# 使用默认参数
./create-vm.sh

# 自定义参数
./create-vm.sh my-vm 4096 4 50 /path/to/iso
```

## 常见问题

### Q1: 虚拟机创建失败

**错误**: `ERROR    internal error: process exited while connecting to monitor`

**解决**:
```bash
# 检查 KVM 模块
lsmod | grep kvm

# 检查权限
sudo usermod -aG libvirt $USER
sudo usermod -aG kvm $USER

# 重启 libvirt 服务
sudo systemctl restart libvirtd
```

### Q2: 无法连接到虚拟机

**解决**:
```bash
# 检查虚拟机状态
virsh list --all

# 启动虚拟机
virsh start vm-name

# 查看 VNC 端口
virsh vncdisplay vm-name

# 使用 virt-viewer
virt-viewer vm-name
```

### Q3: 虚拟机没有网络

**解决**:
```bash
# 检查虚拟网络
virsh net-list --all

# 启动默认网络
virsh net-start default

# 检查虚拟机网卡
virsh domiflist vm-name

# 在虚拟机内检查
ip addr show
```

### Q4: 磁盘空间不足

**解决**:
```bash
# 查看存储池空间
virsh pool-info default

# 清理不用的虚拟机
virsh undefine old-vm
virsh vol-delete old-vm.qcow2 --pool default

# 或使用其他存储池
virsh pool-list --all
```

## 最佳实践

### 1. 虚拟机命名规范

```bash
# 推荐格式: 系统-用途-编号
centos7-web-01
ubuntu-db-01
rocky9-test-01
```

### 2. 资源分配建议

**最小配置**:
- CPU: 1 核
- 内存: 1GB
- 磁盘: 10GB

**推荐配置**:
- CPU: 2 核
- 内存: 2-4GB
- 磁盘: 20-50GB

**生产环境**:
- CPU: 4+ 核
- 内存: 8+ GB
- 磁盘: 100+ GB

### 3. 磁盘格式选择

**qcow2** (推荐):
- ✅ 支持快照
- ✅ 动态分配空间
- ✅ 支持压缩
- ❌ 性能略低

**raw**:
- ✅ 性能最好
- ❌ 不支持快照
- ❌ 占用固定空间

### 4. 网络模式选择

**NAT** (默认):
- ✅ 简单易用
- ✅ 虚拟机可以访问外网
- ❌ 外网无法直接访问虚拟机

**桥接**:
- ✅ 虚拟机获得独立 IP
- ✅ 外网可以直接访问
- ❌ 配置较复杂
