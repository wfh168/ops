# Jenkins 集成学习指南

欢迎学习 Jenkins 集成！本模块将教你如何搭建和使用企业级 CI/CD 平台。

---

## 📚 学习目标

完成本模块后，你将能够：

✅ 安装和配置 Jenkins 服务器  
✅ 管理插件和系统配置  
✅ 创建和管理 Job  
✅ 配置构建触发器  
✅ 实现持续集成（CI）  
✅ 实现持续部署（CD）  
✅ 集成 GitLab/GitHub  
✅ 配置 Pipeline as Code  
✅ 实施自动化测试和部署

## 💻 实验环境

### 最小配置
- CPU：2核
- 内存：2GB
- 硬盘：50GB
- 操作系统：CentOS 7/8 或 Ubuntu 18.04+
- JDK：11 或 17

### 推荐配置
- CPU：4核+
- 内存：4GB+
- 硬盘：100GB+
- SSD 硬盘

---

## 🎓 实战项目

### 项目1：Java 项目 CI/CD
```
流程：
1. 代码提交触发构建
2. Maven 编译和打包
3. 单元测试
4. 代码质量检查（SonarQube）
5. 构建 Docker 镜像
6. 部署到测试环境
7. 自动化测试
8. 部署到生产环境
```

### 项目2：前端项目 CI/CD
```
流程：
1. 代码提交触发构建
2. npm install 安装依赖
3. npm run build 构建
4. 静态资源上传到 OSS
5. CDN 缓存刷新
6. 通知部署结果
```

### 项目3：多环境部署
```
环境：
- 开发环境（自动部署）
- 测试环境（自动部署）
- 预发布环境（手动审批）
- 生产环境（手动审批 + 灰度发布）
```
