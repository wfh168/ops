## ⚠️ 常见问题

### 1. 脚本执行权限问题
```bash
# 添加执行权限
chmod +x script.sh

# 或使用 bash 执行
bash script.sh
```

### 2. 变量未定义
```bash
# 使用默认值
value=${var:-default}

# 检查变量是否存在
if [ -z "$var" ]; then
    echo "变量未定义"
fi
```

### 3. 路径问题
```bash
# 获取脚本所在目录
SCRIPT_DIR=$(cd "$(dirname "$0")" && pwd)

# 使用绝对路径
cd "$SCRIPT_DIR" || exit 1
```

### 4. 特殊字符处理
```bash
# 使用引号
echo "包含空格的字符串"

# 转义特殊字符
echo "价格: \$100"
```
