# Java 项目部署学习指南

欢迎学习 Java 项目部署！本模块将教你如何部署和管理企业级 Java 应用。

---

## 📚 学习目标

完成本模块后，你将能够：

✅ 理解 Java 应用架构  
✅ 部署 Spring Boot 应用  
✅ 部署传统 Java Web 应用  
✅ 配置应用服务器  
✅ 实现负载均衡和高可用  
✅ 配置数据库连接池  
✅ 实施监控和日志管理  
✅ 性能调优和故障排查  
✅ 实现自动化部署  

---

## 📖 学习内容

### 1️⃣ Java 应用部署基础
- Java 应用架构
- JDK 环境配置
- Maven/Gradle 构建
- Spring Boot 部署
- 传统 WAR 包部署
- 配置文件管理

**学习时间**：1.5天  
**难度**：⭐⭐

---

### 2️⃣ 应用服务器配置
- Tomcat 配置和优化
- Nginx 反向代理
- 负载均衡配置
- Session 共享
- 静态资源分离
- HTTPS 配置

**学习时间**：1.5天  
**难度**：⭐⭐⭐

---

### 3️⃣ 监控、优化与自动化
- JVM 监控和调优
- 应用性能监控（APM）
- 日志收集和分析
- 数据库连接池优化
- 缓存配置
- 自动化部署实战
- 故障排查

**学习时间**：2天  
**难度**：⭐⭐⭐⭐

---

## 🎯 学习路线

```
第1-2天：基础部署
  ├─ JDK 安装配置
  ├─ Maven 构建
  ├─ Spring Boot 部署
  ├─ Tomcat 部署
  └─ 配置文件管理

第3-4天：高可用架构
  ├─ Nginx 负载均衡
  ├─ Tomcat 集群
  ├─ Session 共享
  ├─ 数据库配置
  └─ 缓存配置

第5天：监控和优化
  ├─ JVM 调优
  ├─ 性能监控
  ├─ 日志管理
  ├─ 故障排查
  └─ 自动化部署
```

## 💻 实验环境

### 开发环境
- JDK 8/11/17
- Maven 3.6+
- IDE：IntelliJ IDEA / Eclipse

### 部署环境
- CPU：4核
- 内存：8GB
- 硬盘：100GB
- 操作系统：CentOS 7/8 或 Ubuntu 18.04+

### 软件栈
- JDK 11
- Tomcat 9 / Spring Boot
- Nginx 1.20+
- MySQL 8.0
- Redis 6.0+

## 🎓 实战项目

### 项目1：Spring Boot 微服务部署
```
架构：
- Spring Boot 应用
- Nginx 负载均衡
- MySQL 数据库
- Redis 缓存
- ELK 日志系统
```

### 项目2：传统 Java Web 应用集群
```
架构：
- Tomcat 集群（3节点）
- Nginx 负载均衡
- Session 共享（Redis）
- MySQL 主从复制
- 监控系统
```

### 项目3：完整 CI/CD 流程
```
流程：
1. Git 代码提交
2. Jenkins 自动构建
3. Maven 编译打包
4. 单元测试
5. Docker 镜像构建
6. 自动部署到测试环境
7. 自动化测试
8. 部署到生产环境
```
