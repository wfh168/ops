# GitLab 配置学习指南

欢迎学习 GitLab 配置！本模块将教你如何搭建和管理企业级代码仓库平台。

---

## 📚 学习目标

完成本模块后，你将能够：

✅ 安装和配置 GitLab 服务器  
✅ 管理用户、组和项目  
✅ 配置 SSH 和 HTTPS 访问  
✅ 设置权限和访问控制  
✅ 配置 CI/CD Pipeline  
✅ 实施备份和恢复策略  
✅ 集成第三方服务  
✅ 监控和优化 GitLab 性能  

---

## 📖 学习内容

### 1️⃣ GitLab 安装与基础配置
- GitLab 简介和架构
- 系统要求和准备
- GitLab 安装（CE/EE）
- 基础配置和初始化
- 域名和 HTTPS 配置
- 邮件服务配置

**学习时间**：1天  
**难度**：⭐⭐

---

### 2️⃣ 用户和权限管理
- 用户管理
- 组和项目管理
- 权限级别和角色
- SSH 密钥管理
- 访问令牌
- LDAP 集成

**学习时间**：1天  
**难度**：⭐⭐⭐

---

### 3️⃣ CI/CD 与高级功能
- GitLab CI/CD 概述
- .gitlab-ci.yml 编写
- Runner 安装和配置
- Pipeline 设计
- 自动化部署
- 备份和恢复
- 监控和日志

**学习时间**：2天  
**难度**：⭐⭐⭐⭐

## 💻 实验环境

### 最小配置
- CPU：2核
- 内存：4GB
- 硬盘：50GB
- 操作系统：CentOS 7/8 或 Ubuntu 18.04+

### 推荐配置
- CPU：4核+
- 内存：8GB+
- 硬盘：100GB+
- SSD 硬盘（提升性能）
