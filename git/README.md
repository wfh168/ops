# Git 版本控制学习指南

欢迎学习 Git 版本控制系统！本模块将系统学习 Git 从基础到高级的全部内容。

## 📚 学习目标

完成本模块后，你将能够：

✅ 理解版本控制原理  
✅ 掌握 Git 基础操作  
✅ 熟练使用分支管理  
✅ 掌握团队协作流程  
✅ 解决常见冲突问题  
✅ 使用 GitHub/GitLab  
✅ 掌握 Git 工作流

## 🎯 学习路线

```
第1-3天：Git 基础
  ├─ Git 安装配置
  ├─ 基础命令
  ├─ 文件管理
  └─ 提交历史

第4-7天：分支管理
  ├─ 分支操作
  ├─ 合并策略
  ├─ 冲突解决
  └─ 标签管理

第8-10天：远程协作
  ├─ 远程仓库
  ├─ GitHub 使用
  ├─ 团队协作
  └─ Pull Request

第11-14天：高级操作
  ├─ Rebase 变基
  ├─ Stash 储藏
  ├─ 回退操作
  └─ Git Hooks

第15-17天：工作流
  ├─ Git Flow
  ├─ 协作规范
  ├─ 代码审查
  └─ CI/CD 集成

第18-20天：实战应用
  ├─ 项目管理
  ├─ 版本发布
  ├─ 问题排查
  └─ 最佳实践
```

## 💻 实验环境

### 软件要求
- Git：2.30+
- 操作系统：Linux、Windows、Mac
- 代码编辑器：VS Code、Sublime Text
- 终端工具：Git Bash、iTerm2

### 推荐配置
- GitHub 账号（免费）
- GitLab 账号（可选）
- SSH 密钥配置
- Git 图形化工具（GitKraken、SourceTree）
