## VLAN划分

### 核心交换机VLAN配置

```bash
# 华为交换机配置示例

# 创建VLAN
vlan batch 10 20 30 40 50

# VLAN 10 - 管理网络
vlan 10
  description Management
  
# VLAN 20 - 客户机网络
vlan 20
  description Client-Network
  
# VLAN 30 - 服务器网络
vlan 30
  description Server-Network
  
# VLAN 40 - 办公网络
vlan 40
  description Office-Network
  
# VLAN 50 - 监控网络
vlan 50
  description Monitor-Network

# 配置VLAN接口（三层）
interface Vlanif10
  ip address 10.0.10.1 255.255.255.0
  description Management-Gateway
  
interface Vlanif20
  ip address 10.0.20.1 255.255.252.0
  description Client-Gateway
  dhcp select relay
  dhcp relay server-ip 10.0.30.50
  
interface Vlanif30
  ip address 10.0.30.1 255.255.255.0
  description Server-Gateway
  
interface Vlanif40
  ip address 10.0.40.1 255.255.255.0
  description Office-Gateway
  
interface Vlanif50
  ip address 10.0.50.1 255.255.255.0
  description Monitor-Gateway

# 配置上联口（Trunk）
interface GigabitEthernet0/0/1
  port link-type trunk
  port trunk allow-pass vlan all
  description Uplink-to-Router
  
# 配置下联口（Trunk到汇聚交换机）
interface GigabitEthernet0/0/2
  port link-type trunk
  port trunk allow-pass vlan all
  description Downlink-to-Aggregation-SW1
  
interface GigabitEthernet0/0/3
  port link-type trunk
  port trunk allow-pass vlan all
  description Downlink-to-Aggregation-SW2
```

### 接入交换机配置

```bash
# 接入交换机配置（客户机接入）

# 创建VLAN
vlan batch 10 20

# 管理VLAN
vlan 10
  description Management

# 客户机VLAN
vlan 20
  description Client-Network

# 配置管理接口
interface Vlanif10
  ip address 10.0.10.11 255.255.255.0
  
# 配置上联口（Trunk）
interface GigabitEthernet0/0/1
  port link-type trunk
  port trunk allow-pass vlan 10 20
  description Uplink-to-Core
  
# 配置客户机接口（Access）
interface range GigabitEthernet0/0/2 to GigabitEthernet0/0/48
  port link-type access
  port default vlan 20
  description Client-Ports
  stp edged-port enable
  storm-control broadcast min 10 max 50
```

### 2. 游戏更新服务器

#### 配置脚本
```bash
#!/bin/bash
# 游戏更新服务器配置

# 安装必要软件
apt update
apt install -y nginx rsync aria2

# 配置Nginx
cat > /etc/nginx/sites-available/game-update << 'EOF'
server {
    listen 80;
    server_name game-update.local;
    
    root /data/games;
    autoindex on;
    autoindex_exact_size off;
    autoindex_localtime on;
    
    location / {
        try_files $uri $uri/ =404;
    }
    
    # 限速配置
    limit_rate 10m;
}
EOF

ln -s /etc/nginx/sites-available/game-update /etc/nginx/sites-enabled/
systemctl restart nginx

# 创建游戏目录
mkdir -p /data/games/{steam,epic,origin,ubisoft}

# 配置自动更新脚本
cat > /usr/local/bin/game-update.sh << 'EOF'
#!/bin/bash
# 游戏自动更新脚本

GAME_DIR="/data/games"
LOG_FILE="/var/log/game-update.log"

echo "$(date): 开始更新游戏" >> $LOG_FILE

# Steam游戏更新
steamcmd +login anonymous +app_update 730 validate +quit

# 记录更新日志
echo "$(date): 更新完成" >> $LOG_FILE
EOF

chmod +x /usr/local/bin/game-update.sh

# 添加定时任务
echo "0 3 * * * /usr/local/bin/game-update.sh" | crontab -
```

## 网络安全

### 1. 防火墙规则

```bash
# iptables防火墙规则

#!/bin/bash
# 网吧防火墙配置

# 清空现有规则
iptables -F
iptables -X
iptables -Z

# 默认策略
iptables -P INPUT DROP
iptables -P FORWARD DROP
iptables -P OUTPUT ACCEPT

# 允许本地回环
iptables -A INPUT -i lo -j ACCEPT

# 允许已建立的连接
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许管理网络访问
iptables -A INPUT -s 10.0.10.0/24 -j ACCEPT

# 允许客户机访问服务器
iptables -A FORWARD -s 10.0.20.0/22 -d 10.0.30.0/24 -j ACCEPT
iptables -A FORWARD -m state --state ESTABLISHED,RELATED -j ACCEPT

# 禁止客户机互访
iptables -A FORWARD -s 10.0.20.0/22 -d 10.0.20.0/22 -j DROP

# 允许客户机访问互联网
iptables -A FORWARD -s 10.0.20.0/22 -o eth0 -j ACCEPT

# NAT配置
iptables -t nat -A POSTROUTING -s 10.0.0.0/16 -o eth0 -j MASQUERADE

# 防止DDoS攻击
iptables -A INPUT -p tcp --syn -m limit --limit 1/s -j ACCEPT
iptables -A INPUT -p icmp --icmp-type echo-request -m limit --limit 1/s -j ACCEPT

# 保存规则
iptables-save > /etc/iptables/rules.v4
```

### 2. 访问控制列表（ACL）

```bash
# 核心交换机ACL配置

# 创建ACL
acl number 3000
  description Protect-Server-Network
  rule 5 permit ip source 10.0.10.0 0.0.0.255
  rule 10 permit ip source 10.0.40.0 0.0.0.255
  rule 15 deny ip source any
  
# 应用到VLAN接口
interface Vlanif30
  traffic-filter inbound acl 3000
```

## 总结

这个方案提供了完整的网吧网络部署架构，包括：

1. **网络拓扑**：三层架构，核心-汇聚-接入
2. **VLAN划分**：管理、客户机、服务器、办公、监控分离
3. **IP规划**：合理的地址分配和网段划分
4. **安全防护**：防火墙、ACL、端口安全
5. **监控管理**：完善的监控和日志系统

根据实际规模和预算，可以灵活调整设备配置和数量。
