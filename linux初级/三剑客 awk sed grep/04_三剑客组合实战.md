# 三剑客组合实战

## 三剑客特点对比

| 工具 | 擅长 | 适用场景 |
|------|------|----------|
| grep | 过滤、查找 | 搜索关键词、提取匹配行 |
| sed | 替换、编辑 | 批量替换、删除行、插入行 |
| awk | 分析、统计 | 处理结构化数据、统计计算 |

---

## 一、组合使用原则

### 管道组合

```bash
# 基本模式
grep "pattern" file | sed 's/old/new/' | awk '{print $1}'

# 执行顺序：grep → sed → awk
```

### 选择合适的工具

```bash
# ❌ 不推荐：用 awk 做简单过滤
awk '/pattern/' file.txt

# ✅ 推荐：用 grep
grep "pattern" file.txt

# ❌ 不推荐：用 sed 做复杂统计
sed -n 's/pattern/&/p' file.txt | wc -l

# ✅ 推荐：用 awk
awk '/pattern/ {count++} END{print count}' file.txt
```

## 二、日志分析实战

### 案例1：Nginx 访问日志分析

```bash
# 日志格式示例
# 192.168.1.100 - - [07/Jan/2024:10:00:00 +0800] "GET /index.html HTTP/1.1" 200 1024

# 统计访问最多的 IP（前10）
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10

# 统计访问最多的 URL
awk '{print $7}' access.log | sort | uniq -c | sort -rn | head -10

# 统计 HTTP 状态码分布
awk '{print $9}' access.log | sort | uniq -c | sort -rn

# 统计每小时的访问量
awk '{print $4}' access.log | cut -d: -f2 | sort | uniq -c

# 查找 404 错误的 URL
awk '$9==404 {print $7}' access.log | sort | uniq -c | sort -rn

# 统计流量（字节）
awk '{sum+=$10} END{print sum/1024/1024 "MB"}' access.log

# 查找响应时间超过1秒的请求
awk '$NF>1 {print $0}' access.log
```

### 案例2：系统日志分析

```bash
# 查找错误日志
grep -i "error" /var/log/messages | tail -20

# 统计错误类型
grep -i "error" /var/log/messages | awk '{print $5}' | sort | uniq -c | sort -rn

# 查找特定时间段的日志
sed -n '/Jan  7 10:/,/Jan  7 11:/p' /var/log/messages

# 统计每小时的错误数
grep -i "error" /var/log/messages | awk '{print $1,$2,$3}' | cut -d: -f1 | sort | uniq -c

# 查找最频繁的错误消息
grep -i "error" /var/log/messages | awk -F'error' '{print $2}' | sort | uniq -c | sort -rn | head -10
```

## 三、文本处理实战

### 案例3：CSV 数据处理

```bash
# 示例数据：name,age,city
# John,25,Beijing
# Mary,30,Shanghai

# 提取特定列
awk -F',' '{print $1, $3}' data.csv

# 过滤年龄大于25的
awk -F',' '$2>25 {print $0}' data.csv

# 计算平均年龄
awk -F',' 'NR>1 {sum+=$2; count++} END{print sum/count}' data.csv

# 按城市分组统计
awk -F',' 'NR>1 {city[$3]++} END{for(c in city) print c, city[c]}' data.csv

# 添加表头
awk 'BEGIN{print "Name,Age,City"} {print}' data.csv

# 转换为 TSV
awk -F',' '{print $1"\t"$2"\t"$3}' data.csv
```

### 案例4：配置文件处理

```bash
# 提取有效配置（去除注释和空行）
grep -v "^#" config.ini | grep -v "^$"

# 或使用 sed
sed '/^#/d; /^$/d' config.ini

# 提取特定配置项
grep "^port" config.ini | awk -F'=' '{print $2}'

# 批量修改配置
sed -i 's/port=80/port=8080/g' config.ini

# 添加配置项
sed -i '/\[section\]/a\new_option=value' config.ini

# 删除配置项
sed -i '/^old_option/d' config.ini
```

## 四、系统管理实战

### 案例5：进程管理

```bash
# 查找占用 CPU 最高的进程
ps aux | sort -k3 -rn | head -10

# 查找占用内存最高的进程
ps aux | sort -k4 -rn | head -10

# 统计每个用户的进程数
ps aux | awk 'NR>1 {user[$1]++} END{for(u in user) print u, user[u]}'

# 查找僵尸进程
ps aux | awk '$8=="Z" {print $0}'

# 批量杀死进程
ps aux | grep "process_name" | grep -v grep | awk '{print $2}' | xargs kill -9
```

### 案例6：磁盘管理

```bash
# 查找大文件（大于100M）
find / -type f -size +100M -exec ls -lh {} \; | awk '{print $5, $NF}'

# 统计目录大小并排序
du -sh /* | sort -h

# 查找占用空间最大的目录
du -h --max-depth=1 / | sort -h | tail -10

# 清理日志文件
find /var/log -name "*.log" -mtime +7 -exec ls -lh {} \; | awk '{print $NF}' | xargs rm -f
```

### 案例7：网络监控

```bash
# 统计网络连接状态
netstat -an | awk '/^tcp/ {state[$NF]++} END{for(s in state) print s, state[s]}'

# 统计连接最多的 IP
netstat -an | grep ESTABLISHED | awk '{print $5}' | cut -d: -f1 | sort | uniq -c | sort -rn

# 查找监听端口
netstat -tunlp | grep LISTEN | awk '{print $4}' | awk -F: '{print $NF}' | sort -n

# 统计每个端口的连接数
netstat -an | grep ESTABLISHED | awk '{print $4}' | awk -F: '{print $NF}' | sort | uniq -c | sort -rn
```

## 五、数据统计实战

### 案例8：访问统计

```bash
# 统计每天的访问量
awk '{print $4}' access.log | cut -d: -f1 | sort | uniq -c

# 统计每小时的访问量
awk '{print $4}' access.log | cut -d: -f1-2 | sort | uniq -c

# 统计 PV（页面浏览量）
wc -l access.log

# 统计 UV（独立访客）
awk '{print $1}' access.log | sort -u | wc -l

# 统计平均响应时间
awk '{sum+=$NF; count++} END{print sum/count}' access.log

# 统计响应时间分布
awk '{
    if($NF<0.1) fast++
    else if($NF<1) medium++
    else slow++
} END{
    print "Fast (<0.1s):", fast
    print "Medium (0.1-1s):", medium
    print "Slow (>1s):", slow
}' access.log
```

### 案例9：性能分析

```bash
# 分析慢查询日志
grep "Query_time" slow.log | awk '{print $3}' | sort -n | tail -10

# 统计慢查询的 SQL
grep "Query_time" slow.log -A 1 | grep "^SELECT" | sort | uniq -c | sort -rn

# 分析 API 响应时间
awk '$NF>1 {print $7, $NF}' access.log | sort -k2 -rn | head -20

# 统计错误率
awk '{
    total++
    if($9>=400) error++
} END{
    print "Total:", total
    print "Errors:", error
    print "Error Rate:", error/total*100 "%"
}' access.log
```

```bash

LOGFILE="/var/log/nginx/access.log"
REPORT="/tmp/log_report.txt"

cat > $REPORT << EOF
=================================
Nginx Access Log Analysis Report
Date: $(date)
=================================

Top 10 IPs:
$(awk '{print $1}' $LOGFILE | sort | uniq -c | sort -rn | head -10)

Top 10 URLs:
$(awk '{print $7}' $LOGFILE | sort | uniq -c | sort -rn | head -10)

Status Code Distribution:
$(awk '{print $9}' $LOGFILE | sort | uniq -c | sort -rn)

Total Requests: $(wc -l < $LOGFILE)
Unique Visitors: $(awk '{print $1}' $LOGFILE | sort -u | wc -l)
Total Traffic: $(awk '{sum+=$10} END{print sum/1024/1024 "MB"}' $LOGFILE)

=================================
EOF

cat $REPORT
```

### 脚本2：系统监控

```bash
#!/bin/bash

# CPU 使用率
CPU_USAGE=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}' | cut -d% -f1)

# 内存使用率
MEM_USAGE=$(free | awk 'NR==2{printf "%.2f", $3/$2*100}')

# 磁盘使用率
DISK_USAGE=$(df -h / | awk 'NR==2{print $5}' | sed 's/%//')

# 检查并报警
if [ $(echo "$CPU_USAGE > 80" | bc) -eq 1 ]; then
    echo "CPU usage is high: ${CPU_USAGE}%"
fi

if [ $(echo "$MEM_USAGE > 80" | bc) -eq 1 ]; then
    echo "Memory usage is high: ${MEM_USAGE}%"
fi

if [ $DISK_USAGE -gt 80 ]; then
    echo "Disk usage is high: ${DISK_USAGE}%"
fi
```

### 脚本3：批量处理

```bash
#!/bin/bash

# 批量重命名文件
ls *.txt | awk '{
    old=$0
    new=$0
    gsub(/old/, "new", new)
    print "mv", old, new
}' | bash

# 批量修改配置
find /etc/nginx/sites-enabled -name "*.conf" | while read file; do
    sed -i 's/old_value/new_value/g' "$file"
    echo "Updated: $file"
done

# 批量清理日志
find /var/log -name "*.log" -mtime +30 | while read file; do
    size=$(du -h "$file" | awk '{print $1}')
    echo "Deleting: $file ($size)"
    rm -f "$file"
done
```

## 七、性能优化技巧

### 1. 减少管道

```bash
# ❌ 低效：多次管道
cat file.txt | grep "pattern" | awk '{print $1}' | sort | uniq

# ✅ 高效：合并操作
awk '/pattern/ {print $1}' file.txt | sort -u
```

### 2. 避免不必要的命令

```bash
# ❌ 低效
cat file.txt | grep "pattern"

# ✅ 高效
grep "pattern" file.txt
```

### 3. 使用合适的工具

```bash
# ❌ 低效：用 grep 统计
grep "pattern" file.txt | wc -l

# ✅ 高效：用 grep -c
grep -c "pattern" file.txt

# ✅ 更高效：用 awk
awk '/pattern/ {count++} END{print count}' file.txt
```
