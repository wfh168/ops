# 系统信息与进程命令

## 一、系统信息

### 1. 主机信息

```bash
hostname                          # 查看主机名
hostnamectl                       # 查看详细主机信息（CentOS 7+）
hostnamectl set-hostname newname  # 修改主机名

uname -a                          # 查看内核信息
uname -r                          # 只看内核版本
cat /etc/os-release               # 查看系统版本
cat /etc/redhat-release           # CentOS/RHEL 版本
```

### 2. CPU 信息

```bash
lscpu                             # 查看 CPU 信息
cat /proc/cpuinfo                 # 详细 CPU 信息
nproc                             # CPU 核心数
```

### 3. 内存信息

```bash
free -h                           # 查看内存使用（人性化显示）
free -m                           # 以 MB 显示
cat /proc/meminfo                 # 详细内存信息
```

#### free 输出解读
```
              total        used        free      shared  buff/cache   available
Mem:           7.6G        2.1G        3.2G        256M        2.3G        5.0G
Swap:          2.0G          0B        2.0G
```
- total：总内存
- used：已使用
- free：完全空闲
- buff/cache：缓存（可回收）
- available：实际可用 = free + 可回收的缓存

### 4. 磁盘信息

```bash
df -h                             # 查看磁盘使用情况
df -i                             # 查看 inode 使用
df -Th                            # 显示文件系统类型
du -sh /var                       # 查看目录大小
du -sh /*                         # 查看根目录下各目录大小
du -h --max-depth=1 /var          # 查看一级子目录大小
lsblk                             # 查看块设备
fdisk -l                          # 查看磁盘分区
```

### 5. 网络信息

```bash
ip addr                           # 查看 IP 地址（推荐）
ip a                              # 简写
ifconfig                          # 传统命令（需安装 net-tools）
ip route                          # 查看路由表
ss -tunlp                         # 查看端口监听（推荐）
netstat -tunlp                    # 传统命令
```

### 6. 系统负载

```bash
uptime                            # 运行时间和负载
w                                 # 登录用户和负载
top                               # 动态查看系统状态
htop                              # 更友好的 top（需安装）
```

#### 负载理解
```
load average: 0.52, 0.58, 0.59
              1分钟 5分钟 15分钟
```
- 负载值 < CPU核心数：正常
- 负载值 = CPU核心数：满载
- 负载值 > CPU核心数：过载

## 二、进程管理

### 1. ps - 查看进程

```bash
ps aux                            # 查看所有进程（BSD 风格）
ps -ef                            # 查看所有进程（标准风格）
ps aux | grep nginx               # 查找特定进程
ps -ef | grep java                # 查找 java 进程
ps aux --sort=-%mem | head        # 按内存排序
ps aux --sort=-%cpu | head        # 按 CPU 排序
```

#### ps aux 输出解读
```
USER  PID %CPU %MEM    VSZ   RSS TTY  STAT START   TIME COMMAND
root    1  0.0  0.1 193700  6824 ?    Ss   Jan01   0:05 /usr/lib/systemd/systemd
```
- PID：进程 ID
- %CPU：CPU 使用率
- %MEM：内存使用率
- STAT：进程状态（S睡眠 R运行 Z僵尸 T停止）
- TIME：累计 CPU 时间

### 2. top - 动态监控

```bash
top                               # 启动 top
```

#### top 交互命令
| 按键 | 功能 |
|------|------|
| q | 退出 |
| P | 按 CPU 排序 |
| M | 按内存排序 |
| k | 杀死进程（输入 PID） |
| 1 | 显示每个 CPU 核心 |
| c | 显示完整命令 |
| h | 帮助 |

### 3. kill - 终止进程

```bash
kill PID                          # 发送 SIGTERM（15），优雅终止
kill -9 PID                       # 发送 SIGKILL（9），强制终止
kill -15 PID                      # 等同于 kill PID
killall nginx                     # 按名称杀死所有进程
pkill -f "java.*tomcat"           # 按模式杀死进程
```

#### 常用信号
| 信号 | 编号 | 含义 |
|------|------|------|
| SIGHUP | 1 | 重新加载配置 |
| SIGINT | 2 | 中断（Ctrl+C） |
| SIGKILL | 9 | 强制终止 |
| SIGTERM | 15 | 优雅终止（默认） |

### 4. 后台运行

```bash
command &                         # 后台运行
nohup command &                   # 后台运行，退出终端不停止
nohup command > output.log 2>&1 & # 后台运行并记录日志
jobs                              # 查看后台任务
fg %1                             # 将任务调到前台
bg %1                             # 将任务放到后台
Ctrl + Z                          # 暂停当前任务
```

### 5. 服务管理（systemctl）

```bash
systemctl start nginx             # 启动服务
systemctl stop nginx              # 停止服务
systemctl restart nginx           # 重启服务
systemctl reload nginx            # 重新加载配置
systemctl status nginx            # 查看状态
systemctl enable nginx            # 开机自启
systemctl disable nginx           # 取消开机自启
systemctl is-enabled nginx        # 检查是否开机自启
systemctl list-units --type=service  # 列出所有服务
```

## 三、实用组合

### 查找占用最多资源的进程
```bash
# CPU 占用前10
ps aux --sort=-%cpu | head -11

# 内存占用前10
ps aux --sort=-%mem | head -11
```

### 查找并杀死进程
```bash
# 查找 nginx 进程并杀死
ps aux | grep nginx | grep -v grep | awk '{print $2}' | xargs kill -9

# 更简单的方式
pkill nginx
killall nginx
```

### 监控特定进程
```bash
watch -n 1 "ps aux | grep nginx"
```

## 练习题

1. 如何查看系统运行了多长时间？
2. 如何找出内存占用最高的 5 个进程？
3. 如何让一个脚本在后台运行，且退出终端后不停止？

<details>
<summary>答案</summary>

1. `uptime` 或 `w`
2. `ps aux --sort=-%mem | head -6`
3. `nohup ./script.sh > output.log 2>&1 &`

</details>
