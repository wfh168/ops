# 压缩与打包命令

## 概念区分

- 打包：将多个文件合并成一个文件（不压缩）
- 压缩：减小文件体积
- Linux 常用：先打包再压缩

---

## 一、tar - 打包/解包（最常用）

### 核心参数
| 参数 | 含义 |
|------|------|
| -c | 创建打包文件（create） |
| -x | 解包（extract） |
| -v | 显示过程（verbose） |
| -f | 指定文件名（file），必须放最后 |
| -z | 使用 gzip 压缩/解压 |
| -j | 使用 bzip2 压缩/解压 |
| -J | 使用 xz 压缩/解压 |
| -t | 查看包内容（不解压） |
| -C | 指定解压目录 |

### 打包压缩

```bash
# tar.gz 格式（最常用）
tar -czvf archive.tar.gz file1 file2 dir1    # 打包并压缩
tar -czvf backup.tar.gz /etc                  # 打包整个目录

# tar.bz2 格式（压缩率更高）
tar -cjvf archive.tar.bz2 file1 dir1

# tar.xz 格式（压缩率最高，但较慢）
tar -cJvf archive.tar.xz file1 dir1

# 仅打包不压缩
tar -cvf archive.tar file1 dir1
```

### 解压解包

```bash
# 解压 tar.gz
tar -xzvf archive.tar.gz                      # 解压到当前目录
tar -xzvf archive.tar.gz -C /tmp              # 解压到指定目录

# 解压 tar.bz2
tar -xjvf archive.tar.bz2

# 解压 tar.xz
tar -xJvf archive.tar.xz

# 解压普通 tar
tar -xvf archive.tar
```

### 查看包内容

```bash
tar -tzvf archive.tar.gz                      # 查看内容，不解压
tar -tvf archive.tar                          # 查看 tar 包内容
```

### 实用技巧

```bash
# 排除某些文件
tar -czvf backup.tar.gz /data --exclude="*.log" --exclude="cache"

# 打包时保留权限
tar -czvpf backup.tar.gz /etc

# 增量备份（只打包新文件）
tar -czvf backup.tar.gz /data --newer-mtime="2024-01-01"
```

## 二、gzip / gunzip - 压缩/解压

```bash
gzip file.txt                     # 压缩，生成 file.txt.gz（原文件删除）
gzip -k file.txt                  # 压缩，保留原文件
gzip -d file.txt.gz               # 解压
gunzip file.txt.gz                # 解压（等同于 gzip -d）
gzip -l file.txt.gz               # 查看压缩信息
zcat file.txt.gz                  # 查看压缩文件内容（不解压）
```

> gzip 只能压缩单个文件，不能压缩目录

---

## 三、bzip2 / bunzip2 - 更高压缩率

```bash
bzip2 file.txt                    # 压缩，生成 file.txt.bz2
bzip2 -k file.txt                 # 保留原文件
bzip2 -d file.txt.bz2             # 解压
bunzip2 file.txt.bz2              # 解压
bzcat file.txt.bz2                # 查看内容
```

---

## 四、xz - 最高压缩率

```bash
xz file.txt                       # 压缩
xz -k file.txt                    # 保留原文件
xz -d file.txt.xz                 # 解压
unxz file.txt.xz                  # 解压
xzcat file.txt.xz                 # 查看内容
```

---

## 五、zip / unzip - 跨平台格式

```bash
# 压缩
zip archive.zip file1 file2       # 压缩文件
zip -r archive.zip dir1           # 递归压缩目录
zip -e archive.zip file1          # 加密压缩

# 解压
unzip archive.zip                 # 解压到当前目录
unzip archive.zip -d /tmp         # 解压到指定目录
unzip -l archive.zip              # 查看内容
unzip -o archive.zip              # 覆盖已存在文件
```

> zip 格式与 Windows 兼容，适合跨平台传输

---

## 六、压缩格式对比

| 格式 | 压缩率 | 速度 | 命令 | 适用场景 |
|------|--------|------|------|----------|
| .gz | 中等 | 快 | gzip | 日常使用，日志压缩 |
| .bz2 | 较高 | 中等 | bzip2 | 需要较高压缩率 |
| .xz | 最高 | 慢 | xz | 归档存储 |
| .zip | 中等 | 快 | zip | 跨平台传输 |

## 七、常用场景

### 备份网站
```bash
tar -czvf /backup/web_$(date +%Y%m%d).tar.gz /var/www/html
```

### 备份数据库配置
```bash
tar -czvf mysql_conf.tar.gz /etc/my.cnf /var/lib/mysql
```

### 传输文件（压缩后传输更快）
```bash
tar -czvf - /data | ssh user@remote "cat > /backup/data.tar.gz"
```

### 解压到指定目录
```bash
tar -xzvf backup.tar.gz -C /restore/
```

## 练习题

1. 将 /etc 目录打包压缩为 etc_backup.tar.gz
2. 查看 archive.tar.gz 包含哪些文件（不解压）
3. 将 backup.tar.gz 解压到 /tmp/restore 目录

<details>
<summary>答案</summary>

1. `tar -czvf etc_backup.tar.gz /etc`
2. `tar -tzvf archive.tar.gz`
3. `tar -xzvf backup.tar.gz -C /tmp/restore`

</details>
