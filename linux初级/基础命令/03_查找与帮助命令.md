# 查找与帮助命令

## 一、查找命令

### 1. find - 文件查找（最强大）

```bash
# 基本语法
find [搜索路径] [选项] [动作]
```

#### 按名称查找
```bash
find /etc -name "passwd"              # 精确查找
find /etc -name "*.conf"              # 通配符查找
find /etc -iname "PASSWD"             # 忽略大小写
find / -name "*.log" 2>/dev/null      # 忽略权限错误
```

#### 按类型查找
```bash
find /tmp -type f                     # 查找普通文件
find /tmp -type d                     # 查找目录
find /tmp -type l                     # 查找软链接
```

#### 按大小查找
```bash
find / -size +100M                    # 大于100M的文件
find / -size -10k                     # 小于10k的文件
find / -size 50M                      # 等于50M的文件
```

#### 按时间查找
```bash
find /var/log -mtime -7               # 7天内修改过的文件
find /var/log -mtime +30              # 30天前修改的文件
find /tmp -mmin -60                   # 60分钟内修改的文件
```

#### 按权限/属主查找
```bash
find / -perm 777                      # 权限为777的文件
find / -user root                     # 属主为root的文件
find / -nouser                        # 没有属主的文件（孤儿文件）
```

#### 组合条件
```bash
find /var -type f -name "*.log" -size +10M    # 多条件组合
find /tmp -type f -a -mtime +7                # -a 表示 AND
find /tmp -type f -o -type d                  # -o 表示 OR
find /tmp ! -name "*.txt"                     # ! 表示取反
```

#### 对结果执行操作
```bash
find /tmp -name "*.tmp" -delete               # 删除找到的文件
find /tmp -name "*.sh" -exec chmod +x {} \;   # 批量加执行权限
find /var/log -name "*.log" -exec ls -lh {} \;  # 查看详情
find . -type f -name "*.txt" | xargs rm -f    # 配合 xargs
```

### 2. locate - 快速查找（基于数据库）

```bash
locate passwd                         # 快速查找
updatedb                              # 更新数据库（新文件需要先更新）
locate -i Passwd                      # 忽略大小写
```

> locate 比 find 快，但依赖数据库，新文件可能找不到

### 3. which - 查找命令位置

```bash
which ls                              # 显示命令的绝对路径
which python                          # 查找 python 在哪
```

### 4. whereis - 查找命令及文档

```bash
whereis ls                            # 显示命令、源码、手册位置
whereis -b ls                         # 只显示二进制文件
whereis -m ls                         # 只显示手册位置
```

## 二、帮助命令

### 1. man - 手册页（最详细）

```bash
man ls                                # 查看 ls 命令手册
man 5 passwd                          # 查看配置文件手册
man -k keyword                        # 搜索相关手册
```

#### man 手册章节
| 章节 | 内容 |
|------|------|
| 1 | 用户命令 |
| 2 | 系统调用 |
| 3 | 库函数 |
| 4 | 设备文件 |
| 5 | 配置文件格式 |
| 6 | 游戏 |
| 7 | 杂项 |
| 8 | 管理员命令 |

#### man 页面操作
```
空格/PageDown  下一页
b/PageUp       上一页
/keyword       搜索
n              下一个匹配
q              退出
```

### 2. --help - 快速帮助

```bash
ls --help                             # 查看命令简要帮助
mkdir --help                          # 比 man 更简洁
```

### 3. info - 详细文档

```bash
info ls                               # 比 man 更详细的文档
```

### 4. 内置命令帮助

```bash
help cd                               # 查看 shell 内置命令帮助
type cd                               # 判断命令类型
```

## 三、实用技巧

### 命令历史
```bash
history                               # 查看历史命令
history 20                            # 最近20条
!100                                  # 执行第100条历史命令
!!                                    # 执行上一条命令
!ls                                   # 执行最近以 ls 开头的命令
Ctrl + r                              # 搜索历史命令
```

### Tab 补全
```bash
# 输入部分命令或路径后按 Tab 键自动补全
# 按两次 Tab 显示所有可能的选项
```

### 命令别名
```bash
alias ll='ls -la'                     # 创建别名
alias                                 # 查看所有别名
unalias ll                            # 删除别名
```

## 练习题

1. 查找 /var/log 下 7 天前且大于 10M 的日志文件
2. 查找系统中所有权限为 777 的文件
3. 如何查看 chmod 命令的详细用法？

<details>
<summary>答案</summary>

1. `find /var/log -type f -mtime +7 -size +10M`
2. `find / -perm 777 -type f 2>/dev/null`
3. `man chmod` 或 `chmod --help`

</details>
