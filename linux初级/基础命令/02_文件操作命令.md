# 文件操作命令

## 1. touch - 创建文件/更新时间戳

```bash
touch file.txt                # 创建空文件（文件存在则更新时间戳）
touch file1 file2 file3       # 创建多个文件
touch /tmp/test.log           # 指定路径创建
```

## 2. cp - 复制文件或目录

```bash
cp file1 file2                # 复制 file1 为 file2
cp file1 /tmp/                # 复制到 /tmp 目录
cp -r dir1 dir2               # 递归复制目录（重要！）
cp -p file1 file2             # 保留原文件属性（权限、时间）
cp -a dir1 dir2               # 归档复制，等于 -pdr（常用于备份）
cp -i file1 file2             # 覆盖前提示确认
```

### 常用组合
```bash
cp -av /data /backup/         # 备份目录，显示过程
cp -rp /etc /etc.bak          # 备份配置目录
```

## 3. mv - 移动/重命名

```bash
mv file1 file2                # 重命名 file1 为 file2
mv file1 /tmp/                # 移动到 /tmp 目录
mv file1 /tmp/newname         # 移动并重命名
mv dir1 dir2                  # 重命名目录（dir2不存在）
mv dir1 /data/                # 移动目录到 /data
```

> mv 不需要 -r 参数就能操作目录

## 4. rm - 删除文件或目录

```bash
rm file.txt                   # 删除文件
rm -f file.txt                # 强制删除，不提示
rm -r dir1                    # 递归删除目录
rm -rf dir1                   # 强制递归删除（危险！）
rm -i file.txt                # 删除前确认
```

### ⚠️ 危险操作警告
```bash
# 以下命令千万小心！
rm -rf /                      # 删除整个系统！！！
rm -rf /*                     # 同上！！！
rm -rf ./*                    # 删除当前目录所有内容

# 安全建议
# 1. 删除前先 ls 确认
# 2. 使用 mv 移动到回收目录而非直接删除
# 3. 重要数据先备份
```

## 5. 文件查看命令

### cat - 查看文件全部内容
```bash
cat file.txt                  # 查看文件内容
cat -n file.txt               # 显示行号
cat -A file.txt               # 显示特殊字符（排查问题用）
cat file1 file2 > merged      # 合并文件
```

### more - 分页查看
```bash
more file.txt                 # 分页显示
# 空格：下一页
# 回车：下一行
# q：退出
```

### less - 更强大的分页查看
```bash
less file.txt                 # 分页显示
# 空格/PageDown：下一页
# b/PageUp：上一页
# /keyword：向下搜索
# ?keyword：向上搜索
# n：下一个匹配
# N：上一个匹配
# g：跳到开头
# G：跳到结尾
# q：退出
```

### head - 查看文件开头
```bash
head file.txt                 # 默认显示前10行
head -n 20 file.txt           # 显示前20行
head -20 file.txt             # 简写形式
```

### tail - 查看文件结尾
```bash
tail file.txt                 # 默认显示后10行
tail -n 20 file.txt           # 显示后20行
tail -f /var/log/messages     # 实时跟踪日志（重要！）
tail -F /var/log/messages     # 跟踪日志，文件不存在会重试
tail -100f file.log           # 显示后100行并持续跟踪
```

> `tail -f` 是运维排查问题的常用命令

## 6. 其他实用命令

### wc - 统计
```bash
wc -l file.txt                # 统计行数
wc -w file.txt                # 统计单词数
wc -c file.txt                # 统计字节数
```

### file - 查看文件类型
```bash
file /bin/ls                  # 查看文件类型
file /etc/passwd              # ASCII text
```

## 练习题

1. 如何备份 /etc 目录到 /backup 并保留所有属性？
2. 如何实时查看 nginx 的访问日志？
3. 如何查看一个文件的前 5 行和后 5 行？

<details>
<summary>答案</summary>

1. `cp -a /etc /backup/` 或 `cp -rp /etc /backup/`
2. `tail -f /var/log/nginx/access.log`
3. `head -5 file.txt` 和 `tail -5 file.txt`

</details>
