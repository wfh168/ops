# 目录操作命令

## 1. pwd - 显示当前目录

```bash
pwd                 # 显示当前所在的绝对路径
```

## 2. cd - 切换目录

```bash
cd /home            # 切换到 /home 目录
cd ..               # 返回上一级目录
cd ../..            # 返回上两级目录
cd ~                # 回到当前用户家目录
cd -                # 返回上一次所在目录
cd                  # 不加参数，等同于 cd ~
```

### 路径概念
- 绝对路径：从根目录 `/` 开始的完整路径，如 `/home/user/docs`
- 相对路径：从当前目录开始的路径，如 `./docs` 或 `../config`

## 3. ls - 列出目录内容

```bash
ls                  # 列出当前目录文件
ls -l               # 长格式显示（权限、大小、时间等）
ls -a               # 显示所有文件（包括隐藏文件 .开头）
ls -la              # 组合使用
ls -lh              # 人性化显示文件大小（K/M/G）
ls -lt              # 按时间排序（最新在前）
ls -ltr             # 按时间倒序（最旧在前）
ls -ld /etc         # 查看目录本身属性，而非内容
```

### ls -l 输出解读
```
-rw-r--r-- 1 root root 1024 Jan 7 10:00 file.txt
│          │ │    │    │    │           │
│          │ │    │    │    │           └── 文件名
│          │ │    │    │    └── 修改时间
│          │ │    │    └── 文件大小（字节）
│          │ │    └── 所属组
│          │ └── 所有者
│          └── 硬链接数
└── 文件类型和权限
```

## 4. mkdir - 创建目录

```bash
mkdir dir1                    # 创建单个目录
mkdir dir1 dir2 dir3          # 创建多个目录
mkdir -p /a/b/c/d             # 递归创建多级目录（重要！）
mkdir -m 755 mydir            # 创建目录并指定权限
```

## 5. rmdir - 删除空目录

```bash
rmdir emptydir                # 只能删除空目录
rmdir -p a/b/c                # 递归删除空目录
```

> 实际工作中更常用 `rm -r` 删除目录

## 6. tree - 树形显示目录结构

```bash
tree                          # 显示当前目录树
tree -L 2                     # 只显示2层
tree -d                       # 只显示目录
tree /etc                     # 显示指定目录
```

> 需要安装：`yum install tree -y`

## 练习题

1. 如何一次性创建 `/data/backup/2024/01` 这个多级目录？
2. 如何查看 `/etc` 目录本身的属性而不是其内容？
3. `cd -` 和 `cd ~` 有什么区别？

<details>
<summary>答案</summary>

1. `mkdir -p /data/backup/2024/01`
2. `ls -ld /etc`
3. `cd -` 返回上一次所在目录，`cd ~` 回到家目录

</details>
