# 网络与下载命令

## 一、网络诊断

### 1. ping - 测试连通性

```bash
ping www.baidu.com                # 持续 ping
ping -c 4 www.baidu.com           # ping 4 次
ping -c 4 -i 0.5 192.168.1.1      # 间隔 0.5 秒
ping -c 4 -W 2 192.168.1.1        # 超时 2 秒
```

### 2. telnet - 测试端口

```bash
telnet 192.168.1.1 80             # 测试 80 端口是否开放
telnet www.baidu.com 443          # 测试 443 端口
```

> 需要安装：`yum install telnet -y`

### 3. curl - 测试 HTTP

```bash
curl www.baidu.com                # 获取网页内容
curl -I www.baidu.com             # 只看响应头
curl -v www.baidu.com             # 详细信息
curl -o file.html www.baidu.com   # 保存到文件
curl -O http://example.com/file.zip  # 保存为原文件名
curl -L url                       # 跟随重定向
curl -x proxy:port url            # 使用代理
curl -u user:pass url             # 带认证
curl -X POST -d "data" url        # POST 请求
```

### 4. wget - 下载文件

```bash
wget http://example.com/file.zip  # 下载文件
wget -O newname.zip url           # 指定保存文件名
wget -c url                       # 断点续传
wget -b url                       # 后台下载
wget -q url                       # 静默模式
wget --limit-rate=1m url          # 限速下载
wget -r -np url                   # 递归下载
wget -i urls.txt                  # 从文件读取 URL 列表
```

### 5. traceroute - 路由追踪

```bash
traceroute www.baidu.com          # 追踪路由路径
traceroute -n www.baidu.com       # 不解析主机名
```

### 6. nslookup / dig - DNS 查询

```bash
nslookup www.baidu.com            # DNS 查询
nslookup www.baidu.com 8.8.8.8    # 指定 DNS 服务器

dig www.baidu.com                 # 更详细的 DNS 查询
dig +short www.baidu.com          # 简洁输出
dig @8.8.8.8 www.baidu.com        # 指定 DNS 服务器
```

## 二、网络配置

### 1. ip 命令（推荐）

```bash
# 查看 IP 地址
ip addr                           # 查看所有网卡
ip addr show eth0                 # 查看指定网卡
ip -4 addr                        # 只看 IPv4

# 配置 IP（临时）
ip addr add 192.168.1.100/24 dev eth0
ip addr del 192.168.1.100/24 dev eth0

# 启用/禁用网卡
ip link set eth0 up
ip link set eth0 down

# 查看路由
ip route
ip route add default via 192.168.1.1  # 添加默认网关
```

### 2. 网络配置文件（永久）

```bash
# CentOS 7/8 网卡配置
cat /etc/sysconfig/network-scripts/ifcfg-eth0

# 配置示例
TYPE=Ethernet
BOOTPROTO=static              # static 或 dhcp
NAME=eth0
DEVICE=eth0
ONBOOT=yes
IPADDR=192.168.1.100
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DNS1=8.8.8.8
DNS2=114.114.114.114
```

```bash
# 重启网络服务
systemctl restart network         # CentOS 7
nmcli connection reload           # CentOS 8+
```

### 3. DNS 配置

```bash
cat /etc/resolv.conf              # 查看 DNS 配置
# nameserver 8.8.8.8
# nameserver 114.114.114.114
```

### 4. hosts 文件

```bash
cat /etc/hosts                    # 本地域名解析
# 192.168.1.100 myserver.local
```

## 三、端口与连接

### 1. ss - 查看连接（推荐）

```bash
ss -tunlp                         # 查看所有监听端口
ss -tunlp | grep :80              # 查看 80 端口
ss -t                             # 查看 TCP 连接
ss -u                             # 查看 UDP 连接
ss -s                             # 连接统计
```

#### 参数说明
| 参数 | 含义 |
|------|------|
| -t | TCP |
| -u | UDP |
| -n | 不解析服务名 |
| -l | 监听状态 |
| -p | 显示进程 |
| -a | 所有连接 |

### 2. netstat - 传统命令

```bash
netstat -tunlp                    # 查看监听端口
netstat -an                       # 所有连接
netstat -rn                       # 路由表
```

> 需要安装：`yum install net-tools -y`

### 3. lsof - 查看端口占用

```bash
lsof -i :80                       # 查看 80 端口被谁占用
lsof -i tcp                       # 所有 TCP 连接
lsof -i -P -n                     # 所有网络连接
```

## 四、远程连接

### 1. ssh - 远程登录

```bash
ssh user@192.168.1.100            # 远程登录
ssh -p 2222 user@host             # 指定端口
ssh user@host "command"           # 远程执行命令
```

### 2. scp - 远程复制

```bash
# 本地 -> 远程
scp file.txt user@host:/tmp/
scp -r dir/ user@host:/tmp/       # 复制目录

# 远程 -> 本地
scp user@host:/tmp/file.txt ./
scp -r user@host:/tmp/dir/ ./

# 指定端口
scp -P 2222 file.txt user@host:/tmp/
```

### 3. rsync - 同步（更强大）

```bash
rsync -av /src/ /dest/            # 本地同步
rsync -av /src/ user@host:/dest/  # 推送到远程
rsync -av user@host:/src/ /dest/  # 从远程拉取
rsync -avz --delete /src/ /dest/  # 同步并删除多余文件
```

## 五、防火墙基础

### firewalld（CentOS 7+）

```bash
systemctl status firewalld        # 查看状态
systemctl start firewalld         # 启动
systemctl stop firewalld          # 停止

firewall-cmd --list-all           # 查看规则
firewall-cmd --add-port=80/tcp --permanent   # 开放端口
firewall-cmd --remove-port=80/tcp --permanent # 关闭端口
firewall-cmd --reload             # 重新加载
```

## 练习题

1. 如何测试远程服务器的 22 端口是否开放？
2. 如何查看本机 80 端口被哪个进程占用？
3. 如何下载一个大文件并支持断点续传？

<details>
<summary>答案</summary>

1. `telnet 192.168.1.1 22` 或 `curl -v telnet://192.168.1.1:22`
2. `ss -tunlp | grep :80` 或 `lsof -i :80`
3. `wget -c http://example.com/bigfile.zip`

</details>
