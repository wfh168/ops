# 网络基础概念

## OSI 七层模型

```
应用层 (Application)     ──▶  HTTP、FTP、SSH、DNS
表示层 (Presentation)    ──▶  加密、压缩
会话层 (Session)         ──▶  会话管理
传输层 (Transport)       ──▶  TCP、UDP
网络层 (Network)         ──▶  IP、ICMP、路由
数据链路层 (Data Link)   ──▶  MAC、交换机
物理层 (Physical)        ──▶  网线、光纤
```

## TCP/IP 四层模型

```
应用层    ──▶  HTTP、FTP、SSH、DNS
传输层    ──▶  TCP、UDP
网络层    ──▶  IP、ICMP
网络接口层 ──▶  以太网、WiFi
```

## 一、IP 地址

### IPv4 地址

```bash
# 格式：x.x.x.x（每个 x 是 0-255）
192.168.1.100

# 组成
网络部分 + 主机部分
```

### IP 地址分类

| 类别 | 范围 | 默认子网掩码 | 用途 |
|------|------|-------------|------|
| A类 | 1.0.0.0 - 126.255.255.255 | 255.0.0.0 | 大型网络 |
| B类 | 128.0.0.0 - 191.255.255.255 | 255.255.0.0 | 中型网络 |
| C类 | 192.0.0.0 - 223.255.255.255 | 255.255.255.0 | 小型网络 |

### 私有 IP 地址

| 类别 | 范围 |
|------|------|
| A类 | 10.0.0.0 - 10.255.255.255 |
| B类 | 172.16.0.0 - 172.31.255.255 |
| C类 | 192.168.0.0 - 192.168.255.255 |

### 特殊 IP 地址

```bash
127.0.0.1       # 本地回环地址
0.0.0.0         # 所有地址
255.255.255.255 # 广播地址
```

## 二、子网掩码

### 作用
- 区分网络部分和主机部分
- 确定网络范围

### 常见子网掩码

| CIDR | 子网掩码 | 可用主机数 |
|------|---------|-----------|
| /24 | 255.255.255.0 | 254 |
| /25 | 255.255.255.128 | 126 |
| /26 | 255.255.255.192 | 62 |
| /27 | 255.255.255.224 | 30 |
| /28 | 255.255.255.240 | 14 |
| /30 | 255.255.255.252 | 2 |

### CIDR 表示法

```bash
192.168.1.0/24
# 192.168.1.0 是网络地址
# /24 表示前24位是网络部分
# 等同于 255.255.255.0
```

## 三、网关

### 什么是网关
- 网络的出口
- 连接不同网络的设备
- 通常是路由器的 IP

### 默认网关

```bash
# 查看网关
ip route
route -n

# 示例
default via 192.168.1.1 dev eth0
# 192.168.1.1 是默认网关
```

## 四、DNS

### 什么是 DNS
- Domain Name System（域名系统）
- 将域名转换为 IP 地址
- 例如：www.baidu.com → 220.181.38.148

### DNS 服务器

```bash
# 常用公共 DNS
8.8.8.8         # Google DNS
114.114.114.114 # 国内 DNS
223.5.5.5       # 阿里 DNS
1.1.1.1         # Cloudflare DNS
```

### DNS 解析过程

```
1. 查询本地 hosts 文件
2. 查询本地 DNS 缓存
3. 查询配置的 DNS 服务器
4. DNS 服务器递归查询
5. 返回 IP 地址
```

## 六、TCP vs UDP

### TCP（传输控制协议）

```bash
# 特点
- 面向连接
- 可靠传输
- 有序传输
- 流量控制
- 拥塞控制

# 适用场景
- HTTP/HTTPS
- FTP
- SSH
- 邮件
```

### UDP（用户数据报协议）

```bash
# 特点
- 无连接
- 不可靠
- 无序
- 速度快
- 开销小

# 适用场景
- DNS
- 视频直播
- 在线游戏
- VoIP
```

### TCP 三次握手

```
客户端                    服务器
  │                        │
  │──── SYN ──────────────▶│  1. 请求连接
  │                        │
  │◀──── SYN+ACK ──────────│  2. 确认并请求
  │                        │
  │──── ACK ──────────────▶│  3. 确认连接
  │                        │
  │    连接建立             │
```

### TCP 四次挥手

```
客户端                    服务器
  │                        │
  │──── FIN ──────────────▶│  1. 请求关闭
  │                        │
  │◀──── ACK ──────────────│  2. 确认关闭
  │                        │
  │◀──── FIN ──────────────│  3. 请求关闭
  │                        │
  │──── ACK ──────────────▶│  4. 确认关闭
  │                        │
  │    连接关闭             │
```

## 七、MAC 地址

### 什么是 MAC 地址
- Media Access Control Address
- 物理地址，全球唯一
- 48位（6字节），通常用16进制表示
- 例如：00:0c:29:6a:3b:2f

### 查看 MAC 地址

```bash
# 方法1
ip link show

# 方法2
ifconfig

# 方法3
cat /sys/class/net/eth0/address
```

---

## 八、ARP 协议

### 什么是 ARP
- Address Resolution Protocol
- 将 IP 地址转换为 MAC 地址
- 工作在数据链路层

### ARP 缓存

```bash
# 查看 ARP 缓存
arp -n
ip neigh

# 清除 ARP 缓存
ip neigh flush all

# 添加静态 ARP
arp -s 192.168.1.100 00:0c:29:6a:3b:2f
```

---

## 九、ICMP 协议

### 什么是 ICMP
- Internet Control Message Protocol
- 用于网络诊断和错误报告
- ping 命令使用 ICMP

### ICMP 消息类型

| 类型 | 说明 |
|------|------|
| 0 | Echo Reply（ping 响应） |
| 3 | Destination Unreachable |
| 8 | Echo Request（ping 请求） |
| 11 | Time Exceeded |

## 十、网络拓扑

### 常见拓扑结构

```bash
# 星型拓扑
所有设备连接到中心交换机

# 总线型拓扑
所有设备连接到一条总线

设备首尾相连形成环

# 网状拓扑
设备之间多路连接
```

## 练习题

1. 192.168.1.0/24 网络中有多少个可用 IP？
2. TCP 和 UDP 的主要区别是什么？
3. 什么是默认网关？

<details>
<summary>答案</summary>

1. 254个（256 - 2，减去网络地址和广播地址）
2. TCP 面向连接、可靠；UDP 无连接、不可靠但速度快
3. 默认网关是网络的出口，用于访问其他网络的设备，通常是路由器的 IP 地址

</details>
