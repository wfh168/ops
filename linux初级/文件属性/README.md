## 核心概念

### 必须理解的概念

1. **一切皆文件** - Linux 的核心设计哲学
2. **inode** - 文件的元数据存储
3. **软链接 vs 硬链接** - 面试常考
4. **FHS 目录结构** - 知道文件该放哪里

### 必须记住的目录

```bash
/etc          # 配置文件
/var/log      # 日志文件
/home         # 用户家目录
/tmp          # 临时文件
/usr/local    # 手动安装的软件
```

### 必须掌握的命令

```bash
ls -l         # 查看文件属性
ls -i         # 查看 inode
stat          # 详细文件信息
file          # 判断文件类型
ln -s         # 创建软链接
ln            # 创建硬链接
lsattr/chattr # 扩展属性
```

## 学习建议

1. 多用 `ls -l` 观察不同文件的属性
2. 理解 inode 对后续学习磁盘管理很重要
3. 熟悉目录结构，知道配置文件、日志文件在哪
