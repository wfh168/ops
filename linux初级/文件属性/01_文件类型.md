# Linux 文件类型

## 核心概念：一切皆文件

Linux 中所有东西都被抽象为文件，包括硬件设备、目录、网络套接字等。

---

## 文件类型一览

通过 `ls -l` 第一个字符识别文件类型：

| 符号 | 类型 | 英文 | 说明 |
|------|------|------|------|
| `-` | 普通文件 | regular file | 文本、二进制、数据文件 |
| `d` | 目录 | directory | 文件夹 |
| `l` | 软链接 | symbolic link | 快捷方式 |
| `b` | 块设备 | block device | 硬盘、U盘等存储设备 |
| `c` | 字符设备 | character device | 终端、键盘等 |
| `s` | 套接字 | socket | 进程间通信 |
| `p` | 管道 | pipe (FIFO) | 进程间通信 |

---

## 一、普通文件 `-`

```bash
$ ls -l /etc/passwd
-rw-r--r-- 1 root root 2234 Jan 7 10:00 /etc/passwd
^
└── 普通文件
```

### 普通文件分类

```bash
# 文本文件
file /etc/passwd
# /etc/passwd: ASCII text

# 二进制可执行文件
file /bin/ls
# /bin/ls: ELF 64-bit LSB executable...

# 数据文件
file /var/log/wtmp
# /var/log/wtmp: data
```

---

## 二、目录 `d`

```bash
$ ls -ld /etc
drwxr-xr-x 77 root root 4096 Jan 7 10:00 /etc
^
└── 目录
```

目录本质上是一个特殊文件，存储了文件名和 inode 的映射关系。

---

## 三、软链接 `l`

类似 Windows 快捷方式，指向另一个文件。

```bash
$ ls -l /etc/rc.local
lrwxrwxrwx 1 root root 13 Jan 7 10:00 /etc/rc.local -> rc.d/rc.local
^                                                    ^
└── 软链接                                           └── 指向的目标
```

### 创建软链接

```bash
ln -s /path/to/target linkname    # 创建软链接
ln -sf /path/to/target linkname   # 强制覆盖已存在的链接
```

### 软链接特点
- 可以跨文件系统
- 可以链接目录
- 删除原文件，链接失效（断链）
- 有自己的 inode

---

## 四、硬链接

硬链接不是文件类型，而是文件的另一个名字（入口）。

```bash
ln /path/to/file hardlink         # 创建硬链接
```

### 硬链接特点
- 不能跨文件系统
- 不能链接目录
- 删除原文件，硬链接仍可用
- 共享同一个 inode

### 软链接 vs 硬链接

| 特性 | 软链接 | 硬链接 |
|------|--------|--------|
| 跨文件系统 | ✅ 可以 | ❌ 不可以 |
| 链接目录 | ✅ 可以 | ❌ 不可以 |
| 原文件删除 | 链接失效 | 仍可访问 |
| inode | 不同 | 相同 |
| 文件大小 | 很小（存路径） | 与原文件相同 |

```bash
# 查看 inode
ls -li file hardlink softlink
```

---

## 五、块设备 `b`

存储设备，以块为单位读写（如硬盘）。

```bash
$ ls -l /dev/sda
brw-rw---- 1 root disk 8, 0 Jan 7 10:00 /dev/sda
^
└── 块设备
```

常见块设备：
- `/dev/sda` - 第一块 SCSI/SATA 硬盘
- `/dev/sda1` - 第一块硬盘的第一个分区
- `/dev/vda` - 虚拟机磁盘
- `/dev/nvme0n1` - NVMe SSD

---

## 六、字符设备 `c`

以字符为单位读写的设备。

```bash
$ ls -l /dev/tty
crw-rw-rw- 1 root tty 5, 0 Jan 7 10:00 /dev/tty
^
└── 字符设备
```

常见字符设备：
- `/dev/tty` - 当前终端
- `/dev/null` - 黑洞设备（丢弃所有输入）
- `/dev/zero` - 零设备（输出无限的 0）
- `/dev/random` - 随机数生成器

### 特殊设备用法

```bash
# 丢弃输出
command > /dev/null 2>&1

# 创建指定大小的空文件
dd if=/dev/zero of=file.img bs=1M count=100

# 生成随机密码
cat /dev/urandom | tr -dc 'a-zA-Z0-9' | head -c 16
```

---

## 七、套接字 `s`

用于进程间通信。

```bash
$ ls -l /var/run/docker.sock
srw-rw---- 1 root docker 0 Jan 7 10:00 /var/run/docker.sock
^
└── 套接字
```

常见套接字：
- `/var/run/docker.sock` - Docker 通信
- `/var/lib/mysql/mysql.sock` - MySQL 通信

---

## 八、管道 `p`

命名管道，用于进程间通信。

```bash
# 创建命名管道
mkfifo mypipe

$ ls -l mypipe
prw-r--r-- 1 root root 0 Jan 7 10:00 mypipe
^
└── 管道
```

---

## 使用 file 命令识别

```bash
file /etc/passwd          # ASCII text
file /bin/ls              # ELF 64-bit executable
file /dev/sda             # block special
file /dev/tty             # character special
file /etc/rc.local        # symbolic link
```

## 练习题

1. 如何判断一个文件是软链接还是硬链接？
2. `/dev/null` 是什么类型的文件？有什么用途？
3. 软链接和硬链接的主要区别是什么？

<details>
<summary>答案</summary>

1. `ls -l` 查看，软链接显示 `l` 开头且有 `->` 指向目标；硬链接用 `ls -li` 查看 inode，与原文件相同
2. 字符设备文件，用于丢弃不需要的输出
3. 软链接有独立 inode，可跨文件系统，可链接目录，原文件删除后失效；硬链接共享 inode，不能跨文件系统，不能链接目录，原文件删除后仍可用

</details>
