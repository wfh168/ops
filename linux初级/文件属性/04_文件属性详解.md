# 文件属性详解

## ls -l 输出解析

```bash
$ ls -l /etc/passwd
-rw-r--r-- 1 root root 2234 Jan  7 10:00 /etc/passwd
│├──┼──┼──┤ │ │    │    │    │           │
││  │  │  │ │ │    │    │    │           └── 文件名
││  │  │  │ │ │    │    │    └── 修改时间
││  │  │  │ │ │    │    └── 文件大小（字节）
││  │  │  │ │ │    └── 所属组
││  │  │  │ │ └── 所有者
││  │  │  │ └── 硬链接数
││  │  │  └── 其他用户权限
││  │  └── 所属组权限
││  └── 所有者权限
│└── 文件类型
└── 第一个字符：文件类型
```

---

## 一、文件类型（第1位）

| 符号 | 类型 |
|------|------|
| `-` | 普通文件 |
| `d` | 目录 |
| `l` | 软链接 |
| `b` | 块设备 |
| `c` | 字符设备 |
| `s` | 套接字 |
| `p` | 管道 |

---

## 二、权限位（第2-10位）

```
rw-r--r--
│││││││││
│││││││└┴── 其他用户：r-- (只读)
│││││└┴──── 所属组：r-- (只读)
│││└┴────── 所有者：rw- (读写)
```

### 权限含义

| 权限 | 对文件 | 对目录 |
|------|--------|--------|
| r (读) | 查看内容 | 列出目录内容 |
| w (写) | 修改内容 | 创建/删除文件 |
| x (执行) | 执行文件 | 进入目录 |

### 权限数字表示

| 权限 | 二进制 | 数字 |
|------|--------|------|
| r | 100 | 4 |
| w | 010 | 2 |
| x | 001 | 1 |
| - | 000 | 0 |

```bash
rwx = 4+2+1 = 7
rw- = 4+2+0 = 6
r-x = 4+0+1 = 5
r-- = 4+0+0 = 4

# 常见权限组合
755 = rwxr-xr-x    # 目录、可执行文件
644 = rw-r--r--    # 普通文件
600 = rw-------    # 私密文件
777 = rwxrwxrwx    # 完全开放（危险！）
```

---

## 三、硬链接数

```bash
-rw-r--r-- 1 root root 2234 Jan 7 10:00 passwd
           ^
           └── 硬链接数
```

- 普通文件：默认为 1
- 目录：至少为 2（自身 + `.`）
- 每个子目录会增加父目录的链接数（因为子目录中的 `..`）

## 四、所有者和所属组

```bash
-rw-r--r-- 1 root root 2234 Jan 7 10:00 passwd
             │    │
             │    └── 所属组 (group)
             └── 所有者 (owner)
```

### 查看和修改

```bash
# 查看
ls -l filename

# 修改所有者
chown newowner filename
chown newowner:newgroup filename
chown -R newowner directory/      # 递归修改

# 修改所属组
chgrp newgroup filename
chgrp -R newgroup directory/
```

## 五、文件大小

```bash
-rw-r--r-- 1 root root 2234 Jan 7 10:00 passwd
                       │
                       └── 文件大小（字节）
```

```bash
ls -lh                            # 人性化显示（K/M/G）
ls -lS                            # 按大小排序
du -sh filename                   # 查看实际占用空间
```

### 文件大小 vs 磁盘占用

```bash
# 文件大小：文件内容的字节数
# 磁盘占用：实际占用的磁盘块数 × 块大小

ls -ls filename                   # 同时显示两者
stat filename                     # 详细信息
```

## 六、时间戳

```bash
-rw-r--r-- 1 root root 2234 Jan  7 10:00 passwd
                            │
                            └── 默认显示 mtime
```

### 三种时间

| 时间 | 含义 | 查看方式 |
|------|------|----------|
| mtime | 内容修改时间 | `ls -l` (默认) |
| atime | 访问时间 | `ls -lu` |
| ctime | 属性修改时间 | `ls -lc` |

```bash
# 查看所有时间
stat filename

# 按时间排序
ls -lt                            # 按 mtime 排序
ls -lut                           # 按 atime 排序
ls -lct                           # 按 ctime 排序
```

## 七、特殊属性

### lsattr / chattr - 扩展属性

```bash
# 查看扩展属性
lsattr filename

# 设置不可删除（即使 root）
chattr +i filename                # 添加 immutable 属性
chattr -i filename                # 移除

# 只能追加
chattr +a filename                # 添加 append-only 属性
```

| 属性 | 含义 |
|------|------|
| i | 不可修改、删除、重命名 |
| a | 只能追加内容 |
| A | 不更新 atime |
| S | 同步写入磁盘 |

### 实战应用

```bash
# 保护重要配置文件
chattr +i /etc/passwd
chattr +i /etc/shadow

# 保护日志文件（只能追加）
chattr +a /var/log/secure
```

## 八、隐藏文件

以 `.` 开头的文件是隐藏文件。

```bash
ls -a                             # 显示所有文件（包括隐藏）
ls -A                             # 显示隐藏文件（不含 . 和 ..）
```

### 常见隐藏文件

```bash
~/.bashrc                         # Bash 配置
~/.bash_profile                   # 登录配置
~/.bash_history                   # 命令历史
~/.ssh/                           # SSH 配置和密钥
~/.vimrc                          # Vim 配置
```

## 练习题

1. 权限 `rwxr-x---` 对应的数字是多少？
2. 如何让一个文件即使 root 也无法删除？
3. 目录的 x 权限有什么作用？

<details>
<summary>答案</summary>

1. 750 (rwx=7, r-x=5, ---=0)
2. `chattr +i filename`
3. x 权限允许进入（cd）该目录，没有 x 权限即使有 r 权限也无法访问目录内的文件

</details>
