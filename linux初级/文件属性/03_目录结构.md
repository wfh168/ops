# Linux 目录结构

## FHS 标准

FHS（Filesystem Hierarchy Standard）定义了 Linux 目录结构标准。

```
/                           # 根目录，一切的起点
├── bin                     # 基本命令（所有用户）
├── sbin                    # 系统管理命令（root）
├── boot                    # 启动文件、内核
├── dev                     # 设备文件
├── etc                     # 配置文件
├── home                    # 普通用户家目录
├── root                    # root 用户家目录
├── lib                     # 基本共享库
├── lib64                   # 64位共享库
├── media                   # 可移动设备挂载点
├── mnt                     # 临时挂载点
├── opt                     # 第三方软件
├── proc                    # 进程信息（虚拟文件系统）
├── sys                     # 系统信息（虚拟文件系统）
├── run                     # 运行时数据
├── srv                     # 服务数据
├── tmp                     # 临时文件
├── usr                     # 用户程序
│   ├── bin                 # 用户命令
│   ├── sbin                # 系统管理命令
│   ├── lib                 # 库文件
│   ├── local               # 本地安装的软件
│   └── share               # 共享数据
└── var                     # 可变数据
    ├── log                 # 日志文件
    ├── cache               # 缓存
    ├── spool               # 队列数据
    └── tmp                 # 临时文件
```

## 重要目录详解

### / - 根目录
- 整个文件系统的起点
- 所有目录都从这里开始

### /bin 和 /sbin
```bash
/bin                        # 所有用户可用的基本命令
                            # ls, cp, mv, cat, mkdir...

/sbin                       # 系统管理命令（通常需要 root）
                            # fdisk, mkfs, iptables, reboot...
```

> CentOS 7+ 中 /bin 和 /sbin 是 /usr/bin 和 /usr/sbin 的软链接

### /boot - 启动目录
```bash
ls /boot
# vmlinuz-*                 # Linux 内核
# initramfs-*               # 初始化内存盘
# grub2/                    # 引导程序
```

⚠️ 不要随意修改此目录，可能导致系统无法启动

### /dev - 设备目录
```bash
/dev/sda                    # 第一块硬盘
/dev/sda1                   # 第一块硬盘第一分区
/dev/null                   # 黑洞设备
/dev/zero                   # 零设备
/dev/tty                    # 当前终端
/dev/random                 # 随机数生成器
```

### /etc - 配置目录（最重要！）
```bash
/etc/passwd                 # 用户信息
/etc/shadow                 # 用户密码
/etc/group                  # 用户组信息
/etc/hosts                  # 本地 DNS
/etc/resolv.conf            # DNS 服务器配置
/etc/fstab                  # 开机自动挂载
/etc/crontab                # 系统定时任务
/etc/ssh/sshd_config        # SSH 服务配置
/etc/nginx/nginx.conf       # Nginx 配置
/etc/my.cnf                 # MySQL 配置
/etc/sysconfig/             # 系统服务配置目录
/etc/systemd/               # systemd 配置
```

### /home - 用户家目录
```bash
/home/username/             # 普通用户的家目录
~                           # 当前用户家目录的简写
```

### /root - root 家目录
```bash
/root                       # root 用户的家目录（不在 /home 下）
```

### /lib 和 /lib64
```bash
/lib                        # 32位共享库
/lib64                      # 64位共享库
/lib/modules/               # 内核模块
```

### /proc - 进程信息（虚拟）
```bash
/proc/cpuinfo               # CPU 信息
/proc/meminfo               # 内存信息
/proc/loadavg               # 系统负载
/proc/[PID]/                # 进程信息目录
/proc/sys/                  # 内核参数

# 查看进程信息
cat /proc/1/cmdline         # PID 1 的启动命令
ls -l /proc/1/fd            # PID 1 打开的文件描述符
```

### /sys - 系统信息（虚拟）
```bash
/sys/class/                 # 设备类别
/sys/block/                 # 块设备
/sys/devices/               # 所有设备
```

### /tmp - 临时目录
```bash
/tmp                        # 临时文件，重启后可能清空
                            # 所有用户可写
                            # 定期清理
```

### /usr - 用户程序
```bash
/usr/bin                    # 用户命令
/usr/sbin                   # 系统管理命令
/usr/lib                    # 库文件
/usr/local/                 # 本地安装的软件（手动编译安装）
/usr/share/                 # 共享数据（文档、图标等）
/usr/src/                   # 源代码
```

### /var - 可变数据（重要！）
```bash
/var/log/                   # 系统日志
/var/log/messages           # 系统主日志
/var/log/secure             # 安全日志（登录、sudo）
/var/log/nginx/             # Nginx 日志

/var/cache/                 # 缓存文件
/var/spool/                 # 队列数据（邮件、打印）
/var/run/                   # 运行时数据（PID 文件）
/var/lib/                   # 程序数据
/var/lib/mysql/             # MySQL 数据
/var/www/                   # Web 站点目录
```

### /opt - 第三方软件
```bash
/opt                        # 第三方大型软件安装目录
/opt/google/chrome          # 例如 Chrome
```

### /mnt 和 /media
```bash
/mnt                        # 临时挂载点（手动挂载）
/media                      # 可移动设备自动挂载点
```

## 运维常用路径速查

| 用途 | 路径 |
|------|------|
| 系统日志 | /var/log/messages |
| 安全日志 | /var/log/secure |
| 用户信息 | /etc/passwd |
| 用户密码 | /etc/shadow |
| 网络配置 | /etc/sysconfig/network-scripts/ |
| DNS 配置 | /etc/resolv.conf |
| 主机名 | /etc/hostname |
| 开机挂载 | /etc/fstab |
| 定时任务 | /var/spool/cron/ |
| SSH 配置 | /etc/ssh/sshd_config |
| Nginx 配置 | /etc/nginx/ |
| MySQL 数据 | /var/lib/mysql/ |
| Web 目录 | /var/www/html/ |

## 练习题

1. 系统日志文件通常存放在哪个目录？
2. 用户的配置文件（如 .bashrc）存放在哪里？
3. /proc 目录有什么特点？

<details>
<summary>答案</summary>

1. `/var/log/` 目录
2. 用户家目录，如 `/home/username/` 或 `/root/`
3. /proc 是虚拟文件系统，不占用磁盘空间，存储内核和进程的运行时信息

</details>
