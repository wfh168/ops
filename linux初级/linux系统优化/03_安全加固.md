## 一、账号安全

### 禁用不必要的账号

```bash
# 查看所有用户
cat /etc/passwd

# 锁定账号
usermod -L username
passwd -l username

# 删除不必要的账号
userdel -r username

# 检查空密码账号
awk -F: '($2=="") {print $1}' /etc/shadow
```

### 密码策略

```bash
# 编辑密码策略
vim /etc/login.defs

# 密码最长使用天数
PASS_MAX_DAYS   90

# 密码最短使用天数
PASS_MIN_DAYS   7

# 密码最小长度
PASS_MIN_LEN    8

# 密码过期前警告天数
PASS_WARN_AGE   7
```

### 密码复杂度

```bash
# 安装 PAM 模块
yum install -y libpwquality

# 编辑配置
vim /etc/security/pwquality.conf

# 最小长度
minlen = 8

# 至少包含一个小写字母
lcredit = -1

# 至少包含一个大写字母
ucredit = -1

# 至少包含一个数字
dcredit = -1

# 至少包含一个特殊字符
ocredit = -1
```

### 登录失败锁定

```bash
# 编辑 PAM 配置
vim /etc/pam.d/system-auth

# 在 auth 段添加
auth required pam_faillock.so preauth silent audit deny=5 unlock_time=900

# 在 account 段添加
account required pam_faillock.so

# 解释：
# deny=5: 失败5次后锁定
# unlock_time=900: 锁定15分钟
```

### 查看登录失败记录

```bash
# 查看失败登录
lastb

# 查看成功登录
last

# 查看最后登录时间
lastlog
```

## 二、SSH 安全

### 修改 SSH 端口

```bash
# 编辑配置
vim /etc/ssh/sshd_config

# 修改端口
Port 2222

# 重启服务
systemctl restart sshd
```

### 禁用 root 登录

```bash
# 编辑配置
vim /etc/ssh/sshd_config

# 禁用 root 登录
PermitRootLogin no

# 重启服务
systemctl restart sshd
```

### 使用密钥认证

```bash
# 编辑配置
vim /etc/ssh/sshd_config

# 启用密钥认证
PubkeyAuthentication yes

# 禁用密码认证
PasswordAuthentication no

# 重启服务
systemctl restart sshd
```

### 限制 SSH 访问

```bash
# 只允许特定用户登录
vim /etc/ssh/sshd_config
# AllowUsers user1 user2

# 只允许特定组登录
# AllowGroups wheel

# 拒绝特定用户
# DenyUsers baduser

# 限制登录 IP
vim /etc/hosts.allow
# sshd: 192.168.1.0/24

vim /etc/hosts.deny
# sshd: ALL
```

### SSH 超时设置

```bash
# 编辑配置
vim /etc/ssh/sshd_config

# 客户端存活间隔（秒）
ClientAliveInterval 300

# 最大存活次数
ClientAliveCountMax 2

# 重启服务
systemctl restart sshd
```

## 三、防火墙配置

### firewalld 基本配置

```bash
# 启动防火墙
systemctl start firewalld
systemctl enable firewalld

# 查看状态
firewall-cmd --state

# 查看所有规则
firewall-cmd --list-all

# 开放端口
firewall-cmd --add-port=80/tcp --permanent
firewall-cmd --add-port=443/tcp --permanent
firewall-cmd --add-port=2222/tcp --permanent

# 开放服务
firewall-cmd --add-service=http --permanent
firewall-cmd --add-service=https --permanent

# 删除端口
firewall-cmd --remove-port=80/tcp --permanent

# 重新加载
firewall-cmd --reload

# 查看开放的端口
firewall-cmd --list-ports
```

### 限制 IP 访问

```bash
# 添加富规则
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="192.168.1.100" port protocol="tcp" port="22" accept'

# 拒绝特定 IP
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="1.2.3.4" reject'

# 重新加载
firewall-cmd --reload
```

### iptables 基本配置

```bash
# 查看规则
iptables -L -n

# 允许 SSH
iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# 允许 HTTP/HTTPS
iptables -A INPUT -p tcp --dport 80 -j ACCEPT
iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# 允许本地回环
iptables -A INPUT -i lo -j ACCEPT

# 允许已建立的连接
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 拒绝其他
iptables -P INPUT DROP

# 保存规则
service iptables save
```

## 四、文件系统安全

### 重要文件权限

```bash
# 设置关键文件权限
chmod 600 /etc/shadow
chmod 600 /etc/gshadow
chmod 644 /etc/passwd
chmod 644 /etc/group
chmod 600 /boot/grub2/grub.cfg
chmod 600 /root/.ssh/authorized_keys
```

### 查找 SUID/SGID 文件

```bash
# 查找 SUID 文件
find / -perm -4000 -type f 2>/dev/null

# 查找 SGID 文件
find / -perm -2000 -type f 2>/dev/null

# 查找可写文件
find / -perm -002 -type f 2>/dev/null

# 查找无主文件
find / -nouser -o -nogroup 2>/dev/null
```

### 文件完整性检查

```bash
# 安装 AIDE
yum install -y aide

# 初始化数据库
aide --init
mv /var/lib/aide/aide.db.new.gz /var/lib/aide/aide.db.gz

# 检查文件完整性
aide --check

# 更新数据库
aide --update
```

## 五、日志审计

### 配置日志

```bash
# 编辑 rsyslog 配置
vim /etc/rsyslog.conf

# 记录所有日志
*.* /var/log/all.log

# 重启服务
systemctl restart rsyslog
```

### 重要日志文件

| 日志文件 | 说明 |
|---------|------|
| /var/log/messages | 系统主日志 |
| /var/log/secure | 安全日志（登录、sudo） |
| /var/log/cron | 定时任务日志 |
| /var/log/maillog | 邮件日志 |
| /var/log/boot.log | 启动日志 |
| /var/log/dmesg | 内核日志 |

### 日志分析

```bash
# 查看登录失败
grep "Failed password" /var/log/secure

# 统计失败次数最多的 IP
grep "Failed password" /var/log/secure | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn

# 查看 sudo 使用记录
grep "sudo" /var/log/secure

# 查看用户登录记录
last

# 查看登录失败记录
lastb
```

### 日志轮转

```bash
# 编辑 logrotate 配置
vim /etc/logrotate.d/syslog

/var/log/messages {
    daily                   # 每天轮转
    rotate 7                # 保留7天
    compress                # 压缩
    delaycompress           # 延迟压缩
    missingok               # 文件不存在不报错
    notifempty              # 空文件不轮转
    postrotate              # 轮转后执行
        /bin/kill -HUP `cat /var/run/syslogd.pid 2> /dev/null` 2> /dev/null || true
    endscript
}

# 手动执行轮转
logrotate -f /etc/logrotate.conf
```

## 六、内核安全

### 内核参数优化

```bash
# 编辑配置
vim /etc/sysctl.conf

# 禁止 ping
net.ipv4.icmp_echo_ignore_all = 1

# 禁止 IP 转发
net.ipv4.ip_forward = 0

# 防止 SYN 洪水攻击
net.ipv4.tcp_syncookies = 1
net.ipv4.tcp_max_syn_backlog = 8192
net.ipv4.tcp_synack_retries = 2

# 防止 IP 欺骗
net.ipv4.conf.all.rp_filter = 1
net.ipv4.conf.default.rp_filter = 1

# 忽略 ICMP 重定向
net.ipv4.conf.all.accept_redirects = 0
net.ipv4.conf.default.accept_redirects = 0

# 忽略源路由包
net.ipv4.conf.all.accept_source_route = 0
net.ipv4.conf.default.accept_source_route = 0

# 生效
sysctl -p
```

## 八、安全检查脚本

### 综合安全检查

```bash
#!/bin/bash

echo "=== Linux 安全检查 ==="
echo "检查时间: $(date)"
echo

# 1. 检查空密码账号
echo "=== 检查空密码账号 ==="
awk -F: '($2=="") {print $1}' /etc/shadow
echo

# 2. 检查 UID 为 0 的账号
echo "=== 检查 UID 为 0 的账号 ==="
awk -F: '($3==0) {print $1}' /etc/passwd
echo

# 3. 检查 SUID 文件
echo "=== 检查 SUID 文件 ==="
find / -perm -4000 -type f 2>/dev/null | head -10
echo

# 4. 检查登录失败
echo "=== 最近登录失败记录 ==="
lastb | head -10
echo

# 5. 检查 sudo 使用
echo "=== 最近 sudo 使用记录 ==="
grep "sudo" /var/log/secure | tail -10
echo

# 6. 检查监听端口
echo "=== 监听端口 ==="
netstat -tunlp | grep LISTEN
echo

# 7. 检查定时任务
echo "=== 用户定时任务 ==="
for user in $(cut -d: -f1 /etc/passwd); do
    crontab -u $user -l 2>/dev/null | grep -v "^#" | grep -v "^$" && echo "User: $user"
done
echo

# 8. 检查系统更新
echo "=== 可用更新 ==="
yum check-update | grep -v "^$" | wc -l
echo

echo "=== 检查完成 ==="
```

## 练习题

1. 如何禁用 root 远程登录？
2. 如何查找系统中的 SUID 文件？
3. 如何配置登录失败锁定？

<details>
<summary>答案</summary>

1. 编辑 `/etc/ssh/sshd_config`，设置 `PermitRootLogin no`，重启 sshd
2. `find / -perm -4000 -type f 2>/dev/null`
3. 编辑 `/etc/pam.d/system-auth`，添加 `auth required pam_faillock.so preauth silent audit deny=5 unlock_time=900`

</details>
