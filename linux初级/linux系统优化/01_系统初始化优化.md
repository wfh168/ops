# 系统初始化优化

## 为什么要优化

新安装的 Linux 系统默认配置并不适合生产环境，需要进行优化以提高：
- 安全性
- 性能
- 稳定性

---

## 一、关闭 SELinux

### 什么是 SELinux

SELinux（Security-Enhanced Linux）是强制访问控制安全机制，但在生产环境中常常会导致各种权限问题。

### 临时关闭

```bash
# 查看状态
getenforce
# Enforcing（强制）、Permissive（宽容）、Disabled（关闭）

# 临时关闭（重启后失效）
setenforce 0

# 查看状态
getenforce
# Permissive
```

### 永久关闭

```bash
# 编辑配置文件
vim /etc/selinux/config

# 修改为
SELINUX=disabled

# 重启生效
reboot

# 验证
getenforce
# Disabled
```

## 二、关闭防火墙

### firewalld（CentOS 7+）

```bash
# 查看状态
systemctl status firewalld

# 停止防火墙
systemctl stop firewalld

# 禁用开机自启
systemctl disable firewalld

# 验证
systemctl is-enabled firewalld
# disabled
```

### iptables（CentOS 6）

```bash
# 停止 iptables
service iptables stop

# 禁用开机自启
chkconfig iptables off

# 清空规则
iptables -F
iptables -X
iptables -Z
```

> ⚠️ 注意：生产环境应该配置防火墙规则而非完全关闭

## 三、配置 YUM 源

### 备份原有源

```bash
# 备份
cd /etc/yum.repos.d/
mkdir backup
mv *.repo backup/
```

```bash
# 下载阿里云源
```

### 配置阿里云源（CentOS 8）

```bash
# 下载阿里云源
```

## 四、时间同步

### 安装 chrony

```bash
# 安装
yum install -y chrony

# 启动
systemctl start chronyd
systemctl enable chronyd

# 查看状态
systemctl status chronyd
```

### 配置时区

```bash
# 查看当前时区
timedatectl

# 设置时区为上海
timedatectl set-timezone Asia/Shanghai

# 验证
date
```

### 配置 NTP 服务器

```bash
# 编辑配置
vim /etc/chrony.conf

# 修改 NTP 服务器（使用阿里云）
server ntp.aliyun.com iburst
server ntp1.aliyun.com iburst
server ntp2.aliyun.com iburst

# 重启服务
systemctl restart chronyd

# 查看同步状态
chronyc sources -v
```

### 手动同步时间

```bash
# 立即同步
chronyc -a makestep

# 查看时间
date
```

## 七、网络配置

### 配置静态 IP（CentOS 7）

```bash
# 编辑网卡配置
vim /etc/sysconfig/network-scripts/ifcfg-eth0

# 修改为
TYPE=Ethernet
BOOTPROTO=static              # 改为 static
NAME=eth0
DEVICE=eth0
ONBOOT=yes                    # 改为 yes
IPADDR=192.168.1.100          # 添加 IP
NETMASK=255.255.255.0         # 添加子网掩码
GATEWAY=192.168.1.1           # 添加网关
DNS1=8.8.8.8                  # 添加 DNS
DNS2=114.114.114.114

# 重启网络
systemctl restart network

# 验证
ip addr
ping www.baidu.com
```

### 配置 DNS

```bash
# 编辑 DNS 配置
vim /etc/resolv.conf

# 添加
nameserver 8.8.8.8
nameserver 114.114.114.114

# 验证
nslookup www.baidu.com
```

## 八、SSH 优化

### 修改 SSH 端口

```bash
# 备份配置
cp /etc/ssh/sshd_config /etc/ssh/sshd_config.bak

# 编辑配置
vim /etc/ssh/sshd_config

# 修改端口
Port 2222                     # 默认 22

# 重启 SSH
systemctl restart sshd

# 验证（新开终端测试）
ssh -p 2222 root@192.168.1.100
```

### 禁用 root 远程登录

```bash
# 编辑配置
vim /etc/ssh/sshd_config

# 修改
PermitRootLogin no            # 改为 no

# 重启 SSH
systemctl restart sshd
```

### 禁用密码登录（使用密钥）

```bash
# 编辑配置
vim /etc/ssh/sshd_config

# 修改
PasswordAuthentication no     # 改为 no
PubkeyAuthentication yes      # 改为 yes

# 重启 SSH
systemctl restart sshd
```

### 配置 SSH 密钥

```bash
# 在客户端生成密钥
ssh-keygen -t rsa -b 4096

# 复制公钥到服务器
ssh-copy-id -p 2222 user@192.168.1.100

# 测试登录
ssh -p 2222 user@192.168.1.100
```

## 九、系统资源限制

### 修改文件描述符限制

```bash
# 查看当前限制
ulimit -n

# 临时修改
ulimit -n 65535

# 永久修改
vim /etc/security/limits.conf

# 添加
* soft nofile 65535
* hard nofile 65535
* soft nproc 65535
* hard nproc 65535

# 重新登录生效
# 验证
ulimit -n
```

### 修改内核参数

```bash
# 编辑配置
vim /etc/sysctl.conf

# 添加
# 网络优化
net.ipv4.tcp_tw_reuse = 1
net.ipv4.tcp_tw_recycle = 0
net.ipv4.tcp_fin_timeout = 30
net.ipv4.tcp_keepalive_time = 1200
net.ipv4.ip_local_port_range = 10000 65000
net.ipv4.tcp_max_syn_backlog = 8192
net.ipv4.tcp_max_tw_buckets = 5000

# 文件系统优化
fs.file-max = 655350

# 生效
sysctl -p

# 验证
sysctl -a | grep tcp_tw_reuse
```

## 十一、优化脚本

### 一键优化脚本

```bash
#!/bin/bash

echo "=== 开始系统优化 ==="

# 1. 关闭 SELinux
echo "1. 关闭 SELinux..."
setenforce 0
sed -i 's/SELINUX=enforcing/SELINUX=disabled/g' /etc/selinux/config

# 2. 关闭防火墙
echo "2. 关闭防火墙..."
systemctl stop firewalld
systemctl disable firewalld

# 3. 配置 YUM 源
echo "3. 配置 YUM 源..."
mkdir -p /etc/yum.repos.d/backup
mv /etc/yum.repos.d/*.repo /etc/yum.repos.d/backup/
curl -o /etc/yum.repos.d/CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo
yum install -y epel-release
yum clean all
yum makecache

# 4. 时间同步
echo "4. 配置时间同步..."
yum install -y chrony
systemctl start chronyd
systemctl enable chronyd
timedatectl set-timezone Asia/Shanghai

# 5. 安装常用工具
echo "5. 安装常用工具..."
yum install -y vim wget curl net-tools lsof telnet tree htop

# 6. 优化文件描述符
echo "6. 优化文件描述符..."
cat >> /etc/security/limits.conf << EOF
* soft nofile 65535
* hard nofile 65535
* soft nproc 65535
* hard nproc 65535
EOF

# 7. 优化内核参数
echo "7. 优化内核参数..."
cat >> /etc/sysctl.conf << EOF
net.ipv4.tcp_tw_reuse = 1
net.ipv4.tcp_fin_timeout = 30
net.ipv4.tcp_keepalive_time = 1200
net.ipv4.ip_local_port_range = 10000 65000
net.ipv4.tcp_max_syn_backlog = 8192
fs.file-max = 655350
EOF
sysctl -p

echo "=== 系统优化完成 ==="
echo "建议重启系统使所有配置生效"
```

## 练习题

1. 如何永久关闭 SELinux？
2. 如何配置系统时间同步？
3. 如何修改 SSH 默认端口？

<details>
<summary>答案</summary>

1. 编辑 `/etc/selinux/config`，设置 `SELINUX=disabled`，然后重启
2. 安装 chrony，配置 NTP 服务器，启动 chronyd 服务
3. 编辑 `/etc/ssh/sshd_config`，修改 `Port` 参数，重启 sshd 服务

</details>
