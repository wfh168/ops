# 性能监控与调优

## 性能监控四大指标

- CPU
- 内存
- 磁盘 I/O
- 网络

---

## 一、CPU 监控

### top - 实时监控

```bash
# 启动 top
top

# 常用快捷键
P    # 按 CPU 使用率排序
M    # 按内存使用率排序
1    # 显示每个 CPU 核心
k    # 杀死进程
q    # 退出
```

#### top 输出解读

```
top - 10:00:00 up 10 days,  1:23,  2 users,  load average: 0.52, 0.58, 0.59
Tasks: 150 total,   1 running, 149 sleeping,   0 stopped,   0 zombie
%Cpu(s):  5.2 us,  2.1 sy,  0.0 ni, 92.5 id,  0.2 wa,  0.0 hi,  0.0 si,  0.0 st
MiB Mem :   7680.0 total,   2048.0 free,   3072.0 used,   2560.0 buff/cache
MiB Swap:   2048.0 total,   2048.0 free,      0.0 used.   4096.0 avail Mem
```

| 字段 | 说明 |
|------|------|
| us | 用户空间 CPU 使用率 |
| sy | 内核空间 CPU 使用率 |
| ni | 改变过优先级的进程 CPU 使用率 |
| id | 空闲 CPU 百分比 |
| wa | I/O 等待 CPU 百分比 |
| hi | 硬中断 CPU 使用率 |
| si | 软中断 CPU 使用率 |

### htop - 更友好的 top

```bash
# 安装
yum install -y htop

# 启动
htop

# 优点
# - 彩色显示
# - 支持鼠标操作
# - 更直观的界面
```

### uptime - 系统负载

```bash
uptime
# 10:00:00 up 10 days,  1:23,  2 users,  load average: 0.52, 0.58, 0.59
#                                                       1分钟 5分钟 15分钟

# 负载理解
# 负载 < CPU核心数：正常
# 负载 = CPU核心数：满载
# 负载 > CPU核心数：过载
```

### mpstat - 多核 CPU 监控

```bash
# 安装
yum install -y sysstat

# 查看所有 CPU
mpstat -P ALL 1

# 每秒刷新一次
mpstat 1
```

### 查找 CPU 占用高的进程

```bash
# 方法1：使用 top
top
# 按 P 键按 CPU 排序

# 方法2：使用 ps
ps aux --sort=-%cpu | head -10

# 方法3：查看具体进程
ps aux | grep process_name
```

## 二、内存监控

### free - 内存使用

```bash
# 查看内存
free -h

# 输出示例
              total        used        free      shared  buff/cache   available
Mem:          7.5Gi       3.0Gi       2.0Gi       256Mi       2.5Gi       4.0Gi
Swap:         2.0Gi          0B       2.0Gi
```

#### 字段说明

| 字段 | 说明 |
|------|------|
| total | 总内存 |
| used | 已使用（不含缓存） |
| free | 完全空闲 |
| shared | 共享内存 |
| buff/cache | 缓存（可回收） |
| available | 实际可用 = free + 可回收缓存 |

### vmstat - 虚拟内存统计

```bash
# 每秒刷新一次
vmstat 1

# 输出示例
procs -----------memory---------- ---swap-- -----io---- -system-- ------cpu-----
 r  b   swpd   free   buff  cache   si   so    bi    bo   in   cs us sy id wa st
 1  0      0 2048000 102400 2560000  0    0     5    10  100  200  5  2 92  1  0
```

| 字段 | 说明 |
|------|------|
| r | 运行队列长度 |
| b | 阻塞进程数 |
| swpd | 使用的 swap |
| free | 空闲内存 |
| si | 从 swap 读入内存 |
| so | 从内存写入 swap |

### 查找内存占用高的进程

```bash
# 方法1：使用 top
top
# 按 M 键按内存排序

# 方法2：使用 ps
ps aux --sort=-%mem | head -10

# 方法3：查看进程内存详情
cat /proc/PID/status | grep -i mem
```

### 清理缓存

```bash
# 查看缓存
free -h

# 清理 PageCache
sync; echo 1 > /proc/sys/vm/drop_caches

# 清理 dentries 和 inodes
sync; echo 2 > /proc/sys/vm/drop_caches

# 清理所有缓存
sync; echo 3 > /proc/sys/vm/drop_caches

# 验证
free -h
```

## 三、磁盘 I/O 监控

### iostat - I/O 统计

```bash
# 安装
yum install -y sysstat

# 查看 I/O 统计
iostat -x 1

# 输出示例
Device            r/s     w/s     rkB/s     wkB/s   %util
sda              5.00   10.00    100.00    200.00   15.00
```

| 字段 | 说明 |
|------|------|
| r/s | 每秒读请求数 |
| w/s | 每秒写请求数 |
| rkB/s | 每秒读取 KB |
| wkB/s | 每秒写入 KB |
| %util | I/O 使用率 |

### iotop - I/O 进程监控

```bash
# 安装
yum install -y iotop

# 启动
iotop

# 按 I/O 使用率排序
iotop -o
```

### df - 磁盘使用

```bash
# 查看磁盘使用
df -h

# 查看 inode 使用
df -i

# 查看文件系统类型
df -Th
```

### du - 目录大小

```bash
# 查看目录大小
du -sh /var

# 查看一级子目录
du -h --max-depth=1 /var

# 排序显示
du -sh /* | sort -h
```

### 查找大文件

```bash
# 查找大于 100M 的文件
find / -type f -size +100M -exec ls -lh {} \; 2>/dev/null

# 查找并排序
find / -type f -size +100M -exec du -h {} \; 2>/dev/null | sort -h

# 查找占用空间最大的目录
du -h --max-depth=1 / | sort -h | tail -10
```

## 四、网络监控

### netstat - 网络连接

```bash
# 查看所有连接
netstat -an

# 查看监听端口
netstat -tunlp

# 统计连接状态
netstat -an | awk '/^tcp/ {state[$NF]++} END{for(s in state) print s, state[s]}'

# 查看连接数最多的 IP
netstat -an | grep ESTABLISHED | awk '{print $5}' | cut -d: -f1 | sort | uniq -c | sort -rn | head -10
```

### ss - 更快的 netstat

```bash
# 查看所有连接
ss -an

# 查看监听端口
ss -tunlp

# 统计连接状态
ss -s

# 查看 TCP 连接
ss -t
```

### iftop - 实时流量监控

```bash
# 安装
yum install -y iftop

# 启动
iftop

# 指定网卡
iftop -i eth0
```

### nload - 网络流量监控

```bash
# 安装
yum install -y nload

# 启动
nload

# 指定网卡
nload eth0
```

### 查看网络流量

```bash
# 实时查看
watch -n 1 "ifconfig eth0 | grep 'RX packets\|TX packets'"

# 或使用 sar
sar -n DEV 1
```

## 五、系统调优

### CPU 调优

```bash
# 1. 调整进程优先级
nice -n 10 command              # 启动时设置
renice -n 10 -p PID             # 运行时调整

# 2. 绑定 CPU 核心
taskset -c 0,1 command          # 绑定到 CPU 0 和 1

# 3. 关闭不必要的服务
systemctl list-unit-files | grep enabled
systemctl disable service_name
```

### 内存调优

```bash
# 1. 调整 swap 使用倾向
vim /etc/sysctl.conf
# vm.swappiness = 10              # 0-100，越小越少用 swap

# 2. 调整缓存回收
# vm.vfs_cache_pressure = 50      # 默认 100

# 生效
sysctl -p
```

### 磁盘 I/O 调优

```bash
# 1. 修改 I/O 调度器
# 查看当前调度器
cat /sys/block/sda/queue/scheduler

# 修改为 deadline（适合数据库）
echo deadline > /sys/block/sda/queue/scheduler

# 修改为 noop（适合 SSD）
echo noop > /sys/block/sda/queue/scheduler

# 2. 调整预读大小
blockdev --setra 8192 /dev/sda

# 3. 使用 noatime 挂载（减少写入）
vim /etc/fstab
# /dev/sda1  /  ext4  defaults,noatime  0  0
```

### 网络调优

```bash
# 编辑内核参数
vim /etc/sysctl.conf

# 网络优化
net.core.somaxconn = 65535
net.core.netdev_max_backlog = 65535
net.ipv4.tcp_max_syn_backlog = 8192
net.ipv4.tcp_tw_reuse = 1
net.ipv4.tcp_fin_timeout = 30
net.ipv4.tcp_keepalive_time = 1200
net.ipv4.ip_local_port_range = 10000 65000

# 生效
sysctl -p
```

## 六、性能分析工具

### dstat - 综合监控

```bash
# 安装
yum install -y dstat

# 启动
dstat

# 详细模式
dstat -cdngy
# c: CPU
# d: 磁盘
# n: 网络
# g: 页面
# y: 系统
```

### sar - 系统活动报告

```bash
# 安装
yum install -y sysstat

# CPU 使用率
sar -u 1 10                     # 每秒采样，共10次

# 内存使用
sar -r 1 10

# I/O 统计
sar -b 1 10

# 网络统计
sar -n DEV 1 10

# 查看历史数据
sar -u -f /var/log/sa/sa07      # 查看7号的数据
```

### perf - 性能分析

```bash
# 安装
yum install -y perf

# CPU 性能分析
perf top

# 记录性能数据
perf record -g command

# 查看报告
perf report
```

## 七、性能监控脚本

### 综合监控脚本

```bash
#!/bin/bash

echo "=== 系统性能监控 ==="
echo "时间: $(date)"
echo

# CPU
echo "=== CPU 使用率 ==="
top -bn1 | grep "Cpu(s)" | awk '{print "User: "$2", System: "$4", Idle: "$8}'
echo

# 内存
echo "=== 内存使用 ==="
free -h | awk 'NR==2{printf "Total: %s, Used: %s (%.2f%%), Free: %s\n", $2, $3, $3/$2*100, $4}'
echo

# 磁盘
echo "=== 磁盘使用 ==="
df -h | awk 'NR>1 && $5+0>80 {print $0}'
echo

# 负载
echo "=== 系统负载 ==="
uptime | awk -F'load average:' '{print $2}'
echo

# 网络连接
echo "=== 网络连接数 ==="
netstat -an | awk '/^tcp/ {state[$NF]++} END{for(s in state) print s": "state[s]}'
```

## 练习题

1. 如何查看系统负载？
2. 如何查找占用 CPU 最高的进程？
3. 如何清理系统缓存？

<details>
<summary>答案</summary>

1. `uptime` 或 `top` 命令
2. `ps aux --sort=-%cpu | head -10` 或 `top` 按 P 键
3. `sync; echo 3 > /proc/sys/vm/drop_caches`

</details>
