# 用户和组概念

## Linux 多用户系统

Linux 是多用户操作系统，支持多个用户同时登录和使用。

```
┌─────────────────────────────────────────────────────────┐
│                    Linux 用户体系                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   用户 (User)                    组 (Group)             │
│   ┌──────────┐                  ┌──────────┐           │
│   │  root    │                  │  root    │           │
│   │  UID: 0  │──────────────────│  GID: 0  │           │
│   └──────────┘                  └──────────┘           │
│                                                         │
│   ┌──────────┐                  ┌──────────┐           │
│   │  user1   │                  │  user1   │           │
│   │  UID:1000│──────────────────│  GID:1000│           │
│   └──────────┘                  └──────────┘           │
│        │                              │                │
│        └──────────────────────────────┘                │
│                   主组 (Primary Group)                  │
│                                                         │
│        ┌──────────────────────────────┐                │
│        │      附加组 (Secondary)       │                │
│        │  wheel, docker, developers   │                │
│        └──────────────────────────────┘                │
└─────────────────────────────────────────────────────────┘
```

## 用户类型

### 1. root 用户（超级管理员）
- UID = 0
- 拥有系统最高权限
- 可以执行任何操作
- 家目录：`/root`

```bash
# 切换到 root
su -                              # 需要 root 密码
sudo -i                           # 需要当前用户密码（需在 sudoers 中）
```

### 2. 系统用户（服务账号）
- UID: 1-999（CentOS 7+）或 1-499（CentOS 6）
- 用于运行系统服务
- 通常不能登录
- 无家目录或家目录为 `/sbin/nologin`

```bash
# 常见系统用户
bin, daemon, adm, lp, mail, nobody
nginx, mysql, redis, apache
```

### 3. 普通用户
- UID: 1000+（CentOS 7+）或 500+（CentOS 6）
- 日常使用的账号
- 权限受限
- 家目录：`/home/username`

## 用户标识

### UID（User ID）
- 系统通过 UID 识别用户，而非用户名
- UID 0 = root
- UID 1-999 = 系统用户
- UID 1000+ = 普通用户

```bash
# 查看当前用户 UID
id
id -u                             # 只显示 UID
id username                       # 查看指定用户

# 输出示例
uid=1000(user1) gid=1000(user1) groups=1000(user1),10(wheel)
```

## 用户组

### 组的作用
- 方便批量管理权限
- 一个用户可以属于多个组
- 每个用户必须有一个主组

### GID（Group ID）
- 系统通过 GID 识别组
- GID 0 = root 组
- GID 1-999 = 系统组
- GID 1000+ = 普通组

### 主组 vs 附加组

```bash
# 主组（Primary Group）
- 用户创建时自动分配
- 通常与用户名同名
- 用户创建的文件默认属于主组

# 附加组（Secondary Groups）
- 用户可以加入的其他组
- 用于获得额外权限
- 一个用户可以属于多个附加组
```

```bash
# 查看用户所属组
groups                            # 当前用户
groups username                   # 指定用户

# 查看详细信息
id username
# uid=1000(user1) gid=1000(user1) groups=1000(user1),10(wheel),992(docker)
#                 │                        │           └── 附加组
#                 └── 主组                 └── 主组
```

## 用户配置文件

### /etc/passwd - 用户信息

```bash
cat /etc/passwd
```

格式：`用户名:密码占位符:UID:GID:描述:家目录:登录Shell`

```
root:x:0:0:root:/root:/bin/bash
│    │ │ │ │    │     └── 登录 Shell
│    │ │ │ │    └── 家目录
│    │ │ │ └── 描述信息
│    │ │ └── 主组 GID
│    │ └── UID
│    └── 密码占位符（实际密码在 /etc/shadow）
└── 用户名
```

示例：
```
user1:x:1000:1000:User One:/home/user1:/bin/bash
nginx:x:998:996:Nginx web server:/var/lib/nginx:/sbin/nologin
```

### /etc/shadow - 密码信息

```bash
sudo cat /etc/shadow
```

格式：`用户名:加密密码:最后修改:最小间隔:最大间隔:警告期:不活动期:过期时间:保留`

```
root:$6$xyz...:18000:0:99999:7:::
│    │         │     │ │     │
│    │         │     │ │     └── 密码过期前警告天数
│    │         │     │ └── 密码最大有效期
│    │         │     └── 密码最小修改间隔
│    │         └── 最后一次修改密码的日期（从1970-01-01算起）
│    └── 加密后的密码
└── 用户名
```

特殊标记：
- `!!` 或 `*` - 账号被锁定
- `!` 开头 - 密码被锁定

### /etc/group - 组信息

```bash
cat /etc/group
```

格式：`组名:密码占位符:GID:组成员列表`

```
wheel:x:10:user1,user2
│     │ │  └── 组成员（逗号分隔）
│     │ └── GID
│     └── 密码占位符
└── 组名
```

### /etc/gshadow - 组密码

```bash
sudo cat /etc/gshadow
```

格式：`组名:加密密码:组管理员:组成员`

## 登录 Shell

### 常见 Shell

| Shell | 路径 | 说明 |
|-------|------|------|
| bash | /bin/bash | 最常用的 Shell |
| sh | /bin/sh | 传统 Shell |
| zsh | /bin/zsh | 功能强大的 Shell |
| nologin | /sbin/nologin | 禁止登录 |
| false | /bin/false | 禁止登录 |

```bash
# 查看当前 Shell
echo $SHELL

# 查看系统支持的 Shell
cat /etc/shells

# 修改 Shell
chsh -s /bin/zsh                  # 修改当前用户
chsh -s /bin/bash username        # 修改指定用户
```

## 用户环境变量

### 查看当前用户信息

```bash
whoami                            # 当前用户名
id                                # 当前用户详细信息
who                               # 当前登录用户
w                                 # 当前登录用户及活动
last                              # 登录历史
lastlog                           # 所有用户最后登录时间
```

### 环境变量

```bash
echo $USER                        # 当前用户名
echo $UID                         # 当前用户 UID
echo $HOME                        # 家目录
echo $SHELL                       # 当前 Shell
echo $PATH                        # 命令搜索路径
```

## 练习题

1. root 用户的 UID 是多少？
2. 如何查看一个用户属于哪些组？
3. /etc/passwd 和 /etc/shadow 有什么区别？

<details>
<summary>答案</summary>

1. UID = 0
2. `groups username` 或 `id username`
3. /etc/passwd 存储用户基本信息（所有用户可读），/etc/shadow 存储加密密码（只有 root 可读）

</details>
