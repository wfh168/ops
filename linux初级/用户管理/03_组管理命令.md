# 组管理命令

## 一、创建组

### groupadd - 创建组

```bash
# 基本用法
groupadd groupname                # 创建组（自动分配 GID）

# 指定 GID
groupadd -g 2000 groupname

# 创建系统组
groupadd -r groupname             # GID < 1000
```

### 示例

```bash
# 创建开发组
groupadd developers

# 创建指定 GID 的组
groupadd -g 3000 project_team

# 创建系统组
groupadd -r nginx
```

---

## 二、修改组

### groupmod - 修改组属性

```bash
# 修改组名
groupmod -n newname oldname

# 修改 GID
groupmod -g 2500 groupname
```

### 示例

```bash
# 重命名组
groupmod -n devteam developers

# 修改组 GID
groupmod -g 3500 devteam
```

## 三、删除组

### groupdel - 删除组

```bash
# 删除组
groupdel groupname
```

### 注意事项

```bash
# 不能删除用户的主组
groupdel user1                    # 如果 user1 是某用户的主组，会报错

# 删除前先检查
getent group groupname            # 查看组成员
grep groupname /etc/group         # 查看组信息
```

## 四、组成员管理

### gpasswd - 组管理工具（推荐）

```bash
# 添加用户到组
gpasswd -a username groupname     # add

# 从组中删除用户
gpasswd -d username groupname     # delete

# 设置组管理员
gpasswd -A admin_user groupname   # Administrator

# 设置组成员（覆盖）
gpasswd -M user1,user2,user3 groupname  # Members

# 删除组密码
gpasswd -r groupname              # remove password

# 设置组密码
gpasswd groupname                 # 交互式设置
```

### usermod 方式

```bash
# 修改用户的附加组
usermod -G group1,group2 username # 覆盖原有附加组
usermod -aG group1 username       # 追加到附加组（推荐）

# 修改用户的主组
usermod -g newgroup username
```

## 五、查询组

### 查看组信息

```bash
# 查看所有组
cat /etc/group
getent group                      # 更好的方式

# 查看指定组
getent group groupname
grep "^groupname:" /etc/group

# 查看组成员
getent group groupname | cut -d: -f4
lid -g groupname                  # 需要安装 libuser

# 查看用户所属组
groups username
id username
```

### 查看组 GID

```bash
# 查看组 GID
getent group groupname | cut -d: -f3
id -g groupname
```

## 六、组的类型

### 主组（Primary Group）

```bash
# 查看用户主组
id -gn username

# 修改用户主组
usermod -g newgroup username

# 用户创建文件时，默认属于主组
touch file.txt
ls -l file.txt
# -rw-r--r-- 1 user1 user1 0 Jan 7 10:00 file.txt
#                    │
#                    └── 主组
```

### 附加组（Secondary Groups）

```bash
# 查看用户所有组
groups username
id -Gn username

# 添加附加组
usermod -aG group1,group2 username
gpasswd -a username groupname

# 移除附加组
gpasswd -d username groupname
```

## 七、临时切换组

### newgrp - 切换当前组

```bash
# 切换到指定组（需要是该组成员）
newgrp groupname

# 查看当前组
id -gn

# 退出组切换
exit
```

### 使用场景

```bash
# 场景：创建文件时使用特定组
$ id -gn
user1

$ newgrp developers
$ id -gn
developers

$ touch project_file.txt
$ ls -l project_file.txt
-rw-r--r-- 1 user1 developers 0 Jan 7 10:00 project_file.txt
                   │
                   └── 文件属于 developers 组

$ exit                            # 退出 newgrp
```

## 八、特殊组

### wheel 组

```bash
# wheel 组成员可以使用 sudo
usermod -aG wheel username

# 配置文件
cat /etc/sudoers
# %wheel  ALL=(ALL)       ALL
```

### docker 组

```bash
# docker 组成员可以使用 docker 命令
usermod -aG docker username

# 需要重新登录生效
```

### sudo 组（Ubuntu/Debian）

```bash
# Ubuntu 使用 sudo 组而非 wheel
usermod -aG sudo username
```

## 九、实战案例

### 创建项目组并添加成员

```bash
# 1. 创建项目组
groupadd project_alpha

# 2. 添加成员
gpasswd -a user1 project_alpha
gpasswd -a user2 project_alpha
gpasswd -a user3 project_alpha

# 3. 验证
getent group project_alpha
# project_alpha:x:3000:user1,user2,user3
```

### 创建共享目录

```bash
# 1. 创建组
groupadd developers

# 2. 创建共享目录
mkdir /data/shared

# 3. 设置目录属组
chgrp developers /data/shared

# 4. 设置权限
chmod 2775 /data/shared           # 2 = SGID，新文件继承组
#     │
#     └── SGID 位，后面会详细讲

# 5. 添加用户到组
gpasswd -a user1 developers
gpasswd -a user2 developers

# 6. 验证
ls -ld /data/shared
# drwxrwsr-x 2 root developers 4096 Jan 7 10:00 /data/shared
#       ^
#       └── s 表示 SGID
```

### 批量添加用户到组

```bash
# 方法1：使用 gpasswd -M
gpasswd -M user1,user2,user3,user4 developers

# 方法2：循环添加
for user in user1 user2 user3 user4; do
    gpasswd -a "$user" developers
done

# 方法3：使用 usermod
for user in user1 user2 user3 user4; do
    usermod -aG developers "$user"
done
```

## 十、组管理最佳实践

### 1. 使用组管理权限

```bash
# 不推荐：直接给用户权限
chown user1 /data/project

# 推荐：通过组管理
groupadd project_team
chgrp project_team /data/project
chmod 2775 /data/project
gpasswd -a user1 project_team
gpasswd -a user2 project_team
```

### 2. 定期审计组成员

```bash
# 检查关键组成员
getent group wheel
getent group docker
getent group sudo

# 检查用户所属组
for user in $(cut -d: -f1 /etc/passwd); do
    echo "$user: $(groups $user)"
done
```

### 3. 命名规范

```bash
# 好的命名
developers
project_alpha
web_admins

# 不好的命名
group1
temp
test
```

## 练习题

1. 如何将用户添加到组而不影响其他组？
2. 如何查看一个组有哪些成员？
3. wheel 组有什么特殊作用？

<details>
<summary>答案</summary>

1. `usermod -aG groupname username` 或 `gpasswd -a username groupname`
2. `getent group groupname | cut -d: -f4` 或 `lid -g groupname`
3. wheel 组成员可以使用 sudo 命令获得 root 权限

</details>
