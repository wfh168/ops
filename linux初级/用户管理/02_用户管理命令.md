# 用户管理命令

## 一、创建用户

### useradd - 创建用户

```bash
# 基本用法
useradd username                  # 创建用户（使用默认设置）

# 常用选项
useradd -m username               # 创建用户并创建家目录
useradd -m -s /bin/bash username  # 指定 Shell
useradd -m -d /data/user1 user1   # 指定家目录
useradd -u 1500 username          # 指定 UID
useradd -g groupname username     # 指定主组
useradd -G group1,group2 username # 指定附加组
useradd -c "描述信息" username     # 添加描述
useradd -e 2024-12-31 username    # 设置过期时间
```

### 完整示例

```bash
# 创建一个完整的用户
useradd -m -s /bin/bash -c "Developer User" -G wheel,docker dev1

# 解释：
# -m: 创建家目录 /home/dev1
# -s /bin/bash: 设置 Shell
# -c "Developer User": 添加描述
# -G wheel,docker: 加入 wheel 和 docker 组
```

### 默认配置

```bash
# 查看默认配置
useradd -D

# 默认配置文件
cat /etc/default/useradd
cat /etc/login.defs               # 更详细的配置
```

## 二、设置密码

### passwd - 修改密码

```bash
# 修改当前用户密码
passwd

# 修改指定用户密码（需要 root）
passwd username

# 锁定用户
passwd -l username                # lock

# 解锁用户
passwd -u username                # unlock

# 删除密码（不安全！）
passwd -d username                # delete

# 强制用户下次登录修改密码
passwd -e username                # expire

# 查看密码状态
passwd -S username                # status
```

### 非交互式设置密码

```bash
# 方法1：使用 echo
echo "newpassword" | passwd --stdin username

# 方法2：使用 chpasswd
echo "username:newpassword" | chpasswd

# 批量修改密码
cat > users.txt << EOF
user1:pass1
user2:pass2
user3:pass3
EOF
chpasswd < users.txt
```

## 三、修改用户

### usermod - 修改用户属性

```bash
# 修改用户名
usermod -l newname oldname        # login name

# 修改家目录
usermod -d /new/home -m username  # -m 移动原家目录内容

# 修改 UID
usermod -u 1500 username

# 修改主组
usermod -g newgroup username

# 修改附加组
usermod -G group1,group2 username # 覆盖原有附加组
usermod -aG group1,group2 username # 追加附加组（推荐）

# 修改 Shell
usermod -s /bin/zsh username

# 修改描述
usermod -c "New Description" username

# 锁定/解锁用户
usermod -L username               # Lock
usermod -U username               # Unlock

# 设置过期时间
usermod -e 2024-12-31 username
```

### 常用场景

```bash
# 将用户加入 wheel 组（获得 sudo 权限）
usermod -aG wheel username

# 将用户加入 docker 组
usermod -aG docker username

# 修改用户 Shell
usermod -s /bin/bash username
```

## 四、删除用户

### userdel - 删除用户

```bash
# 删除用户（保留家目录）
userdel username

# 删除用户及家目录
userdel -r username               # 推荐

# 强制删除（即使用户已登录）
userdel -f username
```

### 删除用户的完整步骤

```bash
# 1. 查看用户信息
id username

# 2. 查看用户进程
ps -u username

# 3. 杀死用户进程
pkill -u username

# 4. 删除用户
userdel -r username

# 5. 确认删除
id username                       # 应该报错
ls /home/                         # 家目录应该不存在
```

## 五、查询用户

### id - 查看用户信息

```bash
id                                # 当前用户
id username                       # 指定用户
id -u username                    # 只显示 UID
id -g username                    # 只显示主组 GID
id -G username                    # 显示所有组 GID
id -un username                   # 显示用户名
id -gn username                   # 显示主组名
```

### 其他查询命令

```bash
# 查看当前用户
whoami
who
w

# 查看用户列表
cat /etc/passwd | cut -d: -f1
getent passwd                     # 更好的方式

# 查看登录历史
last                              # 登录历史
last username                     # 指定用户
lastlog                           # 所有用户最后登录时间
lastlog -u username               # 指定用户

# 查看当前登录用户
who
w                                 # 更详细
users                             # 简洁显示
```

## 六、切换用户

### su - 切换用户

```bash
# 切换到 root（需要 root 密码）
su                                # 不切换环境变量
su -                              # 完全切换（推荐）
su - root                         # 同上

# 切换到其他用户
su - username                     # 需要目标用户密码

# 以其他用户身份执行命令
su - username -c "command"
```

### sudo - 以 root 权限执行

```bash
# 以 root 权限执行命令（需要当前用户密码）
sudo command

# 切换到 root
sudo -i                           # 完全切换
sudo -s                           # 保留环境变量

# 以其他用户身份执行
sudo -u username command

# 编辑需要 root 权限的文件
sudo vim /etc/hosts
```

### su vs sudo

| 特性 | su | sudo |
|------|----|----|
| 需要密码 | 目标用户密码 | 当前用户密码 |
| 权限范围 | 完全切换用户 | 执行单个命令 |
| 安全性 | 需要知道 root 密码 | 不需要 root 密码 |
| 审计 | 难以追踪 | 有日志记录 |
| 推荐 | ❌ | ✅ |

## 七、批量管理

### 批量创建用户

```bash
# 创建用户列表
cat > users.txt << EOF
user1
user2
user3
EOF

# 批量创建
while read user; do
    useradd -m -s /bin/bash "$user"
    echo "$user:defaultpass" | chpasswd
    echo "Created user: $user"
done < users.txt
```

### 批量删除用户

```bash
# 删除 UID 1000-1010 的用户
for uid in {1000..1010}; do
    username=$(getent passwd $uid | cut -d: -f1)
    if [ -n "$username" ]; then
        userdel -r "$username"
        echo "Deleted: $username"
    fi
done
```

## 八、实战案例

### 创建开发用户

```bash
# 创建开发用户，加入必要的组
useradd -m -s /bin/bash -c "Developer" -G wheel,docker developer
passwd developer
```

### 创建服务账号

```bash
# 创建 nginx 服务账号（不能登录）
useradd -r -s /sbin/nologin -c "Nginx Web Server" nginx
```

### 临时禁用用户

```bash
# 方法1：锁定密码
passwd -l username

# 方法2：修改 Shell
usermod -s /sbin/nologin username

# 恢复
passwd -u username
usermod -s /bin/bash username
```

## 练习题

1. 如何创建一个用户并同时设置密码？
2. 如何将用户加入 wheel 组而不影响其他组？
3. su 和 sudo 的主要区别是什么？

<details>
<summary>答案</summary>

1. `useradd -m username && echo "password" | passwd --stdin username`
2. `usermod -aG wheel username`（-a 表示追加，不会覆盖原有组）
3. su 需要目标用户密码，完全切换用户；sudo 需要当前用户密码，只执行单个命令，更安全

</details>
