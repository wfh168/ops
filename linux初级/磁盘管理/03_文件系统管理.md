# 文件系统管理

## 一、创建文件系统

### mkfs 命令

```bash
# 基本语法
mkfs.文件系统类型 设备名

# 创建 ext4 文件系统
mkfs.ext4 /dev/sdb1

# 创建 xfs 文件系统
mkfs.xfs /dev/sdb1

# 创建 vfat 文件系统
mkfs.vfat /dev/sdb1
```

### 格式化选项

```bash
# ext4 格式化选项
mkfs.ext4 -L mylabel /dev/sdb1           # 设置卷标
mkfs.ext4 -b 4096 /dev/sdb1              # 设置块大小
mkfs.ext4 -m 1 /dev/sdb1                 # 预留空间百分比

# xfs 格式化选项
mkfs.xfs -f /dev/sdb1                    # 强制格式化
mkfs.xfs -L mylabel /dev/sdb1            # 设置卷标
mkfs.xfs -i size=512 /dev/sdb1           # 设置 inode 大小
```

## 二、挂载文件系统

### mount 命令

```bash
# 基本挂载
mount /dev/sdb1 /mnt

# 指定文件系统类型
mount -t ext4 /dev/sdb1 /mnt

# 只读挂载
mount -o ro /dev/sdb1 /mnt

# 读写挂载
mount -o rw /dev/sdb1 /mnt

# 查看所有挂载
mount
df -h
```

### 挂载选项

```bash
# 常用挂载选项
mount -o defaults /dev/sdb1 /mnt         # 默认选项
mount -o noatime /dev/sdb1 /mnt          # 不更新访问时间
mount -o nodiratime /dev/sdb1 /mnt       # 不更新目录访问时间
mount -o noexec /dev/sdb1 /mnt           # 不允许执行程序
mount -o nosuid /dev/sdb1 /mnt           # 忽略 SUID 位
mount -o ro /dev/sdb1 /mnt               # 只读
mount -o rw /dev/sdb1 /mnt               # 读写

# 组合选项
mount -o defaults,noatime,nodiratime /dev/sdb1 /mnt
```

### 卸载文件系统

```bash
# 卸载
umount /mnt
umount /dev/sdb1

# 强制卸载
umount -f /mnt

# 懒卸载（等待进程释放）
umount -l /mnt

# 查看占用进程
lsof /mnt
fuser -m /mnt

# 杀死占用进程
fuser -k /mnt
```

## 三、开机自动挂载

### /etc/fstab 配置

```bash
# 编辑 fstab
vim /etc/fstab

# 格式
设备    挂载点    文件系统    选项    dump    fsck
```

### 配置示例

```bash
# 使用设备名
/dev/sdb1    /data    ext4    defaults    0    0

# 使用 UUID（推荐）
UUID=xxx-xxx-xxx    /data    ext4    defaults    0    0

# 使用卷标
LABEL=mydata    /data    ext4    defaults    0    0

# 常用配置
/dev/sdb1    /data    ext4    defaults,noatime    0    2
/dev/sdb2    /backup  xfs     defaults,noatime    0    2
/dev/sdb3    none     swap    defaults            0    0
```

### 字段说明

| 字段 | 说明 |
|------|------|
| 设备 | 设备名、UUID 或 LABEL |
| 挂载点 | 挂载目录 |
| 文件系统 | ext4、xfs、swap 等 |
| 选项 | defaults、noatime 等 |
| dump | 是否备份（0=否，1=是） |
| fsck | 开机检查顺序（0=不检查，1=首先，2=其次） |

### 查看 UUID

```bash
# 方法1：blkid
blkid /dev/sdb1

# 方法2：lsblk
lsblk -f

# 方法3：查看目录
ls -l /dev/disk/by-uuid/
```

### 测试 fstab

```bash
# 测试挂载（不实际挂载）
mount -a -f

# 实际挂载所有
mount -a

# 重新挂载
mount -o remount /data
```

## 四、文件系统检查与修复

### fsck 检查

```bash
# 检查文件系统（必须先卸载）
umount /dev/sdb1
fsck /dev/sdb1

# 自动修复
fsck -y /dev/sdb1

# 强制检查
fsck -f /dev/sdb1

# 检查 ext4
e2fsck /dev/sdb1

# 检查 xfs
xfs_repair /dev/sdb1
```

### 文件系统状态

```bash
# 查看 ext4 状态
tune2fs -l /dev/sdb1

# 查看 xfs 状态
xfs_info /dev/sdb1
```

## 五、文件系统调优

### ext4 调优

```bash
# 设置预留空间（默认5%）
tune2fs -m 1 /dev/sdb1

# 设置卷标
tune2fs -L mydata /dev/sdb1

# 设置最大挂载次数
tune2fs -c 30 /dev/sdb1

# 设置检查间隔
tune2fs -i 180d /dev/sdb1

# 启用日志
tune2fs -O has_journal /dev/sdb1
```

### xfs 调优

```bash
# xfs 不支持缩小，只能扩展
# 调优主要在创建时完成

# 创建时指定参数
mkfs.xfs -i size=512 -d agcount=16 /dev/sdb1
```

## 六、文件系统扩展

### ext4 扩展

```bash
# 1. 扩展分区（使用 fdisk 或 parted）
# 2. 刷新分区表
partprobe /dev/sdb

# 3. 扩展文件系统
resize2fs /dev/sdb1

# 在线扩展（已挂载）
resize2fs /dev/sdb1
```

### xfs 扩展

```bash
# xfs 只能扩展，不能缩小
# 必须在挂载状态下扩展

# 扩展文件系统
xfs_growfs /data
```

### 缩小 ext4

```bash
# 1. 卸载文件系统
umount /dev/sdb1

# 2. 检查文件系统
e2fsck -f /dev/sdb1

# 3. 缩小文件系统
resize2fs /dev/sdb1 10G

# 4. 缩小分区（使用 fdisk 或 parted）
```

## 七、交换分区

### 创建 swap

```bash
# 1. 创建分区
fdisk /dev/sdb
# n -> p -> 2 -> 回车 -> +4G -> t -> 2 -> 82 -> w

# 2. 格式化为 swap
mkswap /dev/sdb2

# 3. 启用 swap
swapon /dev/sdb2

# 4. 查看 swap
swapon -s
free -h
```

### 使用文件作为 swap

```bash
# 1. 创建文件
dd if=/dev/zero of=/swapfile bs=1M count=2048

# 2. 设置权限
chmod 600 /swapfile

# 3. 格式化
mkswap /swapfile

# 4. 启用
swapon /swapfile

# 5. 开机自动启用
echo '/swapfile none swap defaults 0 0' >> /etc/fstab
```

### 关闭 swap

```bash
# 临时关闭
swapoff /dev/sdb2

# 永久关闭（注释 fstab 中的 swap 行）
vim /etc/fstab
# 注释掉 swap 行
```

## 八、实战案例

### 案例1：添加新数据盘

```bash
# 1. 查看新磁盘
lsblk

# 2. 分区
fdisk /dev/sdb
# n -> p -> 1 -> 回车 -> 回车 -> w

# 3. 格式化
mkfs.ext4 /dev/sdb1

# 4. 创建挂载点
mkdir /data

# 5. 挂载
mount /dev/sdb1 /data

# 6. 配置开机自动挂载
echo "UUID=$(blkid -s UUID -o value /dev/sdb1) /data ext4 defaults,noatime 0 2" >> /etc/fstab

# 7. 测试
mount -a
df -h
```

### 案例2：扩展根分区

```bash
# 假设根分区是 /dev/sda3

# 1. 扩展分区（使用 fdisk 删除并重建，起始扇区不变）
fdisk /dev/sda
# d -> 3 -> n -> p -> 3 -> 起始扇区（记住原来的） -> 回车 -> w

# 2. 刷新分区表
partprobe /dev/sda

# 3. 扩展文件系统
# ext4
resize2fs /dev/sda3

# xfs
xfs_growfs /
```

### 案例3：迁移数据到新磁盘

```bash
# 1. 准备新磁盘
fdisk /dev/sdb
mkfs.ext4 /dev/sdb1
mkdir /newdata
mount /dev/sdb1 /newdata

# 2. 同步数据
rsync -av /olddata/ /newdata/

# 3. 验证数据
diff -r /olddata /newdata

# 4. 切换挂载点
umount /olddata
umount /newdata
mount /dev/sdb1 /olddata

# 5. 更新 fstab
vim /etc/fstab
```

## 九、常见问题

### 1. 挂载失败

```bash
# 检查设备是否存在
lsblk

# 检查文件系统类型
blkid /dev/sdb1

# 检查挂载点是否存在
ls -ld /mnt

# 查看错误信息
dmesg | tail
```

### 2. 无法卸载

```bash
# 查看占用进程
lsof /mnt
fuser -m /mnt

# 杀死进程
fuser -k /mnt

# 强制卸载
umount -f /mnt
```

### 3. 文件系统损坏

```bash
# 卸载文件系统
umount /dev/sdb1

# 检查修复
fsck -y /dev/sdb1

# 如果无法修复，尝试恢复数据
testdisk /dev/sdb1
```
