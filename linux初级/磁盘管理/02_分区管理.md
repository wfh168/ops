# 分区管理

## 一、fdisk 分区工具（MBR）

### 基本用法

```bash
# 进入分区工具
fdisk /dev/sdb

# 常用命令
m    # 帮助
p    # 打印分区表
n    # 新建分区
d    # 删除分区
t    # 修改分区类型
w    # 保存并退出
q    # 不保存退出
```

### 创建分区实战

```bash
# 1. 进入 fdisk
fdisk /dev/sdb

# 2. 查看当前分区
Command (m for help): p

# 3. 创建新分区
Command (m for help): n
Partition type:
   p   primary (0 primary, 0 extended, 4 free)
   e   extended
Select (default p): p                    # 选择主分区
Partition number (1-4, default 1): 1     # 分区号
First sector: (直接回车，使用默认)
Last sector: +10G                        # 大小 10G

# 4. 保存退出
Command (m for help): w
```

### 删除分区

```bash
fdisk /dev/sdb

# 删除分区
Command (m for help): d
Partition number (1-4): 1

# 保存
Command (m for help): w
```

### 修改分区类型

```bash
fdisk /dev/sdb

# 修改类型
Command (m for help): t
Partition number (1-4): 1
Hex code (type L to list all codes): 82  # 82 = Linux swap

# 常用类型代码
# 83 = Linux
# 82 = Linux swap
# 8e = Linux LVM
```

## 三、parted 分区工具（通用）

### 基本用法

```bash
# 交互模式
parted /dev/sdb

# 命令模式
parted /dev/sdb print
parted /dev/sdb mkpart primary 0% 10GB
```

### 创建分区

```bash
# 1. 创建 GPT 分区表
parted /dev/sdb mklabel gpt

# 2. 创建分区
parted /dev/sdb mkpart primary 0% 10GB
parted /dev/sdb mkpart primary 10GB 20GB

# 3. 查看分区
parted /dev/sdb print
```

### 删除分区

```bash
# 删除分区1
parted /dev/sdb rm 1
```

### 调整分区大小

```bash
# 扩展分区（需要先卸载）
parted /dev/sdb resizepart 1 20GB
```

## 四、分区实战案例

### 案例1：添加新磁盘并分区

```bash
# 1. 查看新磁盘
lsblk
fdisk -l

# 2. 创建分区（假设新磁盘是 /dev/sdb）
fdisk /dev/sdb
# n -> p -> 1 -> 回车 -> +50G -> w

# 3. 刷新分区表
partprobe /dev/sdb

# 4. 查看结果
lsblk
```

### 案例2：创建多个分区

```bash
# 创建3个分区
fdisk /dev/sdb

# 分区1: 10G
n -> p -> 1 -> 回车 -> +10G

# 分区2: 20G
n -> p -> 2 -> 回车 -> +20G

# 分区3: 剩余空间
n -> p -> 3 -> 回车 -> 回车

# 保存
w
```

### 案例3：创建扩展分区和逻辑分区

```bash
fdisk /dev/sdb

# 创建3个主分区
n -> p -> 1 -> 回车 -> +10G
n -> p -> 2 -> 回车 -> +10G
n -> p -> 3 -> 回车 -> +10G

# 创建扩展分区（使用剩余空间）
n -> e -> 4 -> 回车 -> 回车

# 创建逻辑分区
n -> l -> 回车 -> +5G
n -> l -> 回车 -> +5G

# 保存
w
```

## 五、分区表刷新

### partprobe 刷新

```bash
# 刷新分区表
partprobe /dev/sdb

# 或重新读取分区表
partprobe -s /dev/sdb
```

### 手动刷新

```bash
# 如果 partprobe 不生效
echo 1 > /sys/block/sdb/device/rescan

# 或重启系统
reboot
```

## 六、分区对齐

### 为什么要对齐

- 提高性能
- 减少写入放大
- 延长 SSD 寿命

### 检查对齐

```bash
# 检查分区起始扇区
fdisk -l /dev/sdb

# 起始扇区应该是 2048 的倍数（1MB 对齐）
# 或 8 的倍数（4KB 对齐）
```

### 创建对齐的分区

```bash
# fdisk 默认会对齐
fdisk /dev/sdb
n -> p -> 1 -> 回车 -> +10G -> w

# parted 指定对齐
parted -a optimal /dev/sdb mkpart primary 0% 10GB
```

## 七、分区表备份与恢复

### 备份分区表

```bash
# 备份 MBR 分区表
dd if=/dev/sdb of=/backup/sdb_mbr.img bs=512 count=1

# 备份 GPT 分区表
sgdisk --backup=/backup/sdb_gpt.img /dev/sdb

# 使用 sfdisk 备份
sfdisk -d /dev/sdb > /backup/sdb_partition.txt
```

### 恢复分区表

```bash
# 恢复 MBR
dd if=/backup/sdb_mbr.img of=/dev/sdb bs=512 count=1

# 恢复 GPT
sgdisk --load-backup=/backup/sdb_gpt.img /dev/sdb

# 使用 sfdisk 恢复
sfdisk /dev/sdb < /backup/sdb_partition.txt
```

## 八、常见问题

### 1. 分区后看不到新分区

```bash
# 刷新分区表
partprobe /dev/sdb

# 或查看内核是否识别
cat /proc/partitions
```

### 2. 设备忙无法分区

```bash
# 查看谁在使用
lsof /dev/sdb
fuser -m /dev/sdb

# 卸载分区
umount /dev/sdb1

# 停止相关进程
fuser -k /dev/sdb
```

### 3. 分区表损坏

```bash
# 尝试修复
fsck /dev/sdb1

# 或使用 testdisk 恢复
yum install -y testdisk
testdisk /dev/sdb
```
