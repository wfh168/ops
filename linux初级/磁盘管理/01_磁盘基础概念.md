# 磁盘基础概念

## 磁盘类型

### 机械硬盘（HDD）
- 使用磁盘盘片存储数据
- 速度较慢（100-200 MB/s）
- 容量大，价格便宜
- 适合存储大量数据

### 固态硬盘（SSD）
- 使用闪存芯片存储数据
- 速度快（500-3500 MB/s）
- 容量相对较小，价格较贵
- 适合系统盘和数据库

### NVMe SSD
- 使用 PCIe 接口
- 速度极快（3000-7000 MB/s）
- 价格最贵
- 适合高性能需求

## 磁盘接口

| 接口 | 速度 | 设备名 | 说明 |
|------|------|--------|------|
| SATA | 600 MB/s | /dev/sda | 最常见 |
| SAS | 1200 MB/s | /dev/sda | 企业级 |
| NVMe | 3500+ MB/s | /dev/nvme0n1 | 高性能 |
| IDE | 133 MB/s | /dev/hda | 已淘汰 |

## 磁盘命名规则

### SATA/SAS 磁盘
```bash
/dev/sda        # 第一块磁盘
/dev/sda1       # 第一块磁盘的第一个分区
/dev/sda2       # 第一块磁盘的第二个分区
/dev/sdb        # 第二块磁盘
/dev/sdb1       # 第二块磁盘的第一个分区
```

### NVMe 磁盘
```bash
/dev/nvme0n1    # 第一块 NVMe 磁盘
/dev/nvme0n1p1  # 第一块 NVMe 磁盘的第一个分区
/dev/nvme0n1p2  # 第一块 NVMe 磁盘的第二个分区
/dev/nvme1n1    # 第二块 NVMe 磁盘
```

### 虚拟磁盘
```bash
/dev/vda        # 虚拟机第一块磁盘
/dev/vda1       # 虚拟机第一块磁盘的第一个分区
/dev/xvda       # Xen 虚拟机磁盘
```

## 磁盘分区

### 分区类型

#### MBR 分区（传统）
- 最多 4 个主分区
- 或 3 个主分区 + 1 个扩展分区
- 扩展分区可包含多个逻辑分区
- 最大支持 2TB 磁盘
- 使用 fdisk 工具

#### GPT 分区（现代）
- 最多 128 个分区
- 支持大于 2TB 的磁盘
- 更安全，有备份分区表
- 使用 gdisk 或 parted 工具

### 分区编号规则

```bash
# MBR 分区
/dev/sda1       # 主分区1
/dev/sda2       # 主分区2
/dev/sda3       # 主分区3
/dev/sda4       # 扩展分区
/dev/sda5       # 逻辑分区1（从5开始）
/dev/sda6       # 逻辑分区2

# GPT 分区
/dev/sda1       # 分区1
/dev/sda2       # 分区2
/dev/sda3       # 分区3
# ... 最多128个
```

## 文件系统

### 常见文件系统

| 文件系统 | 说明 | 适用场景 |
|---------|------|----------|
| ext4 | Linux 默认文件系统 | 通用 |
| xfs | 高性能文件系统 | 大文件、数据库 |
| btrfs | 新一代文件系统 | 快照、压缩 |
| ntfs | Windows 文件系统 | 跨平台 |
| vfat | FAT32 | U盘、兼容性 |
| swap | 交换分区 | 虚拟内存 |

### 文件系统特点

#### ext4
- 稳定可靠
- 支持大文件（16TB）
- 支持大分区（1EB）
- 日志功能

#### xfs
- 高性能
- 适合大文件
- 不支持缩小
- CentOS 7+ 默认

#### btrfs
- 写时复制（COW）
- 支持快照
- 支持压缩
- 仍在发展中

## 查看磁盘信息

### lsblk - 列出块设备

```bash
# 查看所有磁盘
lsblk

# 输出示例
NAME   MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
sda      8:0    0   50G  0 disk 
├─sda1   8:1    0    1G  0 part /boot
├─sda2   8:2    0    4G  0 part [SWAP]
└─sda3   8:3    0   45G  0 part /
sdb      8:16   0  100G  0 disk 
```

### fdisk -l - 查看分区表

```bash
# 查看所有磁盘
fdisk -l

# 查看指定磁盘
fdisk -l /dev/sda
```

### df - 查看磁盘使用

```bash
# 查看磁盘使用
df -h

# 输出示例
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda3        45G   10G   33G  24% /
/dev/sda1       976M  128M  782M  15% /boot
```

### du - 查看目录大小

```bash
# 查看目录大小
du -sh /var

# 查看一级子目录
du -h --max-depth=1 /var

# 排序显示
du -sh /* | sort -h
```

## 磁盘性能测试

### dd 测试

```bash
# 测试写入速度
dd if=/dev/zero of=/tmp/test bs=1M count=1024
# 1024+0 records in
# 1024+0 records out
# 1073741824 bytes (1.1 GB) copied, 5.2 s, 207 MB/s

# 测试读取速度
dd if=/tmp/test of=/dev/null bs=1M
```

### hdparm 测试

```bash
# 安装
yum install -y hdparm

# 测试读取速度
hdparm -t /dev/sda
# /dev/sda:
#  Timing buffered disk reads: 600 MB in  3.00 seconds = 200.00 MB/sec
```

### iostat 监控

```bash
# 安装
yum install -y sysstat

# 查看 I/O 统计
iostat -x 1
```

## 磁盘健康检查

### smartctl 检查

```bash
# 安装
yum install -y smartmontools

# 查看磁盘健康状态
smartctl -H /dev/sda

# 查看详细信息
smartctl -a /dev/sda

# 运行测试
smartctl -t short /dev/sda    # 短测试
smartctl -t long /dev/sda     # 长测试
```

## 练习题

1. 如何查看系统中所有的磁盘和分区？
2. MBR 和 GPT 分区的主要区别是什么？
3. ext4 和 xfs 文件系统有什么区别？

<details>
<summary>答案</summary>

1. `lsblk` 或 `fdisk -l`
2. MBR 最多4个主分区，最大支持2TB；GPT 最多128个分区，支持大于2TB的磁盘
3. ext4 更稳定通用，xfs 性能更好适合大文件，但 xfs 不支持缩小分区

</details>
